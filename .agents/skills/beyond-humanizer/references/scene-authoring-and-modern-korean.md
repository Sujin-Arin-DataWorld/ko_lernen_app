# 장면 저작과 현대 한국어

## 1. Scene Lock

AUTHOR 계열은 빈칸 문장부터 만들지 않는다. 먼저 실제 상호작용을 잠근다.

```text
SCENE             어디서 무슨 일이 벌어지는가
CHANNEL           face-to-face | phone | private-chat | group-chat | public-post | notice
PURPOSE           설명 | 부탁 | 거절 | 제안 | 이견 | 사과 | 확인 | 보고 | 성찰
SPEAKER/ADDRESSEE 역할; 이름·성별은 주어진 경우만
RELATIONSHIP      직장 동료 | 상하 관계 | 친구 | 가족 | 서비스 | 낯선 사람 | 공개 청중
POWER/FAMILIARITY equal/asymmetric/unknown; close/familiar/distant/unknown
SPEECH_STYLE      banmal | haeyo | hamnida | mixed/negotiated | unresolved
EMOTION           source-specified | context-supported | unresolved
CEFR/PEDAGOGY     수행 기능; 목표 표현·문법; 과제 유형
AUTHORITY         canonical | editable | generated | unknown
```

관계, 권력, 채널 중 하나가 종결형이나 호칭을 바꿀 수 있는데 값이 없으면 자연스러운 한 안을 사실처럼 고정하지 않는다. 조건부 안을 주거나 데이터 작업에서는 `FLAG`한다.

## 2. 2026 현대 한국어 기본값

현대성은 신조어, 줄임말, 필러의 양이 아니다. **관계에 맞는 거리, 자연스러운 반응 순서, 필요한 만큼의 완곡성**으로 판정한다.

| 장면 | 기본 후보 | 주의 |
|---|---|---|
| 동등한 직장 동료의 상호 대화 | 해요체 | 보고서·발표 장면이면 합니다체 가능 |
| 처음 만난 서비스 관계·낯선 사람 | 해요체 | `-시-`, 호칭, 요청 부담은 별도 축 |
| 공적 발표·공식 보고·공지 | 합니다체 | 공개라는 이유만으로 모든 대화를 합니다체로 바꾸지 않음 |
| 가까운 친구의 사적 대화 | 반말 | 친밀도가 확정되지 않으면 사용하지 않음 |
| 가족 | 관계별 판단 | 나이만으로 말투를 단정하지 않음 |
| 온라인 | 청중·플랫폼·공개성별 판단 | 사적 채팅과 공개 댓글을 같은 말투로 처리하지 않음 |

해요체는 무조건 중립이 아니다. `-줄래요?`, `-주실래요?`, `-줄 수 있어요?`, `-주실 수 있을까요?`는 친밀도·높임·부담을 다르게 조절한다.

## 3. 담화 기능이 있는 표현만 쓴다

다음 표현은 금지어도 현대어 장식도 아니다.

- `그냥`: 대안을 더 따지지 않음, 최소화, 회피 등 실제 기능이 있을 때
- `일단`: 임시 순서나 후속 단계가 있을 때
- `좀`: 부담 완화, 정도 축소, 부정적 평가 완화 중 하나가 작동할 때
- `괜히`: 불필요한 결과에 대한 화자의 평가가 장면에 있을 때
- `-것 같아요`: 추론·불확실성·관계 완화가 필요할 때
- `-지 않을까요`: 공동 판단을 열거나 제안 강도를 낮출 때

삭제해도 상호작용 효과가 전혀 달라지지 않으면 군더더기일 가능성을 감사한다. 반대로 모두 삭제해 명령조나 단정조가 되면 자연화가 아니다.

## 4. 교과서 냄새 감사

다음 신호가 둘 이상이면 장면을 다시 쓴다.

- 상대 발화, 이유, 위험, 시간 압박이 없이 자기 생각만 완결함
- `내가 오래 지키고 싶은 기준은…`처럼 제목을 문장으로 읽음
- 실제 대화에서 잘 쓰지 않는 정의·명사화로 시작함
- 누구에게 왜 말하는지 없어 어떤 종결형도 붙일 수 있음
- 현판·속담·문화어를 뜻풀이를 위해 대사에 직접 넣음

수정 순서:

```text
상대의 직전 발화 → 학습자가 해야 할 관계 행동 → KO 정본 → 허용 변형 → 성찰
```

예를 들어 `백세청풍`은 직장 대사에 넣지 않는다. 동료가 “그냥 넘어가자”고 할 때 사실대로 알리자는 선택을 말하게 하고, 뒤의 문화 성찰에서 그 선택과 현판의 가치를 연결한다. `탁청재`도 친구에게 현판 이름을 말하게 하지 않고, 감정이 센 답장을 잠시 미루는 행동으로 연결한다.

## 5. 자연스러운 장면 흐름

좋은 학습 장면은 최소한 다음을 제공한다.

1. 상대 발화가 응답할 이유를 만든다.
2. 학습자 발화가 실제 화행 하나를 완수한다.
3. 후속 발화나 성찰이 선택의 결과를 보여 준다.
4. CEFR가 낮아도 부자연스러운 조각 문장으로 단순화하지 않는다.

예:

```text
동료: 이 정도는 그냥 넘어가도 되지 않을까요?
KO: 그냥 넘기기에는 나중에 더 커질 수도 있을 것 같아요. 지금 공유하는 게 낫지 않을까요?
```

```text
친구: 왜 답이 없어? 화났어?
KO: 지금 답하면 내가 너무 감정적으로 말할 것 같아서. 조금만 생각하고 연락할게.
```

이 예문은 유일 정답이 아니다. 장면과 화행을 보존하는 자연스러운 범위를 과제별 변형 계약으로 표시한다.

친구 장면의 허용 변형에는 다음처럼 말하는 방식의 위험을 달리 표현한 문장을 넣을 수 있다.

```text
지금 답하면 내가 말을 너무 막 할 것 같아서. 조금만 생각하고 연락할게.
그냥 답하면 말이 너무 세게 나갈 것 같아서. 조금 있다가 연락할게.
```

표기는 `막할 것`이 아니라 `막 할 것`이다. `말이 너무 감정적일 것 같아서`도 이해되지만, 사람의 말하기 방식을 나타낼 때는 `내가 너무 감정적으로 말할 것 같아서`나 `말이 너무 감정적으로 나올 것 같아서`가 더 자연스럽다. 이 표현들은 답장의 어조가 감정적으로 흐를 위험을 말할 뿐, 화자가 실제로 화났다는 사실까지 확정하지 않는다.

## 6. 직장 요청은 관계와 지시대상을 함께 잠근다

`자료`는 조직의 위계가 아니라 대화에서 가리키는 업무 산출물이다. 실제 지시대상이 주어졌다면 뭉뚱그리지 않는다.

| 지시대상 | 한국어 후보 | EN 후보 | de-DE 후보 |
|---|---|---|---|
| 첨부하거나 공유한 파일 | 첨부해 드린 파일, 아까 공유한 파일 | attached/shared file | angehängte/geteilte Datei |
| 보고서 | 보내 드린 보고서 | report | Bericht |
| 참고용 자료 | 참고자료 | reference material | Informationsmaterial/Unterlagen |
| 표·수치 데이터 | 데이터, 수치 자료 | data, figures | Daten, Zahlen |
| 문맥상 미확정 | 자료 + `FLAG` 또는 조건부 명사 | material(s) + unresolved note | Unterlagen/Materialien + unresolved note |

`확인`은 수신·내용·상태를 확인하거나 가볍게 살펴보는 범위가 넓고, `검토`는 내용 판단이나 피드백을 기대하는 더 실질적인 review에 가깝다. 두 동사를 격식 차이만으로 바꾸지 않는다.

관계가 달라지면 같은 요청도 다음처럼 달라질 수 있다.

```text
상사에게: 보내 드린 보고서 검토 부탁드립니다.
동료에게: 아까 공유한 파일 한번 확인해 주세요.
외부 관계자에게: 첨부해 드린 자료 확인 부탁드립니다.
공식 브리핑에서: 배포해 드린 자료 확인 부탁드리겠습니다.
```

마지막 문장은 실제로 자료를 배포했다는 장면에서 쓰는 발표·안내형이다. `자료 확인 부탁드리겠습니다`는 가능한 격식형이지만 모든 일대일 업무 요청의 자동 상향 표현은 아니다. 중립적인 정중 요청에는 `자료 확인 부탁드립니다`가 흔히 더 간결하다. 상사·동료·외부 관계자라는 이름만으로 고정하지 말고 채널, 요청 부담, 피드백 필요 여부, 이미 보냈는지를 Scene Lock에 기록한다.

## 7. 가족의 문 잠그기 요청은 FORCE와 PRESUP을 구분한다

```text
가까운 동등 관계의 부탁: 나갈 때 문 꼭 잠가 줘.
이미 공유된 규칙을 상기: 나갈 때 문 잠그는 거 잊으면 안 되는 거 알지?
준수를 재확인하는 단호한 부탁: 나갈 때 문 꼭 잠그고 나가 줘. 알겠지?
높임이 필요한 관계: 나가실 때 문 꼭 잠가 주세요.
```

`-아/어 줘`는 부탁으로 구성하지만 그 자체가 항상 부드럽다는 뜻은 아니다. `알지?`는 상대도 이미 아는 규칙이라는 전제를 더하고, `알겠지?`는 응답과 준수를 요구해 압박이 커질 수 있다. 따라서 두 형태를 `잊지 마`의 보편적인 순화형으로 자동 교체하지 않는다. 표준 활용은 `잠그다 → 잠가`이며 정본에는 `잠궈`를 쓰지 않는다.

## 8. EN·DE 독립 현지화

KO 정본에서 PIVOT을 잠근 뒤 EN과 DE를 각각 만든다.

- 영어: 국제적으로 자연스러운 현대 영어. 한국어 완곡형을 hedge 개수로 복제하지 말고 선택권·부담을 보존한다.
- 독일어: 기본 `de-DE`. `du/Sie`는 한국어 말끝 치환이 아니라 관계·권력·채널로 정한다.
- 한 목표어에서 생긴 추가 의미를 다른 목표어로 전파하지 않는다.
- 세 언어의 문장 수와 어순이 달라도 같은 사건·화행·관계면 허용한다.

## 9. 완료 조건

- KO가 단독으로 실제 장면에서 자연스럽다.
- 말끝, 호칭, 완곡성이 잠근 관계와 맞다.
- EN/DE가 KO의 번역투가 아니라 각 언어의 정상적인 담화다.
- 문화어는 행동과 성찰을 연결하고 대사를 점유하지 않는다.
- unresolved 관계·감정·절차를 문장이 몰래 확정하지 않는다.
