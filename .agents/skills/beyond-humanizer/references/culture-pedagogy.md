# 문화 중개와 교육 문항

## 문화 항목

문화 번역은 `낯선 단어 삭제`와 `백과사전식 설명` 사이의 선택이 아니다.

1. 무엇이 학습 목표인지 정한다: 개념, 행동, 관계, 화행, 어휘.
2. 본문에서 보존할지, 기능상 대응으로 바꿀지, 짧은 문화 노트로 분리할지 고른다.
3. 설명은 이 장면을 이해하는 데 필요한 만큼만 쓴다.
4. 문화 규범을 절대적·고정된 국민성으로 말하지 않는다.

문화 노트는 다음 세 칸으로 제한한다.

```text
IN_THIS_SCENE   이 발화가 지금 수행하는 기능
RANGE           관계·세대·지역·장르에 따라 달라질 수 있는 범위
LEARNER_ACTION  학습자가 관찰하거나 선택할 수 있는 실제 행동
```

`IN_THIS_SCENE`에서 관찰한 기능을 곧바로 “한국인은 항상”으로 확대하지 않는다. `RANGE`는 모든 변이를 나열하는 면책 문구가 아니라 이 학습 장면의 경계를 밝힌다. `LEARNER_ACTION`은 성격 모방이 아니라 호칭·말끝·응답·설명 전략처럼 실행 가능한 선택이어야 한다.

예:

- `세배`: 문화 항목이면 없애지 않는다. A2 본문에서는 “traditional New Year's bow / traditioneller Neujahrsgruß mit tiefer Verbeugung” 정도로 최소 중개하고, 세부는 노트로 분리한다.
- `정이 들다`: love/friendship 한 단어로 고정하지 않는다. 함께한 시간 속에서 애착과 친밀감이 자라는 사건을 자연스럽게 재구성한다.
- `맞장구를 치다`: agree와 같지 않다. 듣는 동안 보이는 호응 행동과 관계 효과를 장면에 맞게 표현한다.
- `눈치를 보다`: 타인의 반응·분위기를 살피는 기능을 먼저 정한다. 소심함이나 부정적 국민성으로 자동 평가하지 않는다.
- `말을 놓다`: 단순히 `use du`가 아니다. 한국어 speech style 전환과 관계 협상을 설명한다.
- `밥 먹었어요?`: 실제 식사 확인일 수도, 익숙한 관계에서 안부·돌봄을 보이는 질문일 수도 있다. 장면 근거 없이 “한국식 hello”로 보편화하지 않는다.

## CEFR

CEFR는 희귀 어휘의 사다리가 아니라 수행 가능한 의사소통 활동의 범위다.

| 범위 | 한글소리 기준 |
|---|---|
| A1–A2 | 구체적 장면, 주요 부담 1개, 실제 사용할 짧은 발화 |
| B1–B2 | 원인·결과·비교·조건, 직장·미디어·사회 장면의 명확한 관계 |
| C1–C2 | 관점 조절, 제도적 인과, 책임·권한·근거·함축의 정교한 통제 |

- 쉬운 레벨을 위해 부자연스러운 한국어를 만들지 않는다.
- 높은 레벨을 위해 행정명사·희귀 한자어·법률체를 무작정 추가하지 않는다.
- mediation과 plurilingual/pluricultural competence를 반영해, 학습자가 의미와 문화를 다른 사람에게 설명하고 관계를 조정하는 과제를 포함할 수 있다.

## Pedagogical Target Lock

문장을 자연스럽게 고치기 전에 다음을 고정한다.

```text
target expression / grammar
communicative function
required surface form
accepted variants
what evidence makes the answer correct
```

target이 `맞장구`인데 문장을 `잘 들었어요`로 바꾸면 자연스럽더라도 문항은 실패다. target을 살린 자연스러운 장면으로 다시 쓴다.

## Cloze

모든 선택지를 실제 빈칸에 넣어 본다.

1. 문법적으로 완성되는가?
2. 장면상 자연스러운 다른 정답이 되는가?
3. 정답과 같은 형태 범주·난이도인가?
4. 길이·조사·깨진 문자열만으로 답이 드러나는가?

통과 조건:

- 정답 가능한 선택지는 정확히 하나다.
- 오답은 형태상 그럴듯하지만 주어진 문맥에서는 틀리다.
- `대화/미소/안부를 치다`처럼 동사 결합 자체가 깨져 형태만 보고 지우는 오답 세트는 고품질 문항이 아니다.
- `농담/박수를 치다`처럼 다른 자연스러운 장면을 만드는 선택지도 부적합하다.
- 필요한 경우 distractor만 바꾸기보다 문장에 의미 단서를 강화한다.

## Satz·번역 prompt

- `targetKo`, `promptDe`, `promptEn`은 같은 발화 목적과 정보를 가진다.
- 한국어 어순을 그대로 따라 목표어를 부자연스럽게 만들지 않는다.
- 반대로 prompt를 자연화하면서 목표 문법을 추론할 단서를 지우지 않는다.
- distractor는 사용되지 않은 한국어 어절이어야 하고, 정답 문장과 조립 계약을 깨지 않는다.

## 시나리오

- 각 turn의 화자, 청자, 관계, 의도, speech style을 연속해서 본다.
- 한국어 높임 변화가 관계 변화인지 실수인지 판정한다.
- 문화 노트가 대사를 대신하지 않게 한다.
- 역할·기관·절차는 scenario metadata나 대사에 있을 때만 구체화한다.
- 실제 한국어 화자 검수 전에는 “원어민 검증 완료”라고 표시하지 않는다.
