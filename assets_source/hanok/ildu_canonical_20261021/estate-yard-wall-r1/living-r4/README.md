# 일두고택 전체 흙마당 R4

사용자 지적: 밭은 좋지만 전체 마당은 자연스러운 흙처럼 보이지 않는다.

## 원인과 변경

현재 장면의 가시 흙바닥 두 객체에는 R3 재질이 연결되어 있었다. 북쪽 넓은 빈 마당도 ray cast로 같은 재질임을 확인했다. 누락된 재질 연결보다 화면에서 사라지는 미세 입자, 넓은 면의 비슷한 밀도, 독립적으로 보이는 두 쓸림 패치가 문제다.

R4는 중간 크기 연속 흙기질과 장소별 다짐/응집 밀도를 사용한다. 전면 마당·중앙 통로·북쪽 빈 마당·측면의 통계가 부드럽게 이어지도록 한다. 큰 갈색 구름, 균일 자갈, 셀 경계, 검은 접점 띠, 반복 쓸림 무늬는 피한다. 기존 R3 셰이더를 복사해 범위 밖 Surface에 그대로 연결한다.

밭 2개, 풀, R3 담장, 건축 형상·UV·변환·부재 배치·조명은 보존한다. `ground-scope.json`은 현재 담장 부재 bounds에 근거한 재질 범위이며 역사 실측 도면을 새로 주장하지 않는다.

## 재현과 검증

`run.py`는 R1 native SHA `586b8a5328e7c0deaeff5f340639708c927ea224a429aca70dc313adadddff68`에 R3 library SHA `f7bbe968db527719cc160d4bb403b5f1dbd262a0d7b49a307982025968e3012a`를 재구성하고 흙 2개 슬롯만 교체한다.

`blender -b <R1 native> -t 8 --python-exit-code 1 --python <living-r4/run.py> -- render full`

검증 완료한 R4 라이브러리의 후속 시점 렌더는 `-- apply render overview detail`로 재구성한다. A는 동일 카메라·조명·해상도·샘플·seed의 R3 최종 B를 SHA 검사 후 재사용한다. full부터 실제1280px/477px 검수하고, 근접 질감만으로 전체 자연스러움 성공을 주장하지 않는다.
