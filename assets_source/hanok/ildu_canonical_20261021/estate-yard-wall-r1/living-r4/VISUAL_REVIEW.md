# R4 실제 렌더 검수

## 이전 결과의 문제

- R3: 미세 입자와 두 쓸림 패치 개선이 전체 마당 자연스러움을 증명하지 못했다. 큰 마당의 비슷한 색·밀도가 인공적으로 보였다.
- `first-visible-trial/`: 전체 흙결 차이는 보이지만 북쪽 마당에 등방성 얼룩이 고르게 깔려 노이즈 카펫처럼 보였다. 아트디렉터 미통과.
- `second-visible-consolidated/`: 넓은 다짐면과 편측 잔류 결로 전체 1280px/477px 제한 개선 검수는 통과했다. 하지만 root의 실제 detail 검수에서 작은 입자가 너무 약해 부드러운 천처럼 보이는 문제가 확인됐다. 이 라이브러리 SHA는 `64b43f9e4370103c2ab1be00c8b132985d949fede1428fa41ad3524ba9c00cf3`이며 최종본으로 전달하지 않는다.

## 마지막 보정

큰 분포·다짐 범위·팔레트를 유지하면서 기존 fine Noise42의 색 대비와 Normal만 보강한다. 새 패턴·밭 재질·담장·건축은 바꾸지 않는다. 첫 시도부터 강했던 미세 자갈 사진이나 셀 색을 다시 적용하는 작업이 아니다.

최종 같은 카메라 full/overview/detail A/B 6장과 실제 브라우저 검수가 완료됐다. 최종 library SHA `5be498fbf7f8d95011610c4c380fa6efb23ecf3b042907cab6d184d6959ec9de`. `package-verification.json`과 `browser-qa.json`이 통과했다. Blender 실행은 exit0으로 정상 종료했다.

root와 흙 디자이너가 실제 최종 detail 1280px를 확인했다. 이전의 부드러운 천 같은 면보다 고운 모래성 입자가 읽히며 큰 자갈·검흰 점·셀 경계는 아니다. 실제 전체477px에서는 미세 입자가 표면 마감으로 합쳐지고, 큰 다짐과 잔류 거친 구역의 분포 및 건축 위계는 유지된다. 전체 분포 검수의 근거와 최종 미세 입자 검수의 근거를 구분한다.

브라우저는 실제610×668 viewport에서 이미지477px, 가로 넘침 없음, 모든 버튼48px로 확인했다. 3시점 이미지 로딩, A0/B100, range Home+ArrowRight=1 조작을 확인하고 고택 전체 B100으로 복원했다. 화면 근거는 `browser-final.png`다.

## 판정 범위

일러스트 마당의 재료감·다짐 분포를 개선하는 로컬 후보로 평가한다. 역사적 발자국·정확한 과거 흙 상태·현장 사진 수준의 사실성·실제 앱 적용·사용자 승인을 주장하지 않는다. 북쪽 상단과 우측에 남는 약한 절차적 얼룩감, 원경에서 미세한 좁은 통로 차이는 별도 한계로 남긴다.
