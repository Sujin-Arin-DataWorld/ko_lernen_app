# Palette-preserving painterliness decision

Current user clarification: warmth means affection from deliberate hand brushwork and coherent material expression, not a yellow/brown color shift. The R3 temperature-glaze branch is withdrawn. The two-defect checkpoint is preserved.

Root initial position before council feedback: keep the native source and palette, organize the existing paint textures into a common coarse/medium/fine stroke hierarchy and controlled diffuse shading. A new style image that changes architecture or a global painterly blur is inappropriate. Preview one actual facade section first.

Reasons: source silhouette/plaques must remain exact; additional raw texture detail already failed; visible intentional paint decisions across materials matter more than physically noisy roughness. Risk: procedural stroke fields can become another layer of stains, and simplified shading can turn the house into a cel-shaded game asset.
