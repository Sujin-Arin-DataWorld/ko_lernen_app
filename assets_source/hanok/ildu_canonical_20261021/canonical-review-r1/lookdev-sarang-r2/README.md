# 사랑채 손그림 재질 후보 R2

사용자 요청: 건축 형상·외관·구조·디테일을 고정하고, 목재·기와·돌·회벽·창호지와 작은 부재까지 따뜻한 손그림 재료감으로 표현한다.

## 현재 산출물과 범위

- `index.html`: 같은 카메라·조명의 직전 시안/새 후보 경계 비교. 전체, 목재, 서까래·창살, 벽·창호, 돌, 기와, 현판 정면.
- `render_handpainted.py`: 기존 R1 native에서 복사한 재질만 변경하는 재현 스크립트.
- `textures/`: imagegen으로 생성한 손그림 표현의 목재와 광물·종이 텍스처. 사람 작가가 직접 제작한 원화라고 주장하지 않는다. 정확한 프롬프트는 `PROMPTS.md`.
- `sarang-handpaint-candidate.blend`: 생성 텍스처를 포함해 저장한 독립 후보. 원본 native와 승인된 세 문 모델을 덮어쓰지 않는다.
- 이 작업은 사랑채 한 동의 native 재질 시안이다. 새 재질을 360도 GLB·공정 화면·Flutter에 적용하거나 정본으로 승격하지 않았다.

## 조사에서 확인한 원인

1. R1은 주로 색조와 roughness floor만 조정해 붓결/안료 농담/표면 요철의 차이가 약했다.
2. 반복되는 원본 옹이와 균일한 색이 복제 판재처럼 보였다. 신규 손그림 색 신호와 고정된 부재별 농담을 주고 원본 옹이 강조를 낮췄다.
3. 둥근 서까래 끝면 4개 객체의 실제 UV는 `Craft end grain`이다. 옆면용 `Gye cared member grain v52`를 읽으면 단색이 된다. 원래 끝면 UV와 보존 원본의 16종 나이테 샘플을 연결한다.
4. 창살뿐 아니라 `rebated bead`, `lower moulding`, `rear paper rail`, `inner bevel bead` 등 작은 부재에도 폭에 맞는 별도 스케일이 필요하다.
5. 온돌 바닥 3개에는 UV가 없다. 기존 메시와 UV를 변경하지 않고 object 좌표로 종이 재질을 샘플한다.
6. 이번 사랑채 목록에는 독립 쇠장식 객체/재질명이 없다. `lock rail`은 목재다. 추정으로 금속 재질을 붙이거나 철물을 새로 만들지 않는다.

## 부재별 처리

- 기둥·보·도리·서까래 옆면·마루·판벽·난간: 길이 방향의 손그림 칠, 섬유결, 낮은 광택.
- 서까래 마구리: 실제 끝면 UV로 나이테와 얕은 절단면 결을 분리.
- 창살·문틀의 작은 테두리·몰딩: 작은 폭에 맞춘 붓결.
- 기와·용마루·막새: 먹회색 안료와 마른 점토 표면.
- 기단·계단·초석: 광물 색면과 얕은 도구 자국.
- 회벽: 겹쳐 바른 회와 미세한 붓자국.
- 창호지·온돌 바닥 종이: 따뜻한 섬유와 잔결. 기존 투명도 연결은 보존.
- 지붕 장식면: 원래 문양과 색을 유지하고 미세한 무광 표면만 추가.
- 현판 및 현판 보드 4개 객체: 원문·이미지·재질·UV 보존.

## 검증과 실패 시안

`verification.json`, `material-coverage.json`, `surface-mapping-audit.json`, `render-manifest.json`가 실제 완료 근거다. 렌더 후 native를 다시 열어 710개 메시의 형상·UV·변환·수정자·기록된 속성 및 보존 이미지 바이트를 대조한다.

`probe-weak-strokes/`는 붓결 차이가 약했던 시험, `probe-straight-strokes/`는 줄무늬가 과했던 시험이다. 사용자 승인 또는 최종 후보로 취급하지 않는다.

## 적용한 스킬 판단

- Superpowers verification-before-completion: 저장 전 메모리 상태뿐 아니라 저장한 native를 재개방해 보존 검사.
- frontend-ui-engineering: 키보드 가능한 비교 경계와 48px 이상 시점 버튼, 작은 화면에서 줄바꿈, 로딩 오류와 재시도.
- imagegen: 건축 이미지를 다시 생성하지 않고 재질용 비트맵만 생성해 실제 원본 부재에 소비. 파일을 프로젝트로 복사하고 native에도 pack.

상담 검수는 기존 디자이너 에이전트의 읽기 전용 이미지/710개 부재 목록 점검으로 진행했다. 형상 수정이나 승인 승계는 하지 않았다.
