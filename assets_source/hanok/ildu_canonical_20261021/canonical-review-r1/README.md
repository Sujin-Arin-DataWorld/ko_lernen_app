# 일두고택 제작 정본과 건설 공정 검토판

## 확정된 정본

사용자가 이 대화에서 명시적으로 지정한 **이 세션 제작 R6c 협문 두 개와 사당문**이 정본입니다.

| 대상 | 원본 | 공정 수 | 원본 메시 부재 |
|---|---|---:|---:|
| 사랑채 왼쪽 협문 | `../left-new.blend` | 6 | 680 |
| 안채 연결 협문 | `../right-new.blend` | 6 | 530 |
| 사당문 | `../shrine-new.blend` | 8 | 445 |

정확한 SHA-256과 사용자 지정 발언은 `../CANONICAL_PROMOTION.json`에 있습니다.
이전 R12 문 모델·예전 재제작 시안·생성 앱 목업은 이 세 문의 현재 정본이 아닙니다.
외관, 지붕선, 문창호, 디테일, 구조, 모양과 배치는 고정합니다. 향후 일러스트 표현은 재질·색상에만 적용합니다.

## 건물과 공정

검토판은 **11동 + 문 4곳 + 공유 담장/마당** 16항목입니다.
협문 두 곳의 공정 ID를 중복 계산하지 않으면 **154개 고유 공정**, 건물 인스턴스별로 보이는 단계는 **160개**입니다.

| 건물 | 단계 |
|---|---:|
| 사랑채 | 16 |
| 안사랑채 | 14 |
| 안채 | 14 |
| 사당 | 12 |
| 중문간채 | 12 |
| 아랫채 | 12 |
| 곳간채 | 11 |
| 안채곳간채 | 11 |
| 창고 | 8 |
| 북측 측간 | 9 |
| 남측 측간 | 9 |
| 대문 | 12 |
| 사랑채 왼쪽 협문 | 6 |
| 안채 연결 협문 | 6 |
| 사당문 | 8 |
| 담장·마당 | 공유 공간, 별도 보상 공정 없음 |

기존 건물은 기존 R12 부재·공정 연결을 유지합니다. 새 세 문만 이 세션의 정확한 부재 배정으로 교체했습니다.
빈 단계나 신규 형상이 없는 단계도 실제 기존 공정 목록에서 삭제하지 않습니다.
공정 시각화는 조립을 설명하는 해석이며 실제 역사적 시공 순서 전체의 증명은 아닙니다.
기존 `construction/verification.json`의 과거 `userApproved: false`는 작성 당시 검수 기록입니다.
현재 정본 지정은 최신 `CANONICAL_PROMOTION.json`이 우선하며 과거 검증 기록을 소급 수정하지 않습니다.

## 사용

HTTP 서버에서 `index.html`을 엽니다. 왼쪽 목록 또는 모바일 건물 선택 → 공정 선택 → 드래그 회전/휠·두 손가락 확대.
정면·배면·좌우·위·처마 프리셋, 90도 회전, 확대/축소, 처음 구도, 키보드 방향키/+/−/Home을 제공합니다.
사랑채와 중문간채는 기존 단독 완성 지붕과 단지 연결형을 구분합니다.
단독 완성형에서 이전 공정을 고르면 원래 연결형 공정 모델로 돌아갑니다.

**새 세 문은 승인된 Blender 원본의 실제 재질을 베이크한 컬러 3D입니다.**
Base Color·Normal·Roughness/Metallic·Specular를 포함하며, 6/6/8단계에서 같은 부재·재질·좌표를 공유합니다.
회색 구조용 GLB를 현재 세 문의 최종 표시로 연결하지 않습니다. 색을 새로 추측해 칠하지 않았습니다.
사당문의 얇은 태극 칠 두 부재는 연속 UV로 별도 베이크하여 작은 삼각형 경계의 격자 자국을 제거했습니다.
정점·인덱스·노멀·변환과 공정 배정은 원래 베이크 모델과 바이트 단위로 대조했습니다.

**이번 일러스트 표현 표본은 사당문 1동입니다.** 상단 `표현`에서 일러스트 광원과 재질 확인광을 비교할 수 있습니다.
따뜻한 방향광, 열린 그늘, 절제된 반사와 실시간 접합 그림자로 원래 재료의 명암을 정리합니다.
승인 색과 원본 재질은 보존하며, 새로운 손그림 텍스처를 덧칠했다고 주장하지 않습니다.
완성본 그림자를 공정 텍스처에 구워 넣지 않아, 각 단계에 실제로 존재하는 부재만 그림자를 만듭니다.

다른 건물의 회전용 3D는 아직 구조 검토용 중성 재질입니다. 승인 색과 질감은 연결한 원본 렌더에서 확인합니다.
`construction-surface-policy.json`은 전체 건물의 승인 재질 출처와 후속 공정 변환 규칙을 기록합니다.
현재 대용량 원본 품질 GLB는 제작 검토용이며 모바일 용량·성능 최적화 및 기기 검증을 마친 앱 배포물이 아닙니다.
원본 렌더를 고르면 고정 시점임을 명시합니다. 이미지를 회전시켜 360도라고 표시하지 않습니다.

## 근거와 검증

- `package-verification.json`: 16개 GLB 및 이미지 의존성, 최신 문 원본 해시, 새 문 단계 extras의 정확한 대응.
- `browser-groups-qa.json`: 실제 브라우저에서 16항목과 160단계 순회, 단계별 메시 누적과 오류 검사.
- `browser-controls-qa.json`: 실제 카메라 90도 4회, 확대/축소 거리, 키보드 회전.
- `material-model-verification.json`: 세 문의 1,655부재 형상·노멀·변환 보존, 재질 포함, 단계 배정.
- `material-browser-qa.json`: 실제 컬러 3D의 20단계 순회, 재질/텍스처 동일성, 402/320px 가로 넘침 검사.
- `paint-uv-verification.json`: 태극 칠 2부재의 연속 UV 수정과 원본 보존.
- `PILOT_ART_DIRECTION.md`: 세 관점 디자인 검토와 이번 표본의 실제 적용 범위.
- `assembly-verification.json`: 전체 native 결합본이 보존 검사와 저장을 마친 경우 생성됩니다.
- `../surface-package-verification.json`: 최신 세 문 21장 렌더, 도면 선택 검사 65개, 원본 해시와 기준 형상.
- 조작 구현은 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html), 자원 수명은 [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) 공식 문서를 확인했습니다.

기존 사용자 승인 근거, 현재 정본 지정, 앱 통합, 실제 기기, 배포는 각각 별개 상태입니다.
현재 작업은 제작 정본 보존·검토판·커밋이며 학습 자격·보상·서비스 상태나 앱 화면을 변경하지 않습니다.
