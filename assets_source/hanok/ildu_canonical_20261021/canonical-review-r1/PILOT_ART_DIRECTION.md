# 사당문 8단계 실제 3D 표본 — 초기 아트 판단

## 고정 기준

현재 사용자는 이 세션에서 완성·승인한 협문 두 개와 사당문을 정본으로 지정했다.
회색 구조용 GLB는 요구한 최종 재질 표시가 아니며 현재 공개 결과를 교체해야 한다.
원본 외관·형상·구조·디테일·태극과 승인 색은 유지한다. 공정 1~8은 완성본과 같은 부재의 동일 베이크를 공유한다.
이번 일러스트 표현 시험은 사당문 한 동에 한정하며 다른 건물을 일괄 재작업하지 않는다.

## Architect 초기 판단 — 다른 목소리 읽기 전

승인 원본의 실제 Base Color·Normal·Roughness/Metallic·Specular를 먼저 충실하게 이전하고,
별도 표시 후보에서 따뜻하고 부드러운 광원과 절제된 반사로 일러스트 명암을 조정한다.

1. 승인받은 재질의 출처와 원본 해시를 보존해야 신뢰를 회복할 수 있다.
2. 같은 베이크/부재 좌표를 공유하면 공정 전환에서 결·색과 표면이 바뀌지 않는다.
3. 구조를 바꾸는 면 분할이나 균일 노이즈보다 실제 재료의 큰 색면·미세 결을 읽을 수 있는 광원이 먼저다.

가장 큰 위험은 UV·노멀·거칠기의 변환 결함을 스타일 문제로 오판하는 것이다.
실제 회전 화면과 원본 렌더를 먼저 대조하고 표시 후보는 원본과 분리해 비교한다.

## Council 결과 — 실제 이미지 확인 후

- Critic: 승인 원본 자체에 자연스러운 목재·기와·석재가 있다. 검은 AO나 통일된 거칠기보다 열린 그늘과 부드러운 방향광을 우선한다. 공정 그림자는 현재 부재만 따라야 한다.
- Pragmatist: 실제 PBR을 재사용하고 앱 크기에서 본다. 따뜻한 큰 명암, 작은 하이라이트, 절제된 미세 결이 적절하다. 종이 노이즈 하나를 얹는 것만으로는 부족하다.
- Skeptic: 충실한 재질 이전 자체는 일러스트 스타일을 증명하지 않는다. 참조 그림의 분위기는 주변 풍경과 구도에서도 나오므로 단독 문을 과도하게 노랗게 칠하지 않는다.

**채택 판단:** 세 문은 승인된 실제 재질을 정본으로 보존하고, 사당문 한 동에서 별도 광원 후보를 비교한다.
참조 이미지의 산·호랑이·주변 한옥이나 건축 비례를 이 모델의 권위로 사용하지 않는다.
스타일 표본은 따뜻한 방향광, 중간 밝기의 환경광, 차분한 보조광, 반경 3의 PCF 그림자를 적용했다.
전체 완성 형상의 카메라 범위·광원·노출을 공정 전체에서 고정한다. 단계마다 텍스처를 새로 생성하거나 확대하지 않는다.

**가장 강한 이견:** Skeptic의 지적대로 이 결과를 새로운 손그림 스타일 완성으로 부르지 않는다.
이번에는 원본 재질을 살린 일러스트 광원 표본까지 검증했다. 큰 색면을 새로 그리거나 종이결을 추가하는 별도 표면 작업은 아직 하지 않았다.

## 발견한 변환 결함과 수정

사당문 태극의 작은 삼각형 UV 섬 때문에 얇은 격자 자국이 생겼다. 노멀 강도와 카메라 깊이를 각각 바꿔도 자국이 남아 UV 표본을 조사했다.
칠 부재 2개를 1024px 연속 평면 UV에서 원본 셰이더로 다시 베이크하자 자국이 사라졌다.
원본 `.blend`를 저장하지 않았고, 최종 GLB의 POSITION/NORMAL/인덱스/노드 변환이 최초 베이크와 일치하는지 독립 검사했다.
형상 변경으로 재질 결함을 숨기지 않았다.

## 남은 구분

승인된 원본의 정본 지정, 실제 PBR 변환, 새 광원 후보의 사용자 승인, 전체 장면 접합 검수, 모바일 최적화·실기기는 별개다.
다른 11동 및 기존 대문을 컬러 공정 3D로 일괄 변환한 상태는 아니다.
