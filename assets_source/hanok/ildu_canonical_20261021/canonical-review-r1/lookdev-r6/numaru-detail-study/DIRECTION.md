# 누마루 한 구간: 이미지 텍스처 묘사

사용자 요청: 현재 좋아진 색감과 재료 대비를 기준으로, 기둥 하나 + 난간 한 칸 + 위쪽 기와 + 아래쪽 초석을 먼저 묘사한다. 건축 형상은 보존한다.

## 기준

- source: ../sarang-illustration-study/sarang-illustration-candidate.blend
- source SHA-256: a4b8ec30a1850356d9022487ba6f46f8977d0591cf8a013939159813db6da51f
- 일러스트 텍스처는 imagegen으로 제작하고 두 번째 결과를 채택했다. 첫 번째 결과의 과도한 미세 입자를 정리했다.
- 원본 UV의 길이 방향을 따라 목리를 배치하고, 부재별 고정된 좌표 차이로 같은 무늬의 반복을 줄였다.
- 첫 매핑에서 기둥의 줄무늬와 중간 경계가 드러나 재작업했다. 기둥은 기존 UV의 실측 범위로 아틀라스 안에 한 번만 배치한다. 나머지 부재는 연속적인 왕복 좌표로 경계의 색 단절을 방지한다.
- 하나의 아틀라스로부터 색·거칠기·얕은 범프 채널을 분리해 조절한다. 세 장을 각각 그린 방식은 아니다.
- 기둥·난간의 기존 색 계열, 기와의 회청색, 돌의 회색·황토색을 유지한다. 햇빛과 그림자는 기존 조명에서 나온다.
- 긴 난간 상부는 기존 좌표에 따른 영역 마스크로 제한한다. 메시 분할, 새 UV, 변형은 없다.

## 보존 검사

711개 메시의 형상·UV·변환, 부재 속성과 단계, 객체 속성, 조명, 원본 재질 그래프와 기존 이미지 바이트, 변경하지 않은 재질 슬롯을 저장 후 재개방하여 검사한다. verification.json이 실제 결과다.

## 비교

정면·사선·반대편·난간 확대의 이전/후보 8장. 같은 카메라와 조명, 24 samples, CPU 4 threads. render-manifest.json이 렌더 파일과 해시를 기록한다.

이번 결과는 누마루 구간의 재질 검토 시안이다. 사랑채 전체 확장, 정본 승격, 앱 적용은 포함하지 않는다.

## 사용자 추가 지시: 따뜻한 주황갈색

사용자가 첨부한 세 사진을 기준으로 짙은 갈색을 조금 밝고 따뜻하게 바꾼 별도 시안을 추가했다. 첫 사진의 절제된 따뜻함을 기본으로 삼고, 두 번째의 강한 꿀빛과 세 번째의 햇빛 영향을 과장하지 않는다. 사진 원본과 해시는 warm-references.json에 기록했다.

색 조정은 사랑채의 목재·창살·마구리 재질에만 적용한다. 최종 색에 linear RGB (1.36, 1.19, 1.02)를 곱하여 기존 결의 상대 명암을 유지한다. 기존 조명과 거칠기·범프, 비목재 재질 및 현판은 보존한다. 이 색 변형은 sarang-numaru-warm-detail.blend에 저장되어 기존 갈색 시안과 함께 남는다.

상세 묘사는 여전히 누마루 한 구간만 적용했다. 목재 색 조정과 상세 묘사의 적용 범위는 다르다. warm-verification.json과 warm-render-manifest.json이 따뜻한 색 시안의 별도 보존 검사와 렌더 근거다.

## 2026-10-23 재료 고증 연결

[건물별 재료 적용안](../building-craft-research-20261023/REPORT.md)을 다음 누마루 묘사에 연결한다. 사용자가 원하는 따뜻한 주황갈색은 표현 방향이며 확정 수종/원색 측정값이 아니다. 누마루 내부에서 기존 석가산을 보는 구도, 판벽 수장공간, 활주/돌기둥 받침, 종이 벽서와 목판 현판의 재료 차이를 검수한다. 기와 산지/전량 수제/창살 춘양목/눈곱재기창/들어열개 방식은 해당 부재 근거 없이 확정하거나 새로 만들지 않는다. 이번에는 조사 기준만 반영했으며 warm 렌더와 Blender 파일은 수정하지 않았다.
