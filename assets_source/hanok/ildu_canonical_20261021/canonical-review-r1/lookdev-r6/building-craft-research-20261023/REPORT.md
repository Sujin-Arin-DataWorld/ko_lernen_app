# 일두고택: 건물별 재료와 생활 흔적 적용안

조사·작업 기준 반영: 2026-10-23. **재질 제작 지침이며 새 렌더 완료나 정본 승격을 뜻하지 않는다.**

## 1. 이번에 정한 방향

사용자가 선택한 따뜻한 주황갈색 목재를 유지하면서, 부재의 제작법·마감·사용 위치에 따라 묘사를 다르게 한다. 넓은 중간 색면 → 형태를 설명하는 결 → 가까이에서 보이는 작은 흔적 순서다. 색을 밝히는 것만으로 끝내지 않고 목재·기와·종이·회벽·돌·쇠가 서로 다른 빛 반응을 갖게 한다.

기준은 현재 일두고택 모델과 실측도면이다. 현재 사진에 나타난 오래된 부재와 수리 흔적을 바탕으로 표현하되, 특정 조선 연도의 모습을 복원했다고 표시하지 않는다. 현대 사진의 색을 그대로 역사적 원색으로 취급하지 않는다.

### 근거의 구분

- **D / 직접 근거**: 일두고택 실측도면의 기입, 사진, 해당 장소의 현장 기록.
- **G / 일반 근거**: 전통 제작법·재료 연구. 일두고택 부재의 산지나 수종을 확정하지 못한다.
- **I / 표현 판단**: 따뜻한 색조, 선택적인 붓결, 비교 렌더의 조도 등 제작자가 정하는 시각적 해석.
- **U / 미확인**: 실제 위치·수종·교체 시기·문양이 확인되지 않은 주장. 형상 추가나 역사 설명의 확정 문장에 사용하지 않는다.

## 4. 재료를 묘사하는 실제 방법

### 목재

- 주조색은 사용자가 원한 절제된 주황갈색. 밝은 면은 꿀빛·황갈색, 중간 면은 따뜻한 갈색, 깊은 틈은 짙은 갈색으로 정리한다. 노출/조명과 재료 고유색은 분리한다.
- 기둥·보에는 길이 방향 결, 마루·판문에는 제재 면에 맞는 넓은 결, 마구리에는 끝결. 수종을 달리 지정하지 않아도 이 차이로 충분히 풍부해진다.
- 소나무·느티나무·참나무의 역사적 사용은 일반 연구로 확인할 수 있지만, 일두고택 각 부재의 수종은 별도 식별 자료가 필요하다. ‘힘 받는 곳=참나무’ 같은 자동 배정은 하지 않는다.[W1]
- 중문채 도면의 들기름 칠은 직접 근거다. 오래된 모든 목재가 동일한 기름 처리로 어두워지고 단단해졌다는 설명은 채택하지 않는다.

### 기와

- 건물별 기존 기와 곡률·열·겹침·막새·망와를 유지한다. 회흑색 중간 면에 기와 한 장 규모의 미약한 색 변화, 얕은 표면, 넓고 약한 반사를 더한다.
- 무작위 얼룩을 지붕 전체에 펼치지 않는다. 성형 흔적은 실제 흔적이 위치한 면에서만 표현한다. 포목흔을 모든 윗면에 도장처럼 찍지 않는다.
- 전통 제작법은 성형·건조·재임·소성 조건에 따라 차이가 난다. ‘70% 건조’와 고정된 가마 적재 순서를 보편 규칙으로 쓰지 않는다.[T1][T2]
- 회흑색의 원인과 물 흡수 성능은 별개다. 탄소 침착을 완전한 방수 코팅으로 묘사하지 않는다. 현재 일두고택 기와의 채토지·가마·교체 이력은 미확인이다.[T3]

### 창호지·벽서·회벽

- 창호지는 얇은 섬유의 낮은 대비와 빛의 산란을 표현한다. 역광에서 은은히 밝아지되 자체발광이나 유리처럼 투명한 재질을 쓰지 않는다.
- 회벽은 불투명하고 잔잔한 미장 면. 종이와 같은 얼룩 텍스처를 공유하지 않는다. ‘충효절의’는 종이 벽서로 알려져 있으므로 글자를 재생성하지 않고 기존 글씨 자산과 표면 분류를 점검한다.[S3]
- 사진 속 흰 기와 끝은 흰 유약·기와 속살·회반죽 중 무엇인지 확인 전 확대하지 않는다. 이미 확인된 회마감 면만 별도 재료로 유지한다.

### 돌·흙·쇠

- 기단의 다듬은 돌 면, 초석의 자연스러운 면, 계단 디딤면, 담장의 흙 줄눈을 별도 강도로 묘사한다. 같은 작은 노이즈를 공통으로 덮지 않는다.
- 부엌의 흙·그을음과 마당의 다진 흙을 구분한다. 그을음은 실제 연소 위치가 근거가 된다.
- 쇠고리·돌쩌귀·자물쇠는 작더라도 별도 반사/거칠기. 나무 결을 공유하지 않는다. 존재하는 철물을 ‘못 없는 한옥’이라는 설명 때문에 지우지 않는다.

## 5. 차경과 작은 창을 적용하는 범위

**바로 작업 기준에 넣는 것:** 누마루에서 기존 석가산과 소나무를 보는 검수 시점, 실내의 그늘과 창밖의 밝기 차이, 문틀·난간이 경치를 둘러싸는 구도. 실제 수목과 담장 위치를 사용한다.[S1][S3]

**확인 후 움직이는 것:** 해당 창의 경첩·들쇠·걸쇠와 원래 개폐 방식. ‘문을 열어 경치를 본다’는 근거만으로 들어열개 리그를 만들지 않는다. 이미 있는 개폐 기능은 보존한다.

**일두고택 형상에는 아직 추가하지 않는 것:** 눈곱재기창. AURI에서 확인되는 실제 전통 창호 용어지만, 이번 도면에서 확인한 작은 격자창과 동일한지는 확정하지 못했다. 누마루 창밖 지리산 천왕봉도 특정 조망 방향을 입증하기 전 배경으로 합성하지 않는다.[G1]

## 6. 추가로 찾아 반영한 항목

1. **빛과 관리의 차이**: 처마에 보호된 면, 손이 닿는 난간, 비에 노출된 판재를 분리하되 과도한 노후화를 피한다.
2. **공간별 창의 목적**: 방의 종이 창호, 부엌 판문, 곳간 환기창, 다락 창을 서로 다르게 다룬다. 정확한 대응은 실측 창호 부호를 따른다.
3. **글씨의 바탕 재료**: 종이 벽서와 목판 현판의 표면·반사 차이. 글자·배치·문양은 보호한다.
4. **사용과 접합의 흔적**: 문고리 주변, 문짝 뒷면, 문턱, 마루 끝면, 기둥-초석 경계. 긁힘의 양보다 위치가 중요하다.
5. **사당의 채색**: 사당의 단청은 별도 재료군으로 보존한다. ‘양반집은 무채색’이라는 일반 문장을 일괄 적용하지 않는다.[S4]
6. **정원·통로·배수**: 누마루-정원의 실제 관계, 헛담과 협문의 시선 차단, 기단 주변의 물 빠짐. 숯층 등 숨은 구조는 근거 확인 후 학습 설명/기존 공정 자료로 다룬다.[S4]
7. **현장 소품은 별도 검토**: 부엌문 위 엄나무가 현장기사에 기록돼 있으나, 현재 모델에 없는 소품을 이 재질 작업에서 자동 생성하지 않는다.[S3]

## 7. 제작 순서와 완료 판정

1. 누마루 한 구간에서 따뜻한 목재·기와·돌의 묘사 다듬기. 기존 색 후보를 비교 기준으로 유지.
2. 중문채 창호로 기름 마감·단면 종이·철물 차이를 검증.
3. 안채와 곳간을 대조해 종이 창호/판문/통풍 살이 구별되는지 검증.
4. 사당·대문·협문·나머지 부속채에 해당 기준 적용. 같은 재질을 모든 채에 일괄 덮지 않음.
5. 누마루 안쪽→정원, 개폐 전후, 처마 아래, 전체 및 402px 크기로 검수.

각 단계는 기존 geometry/UV/transform/memberId/reviewStage/개폐/글씨 보존 검사를 통과해야 한다. 새 재질은 색·거칠기·얕은 요철을 따로 조절하고 광원의 그림자를 색 지도에 굳히지 않는다. 장식·부재가 추가되어야만 가능한 제안은 재질 작업과 분리해 근거를 남긴다.

이번 조사 산출물은 `APPLICATION_MATRIX.json`의 건물별 작업 목록과 이 문서다. Blender 변경, 전체 건물 렌더, GLB 반영, Flutter 반영, 사용자 시각 승인 상태는 모두 별도이며 이번 조사로 완료 처리하지 않는다.
