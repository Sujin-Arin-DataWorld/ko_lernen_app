# 일두고택 R6: 사람이 다듬어 맞춘 한옥의 재료 표현

2026-10-23 사용자 첨부 7장과 최신 지시를 반영한 검토용 방향. 정본 승격 아님.

## 기준

안사랑채2.png와 안사랑채.png의 부재별 결, 창살의 면 구분, 기와의 겹침, 넓은 돌 면을 표현 기준으로 삼는다. 중문2.png와 마지막 중문 사선은 접합과 재료 대비의 참고다. 흙아궁이·우물은 흙/쇠/돌 표현의 참고이며 해당 소품을 건물에 추가하지 않는다. 참고 이미지의 건축 형태·균열·낡음·흰 기와 끝은 복제하지 않는다. 기존 일두고택의 형상·창살 패턴·배치·현판·채색 문양을 고정한다.

사용자가 원하는 것은 사람이 재료를 다듬어 한 채를 지은 느낌, 그리고 그 재료를 정성스럽게 그린 일러스트다. 전체를 갈색으로 보정하거나 균일한 노이즈를 늘리는 것을 성공으로 보지 않는다.

## 확인한 현재 결함

- R6 build_pilot.surface의 붓질은 원색에 0.87~1.13 계수를 곱한 뒤 wood15%, lattice8%, tile12%로 섞는다. 최대 변화는 각각 약1.95%,1.04%,1.56%에 불과하다. 재질 연결이 있어도 작은 부재에서 표현이 읽힌다는 뜻은 아니다.
- ansarang/r6-detail.png의 창살은 폭이 작아 결이 사라지고, 종이와 벽의 명도도 가까워 문 전체가 얇은 디지털 격자로 읽힌다. 큰 기둥·문틀의 결만 상대적으로 두드러진다.
- sarang/r6-eaves.png의 기와는 회색 얼룩이 넓게 연결되고 작은 기와 끝·모서리의 면 구분이 약하다. 마구리의 나이테는 보이나 밝고 규칙적인 원판이 반복되는 인상도 남는다.
- timber_unity는 누마루 판재 간 큰 색 차이를 개선했지만, 작은 부재의 그림 언어까지 해결하지는 않는다.

## 적용할 표현

건축 세밀화에 가까운 부재별 색면과 선택적인 붓질. 실제 결을 바탕으로 유지하면서 어두운 결, 조용한 중간 면, 끊긴 밝은 결을 독립적으로 조절한다. 큰 부재와 작은 부재에 같은 무늬 크기를 쓰지 않는다.

| 부분 | 작업 기준 | 실패 기준 |
|---|---|---|
| 기둥·보·도리 | 같은 목재 계열, 길이 방향 성장륜과 넓은 조용한 면 | 판재별 무작위 색 띠, 균일한 세로 줄무늬 |
| 문틀·창살·난간·몰딩 | 부재 폭에 맞는 짧고 가는 칠, 맞댄 모서리와 앞면 구분 | 확대해도 단색 플라스틱, 검은 외곽선 도배 |
| 판재·문짝·마루 | 판재별 결의 위치는 달라도 평균색은 가까움 | 옹이 도장 반복, 거친 무늬가 접합을 덮음 |
| 서까래·마구리·그 사이 판재 | 옆결/끝결 분리, 끝면 밝기를 목재군 안에 정돈 | 밝은 원판 반복, 구조와 무관한 나이테 |
| 기와·용마루·막새 | 기존 회색, 기와 한 장 규모의 칠, 겹침과 끝면 구분 | 지붕 전체 구름 얼룩, 돌같은 과한 입자 |
| 창호지 | 잔잔한 따뜻한 미색, 낮은 대비 섬유, 창살보다 조용함 | 회벽과 같은 얼룩, 자체발광·검은 빈칸 |
| 회벽·흙벽·줄눈 | 얇은 미장 면, 깨끗한 큰 면과 드문 손질 흔적 | 더러움·균열로 손맛 대체 |
| 기단·초석·계단 | 넓고 끊긴 광물 면, 잔입자 절제 | 모래/자갈 사진처럼 읽힘 |
| 쇠·채색·섬유·기타 | 원래 역할/승인색 유지, 작은 반사와 재료별 표면 | 전부 목재 붓결을 재사용 |

## 첫 시안 범위와 기술 판단

기존 승인 R6 방향을 구체화하는 별도 후보로 안사랑채 창호·기둥·기와·기단을 먼저 비교한다. 사랑채 처마와 누마루가 두 번째 확인 위치다. 현재 unity 원본은 보존한다. 여러 건물에 일괄 배포하는 작업은 이 디테일 비교가 안정될 때까지 중단한다.

기존 UV/부재 속성/원래 재질을 사용한다. 색·거칠기·노멀 노드만 조정하고 메시 변형, 새 부재, UV 재작성은 하지 않는다. 붓 마스크의 실제 분포를 확인해 선택적인 어두운/밝은 칠을 분리하며, 표면 고정 좌표를 사용한다. 기존 결의 명암을 지워버리는 평균색 덮기는 하지 않는다. 부재별 스케일·강도는 제작자가 비교 렌더로 결정할 수 있다. 가장자리 표현을 시험하면 낮은 강도의 재료색 변화만 허용하며 흰 테두리는 금지한다. 기와의 원본 면 분할이 보이는 부분은 재질 문제와 형상/노멀 문제를 구분해 기록한다.

카메라·노출·조명을 같게 두고 이전/후보를 비교한다. 조명의 그림자를 Base Color로 굳히거나 화면 필터로 재질을 대체하지 않는다. 후보 저장 후 다시 열어 형상·UV·속성·현판·원래 재질을 대조한다.

## 시각 완료 조건

- 전체 축소본에서 부재 계열의 조화, 402px에서 문틀/종이/기와/돌 구분.
- 확대본에서 창살·몰딩·끝면까지 실제 칠이 읽히되 기둥보다 절제됨.
- 기와 한 장의 표면과 겹침이 읽히고 전체 지붕의 얼룩이 주제가 되지 않음.
- 최소 전체/창호/처마 3시점과 다른 각도 확인. 각 재료의 실제 사용 면과 확대 검수 기록을 별도로 남김.
- 모든 재질이 연결됐다는 자동검사와 실제 미술적 완성도를 구분.

Blender 후보/렌더/360도 공정/Flutter는 각각 별도 상태다. 현재 공정 GLB와 앱은 이 새 표현으로 변경하지 않았다. 정본 승격·커밋·푸시는 이번 시안에 포함하지 않는다.

## 2026-10-23 건물별 역사·재료 근거 추가

[건물별 재료·창호·기와·조망 적용안](building-craft-research-20261023/REPORT.md)과 [현재 16개 카탈로그 항목 대응표](building-craft-research-20261023/APPLICATION_MATRIX.json)를 이후 제작 기준으로 함께 사용한다. 직접 읽은 2007 도면 6장, 일반 제작법, 표현 판단, 미확인 주장을 구분했다. 중문채 들기름/단면 창호지 마감, 안채 판장문/띠살문/격자살문, 곳간 통풍창, 사랑채 종이 벽서, 사당 채색 보존을 부재별 검수 항목에 넣는다. 작은 창을 눈곱재기창으로 단정하거나 새로운 막새·창·개폐 구조를 추가하지 않는다. 실제 재질/렌더 반영은 다음 제작 단계이며 이번 기록으로 완료 처리하지 않는다.
