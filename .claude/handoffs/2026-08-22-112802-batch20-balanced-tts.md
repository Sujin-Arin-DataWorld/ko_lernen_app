## Architecture Overview

`TtsService` and `tool/generate_tts.py` must choose the same voice before hashing `voice|text`; otherwise the app requests a cache object the generator did not create. Explicit scenario roles remain female for `user` and male for NPC/narrator. All other fixed and dynamic default calls now use a deterministic SHA-1 text policy, which makes the corpus balanced while keeping each phrase's voice stable across screens and sessions.
