# 사랑채 누적 공정 시범 v1

검토 전용이며 런타임 에셋이 아니다. 사용자 승인 전에는 전체 건물 확대,
카탈로그 등록, Firebase 반영, 커밋, 푸시 또는 배포에 사용하지 않는다.

## 정체성 원본

- `../sarangchae_try07_edit.png`
- 고정 요소: 6칸 본채, 우측 누마루와 난간, 지붕 위계와 곡선 처마,
  석축 기단과 중앙 계단, 기둥 리듬, 문살, 목재색, 기와 질감

## 배치 각도 생성 사양

- 카메라: 위에서 내려보는 조감, 정면 왼쪽에서 약 20도 평면 회전
- 변경 허용: 배치 시점과 그 시점에서 드러나는 측면 깊이만
- 변경 금지: 지붕 형태, 칸 수, 기단, 계단, 문살, 재료와 색, 비례
- 출력: 단일 건물, RGBA 투명 배경, 모든 처마와 바닥 접점 포함

`sarangchae_v3_placement_angle_v1.png`은 생성 후 배경 추출을 한 차례 더
적용했다. 자동 테스트가 투명 픽셀과 가시 픽셀이 모두 존재하는 RGBA인지
검사한다.

## 누적 구조 계약

`SarangchaeGeometry.standard()` 한 개가 본채와 누마루의 초석, 앞뒤 기둥,
보·도리, 용마루, 처마, 서까래 좌표를 만든다. 1~7단계는 동일 인스턴스를
누적해서 그리며, 8단계는 같은 바닥 접점에 V3 완성 스프라이트를 놓는다.
