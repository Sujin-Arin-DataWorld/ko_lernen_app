# 사랑채 12단계 건설 검토 세트

상태: `review_archive_camera_mismatch`

이 폴더는 사랑채 건설 과정 12단계와 관련 QA 자료를 보존하는 검토용
아카이브다. 앱 런타임 정본이 아니며, 현재 단계 PNG를 그대로 승격해서는
안 된다.

## 확인된 제한 사항

- 14개 `stage_*.png`는 모두 2512x1680 RGBA 투명 PNG다.
- 단계별 축척과 바닥선은 공통 등록값을 사용한다.
- 그러나 카메라는 승인된 약 28도 조감 시점이 아니다.
- `stage_12_complete_v3_base.png`는 거의 정면인 V3 원본
  `sarangchae_try07_edit.png`와 바이트가 동일하며, 6~11단계도 이 카메라를
  유지하도록 제작됐다.
- 따라서 단순 자르기, 기울이기 또는 원근 변형으로 수정하지 않는다.
