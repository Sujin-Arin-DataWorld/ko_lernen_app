이전 UI 목업 승인 취소

먼저 ‘실제 에셋 완성 맵’을 만듭니다

구조 가이드가 들어간 휴대폰 화면부터 만든 순서가 잘못됐습니다. 앱 UI는 2412×2622 완성 맵이 시각 승인된 뒤에만 다시 설계합니다.

PHASE 01 · NOW

실 에셋 완성 맵

실제 2.5D 방향 프레임, 승인 담장, 돌길·우물·장독대를 정확한 구조와 배열로 합성합니다.

PHASE 02 · APPROVAL

완성 맵 시각 승인

건물 정체성, 배치, 거리, 전저후고, 담장 접속과 마당 여유를 전체 이미지로 검토합니다.

PHASE 03 · AFTER

앱 UI 목업 → Flutter

승인된 완성 맵을 실제 앱 화면에 넣어 HUD·편집·Lernpfad를 디자인하고 네이티브로 옮깁니다.

에셋 점검에서 확인한 내용 곳간채·안채곳간채·화장실의 8방향 세트도 다른 작업트리에 생성되어 있습니다. 다만 아직 커밋되지 않은 검토본이므로, 원본 정체성과 방향 일관성을 먼저 확인한 뒤 완성 맵에 사용합니다.
