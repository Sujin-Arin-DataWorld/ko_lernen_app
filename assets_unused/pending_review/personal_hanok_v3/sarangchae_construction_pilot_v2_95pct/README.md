Firebase, 배포 빌드에 연결하지 않는다.

## 고정 계약

- 기준 건물: `../sarangchae_try07_edit.png`
- 공통 캔버스: 2512×1680 RGBA
- 공통 수평 중심: x=1250±0.5px
- 공통 바닥 접점: y=1421px
- 8단계는 기준 건물을 재생성하거나 보정하지 않은 byte-identical 복사본이다.
- 1–7단계는 동일한 사랑채 L자 평면, 정면 칸 구성, 우측 누마루, 기단과 계단,
  주지붕·누마루 지붕을 누적해서 완성한다.

## 결정론적 후처리

생성 원본의 체크무늬 또는 검은 매트가 RGB로 구워져 있어
`tool/extract_checkerboard_alpha.py`로 테두리 중성 매트를 자동 판별해 알파로 복원했다.
건물 색·형태·질감에는 필터나 재도색을 적용하지 않았다. 이어서
`tool/register_hanok_construction_stages.py`가 7단계와 V3 원본에서 공통 변환을
계산하고, 1–7단계에 동일한 축척을 적용한 뒤 수평 중심과 바닥선만 맞췄다.

`source_alpha/`는 1–5단계 정렬 전 RGBA 산출물이며, `source_alpha_r2/`는
2026-08-29에 고친 6–7단계와 추출 QA 기록이다.
`registration.qa.json`은 모든 변환값과 SHA-256을 기록한다.

## 현재 기계 검증 결과

- 8개 파일 모두 2512×1680 RGBA
- 네 모서리 알파 모두 0
- 8개 바닥 접점 모두 y=1421
- 1–7단계 중심 오차 최대 0.5px
- 단계별 폭/완성본 폭 비율 최저 95.985%
- 6단계 어두운 중성 지붕 픽셀 22,570개: 5단계 53,174개보다 적어 완성 기와 혼입 게이트 통과
- 7단계와 8단계 지붕 영역 IoU 96.690%
- 7단계 벽·창호 면적은 완성본의 88.217%로 설치 중 범위(82–96%) 통과
- 7단계와 8단계 외곽 bbox 완전 일치: `[42, 247, 2458, 1421]`
- 8단계 SHA-256은 기준 V3 원본과 100% 동일

기계 검증은 95% 기하 게이트를 통과했지만, 사용자 시각 승인 전에는 다른
건물로 확대하지 않는다.
