# 네 건물의 정면 공정 이미지

중문채 12장, 아래채 12장, 안채 14장, 안채 창고 11장으로 구성한 **49장 제작 검토본**입니다.
모두 1536×1024 PNG 원화이며, 정면 방위 0°·지면 위 29° 부감과 손으로 그린 2.5D 질감을 목표로 생성했습니다.
카메라 각도를 측정한 3D 렌더링 결과는 아닙니다. 흰 배경의 RGB PNG이며 투명 스프라이트가 아닙니다.

## 현재 선택본

`construction_catalog.json`의 49개 `file` 항목이 이 묶음의 현재 선택본입니다.
같은 폴더의 이전 버전 PNG는 생성 이력 보존용입니다. 파일 이름의 버전이 높다는 이유로 임의 교체하지 마세요.
각 PNG 옆의 `.prompt.txt`에 실제 제작 지시를 보관했습니다.
`generation_manifest.json`은 선택본의 입력 참조와 생성 결과 위치를 연결합니다.
`reference_manifest.json`과 `references/`는 기존 완성 정본의 실제 입력 파일과 SHA-256을 보관합니다.
새 공정 이미지나 새 완성 프레임은 기존 8면도 정본을 대체하도록 승인된 자산이 아닙니다.

## 공정과 생활 공간

| 건물 | 공정 수 | 공간에서 드러내는 차이 |
|---|---:|---|
| 중문채 | 12 | 통행문·두 방·오른쪽 열린 마루, 높은 기단과 두 계단 |
| 아래채 | 12 | 세 칸, 마루방·온돌방, 앞 툇마루와 바닥 받침 |
| 안채 | 14 | 팔작 골격, 낮은 부엌과 그 위 다락, 온돌방·대청 |
| 안채 창고 | 11 | 두 보관 공간, 세 출입문, 흙바닥과 물건을 옮기는 길 |

터 → 기단·초석 → 기둥 → 보·도리 → 서까래·처마 → 지붕 바탕 → 기와 → 벽과 바닥 → 창호 → 사용 장면을 건물별로 나눴습니다.
공정은 학습을 위해 묶은 것으로 실제 현장의 모든 작업 순서를 그대로 기록한 시공 매뉴얼이 아닙니다.
도면에서 확인되지 않은 내부 부재·난방 상세는 교육용 재구성이므로 실측 복원 근거로 사용하지 않습니다.

## 제작 검수 범위

- 49개 선택 PNG가 존재하고 1536×1024로 열리며, SHA-256이 서로 다름을 확인했습니다.
- `asset_audit.json`의 기단 패치 비교는 일부 돌무늬 위치의 지표입니다. 기둥 접합이나 29° 카메라를 검증하는 검사가 아닙니다.
- 중문채 3→4단계의 우측 마루 기둥축과 기둥머리 높이에 차이가 남아 있습니다.
- 아래채 1→2단계의 앞쪽 터 외곽선 깊이는 추가 정합이 필요합니다.
- 전체 단계의 기둥·서까래·처마가 완전히 고정된 최종 공정 정본으로 승인하지 않았습니다. `art_review.json`에 남은 항목을 기록했습니다.
- 앱 연결, 투명 배경 변환, 실기기 QA, 학습자 검증은 포함하지 않았습니다.
