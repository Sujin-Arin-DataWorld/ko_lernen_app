# 일두고택 안채 V03 — 45° 간격 8방향 · 공통 28° 2.5D 시안

상태: `runtime_approved`

이 폴더는 승인된 V02 안채 8면 이미지를 방향별 형상·색상·재질 기준으로 그대로 활용해, 모든 방향의 카메라를 수평선 기준 하향 28°로 통일한 검토용 형제 세트다. V02 파일은 수정하거나 덮어쓰지 않았다.

## 공통 카메라 계약

- 방위각: `000°`, `045°`, `090°`, `135°`, `180°`, `225°`, `270°`, `315°`
- 간격: 정확히 45°
- 카메라 고도: 수평선 기준 위 28°에서 건물을 내려다보는 시안
- 투영: 정사영에 가까운 약한 원근의 2.5D, 장초점 느낌
- 롤: 0°, 수평선 유지
- 캔버스: 전 방향 `1672 × 941`, 가로형
- 공통 표현: 좌상단 중성광, 약한 처마·마루 음영, 동일한 석축 기준선 계열
- 공통 팔레트: 짙은 온갈색 목재, 따뜻한 미색 회벽, 먹색 기와, 회베이지 자연석

생성형 이미지이므로 픽셀에서 도면학적 28.000°를 역산해 보증하는 정밀 렌더가 아니라, 동일한 `28°` 카메라 명세를 고정해 만든 방향 검토용 시안이다.

## 형상 잠금

- 긴 일자형 단층 안채와 약 8개 비균등 칸의 리듬을 유지한다.
- 긴 본채 위에는 하나의 연속된 홑처마 팔작 기와지붕만 둔다.
- 물리적 좌측에는 벽 전체보다 약간 작은, 본채에 통합된 부엌·화장실 서비스 공간과 낮은 부속지붕이 있다.
- 물리적 우측에는 낮은 부속지붕이 없다.
- 중앙 2칸 대청마루, 양옆 마루 공간과 뒤쪽 방의 깊이를 유지한다.
- 대청 뒤 목재 창호는 열고 닫을 수 있으며 살짝만 열려 있다. 완전히 뚫린 통로로 만들지 않는다.
- 배면에는 연속된 뒤쪽 마루가 읽혀야 한다.
- 단청, 사찰 장식, 2층, 별도 누각, 임의의 날개채나 추가 지붕을 넣지 않는다.

## 배경·알파 상태

루트의 승인 원본 8장은 비교 기준을 보존하기 위해 `RGB` 상태 그대로 둔다. `transparent_28deg/`에는 캔버스 가장자리와 연결된 밝은 저채도 배경만 제거한 동일 크기 `RGBA` 8장이 있다. 내부 미색 회벽과 석축은 연결성 기준으로 보존했고, 반투명 경계 RGB는 가장 가까운 건물 내부색으로 치환해 흰색 매트 프린지를 막았다.

`tool/promote_ildu_anchae_turntable.py`는 이 투명 원본을 premultiplied RGBA로 축소해 `384 × 512` 런타임 프레임을 재현한다. 런타임 파일은 `assets/illustrations/personal_hanok_v3/turnarounds/ildu_anchae_*.png`이며, 모든 방향이 동일한 스케일과 기준선 `y=472`를 공유한다.
