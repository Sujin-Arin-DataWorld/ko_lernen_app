# 일두고택 창고 8방향 2.5D 검토본 v01

상태: `pending_review_only`

이 폴더는 일두고택 창고의 28° 조감 8방향 검토 자산이다. 방향은 정면을 0°로 두고 45°씩 증가한다. 현재 결과는 런타임, 카탈로그, Firebase 또는 배포 자산의 권위가 아니다.

## 입력 권위

- 스타일·색상·재질·건물 정체성 기준: `../../changgo_final.png`
- 형상 근거: `../../ildu_Blueprint/` 아래 창고 도면 7장
  - 정면도
  - 평면도
  - 우측면도
  - 종단면도
  - 횡단면도
  - 와복도
  - 앙시도

도면에서 고정한 핵심은 장방형 평면, 6칸 전면과 7개 기둥선, 장축을 따르는 맞배지붕, 전면 6개 판문, 폐쇄된 후면·양 측면, 석재 기단이다. 도면 래스터는 이미지 생성 입력으로 넣지 않았으며, 도면에서 읽은 형상 제약만 방향별 생성 지시에 반영했다. 시각 입력은 `changgo_final.png` 한 장만 사용했다.

## 카메라와 방향

- 정사영에 가까운 긴 초점 표현
- 카메라 고도각 28°
- 동일 조명, 동일 지면선, 동일 중심
- 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°
- 최종 프레임: 2048×1536 RGBA
- 공통 기준선: y=1472

## 산출물

- `generated_28deg/`: 방향별 원본 생성 결과. 생성기가 체크무늬를 RGB에 구워 넣었으므로 감사용으로만 보존한다.
- `transparent_28deg/`: 실제 알파 채널을 가진 방향별 최종 PNG 8장.
- `ildu_changgo_8view_transparent_sheet.png`: 투명 4×2 시트.
- `ildu_changgo_8view_review_sheet.png`: 라벨과 중립 배경을 포함한 검토 시트.
- `qa_metrics.json`: 입력·출력 SHA-256, 알파, 바운딩 박스, 팔레트 및 크기 기록.
- `PROMPTS.md`: 방향별 생성 계약.
- `QA_REPORT.md`: 자동·수동 검토 결과.

## 다른 2.5D 세션에서 이어받은 공정

다른 건물의 이미지를 재사용하거나 이미지 입력으로 넣지는 않았다. 같은 프로젝트의 사당·사랑채·중문채 작업에서 검증된 공정 규칙만 참고했다.

1. 원본 생성물을 감사용으로 보존한다.
2. 화면 경계와 연결된 중성 체크무늬만 배경으로 판정한다.
3. 가장 큰 건물 실루엣을 유지하고 알파 가장자리를 짧게 페더링한다.
4. 불투명 본체 RGB는 바꾸지 않고 반투명 가장자리 RGB만 가까운 본체색으로 정리한다.
5. 투영이 같은 반대 방향끼리 크기를 맞춘 뒤 공통 캔버스와 기준선에 배치한다.
6. SHA-256과 알파·여백·컴포넌트·팔레트 검사를 기록한다.

## 재현 및 검증

프로젝트의 Python 환경에서 다음을 실행한다.

```powershell
python -X utf8 .\build_turnaround.py
python -X utf8 .\validate_turnaround.py
```

이미지 생성 자체는 확률적이므로 같은 프롬프트가 같은 픽셀을 보장하지 않는다. 현재 검토 후보는 `qa_metrics.json`의 해시로 고정한다.

## 승격 금지선

사람의 시각 검토와 실제 배치 검토가 끝나기 전에는 이 폴더의 결과를 런타임, 자산 매니페스트, 카탈로그, Firebase 또는 릴리스에 연결하지 않는다.
