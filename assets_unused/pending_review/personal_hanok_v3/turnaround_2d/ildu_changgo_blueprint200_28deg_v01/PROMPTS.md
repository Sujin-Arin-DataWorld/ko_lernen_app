# 창고 8방향 생성 계약

이 문서는 현재 검토본을 만든 공통 지시와 방향별 카메라 계약을 기록한다. 이미지 생성은 방향마다 한 번씩 독립 실행했다. 모든 실행에서 시각 참조는 `changgo_final.png`만 사용했고, 도면 7장에서 읽은 구조 정보는 텍스트 제약으로 전달했다.

## 공통 지시

- 참조 이미지의 바로 그 일두고택 창고를 그린다. 새 건물이나 일반적인 한옥으로 재해석하지 않는다.
- 참조 이미지의 잉크선 밀도, 사실적 목재 결, 황토색 회벽, 짙은 회색 기와, 석재 기단, 풍화 정도와 전체 색조를 유지한다.
- 장방형 6칸 창고와 7개 전면 기둥선을 유지한다.
- 전면에만 6쌍의 판문과 고리형 철물 손잡이를 둔다.
- 후면과 양 측면은 판벽으로 닫고 문, 창, 손잡이를 새로 만들지 않는다.
- 장축 중앙을 따르는 하나의 긴 맞배지붕과 도면의 처마 돌출을 유지한다.
- 카메라는 28° 조감, 정사영에 가까운 긴 초점으로 고정한다.
- 배경, 바닥 풍경, 사람, 소품, 그림자 판, 글자, 라벨을 넣지 않는다.
- 건물 전체를 한 프레임에 넣고 모든 방향에서 같은 조명과 중심을 유지한다.

## 금지 항목

- 팔작지붕, 복합 지붕, 부속채 또는 담장 추가
- 칸 수, 기둥선, 지붕 비례 변경
- 후면·측면에 문이나 손잡이 추가
- 현대식 재료, 채도 상승, 따뜻하거나 차가운 전체 색보정
- 다른 세션의 건물 이미지 또는 3D 출력물을 입력으로 사용
- 단순 2D 회전·왜곡으로 다른 방향을 흉내 내기

실제 투명도는 생성 결과의 RGB 체크무늬를 로컬 후처리로 제거해 만들었다. 후처리는 불투명 본체의 색을 수정하지 않는다.
