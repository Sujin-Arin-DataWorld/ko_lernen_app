## 절대 기준

## 정면 잠금

물리적 정면을 바라볼 때 왼쪽부터 다음 순서와 상대 크기를 그대로 유지합니다.

1. 닫힌 세로판문 쌍문과 고리 손잡이
2. 그 옆의 쌍창호 — 평면도/창호상세도 `04 WD`, 약 1,080×1,020
3. 작은 가로 격자창 — `01 WW`, 약 900×580
4. 오른쪽의 열린 마루칸

두 번째 쌍창호는 세 번째 가로창보다 폭이 조금 더 크고 높이는 확실히 큽니다. 다른 문·창으로 바꾸거나 작은 가로창과 순서를 바꾸지 않습니다.

## 건물 잠금

- 한 줄로 긴 직선형 `一`자 몸체
- 용마루가 정확히 하나인 단일 맞배지붕
- 원본의 두 돌계단, 석축, 목재, 회벽, 기와, 비례, 색과 묘사 방식 유지
- 배면·측면은 기록화 도면으로만 확인하며 임의의 별채·날개·두 번째 지붕을 추가하지 않음

## 카메라 잠금

- 건물 중심을 향하는 동일 거리의 카메라
- 수직 하향축에서 28° 기울인 중상공 조감 카메라(지면 수평 기준 고도 62°)
- 방위각은 45° 간격의 8방향: 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°
- 모든 방향에서 동일한 정사영풍 스케일과 여백
- 정면도처럼 낮은 시점으로 내려가지 않으며, 사선 방향에서는 가까운 지붕면 전체와 반대편 지붕면을 하나의 용마루 양쪽에서 함께 읽을 수 있는 조감
- 각 방향은 진짜 투명 배경의 RGBA PNG
