# 사랑채 v02 런타임 등록 작업본

v01의 방향별 원본 분리 프레임을 384×512 공통 캔버스, 축척과 바닥선에 등록한 후속 작업본이다.

- `transparent_views/`: 현재 런타임과 SHA-256이 같은 8장
- `*_raw.png`: 생성 원시트
- `*_clean.png`: 부산물 정리 시트
- `*_transparent.png`: 알파 처리 시트
- `split_turnaround_sheet.py`: 공통 캔버스 등록과 분리 작업 도구
- `ildu_sarangchae_00_source_original_exact.png`: V3 정본 바이트 보존본

이 README는 원래 v02 폴더에 설명 파일이 없어서 인수인계 패키지에서 추가했다. 이미지와 스크립트는 원본 작업 폴더에서 그대로 복사했다.
