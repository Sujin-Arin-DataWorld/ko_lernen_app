## 도면 계약

`../ildu_Blueprint`에서 파일명에 `아래채`가 포함된 11개 도면을 모두 확인했다. 2007 기록화 도면을 고립된 현존 아래채의 치수 기준으로 삼았고, 이전 보수공사 도면은 측면·배면·높이 관계의 보조 근거로만 사용했다.

- 몸체 폭 7,500 mm
- 칸 리듬 2,430 / 2,370 / 2,670 mm
- 실내 깊이 2,820 mm
- 정면 연속 툇마루 깊이 1,180 mm
- 박공 끝 처마 내밈 650 mm
- 정면·배면 처마 내밈 930 mm
- 맞배 단처마 기와지붕
- 정면: WD02 4짝 짙은 민목 격자 / WD06 2짝 한지 / WD04 2짝 한지
- 배면: WD03 4짝 한지와 WD07 좁은 1짝 한지의 비대칭 구성
- 좌측: WD01 4짝 격자, 아궁이 없음
- 우측: 일반 창호 없음, 낮은 아궁이 2개

## 외관 기준

기와색·목재색·황토벽·석재·철물·선화·노화 질감은 원본 팔레트와 표현을 기준으로 유지했다. 생성 단계의 체크무늬 또는 검정 배경은 경계에 연결된 배경 성분만 분리하고, 건물 내부의 검은 기와·창호·그늘은 보존했다.

통합 커밋에는 최종 8장과 위 핵심 검수 자료만 포함했다. 생성 중간본, 제외 시도, 비등방 강제등록 진단 이미지는 런타임 승격 대상이 아니므로 포함하지 않았다.

자동 검사는 8장 모두 RGBA·캔버스·접지선·투명 모서리·네온 녹색 테두리 0개 조건을 통과했다. 자동 검사는 사람의 실제 앱 배치/회전 검토를 대체하지 않는다.

런타임 뷰어는 8장에 공통 뷰포트 `(448, 274)–(2111, 1259)`를 적용한다. 따라서 좌우 드래그로 45°씩 회전해도 원본 축척과 접지선이 바뀌지 않으며, 핀치 또는 확대·축소 버튼은 화면 표시 배율만 바꾼다.
