## 파일 구성

- references: 정본 복사본과 도면 8장.
- 각 건물의 raw: 생성 도구의 출력 원본. 후보와 폐기 사유는 generation_ledger.json에 있다.
- 각 건물의 prompts: 생성 요청문.
- 각 건물의 stages: 검사를 통과한 최종 정본 파일만 존재한다. 중간 단계 파일은 아직 만들지 않았다.
- learning.json: 한국어를 의미 기준으로 작성한 14단계 설명과 과제. 현대 학습 장면은 역사 기록과 구분한다.
- exercise_design.json: 선택형 과제의 문장과 정답 연결. 실제 앱 채점·보상에 연결되지 않는다.
- glossary.json: 부재 이름의 짧은 KO/EN/DE 보조 설명.
- build_review.py: PNG를 읽어 검사하고 JSON·Markdown·CSV·HTML을 생성한다. 이미지 픽셀은 편집하지 않는다.
- qa: 브라우저 화면 증거와 로컬 서버 로그.

## 남은 제작 공정

1. 생성된 불투명 RGB 배경을 투명화한다.
2. 정본 캔버스와 바닥 접점에 맞추고, 기단·기둥·골조를 공통 레이어로 고정한다.
3. 협문 1→6단계를 먼저 겹쳐 검수한다.
4. 창고 3→4단계의 용마루 높이 차이를 바로잡고, 1→8단계의 기둥열과 내부 구획을 검수한다.
5. 밝고 어두운 배경에서 알파 가장자리와 잘림을 검사한다.
6. 100px 표시와 작은 화면에서 누적 변화·예문 연결을 검수한다.
7. 중간 단계 PNG 12장을 stages에 만들고 검사를 다시 실행한다.

Python을 이용한 이미지 후처리는 아직 실행하지 않았다. 이 패키지는 후처리 전 그림과 검수 기록을 보관한다. 배경 제거와 크기 변경만으로 부재 위치 고정 검사가 통과하는 것은 아니다.

## 다시 검사하기

~~~powershell
python build_review.py --check
~~~

현재 예상 결과는 **실패 12개**다. 중간 단계 PNG가 없어서 발생한다. 원본·최종 해시와 언어 데이터 등 50개 항목은 통과했다. 구조 연결과 시각적 완성도는 이 기계 검사가 대신 판정하지 않는다.

이 패키지는 검토용 산출물을 보관한다. 앱 API, 진행도 저장, 보상, 런타임 카탈로그를 변경하거나 공정 후보를 런타임에 승격하지 않는다.
