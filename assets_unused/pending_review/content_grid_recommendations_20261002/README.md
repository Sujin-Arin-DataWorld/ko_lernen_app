# 한글소리 콘텐츠 네 칸과 추천 시안

독립 검토 시안입니다. 메인 앱과 기존 디자인 작업 파일을 변경하지 않습니다.

- 홈: 설명 없이 그림과 제목으로 구성한 2×2 콘텐츠. 기본값은 Hören, Dialog, Wörter, Grammatik입니다.
- 개인화: 최근 28일의 콘텐츠 선택을 반영합니다. 최근 기록의 비중이 크고, 같은 날의 반복 사용은 세 번까지만 점수에 반영합니다. 네 칸의 위치는 하루 동안 고정합니다.
- 발견: 30분 이상 떨어진 방문 세 번마다 한 콘텐츠를 제안할 수 있습니다. 새 제안은 하루에 한 번 이하, 같은 항목은 일주일에 한 번 이하입니다. 화면에 절반 이상 보이면 노출로 기록합니다.
- 미사용 항목을 우선합니다. 모두 사용한 경우에는 14일 이상 쉬었던 항목을 제안하며, 문구도 바꿉니다. 닫은 항목은 일주일 동안 제외합니다.
- 사용 기록은 이 시안의 브라우저에만 저장합니다. 예시 사용자 모드는 별도 메모리로 동작합니다. 실제 계정 진도·보상·학습 이력은 연결하지 않습니다.
- `usage-recommendations.js`는 UI와 분리된 추천 로직입니다. 실제 앱에 연결할 때에는 기존 접근·학습 조건으로 실행 가능한 항목만 넘기고, 실제 학습 진입 성공 시 기록해야 합니다. 시안의 선택 기록을 학습 완료로 해석하지 않습니다.
- 기존 13개 학습, 8개 게임, 252개 팩과 엽전 원본을 유지합니다. 새 한글·문법 그림은 투명 PNG 원본 바이트를 보존했습니다.

검토 기준 소스: `797160b0664172b2956be0e202bb5df9b246b65c`. 이 기준은 시안 제작 당시의 콘텐츠를 뜻합니다.

이 폴더에서 다음 명령으로 검토 서버를 실행합니다. 다른 세션 서버와 겹치면 포트를 바꿉니다.

```sh
python -m http.server 8814 --bind 127.0.0.1
```

검토 화면: `http://127.0.0.1:8814/`. 왼쪽의 '추천 동작 검토'에서 실제 시안 사용 기록과 예시 사용자 두 종류를 전환할 수 있습니다.

검증: `node --test qa/recommendations.test.cjs`, `qa/layout-check.ps1`, `qa/verify-scope.py`.
검증 영수증: `qa/verification.json`. 새 그림의 프롬프트: `qa/image-prompts.json`.

`qa/layout-check.ps1 -BaseUrl http://127.0.0.1:8814`는 해당 검토 서버를 별도 브라우저 세션에서 검사합니다. `qa/verify-scope.py`는 이 저장소의 기준 커밋과 이미지 지문을 확인하며, 제작자 컴퓨터의 파일 경로에 의존하지 않습니다.

메인 세션에서 검토할 핵심 파일은 `home-content.js`, `usage-recommendations.js`, `content-grid.css`, `assets/grammar.png`, `assets/hangul.png`입니다. `app.js`와 `catalog-review.js`는 시안에 연결한 사용 예시입니다. 이 커밋의 앱 적용 여부는 `lib/` 등 런타임 통합과 별도로 판단해야 합니다.
