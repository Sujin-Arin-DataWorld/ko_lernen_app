접촉 전 손가락의 위치를 일반 스마트폰에서 감지한다고 주장하지 않습니다. 마우스·키보드의 hover·focus, 터치의 접촉·누름·놓음·취소를 구분했습니다. 엽전·보자기는 짧게 한 번 반응하며 다음 버튼을 애니메이션이 막지 않습니다. 실제 잔액을 지급·소비하거나 장식의 소유권을 바꾸지 않습니다.

실제 재질이 느껴지는 3D

한글소리 적용: Lernen의 학습 경로는 녹청 면과 약간 기울어진 실제 그림, Spiele의 도전 영역은 황토 면으로 구분했습니다. 다른 그림은 차분한 인쇄 카드에 담았습니다. 참조의 게시 시점·제품 버전·효과 수치는 확인하지 않았습니다.

100 CSS px 크기 비교. 원본 파일을 수정하지 않고 표시 크기만 바꿉니다. 기능명은 항상 읽을 수 있는 글자로 함께 표시합니다.

  • 빛은 좌측 위에서. 미세한 결은 재질을 구분할 정도로 두고, 거친 노이즈를 UI 전체에 덮지 않습니다.
  • 넓고 매끈한 플라스틱 광택, 젤리 같은 재질, 오브젝트 주변의 큰 발광은 사용하지 않습니다.
  • 수호 캐릭터는 현재 정본을 작게 사용합니다. 이번 UI에는 새 대형 호랑이·까치·해태를 반복 배치하지 않습니다.
  • 인물은 상대를 알려주는 프로필입니다. 수진의 짧은 다크브라운 머리, 크리스티안의 금발·세이지 다크블루 눈을 담은 이전 검토 에셋을 보존해 사용했습니다.

직접 쓴 한국어 · 영어 · 독일어

번역 스킬을 적용하지 않고 한국어 문장을 먼저 쓰고, 영어와 독일어를 각각 직접 옮겼습니다. 성인 친구 수진과 크리스티안이 대학교 근처에서 오후에 만날 약속을 잡는 검토 장면입니다. 반말·독일어 du·일상 영어를 맞췄습니다.

“커피 마시러 갈래?”는 함께 나가자는 초대입니다. “커피 좀 사다 줄래?”는 가져다 달라는 부탁이므로 같은 학습 문장으로 바꾸어 쓰지 않습니다. 영어의 grab a coffee는 친구끼리의 자연스러운 표현으로 옮겼고, 장면과 두 잔의 컵이 함께 가자는 뜻을 뒷받침합니다.

학교 → university / Uni: 이 장면의 장소를 대학교 근처로 명시했습니다. ‘학교’가 모든 맥락에서 대학교라는 뜻이라고 가르치지 않습니다. 세 시는 장면의 오후 시간에 따라 15:00를 뜻합니다.

자연스러운 거절: “미안. 오늘은 좀 어려워.” / Sorry, today doesn't work for me. / Tut mir leid, heute passt es bei mir nicht.는 자연스럽습니다. 과제가 ‘초대를 받아들이고 장소를 묻기’이므로 과제 의도와 다르다고 안내합니다. 문법 오류나 잘못된 말투로 평가하지 않습니다.

UI 문장은 글자 수보다 의미를 기준으로 현지화했습니다. 예를 들어 독일어 카드 제목은 Auf einen Kaffee, 영어는 Make plans for coffee입니다. 세 언어의 설명문에서 장소와 시간을 정하는 목표를 동일하게 전달합니다. 자연스러운 다른 답변도 의미가 맞을 수 있으며, 메타데이터에 대안을 남겼습니다. 자유 발화 채점 기능은 연결하지 않았습니다.

모션과 상태 연결

CTA: 홈의 책은 실제 생성한 직물·종이 재질의 작은 입체 오브젝트입니다. 주요 버튼에는 밝은 도자기색 엠블럼과 짙은 녹청 아래면, 보조 화살표를 넣었습니다. Hören 재생에는 아이콘과 Anhören / Listen / 듣기를 함께 표시하고 실제 음성이 시작하면 정지 아이콘·라벨로 바뀝니다. 비활성 CTA는 글자를 흐리지 않는 차분한 표면으로 구분합니다.

CTA 3종을 직접 눌러 비교 → 새 사용자 Pinterest 핀은 Eddie Luong의 Chatbot Concept App이며 원작은 Book A Nutritionist입니다. 실제 영상의 대화 → 일정 선택 → 확인 버튼 흐름을 확인했습니다. 2020년 콘셉트이므로 2026년 실사용 앱 트렌드의 증거로 부르지 않습니다. 한글소리에는 상황과 다음 행동을 같은 영역에 묶는 원칙을 적용해, 시작 CTA 안에 ‘듣고 대답하기’를 짧게 보여줍니다.

Apple 버튼 지침에서는 선명한 주 행동·아이콘과 텍스트 결합·누름 상태를, Emil의 실제 인터랙션 비교에서는 작은 누름 변화와 반복 조작의 속도를 참고했습니다. 시작형은 입체 책+방향, 재생형은 한 덩어리의 플레이 컨트롤, 보상형은 현재 보자기+열기 행동으로 구분했습니다. 새 엽전 이미지는 이번 승인 버전을 유지합니다.

밝은 엽전 · 보자기 복원

엽전 획득 · 보자기 열기 비교 → 홈 잔액 배지·지갑·학습 완료 보상·한옥 건축 목표를 시안에 다시 연결했습니다. 전체 화면은 밝은 한지·단청 황색·옅은 청색이며 다크 모드를 추가하지 않았습니다. Duolingo 첨부에서는 큰 보상 오브젝트 → 탭해서 열기 → 확인의 순서만 참고했습니다.

현재 main의 YeopjeonService·YeopjeonWallet을 확인했습니다. 확인된 첫 레슨 20엽전, 다른 두 번째 레슨 10엽전, 이미 완료된 레슨 재개 0엽전, 건축 단계 비용 40엽전입니다. 학습으로 건축 단계가 해금된 뒤에 지을 수 있다는 조건도 보존했습니다. 복습 목표는 실제 확인 경로가 아직 없어서 앱에서 지급하지 않는 상태이므로 시안에도 보상을 추가하지 않았습니다.
