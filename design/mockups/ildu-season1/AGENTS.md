# 시즌1 이미지 제작의 디자이너 검수

2026-11-04 사용자 요청: 디자이너 서브에이전트가 합의한 조건을 생성 전후 항상 확인한다.

- 이 경로에서 이미지 제작을 진행할 때 전담 디자이너 검수 서브에이전트를 사용한다. 생성 담당과 다른 에이전트가 실제 정본과 결과 파일을 직접 연다.
- 먼저 `20261104-story-only/DESIGN_REVIEW_GATE.md`와 해당 장면의 원고·최신 캐릭터 포인터를 읽는다.
- 생성 전 참조/고정 외형/크기 형태/시선/접지/소품/서사 조건을 기록하고 검수자의 지시를 반영한다.
- 생성 후 해부학·외형·크기·연기·소품·서사를 각각 PASS/FAIL/UNVERIFIED로 기록한다. 사용 목적의 필수 항목이 FAIL 또는 UNVERIFIED이면 그 목적의 출고와 파생 작업을 막는다. 다른 목적의 제한적 참고 허용은 상위 `design/AGENTS.md`와 검수 기록에 따라 별도로 판정한다.
- 태고 전신이 등장하는 현재 수정 화면은 네 다리와 네 발을 독립적으로 확인할 수 있어야 한다. 가림이나 크롭을 완전한 신체 구조의 근거로 삼지 않는다.
- 후보의 독립 검수는 사용자 승인·정본 승격·앱 적용과 다르다. 이미지 검수를 Flutter/실기기 검사로 보고하지 않는다.
- 현재 범위는 시즌1 이야기 연결 이미지다. 학습 화면·HTML·앱 코드·배포는 이 작업에 포함하지 않는다.
