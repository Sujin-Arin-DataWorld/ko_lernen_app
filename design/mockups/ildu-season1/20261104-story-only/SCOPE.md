## 장면 수정 순서

1. R21b: 탈선비가 플레이어 이름을 부르는 마무리. 학습 버튼 대신 마당으로 돌아가는 이야기 행동.
2. R22–R23: 보관 미확인/재시도와 실제 확인 뒤의 마당 복귀. 거짓 저장 성공을 그리지 않는다.
3. R24: 창고 착공의 부탁과, 조건을 충족한 뒤의 빈 씨앗 주머니 발견을 별도 장면으로 취급한다. 완공 조건을 충족하지 않은 뜰에 완공 건물을 그리지 않는다.
4. R25: 중문 이름표와 이동 동선의 이야기. 책의 한 글자로 사건을 대체하지 않는다.
5. R26: `집` 연습 초안과 정본 보관을 구분하는 이야기. 초안을 정본 쪽지나 자동 보상으로 표시하지 않는다.

각 화면을 생성하기 전에 원문 대사·등장인물·시선 대상·지지점·소품·다음 행동을 기록하고, 생성 뒤 외형과 연기를 별도로 검수한다. 실패 후보로 다음 장면을 파생하지 않는다.

## 공통 UI와 전달 한계

- 깊은 녹색/청록 프레임, 한지 면, 황금 주요 행동의 C안 방향을 유지한다. 한 화면에는 한 화자의 말과 한 가지 주요 이야기 행동을 둔다.
- 구름·설정·엽전은 `C:/Users/vjinn/.codex/generated_images/공통UI정본/CANONICAL_UI.json`의 원본만 사용할 수 있다. 생성 모델이 새로 그린 장식은 정본이 아니다. 이번 이야기 이미지에서 해당 UI를 생략하며, 원본 별도 배치가 필요한 화면은 미완료 항목으로 기록한다.
- 하단 CTA 그림자 아래 여유와 safe area를 둔다. 이미지의 육안 검사는 실제 48dp 터치/16dp 간격/Flutter 검사를 대신하지 않는다.
- 정지 이미지·검토 후보·사용자 승인·앱 적용을 구분한다. 캐릭터 참조를 첨부했다는 이유만으로 동일성을 보증하지 않는다.
