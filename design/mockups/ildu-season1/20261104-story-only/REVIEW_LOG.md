### 검수 기준의 보정

첫 검토에서 먼 골반부터 모든 관절이 직접 보여야 한다는 식의 과도한 지시가 있었다. 검수자는 재검토 후 정상적인 몸통·가까운 허벅지 가림을 허용한다고 정정했다. 가림 밖으로 나오는 기존 다리 윤곽과 독립 발의 연결을 확인해야 하며 숨은 관절을 투시도처럼 그려서는 안 된다. 첫 단독 후보의 “다리 세 개/새 발 추가” 결함이 입증됐다고 보고하지 않는다. 여백 부족은 별도 문제로 남는다.

ANATOMY-03은 불투명 장면의 형태 보조 참고로만 조건부 허용됐다. 그러나 R21b V5의 실제 입력에는 이 후보를 넣지 않고 **승인 body·face와 수진·탈선비 원본, 폐허 환경** 5개만 사용했다. 단독 후보의 외형 검수 결과는 장면 결과에 자동 승계하지 않았다.

## R21b 생성 전 지시

[R21B_PREFLIGHT_V5.json](R21B_PREFLIGHT_V5.json)은 검토 전 초안이다. 실제 생성에는 [R21B_PROMPT_V5.json](R21B_PROMPT_V5.json)을 사용했다.

전담 디자이너의 수정:
- 태고의 코를 막연한 짧은 코로 지시하지 않고 승인된 고양잇과 콧등·코끝·수염 패드·턱으로 지정.
- 수진의 크림 접힌 소매는 니트 소매가 아니라 재킷 안감임을 교정.
- 책 주변 금빛 원·광선·입자·활성화 효과를 명시적으로 금지.
- 좌우 반전과 비대칭 표식의 방향 반전을 금지.
- 서안·책을 옮기지 않고 카메라 높이·프레임을 조정해 모든 발과 서안 뒤 모서리 사이 지면이 보이도록 지시.

서사 검수의 수정:
- 책을 탈선비의 손이나 새 책대로 옮기지 않고 기존 서안에 유지.
- 이미 복원된 `아`는 왼쪽, 오른쪽은 공백.
- 이전 “허허, 소리가 먼저이고…” 대사를 대체하지 않으며 U1-D12 뒷부분을 표시.
- 복귀 CTA 뒤 R22 보관 확인 → R23 마당 복귀를 유지. 저장 완료·소유·보상 문구를 선표시하지 않음.

## R21b V5 결과

원본: `exec-47f534af-ca07-4505-b752-a4db03458cce.png`. **출고 보류.** 이 후보를 정본·번역판·다음 장면의 외형 참조로 사용하지 않는다.

서사 검수에서 KO/DE 문구, 왼쪽 아·오른쪽 공백, 서안이 다리를 가리지 않는 점, 화자/수신자, 저장 완료 문구가 없는 점은 확인했다. 다만:
- 우상단의 온전한 기와지붕·기둥·벽 구조물이 기존 경계문인지 건물인지 불분명하다. 사랑채 착공 전 미복원 상태로 승인하지 않는다.
- 상단 양쪽 금색 소용돌이는 공통 UI 정본 원본이 아닌 생성 장식이다. 공통 UI 규칙 위반이다.
- 기존 승인 서안과 위치가 정확히 동일한지, R22→R23 연속성은 이 정지 이미지 하나로 확인하지 않았다.

캐릭터 최종 독립 판정은 별도 `R21B_POSTFLIGHT.md`에 기록한다. 생성 전 지시가 통과해도 생성 결과가 자동으로 통과하지 않는 실제 사례다.

## 범위와 남은 일

이번 독립 검수 체계는 배정·문서화했고 실제 후보에 적용했다. R21b 결과 및 투명 단독 PNG를 완성으로 보고하지 않는다. R22–R27의 이야기 화면은 이 검수 체계를 적용할 다음 작업이며 이번 수정 배치의 완성본으로 계산하지 않는다. 학습 화면·앱 코드·HTML·Figma·배포는 변경하지 않았다.
