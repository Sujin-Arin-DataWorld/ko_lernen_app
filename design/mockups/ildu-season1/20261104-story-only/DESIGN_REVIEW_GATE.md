# 생성 전후 독립 디자이너 검수

2026-11-04. 사용자가 반복된 다리 누락을 지적하고 전담 검수 서브에이전트를 명시적으로 요청했다. 기존 외형·수치 승인을 바꾸지 않는 실행 규칙이다.

## 담당과 순서

현재 전담 검수자: `/root/character_design_guard`. 이야기 원문·상태 연결 검토: `/root/story_contract_review`. 생성 담당은 검수 결과를 대신 작성하거나 이름만 붙여 검수 완료로 처리하지 않는다. 다음 세션은 같은 역할의 독립 검수자를 다시 배정한다.

1. 최신 승인 포인터·원본 해시·장면 원고를 확인한다.
2. 생성 전 프롬프트와 인물별 시선·크기 형태·지지점을 전담 검수자에게 전달한다.
3. 지시를 반영해 한 후보를 생성한다. 단독 후보에서 외형·해부학·연기 필수 조건이 실패하면 이를 사용한 전체 장면 생성을 진행하지 않는다. 출력 포장 조건만 실패한 경우에도 해당 출력의 출고는 보류한다. 다른 목적의 제한적 참고 허용은 독립 검수자가 별도로 기록하며, 승인 원본을 대체하지 않는다.
4. 생성자와 검수자가 각각 결과 파일을 열고 아래 항목을 기록한다.
5. 통합 후 같은 항목을 다시 검사한다. 단독 통과를 장면에 자동 승계하지 않는다.

## 태고 네 다리의 필수 증거

| 항목 | 필요한 관찰 | 반려 또는 미확인 |
|---|---|---|
| 앞다리 두 개 | 각각 어깨 영역에서 팔꿈치·손목·독립 앞발로 이어지는 두 연결 | 가슴털로 연결을 숨김, 하나의 다리에서 두 발이 갈라짐 |
| 뒷다리 두 개 | 각각 골반 영역에서 허벅지·발목·독립 뒷발까지 이어짐 | 배 아래 뜬 발, 후구·프레임 밖·다른 인물로 누락을 설명 |
| 수량 | 네 다리와 네 발을 별도로 확인 | 발 네 개만 세고 다리 연결을 생략 |
| 지지 | 같은 평면에서 네 발이 자연스럽게 체중을 받음 | 뜬 발, 관통, 계단으로 크기 보정 |
| 프레임 | 귀부터 긴 몸통·후구·네 발·꼬리 끝까지 확인 | 이번 전신 증거 컷에서 크롭/소품 가림 |

원근 때문에 먼 발의 화면 y좌표는 가까운 발과 달라도 된다. 같은 픽셀 행에 네 발을 강제로 맞추지 않는다. 다리 수가 맞아도 성체 몸통·얼굴·크기·연기 검수는 별도다.

검토 중 기준 보정: 먼 골반 상부가 몸통과 가까운 허벅지 뒤에 자연스럽게 가리는 것은 정상이다. 보이지 않는 관절을 투시도처럼 드러내라고 요구하지 않는다. 가림 밖으로 나오는 기존 허벅지·하퇴·발의 윤곽이 일관되게 연결되고 네 다리가 구별되어야 한다. ‘먼 뒷발이 골반보다 앞에 있음’만으로 결함이라고 하지 않으며, 그 이유로 발을 특정 x좌표로 강제하지 않는다. 캔버스 여백 확보는 전신 균일 축소로 하고 너비·높이 점유율을 동시에 강제해 몸통을 왜곡하지 않는다.

## 모든 등장인물의 독립 항목

- 태고: 최신 `TAEGO_CURRENT.json`의 얼굴·몸, 성체 고양잇과 구조, 방향 있는 털·무늬, 왼쪽 가슴 표식, 의도한 시선. 신수형의 어깨 180cm 목표를 사람과의 관계에 적용하되 래스터 실측으로 인증하지 않는다.
- 수진: B2 얼굴·성인 비례·단발·의상·신발·책 지지, 승인 160cm 목표.
- 탈선비: 고정 목재 하회탈·갓·도포·부채 접촉. 탈을 피부 얼굴로 바꾸거나 표정 때문에 조각을 변형하지 않는다.
- 도깨비: 두 뿔·꽃 머리띠·상투·옷·짚신, 손과 방망이 손잡이·무거운 끝의 지지.
- 조이: 승인 원본의 쐐기형 부리·회흑색 윗면·노란 아랫면, 두 날개·두 다리·긴 한 꼬리·갓과 끈·깃 배열. 둥근 다른 새로 바꾸지 않는다.
- 장면: 지정된 인물을 누락하지 않음, 화자와 수신자 분리, 현재 마당/건축 상태와 소품 연속성, 원문 대사, 저장 미확인과 실제 확인 구분.
- 출력: 실제 알파·크기·해시·잘림을 기록. 체크무늬나 RGB 프리뷰를 실제 투명도로 부르지 않는다.

## 판정

PASS는 해당 항목의 관찰만 뜻한다. FAIL은 명백한 불일치, UNVERIFIED는 가림·해상도·근거 부족이다. 사용 목적의 필수 항목이 미확인이면 통과가 아니다. 실패 후보는 파일을 지우지 않고 해시·사유를 남긴다. 외형·해부학 실패본은 후속 생성의 참조에서 제외한다. 출력 포장 조건만 실패한 파일을 다른 목적에 참고하려면 제한과 독립 판정을 별도로 남기며, 그 실패 기록을 삭제하거나 출고 합격으로 바꾸지 않는다. 정확한 cm·모든 줄무늬 좌표·실제 앱의 동작은 정지 목업으로 검증했다고 하지 않는다.

이번 투명 단독 PNG의 출력 기준은 높이 점유 최대 80%, 모든 비영 알파 픽셀을 포함한 사방 최소 8% 완전 투명 여백이다. 생성 시 70–74% 높이·10% 여백을 요청한 것은 모델의 오차를 고려한 여유 목표다. 76% 미만의 가시 개체를 실패로 취급하지 않는다. `α>0` 전체 경계와 `α>16` 가시 경계를 모두 기록하며, 극히 옅은 잔여를 잘림·사지 결함과 혼동하지 않는다.
