# 한글소리 디자인 독립 검수

2026-11-04 사용자 요청: 디자이너 서브에이전트가 합의한 제작 조건을 항상 확인한다.

## 적용 범위와 담당

- 이 경로의 캐릭터·에셋·앱 이미지 목업 작업은 생성 담당과 다른 **디자이너 검수 서브에이전트**를 배정한다. 이 문서는 역할 배정 지침이며 상시 실행 중인 서비스나 자동 차단 프로그램이 아니다.
- 현재 채팅의 역할은 `/root/character_design_guard`다. 새 채팅에서는 같은 이름의 에이전트가 살아 있다고 가정하지 말고 이 역할을 새로 배정한다. 이야기 연결은 별도의 서사 검토자에게 원문 대조를 요청한다.
- 사용자 지정 디자인 스킬을 실제로 읽고 적용한다. 스킬 이름 나열, 참조 첨부, 생성자의 자체 확인만으로 독립 검수 완료를 보고하지 않는다.

## 생성 전 필수 대조

1. 최신 사용자 결정과 현재 Git·파일을 먼저 확인한다. 캐릭터 외형의 최신 승인 포인터와 승인 수치·연기 계약은 별개로 확인한다.
2. 태고의 현재 외형은 `canonical/ensemble/TAEGO_CURRENT.json`을 따른다. 다른 캐릭터의 승인 원본, 치수, 재질, 소품은 `canonical/ensemble/20261102-acting/specifications/`의 계약과 출처를 읽고 확인한다. 오래된 후보를 새 외형 기준으로 승계하지 않는다.
3. 검수자는 실제 참조 파일을 직접 열어 본다. 파일명·축소판·제작자의 설명만 확인한 항목은 `UNVERIFIED`로 기록한다.
4. 화면별 등장인물·형태(기본/신수)·크기 관계·화자/수신자·시선 대상·발/손의 지지·소품·이야기/저장/건축 상태를 명시한다.
5. 생성 전 프롬프트와 참조의 역할을 검수자에게 전달하고 지시를 반영한다. 프롬프트·참조 SHA·검수 지시를 보존한다.

## 생성 후 필수 판정

- 해부학, 고정 외형, 상대 크기, 시선·연기, 소품 접촉, 서사 상태, UI/출력 조건을 **각각** `PASS`, `FAIL`, `UNVERIFIED`로 기록한다.
- 태고 전신 검수 컷은 앞다리 2개·뒷다리 2개와 독립된 발 4개, 꼬리 1개를 확인한다. 정상적인 몸통 가림은 허용하되 가림이나 크롭으로 다리 누락을 합리화하지 않는다. 발 네 개만 세고 다리 연결을 생략하지 않는다.
- 수진·탈선비·도깨비·조이도 얼굴·몸·의상·표식·소품의 정체성을 독립 대조한다. 어느 한 인물의 성공을 전체 합격으로 보고하지 않는다.
- 사용 목적의 필수 조건이 실패하거나 미확인이면 해당 목적의 출고·정본 승격·후속 파생을 보류한다. 정지 목업을 정확한 cm, 동일 리그/줄무늬 좌표, Flutter·실기기·모션·저장 동작 검증으로 보고하지 않는다.
- 다른 사용 목적의 제한적 참고 허용은 별도 판정으로 기록한다. 예: 투명 PNG 여백 실패는 지우지 않으며, 불투명 장면의 형태 보조 참고가 허용돼도 정본 교체 또는 PNG 출고 승인으로 바꾸지 않는다. 승인 원본을 계속 우선한다.
- 실패 이미지의 전체 장면을 반복 재생성하기 전에 실패 원인과 수정 범위를 좁힌다. 합격 캐릭터까지 다시 바꾸지 않는다. 최종 통합 화면에서 가림·접지·시선·크기를 다시 검사한다.
- 독립 AI 검수 통과, 사용자 승인, 정본 등록, 앱 적용·배포는 서로 다른 상태로 보고한다.
