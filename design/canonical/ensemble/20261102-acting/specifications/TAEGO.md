# 태고: 외형·재질·치수·연기 제작 명세

작성일 2026-11-03. 기준은 PR #471 병합 커밋 `02fa1a8f2b1894a88db83370ede13f1630e823b6`의 승인 패키지다. 이 문서는 기존 정본을 상세히 설명하는 인계 명세이며 새 이미지·새 치수·새 색·새 세계관·앱 상태를 승인하지 않는다.

추가 필수: [시선·목/몸 연결·접지 계약](ACTING_MECHANICS.md)과 [마당 부탁 컷 재검토](SHOT_REVIEW_20261103.md). 내려다보기 자체를 금지하지 않는다. 머리만 꺾어 경청을 만들거나 크기를 줄여 친근함을 해결하는 방식을 보류하고 최종 카메라에서 몸과 시선이 자연스럽게 이어지는지 확인한다.

## 1. 한 캐릭터, 서로 다른 자료의 권위

태고는 **푸른 눈과 숯빛 줄무늬를 가진 성체 백호 동료**다. 원본의 얼굴·주둥이·털·표식·고양잇과 몸 구조를 유지하고, 승인된 새 시트의 눈꺼풀·귀·목·시선·자세로 연기한다. 흰 털/검은 줄/큰 덩치만 맞는 다른 호랑이가 정본을 대신하지 않는다.

[CANONICAL_APPROVAL.json](../CANONICAL_APPROVAL.json)의 승인은 외형·제작 목표와 선별된 모델/연기 참고 자료의 승인이다. **새 시트에 보이는 모든 선이 원본과 픽셀 단위로 일치한다거나 실제 cm·동일 리그·독립 스프라이트·앱 동작이 검증됐다는 승인은 아니다.** 충돌하면 원본0의 얼굴/털/무늬와 승인 수치가 우선한다. 승인된 보조 시트를 임의 폐기하거나, 그 차이를 새 평균형 태고로 혼합하지 않는다.

예전 [6표정](../../20261102/assets/taego/02-expressions-six.png)·[6포즈](../../20261102/assets/taego/03-poses-six.png), 생성 폴더의 개별 후보와 현재 **8표정/6포즈**를 혼동하지 않는다. 아래 ID의 셀 위치는 새 시트만 가리킨다. 제작 ID를 사용자 UI에 노출하지 않는다.

## 2. 승인 치수 전체와 미측정 항목

### 2.1 값이 존재하는 항목

| 항목 | 기본형 승인 제작 목표 | 신성 형태의 계산값 | 정의/주의 |
|---|---:|---:|---|
| 어깨높이 | 80cm | 180cm = 80×2.25 | 지면→어깨/기갑. 머리·귀·털 끝 높이가 아님 |
| 코끝→엉덩이 | 120cm | 270cm = 120×2.25 | 중립 측면, 꼬리 제외 |
| 꼬리 길이 | 85cm | 191.25cm = 85×2.25 | 엉덩이→꼬리 끝 |
| 신성 배율 | 균일 2.25배 | 같은 배율을 몸 전체에 적용 | 머리·가슴·앞발만 따로 키우지 않음. 오라 제외 |
| 다리/꼬리/문양 | 다리4·꼬리1·소용돌이3 | 개수 불변 | 가림은 개수 감소의 허가가 아님 |

신성 형태 열은 기존 승인 수치와 균일 배율의 **산술 결과**이며 추가로 실측/승인한 수치가 아니다. 원본 래스터가 이 치수와 일치한다고 검사한 적은 없다. `workflow.targets_not_tests`의 몸 목표2%/비례 목표3%는 향후 보정 모델 QA용 목표이지 현재 PNG 합격 허용오차가 아니다.

크기 비교는 같은 지면·같은 깊이·보정된 정면/측면 카메라에서 한다. 수진은 맨발 정수리160cm이며 머리카락/신발을 제외한다. 큰 신성 태고가 지정된 장면에서는 태고 **어깨180cm**와 수진 정수리를 비교한다. 태고 머리/귀만 수진보다 높게 그려 놓고 이 조건을 충족했다고 하지 않는다. 앉기/엎드리기·가림·원근으로 화면 높이가 달라지는 것과 실제 균일 배율 변경을 구별한다.

현재 귀환 대표 장면에서는 사용자가 수진보다 작은 태고를 거절했고 큰 성체 동료를 유지하도록 수정했다. 이전 P6 축소 원고나 작은 후보를 근거로 이 장면의 크기를 되돌리지 않는다. 다른 장면의 형태 선택은 해당 원고/승인 계약을 따른다. **피로·슬픔·안도 자체가 축소/새끼 변환 트리거는 아니다.** 선택된 형태의 크기를 유지하며 목·귀·눈·지지 자세로 표현한다.

원근이 다른 래스터에서 픽셀 비율을 나누어 새 cm나 얼굴 목표를 만들지 않는다. 자료 없는 부분은 일반 호랑이의 생물학 지식이나 생성기의 상식으로 채워 넣지 않는다.

## 3. 머리에서 발끝까지의 고정 외형

### 3.1 두상·눈·귀·주둥이·입

| 부분 | 보존할 시각 설계 | 바꿀 수 있는 연기/미확인 경계 |
|---|---|---|
| 두상 | 성체 백호의 이마→콧등의 긴 중앙 면, 풍부한 양 볼털, 분리된 수염 패드와 작은 흰 턱. 귀·볼·목이 한 원형 공으로 합쳐지지 않게 한다. | 고개 회전/기울임은 가능. 새끼의 큰 둥근 머리와 짧은 중안면으로 교체하지 않음 |
| 눈 | 회청색/푸른 홍채, 어두운 동공과 눈가, 원본의 눈꺼풀·안와 관계. 원본은 어두운 중앙 동공이 둥글게 읽히며 사람처럼 넓은 흰자위를 강조하지 않는다. | 눈꺼풀 이완/조임과 시선 이동은 새 표정 ID를 따른다. 새 눈 간격/커진 눈·레이저 발광·사람 눈썹 추가 금지 |
| 귀 | 머리 상단 양쪽의 둥근 귀, 어두운 바깥 가장자리와 밝은 속털, 같은 귀 뿌리. 원본 귀는 원래 둥글다. | 듣는 쪽 회전, 걱정/회상에서 낮추기는 가능. 둥근 귀 하나만 보고 곰이라 판정하거나 다른 종의 뾰족귀로 고치지 않음 |
| 코 | 털 없는 매끈한 분홍 갈색 면, 어두운 바깥/콧구멍과 콧등의 깊이. 털과 구별되는 부드러운 하이라이트. | 조명으로 밝기가 달라질 수 있으나 검은 새 코를 기본색으로 채택하지 않음. 광택/PBR 수치는 미정 |
| 주둥이 | 옆/약한3/4에서 코가 수염 패드 앞으로 돌출되고 콧등·코끝·입선·턱이 나뉜다. 양쪽 흰 수염 패드와 어두운 수염점, 흰 수염을 유지. | 회전하면 먼 쪽 패드/눈이 좁아 보일 수 있다. 이를 새 얼굴 폭으로 고정하지 않음. 코를 임의로 늘리는 것도 재설계임 |
| 입·턱 | 코 아래 중앙선, 어두운 입선과 작은 흰 턱 덩어리. 온화한 기본형과 승인된 작고 절제된 입 반응. | 현재 새8표정은 거대한 송곳니/입을 벌린 맹수 연기가 기준이 아니다. 없는 치열·송곳니를 만들어 감정을 과장하지 않음 |
| 수염 | 수염 패드에서 바깥쪽으로 가늘고 길게 뻗는 흰 선, 패드의 점과 시작 관계. 털 수염/입선/줄무늬를 혼동하지 않음. | 회전·표정에 따라 겹침은 가능. 수염 수/길이 수치와 뿌리3D좌표는 미측정. 끝이 잘리거나 한 덩어리 플라스틱이 되면 보류 |

### 3.2 목·몸통·사지·발·꼬리

| 부분 | 고정 기준 | 가변/검수 경계 |
|---|---|---|
| 목·가슴 | 볼 뒤에서 목으로 이어지는 털 방향, 턱 아래와 가슴의 구분, 앞다리 사이의 가슴 흐름. 원본의 풍부한 볼/목털을 유지하되 사자갈기를 덧붙이지 않음. | 목을 낮추거나 귀를 움직일 수 있다. 넓은 목/가슴만 크게 남겨 둥근 털덩어리로 만들지 않음 |
| 어깨·등·흉곽 | 네 발로 선 성체의 어깨→긴 흉곽→허리→후구가 연결된다. 옆으로 긴 몸통과 배 아래 공간이 구분된다. | 몸통 굽힘/체중 이동은 포즈를 따른다. 짧은 통몸·높은 어깨 혹·곰형 등으로 대체하지 않음 |
| 앞다리 | 어깨에서 길게 내려오는 튼튼한 두 앞다리와 손목/발의 흐름. 원본의 줄무늬가 해당 면을 따라 이어짐. | 듣기·관찰에서 몸을 낮춰도 뼈 길이 자체를 줄이지 않음 |
| 뒷다리 | 후구·허벅지 덩어리와 굽은 지지 관계, 서로 구분되는 두 뒤발. | 앉은 포즈의 접힘을 짧아진 다리로 오인하지 않음. 가린 다리를 없다고 세거나 새 다리로 보완하지 않음 |
| 발 | 고양잇과의 둥근 발가락 덩어리와 발목, 원본 끝부분의 짧고 어두운 선/단부를 따름. | 곰 발·긴 사람 손가락으로 교체 금지. 발톱을 항상 길게 노출하거나 오답/보호마다 위협용 발톱을 추가하지 않음 |
| 발톱·육구 | 보이는 발가락 끝은 원본을 대조한다. 발바닥 면은 현재 충분한 기준이 없으므로 미확정. | 발톱 개수/수납 구조, 육구 도형·색을 임의 정본화하지 않음. 바닥 보이는 새 포즈는 근거와 별도 검토 필요 |
| 꼬리 | 몸통 뒤에서 연결되는 한 개의 긴 꼬리, 번갈아 이어지는 짙은 띠와 어두운 끝, 털이 덮인 둥근 끝. | 방향/완만한 곡률은 포즈를 따른다. 짧은 곰 꼬리·깃털 부채·사자 꼬리 술로 바꾸지 않음. 뿌리·끝 중 가린 부분은 미확인 |

## 4. 털 종류·방향·색·재질·조명

아래의 ‘털 종류’는 **일러스트에서 보이는 표현 범주**다. 생물학적 속털/가드헤어 구조나 길이·밀도 측정 결과가 아니다.

| 영역 | 시각적 털 표현과 흐름 |
|---|---|
| 이마·콧등·눈가 | 짧고 정돈된 털결이 두상 면을 따라 흐른다. 이마 분기 줄무늬와 눈꺼풀 경계를 털 노이즈로 지우지 않음 |
| 수염 패드·턱 | 촘촘하고 부드러운 흰 털, 두 패드의 부피와 작은 턱을 구분. 수염은 별개의 가는 긴 선 |
| 볼·귀 안 | 바깥으로 퍼지는 긴 볼털과 귀 안의 밝은 속털이 원본 윤곽을 만든다. 얼굴 전체를 공 모양 솜으로 확대하지 않음 |
| 목·가슴 | 턱 아래에서 가슴으로 내려오는 비교적 풍부한 흰 털. 목/흉곽의 면과 앞다리 연결을 남김 |

공통 광원은 lock의 **부드럽고 따뜻한 주광+중립 보조광**, 재질별 표면 차이와 접촉 그림자다. 광원 방향/색온도/노출/그림자 반경의 승인 수치는 없다. 서사에 맞는 조명 변화가 허용돼도 형태·눈 색·줄무늬·문양이 읽혀야 한다. 푸른 오라는 별도 상태이며 기본 흰 털의 정체성을 바꾸거나 얼굴 실패를 가리는 용도가 아니다. 털을 매끈한 플라스틱/점토 한 재질로 덮지 않는다.

## 5. 줄무늬 지도와 한쪽 가슴 문양

정본은 ‘흰 호랑이에 검은 줄을 충분히 그린 그림’이 아니다. 원본0의 각 표식을 위치·분기·이웃 관계로 대조한다. 좌표화된 UV/완전한 뒤·반대쪽 원본은 아직 없다.

| 영역 | 원본에서 유지할 관계 |
|---|---|
| 이마 중앙 | 정수리 쪽 중심 줄과 양쪽으로 갈라지는 층, 콧등 위로 내려오는 중앙 분기. 임의의 글자/새 문장/왕관 무늬를 넣지 않음 |
| 눈 바깥·볼 | 눈 주변 곡선을 따라 내려오는 여러 굽은 띠, 볼 가장자리의 굵은 띠와 흰 수염 패드의 경계 |
| 코 옆·입 주변 | 수염점과 줄무늬를 구분하고 원본 패드/입선의 좌우 관계 유지. 무늬로 웃는 사람 얼굴을 새로 그리지 않음 |
| 목·가슴·어깨 | 사선으로 내려오는 짙은 띠가 흰 가슴/다리로 이어지는 방향. 문양 때문에 기존 줄을 다른 쪽으로 옮기지 않음 |
| 옆구리·등 | 불규칙한 길이/굽힘/분기가 있는 띠들이 몸통의 길이와 곡면을 따른다. 다른 시트의 줄을 조합한 새 무늬 지도 금지 |
| 앞·뒷다리 | 몸통에서 각 다리로 이어지는 면의 줄과 관절 주위 굽힘. 다리를 접어 줄이 겹친 것을 삭제/추가 무늬로 해결하지 않음 |
| 꼬리 | 몸에서 끝으로 이어지는 띠의 순서와 어두운 끝. 반전/루프 복제로 새 꼬리 무늬를 만들지 않음 |

문양은 **원본에서 장식이 붙은 한쪽 가슴/몸통면**에 고정된다. 정면 원본에서는 화면 오른쪽 가슴에 보인다. 이것은 모든 포즈에서 화면 오른쪽에 떠 있어야 한다는 뜻이 아니다. 몸이 회전하면 같은 몸통면을 따라 이동하고 반대쪽에서 가려질 수 있다. 해부학적 좌우 rig 노드/부착 좌표는 미등록이다.

새 **T-P04(자세 시트2행1열)**는 반대 몸통면으로 진행하는 보정본이다. 이 면에 배지를 하나 더 그려 양쪽 문양을 만들지 않는다. 문양이 안 보이는 올바른 가림과 실제 누락은 면/회전으로 구분한다. 보이는 경우에는 세 소용돌이·긴 꼬리·금/청록 경계·털과의 접착 관계를 원본으로 검수한다. UI의 아이보리 구름과 이 문양은 다른 자산이다.

## 8. 단독·장면·말듣기·상태/접근성 계약

1. **단독 기준:** 얼굴·어깨·등·옆구리·후구·발·꼬리와 해당 면의 문양을 읽을 수 있는 뷰를 쓴다. 근접/큰 포즈가 필요한 경우에도 가려진 부위는 미확인으로 표시한다. 단독 컷의 화면 밖 시선 방향만으로 실제 다른 화자를 정확히 본다고 인증하지 않는다.
2. **장면의 시선:** 현재 화자 한 명→그 화자를 듣는 태고→사용자의 행동 대상→확인된 결과의 순서로 초점을 연결한다. 눈동자와 고개/코 방향이 같은 대상을 가리키는지 본다. 멀리 떨어진 카메라/먼산을 계속 보는 단체사진으로 만들지 않는다.
3. **다른 인물과 크기:** 장면에 지정된 형태와 깊이를 유지한다. 좁은 화면은 카메라/배치를 조정할 문제이며 태고 삭제·새끼 축소·목가슴만 확대하는 해결을 쓰지 않는다. 크기 비교용 어깨·발 지면을 가렸으면 크기 QA는 미확인이다.
4. **단일 화자와 학습 집중:** 태고의 귀/고개/시선은 대화 이해를 돕는다. 동시에 모든 인물이 과장된 연기를 하거나, 반복 호흡/부유/확대축소로 글자·선택·읽기 기준선을 흔들지 않는다.
5. **도움·실패·재개:** 오답에서 같은 문항·입력·조각을 유지하고 조용히 기다리는 반응을 쓴다. T-E05/06을 학습자에 대한 걱정/실망/벌로 오용하지 않는다. 도움 완료와 독립 숙달·지연 유지, 녹음/TTS와 발음 합격을 구별한다.
6. **실제 결과 소유:** 저장 확인 전 성공/안도 연기를 실제 저장 완료처럼 쓰지 않는다. 감사/배지/태고 반응이 건축 소유·엽전·숙달을 발생시키는 별도 소유자가 되지 않는다. 현재 원고·실제 소유에 맞는 건축/단서/신수 공개 상태를 유지한다.
7. **피로와 회복:** 선택된 기본형/신성형의 크기·골격을 유지하고 T-E06/T-P06 같은 귀·눈·목·휴식으로 표현한다. 별도 승인된 서사 전환 없이 모습이 작아지거나 오라 소모가 아기화로 이어지지 않는다.
8. **TTS/영상/모션:** 실제 시작·정지/가시성·route·앱 생명주기와 연결해 화면 밖/백그라운드에서 멈춘다. 읽기/입력 중 반복 연출을 줄이고 동작 줄이기·건너뛰기에서도 동일 상태/다음 행동을 제공한다. 현재 시트는 립싱크·영상·애니메이션이 아니다.
9. **UI/접근성:** 의미가 태고의 작은 표정이나 색에만 담기지 않게 현재 화자/행동/상태를 실제 텍스트·접근성 의미로 제공한다. 320/390dp·100%와 별도200% 글자,48dp 터치·safe area·키보드/보조기술 검사는 앱 단계의 별도 QA다. 정지 참고 시트로 통과를 주장하지 않는다.

## 11. 검수 인계표

검수자는 각 항목을 **확인/불일치/가림·자료부족으로 미확인**으로 구분한다. 미확인을 확인으로 올리지 않는다.

- 기준: 원본0·현재 model/expressions/poses의 정확한 경로/SHA와 선택 ID/셀을 기록했는가.
- 머리: 두상, 콧등/코끝/패드/턱, 눈가·동공·귀 뿌리와 볼털이 원본의 성체로 읽히는가.
- 표식: 이마 분기·눈 바깥/볼·목/어깨·옆구리·다리·꼬리의 무늬를 같은 몸의 위치로 추적했는가.
- 문양: 한쪽 부착면·세 소용돌이·긴 꼬리·금/청록 경계를 확인했는가. 반대 면이면 정상 가림인가.
- 몸: 어깨/긴 등/후구·네 다리 지지와 한 꼬리가 연결되는가. 가려진 부위와 실제 형상 오류를 구분했는가.
- 크기: 지정 형태·균일 배율·같은 지면/깊이를 확인했는가. 머리높이를 어깨높이로 대신하지 않았는가.
- 연기: 실제 현재 화자/학습 대상과 눈·코·귀·목 방향을 맞췄는가. 피로를 축소, 오답을 실망/벌로 연출하지 않았는가.
- 장면: 다른 인물/소품/책/자모/현재 소유 건축·공개 단서도 재대조했는가. 가림으로 실패를 숨기지 않았는가.
- 출력: 실제 알파·매트 가장자리·수염/털·발/꼬리 여백을 확인했는가. 원본 RGB·전체 시트·독립 스프라이트를 구별했는가.
- 런타임: 립싱크/애니메이션·저장/보상·TTS 소유·백그라운드·동작 줄이기·작은 화면/큰 글자·기기 검사를 별도 기록했는가.

현재 승인 상태는 참고 자료의 정본 보존이다. 각 셀은 아직 독립 PNG/상태 앵커/애니메이션으로 내보내지 않았으며, 이 Markdown 작성은 그 작업을 수행한 것이 아니다.
