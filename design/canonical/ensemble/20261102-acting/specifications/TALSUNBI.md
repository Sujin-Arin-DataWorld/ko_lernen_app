## 3. 정수리부터 턱까지: 목탈은 고정 물체

탈선비의 얼굴은 피부 위의 웃음 주름이 아니라 **항상 웃는 조각을 가진 목재 하회탈**이다. 선비는 성인 정령이며, 맨얼굴 노인의 흰 수염을 추가해서 연령을 표현하지 않는다. 두 눈구멍·조각 눈썹·코·볼·입·턱의 관계를 하나의 같은 물체로 보존한다.

| 부위 | 형상·색·재료 관찰과 고정 요소 | 가림·측정 한계와 금지 변경 |
|---|---|---|
| 이마/탈 윗외곽 | 둥근 이마에서 길고 넉넉한 아래 얼굴로 이어지는 따뜻한 황갈색 면. 가운데로 굽어 내려오는 얕은 홈과 위 이마의 곡선 홈이 목재 면을 나눔 | 갓 아래 실제 정수리는 가려짐. 매끈하고 짧은 새 얼굴, 양쪽을 완전 미러로 만든 탈로 바꾸지 않음 |
| 눈구멍 | 검고 좁은 웃는 초승달 틈 두 개. 주변의 두꺼운 목재 위·아래 눈꺼풀과 분리되어 읽힘 | 검정 부분은 사람 홍채/흰자 조합이 아님. 눈을 크게 뜨거나 슬프게 처뜨려 새 감정을 조각하지 않음 |
| 눈썹 | 짙은 먹색 활 모양이 눈꺼풀과 별개로 솟음. 가운데 두께와 가늘어지는 끝, 안쪽의 굽음이 있음 | 털 눈썹·얇은 선 눈썹으로 치환하지 않음. 각도에 따른 보이는 비대칭과 실제 형상 변경을 구분 |
| 코 | 긴 콧등이 아래로 내려오고 둥글게 늘어진 코끝과 별도 콧방울 두 덩어리로 연결됨. 콧방울 아래 어두운 틈이 깊이를 만듦 | 코끝만 작은 단추처럼 만들거나 날카로운 매부리코로 바꾸지 않음. 코의 정확 돌출량은 미측정 |
| 눈 밑/볼 | 가로로 긴 두꺼운 볼 덩어리, 그 위아래 곡면과 홈의 층. 볼 아래와 입가 옆으로 깊은 접힘이 내려옴 | 단순 피부 주름 몇 줄로 대체하거나 볼 덩어리를 지우지 않음 |
| 입/윗니 | 양끝이 올라간 넓은 고정 웃음. 검은 입 안, 밝은 좁은 윗니 띠, 아래의 목재 입술 면이 구별됨 | 윗니의 정확 분절 수는 작은 뷰에서 미확인. 사람 발화 모핑·입 다물기·입꼬리 내림·다른 치열 추가 금지 |

| 턱 | 둥근 큰 턱 면 안을 곡선/세로 홈이 나눔. 얇은 검은 외곽, 목재 턱, 아래의 검은 리본이 별개임 | 뾰족한 턱수염·짧은 새 턱·다른 원형 문양으로 변경하지 않음 |
| 목결/표면 | 황갈색·호박색 목재 결, 얕은 새김, 곡면의 넓은 하이라이트와 홈의 어두운 그림자 | 피부 모공·금속·유광 플라스틱으로 치환하지 않음. 나무 종/칠 종류·정확 RGB·PBR 수치는 미측정 |
| 탈 뒤 머리 | 갓 아래 짙은 머리와 뒤/옆머리 덩어리가 보임 | 갓 안쪽 묶음 구조·모근·완전한 뒤통수는 일부 가림. 새 흰 장발/긴 수염을 보태지 않음 |
| 귀/목 피부 | 탈 뒤에 사람 귀·목의 따뜻한 피부색 일부가 보임. 나무 얼굴과 재료가 다름 | 전체 머리를 나무로 만들지 않음. 피부의 정확 색·SSS·나이별 주름 수치는 미측정 |

얼굴 확대의 작은 점·미세 결은 원본의 관찰 정보다. 다른 작은 뷰에서 보이지 않는 점을 근거 없이 별도의 필수 문장으로 확대하거나, 압축 흔적을 새 조각으로 해석하지 않는다.

## 6. 허리띠와 장식의 원본 내부 차이

띠는 탁한 청록/세이지색 넓은 천의 여러 겹, 두꺼운 매듭, 길게 내려오는 천 끝과 술이다. 별도 짙은 끈에 금빛·청록빛 장식과 술이 달린다. 띠와 매듭의 폭·길이·구슬 수의 전 방향 완전 지도는 미측정이다.

**큰 왼쪽 인물에서는** 금색 큰 구슬 → 큰 청록 구슬 → 긴 짙은 연결부 → 작은 청록 구슬 → 금색 테 → 술의 순서가 읽힌다. **오른쪽 띠 디테일 패널은** 중간 연결부가 짧고 아래 작은 청록 구슬이 생략된 표현이다. 같은 시트 안의 이 차이를 보존해서 기록한다. 큰 인물 재현 작업을 디테일 패널 하나로 뒤집어 “구슬을 새로 추가했다”고 오판하지 않는다. 반대로 어느 표현이든 마음대로 합쳐 새로운 장식으로 만들 수 있다는 뜻도 아니다. 작업마다 직접 기준 뷰를 명시한다.

청록색 천에는 낮은 대비의 긴 문양/짜임이 보이며 띠 끝과 술의 가닥은 분리된다. 반짝이는 금빛 장식은 천과 다른 표면으로 보이지만 실제 금속 종류·금도금·roughness/metallic 값은 **미측정**이다.

## 7. 하체에서 발끝까지

| 영역 | 관찰한 기준 | 한계 |
|---|---|---|
| 바지 | 도포 아래로 넉넉한 회남색 바지, 낮은 대비의 천 문양과 모이는 큰 주름 | 허벅지/무릎/종아리의 실제 둘레와 뼈 길이를 이 부피로 추정하지 않음 |

| 신 윗면 | 어두운 회흑/남색 전통 신, 밝은 테와 둥글게 올라간 앞코. 전경 쪽 신의 앞면과 반대 신의 측면이 다르게 보임 | 신 재료를 고무/가죽/직물 중 하나로 확정하지 않음. 신 길이·굽 높이·밑창 물성 미측정 |

## 8. 부채·책·붓

부채는 상아색 접이식 종이 면, 짙은 갈색 살·바깥 살과 축, 검은 대나무 수묵 줄기/잎이다. 도구 확대에는 축 아래의 고리가 보인다. 펼침·반접음·닫음, 손/가슴/무릎 높이와 원근은 달라질 수 있으나 종이와 살을 같은 소품으로 추적한다. 수묵 줄기와 잎의 위치를 새로운 그림으로 바꾸거나 두 부채를 동시에 복제하지 않는다. 종이 두께·살 개수의 확정 전수·부채 지름·실제 대나무 수종·종이 반투명도는 미측정/미확인이다.

도구 확대의 책은 낡은 갈색 계열 두 권, 붓은 밝은 털/어두운 끝과 긴 어두운 자루로 보인다. 읽기·쓰기 포즈의 소품 참고이며 모든 장면에 책 두 권과 붓을 추가하라는 규칙이 아니다. 서사의 잠든 책과 개인 도구를 같은 파일이라는 근거 없이 동일시하지 않는다. 원본 책 표지의 작은 글씨는 판독 가능한 실제 콘텐츠/진도 ID로 사용하지 않는다.

## 9. 색·빛·표면 수치와 알파

| 계열 | 원본에서 읽히는 방향 | 수치 상태 |
|---|---|---|
| 목탈 | 따뜻한 황갈/호박색, 깊은 홈의 갈색 그림자 | RGB/HEX/Lab·스펙트럼·색공간 보정 팔레트 미측정 |
| 피부 | 따뜻한 살구/갈색의 손·귀·목, 천/나무와 다른 부드러운 빛 | 정확 RGB·SSS·모공/피부 shader 미측정 |
| 갓/리본 | 회흑/먹색, 망과 매트한 리본의 차이 | opacity·IOR·roughness·망 셀·두께 미측정 |
| 겉옷/안감 | 상아색/남색·회청색. 큰 주름과 저대비 문양 | albedo/normal/displacement·직물 스캔·UV 미측정 |
| 띠/장식 | 탁한 청록·세이지, 금빛 장식 | 정확 색·metallic/roughness 미측정 |
| 광원 | 부드러운 따뜻한 주광과 중립적인 보조광, 접촉 그림자와 재료별 빛 반응 | 광원 각도·색온도·lux·노출·HDRI 미측정 |

색 이름은 시각적 기록이며 신규 색 토큰 승인이 아니다. 원본에 들어간 조명색을 새 albedo 값으로 추출해 재질을 고정하지 않는다. 명암이 변해도 목재·피부·천의 차이는 유지한다. 기본 캐릭터에 책의 마법빛·금빛 띠·후광·새 문장을 영구 추가하지 않는다.

원본 시트는 **RGB 전체 그림이며 투명 스프라이트가 아니다.** 캔버스 배경·설명 글자·다른 뷰를 캐릭터 일부로 편입하지 않는다. 알파 없는 원본을 RGBA라고 부르거나, 시트 승인만으로 독립 컷아웃/경계/앵커가 검증됐다고 말하지 않는다.

기존 로컬 검수 재사용 근거는 `C:/dev/hangulsori/_codex_artifacts/season1-story-image-revision-20261102/TALSUNBI_CANONICAL_STUDY.md` 및 `TALSUNBI_SINGLE_TEST_REVIEW.md`다. 단독 생성 테스트 `a4176265390ec1bae298e17d1d6321abe4bad8e2f0381c1b8367f51d4c83d1e4`는 실제 RGBA/알파0–254가 확인된 별도 후보이며 현재 정본 원본을 대체하지 않는다. 알파0 픽셀의 숨은 갈색 RGB만 보고 불투명 배경 실패로 판정하지 않는다. 이 명세는 후보 파일을 복사/승격하지 않았다.

## 10. 연기·서사·검수 인계

프로필의 일반 `expression/gaze` 가변 규칙보다 탈선비의 **목탈 고정** 규칙을 구체적으로 적용한다. 얼굴 감정은 목/고개 방향, 몸의 거리, 어깨·손·부채·서 있는 자세로 표현한다. 표정 변화 때문에 눈구멍·눈썹·코·볼·입·턱을 모핑하지 않는다. 원본의 쓰기·갓 잡기·책 설명·장난기·초대 포즈는 연기 참고이며 동일 rig의 검증된 관절 회전은 아니다.

책 안에서 잠든 정령의 귀환 연출은 캐릭터 몸체와 별도 상태다. 종이빛에 가렸다고 탈·발·몸통 실패를 합격시키지 않고, 연기 하반신/새 수염 마법사로 바꾸지 않는다. 이 문서는 독립 새 화면·런타임 트리거·TTS·저장·보상 로직을 규정하거나 구현하지 않는다.

제작 인계와 QA는 다음 순서로 한다.

1. 현재 프로필과 실제 원본 SHA, 작업에 쓰는 큰 인물/턴어라운드/세부 뷰를 기록한다. 파일명이나 이전 후보가 기준을 대체하지 않는다.
2. 탈 외곽 → 눈구멍/눈썹 → 코/볼 → 입/윗니 → 턱/리본 → 갓/옆 끈 순으로 대조한다. 같은 설계/확인된 재해석/원근·가림 미확인을 분리한다.
3. 겉옷·안감·띠/장식·손·하체·신·부채를 같은 뷰와 비교한다. 보이는 한 부품이 맞아도 가려진 부품은 미확인이다.
4. 같은 지면·깊이와 보정된 시점이 있을 때만 승인 치수를 검증한다. 원근 포즈를 줄자로 쓰거나 비선형으로 얼굴을 늘려 맞춘 뒤 동일성을 선언하지 않는다.
5. 실제 알파 합성, 갓·술·부채·손가락·발끝의 경계/잘림·중복, 몸체와 그림자의 분리, 100% 원본과 실제 사용 크기를 별도로 검사한다. 확대 표시가 없는 정보를 복원해 주지는 않는다.
6. 한 포즈의 조건부 판정을 다른 포즈·언어·다섯 동료 장면·모션·기기에 자동 승계하지 않는다. 실제 조작·동작 줄이기·백그라운드 중지·TTS 소유권은 구현 단계의 별도 검수다.
