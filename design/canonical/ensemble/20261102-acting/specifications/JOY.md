# 조이(Joy) — 외형·치수·재질·연기 제작 명세

작성·직접 확인: 2026-11-03, Europe/Berlin. 문서 기준 checkout은 `codex/character-illustration-spec-20261103`, HEAD 및 당시 `origin/main`은 `02fa1a8f2b1894a88db83370ede13f1630e823b6`이다. 이 문서는 PR #471로 등록된 `20261102-acting` 정본의 세부 해설이며 이미지·원본·승인 범위를 변경하지 않는다.

조이는 **성체 비율을 가진 까치의 축소/기본형**이다. 병아리·참새·까마귀·인간형 새로 바꾸지 않는다. 같은 인물의 발견·안내·함께 고민·기다림을 연기하되 얼굴, 종, 성체 비율, 몸통 문장과 두 긴 날개·두 다리·한 긴 꼬리를 유지한다.

- 앱 장면/목업의 자동 생성, 앱 코드 변경, 실기기 검증·배포.

### 1.1 이전 3뷰 우선 overlay와의 충돌

로컬 `JOY_CANONICAL_STUDY.md`는 당시 사용자 요청을 해석해 `exec-04d456e6-b861-4085-af5e-64c34615d477.png`의 3뷰를 얼굴 최우선으로 적었다. **현재 main의 규칙은 다르다.** 그 3뷰와 같은 바이트가 지금 `assets/joy/model.png`로 등록되어 있으나 역할은 `secondary model/style reference; identity and numeric targets retain authority`다. 얼굴·갓·팔레트는 00 원본이 통제한다.

따라서 과거 문서의 권위 순서를 현재 제작에 그대로 승계하지 않는다. 3뷰를 삭제하거나 00과 바꿔치기하지도 않는다. 현재 얼굴 판단에는 00, 시점·구조 이해에는 모델 보조, 연기에는 승인 표정/포즈를 각각 사용한다.

### 1.2 원본 그림 안의 문장 충돌

직접 확인한 00 그림의 문장은 두 소용돌이로 보이지만, 현행 lock과 별도 문장 원본은 **세 소용돌이**를 고정한다. 일부 모델/연기 그림의 문장 외곽도 별도 문장 원본과 완전히 같다고 입증되지 않았다.

이 차이를 새 얼굴·새 문장으로 평균내거나 승인 원본을 덮어써 해결하지 않는다. 세 소용돌이·몸통 부착이라는 현재 규칙을 명시하고, 실제 파생 제작에서 상충하는 세부가 드러나면 충돌로 기록해 검수한다. 이미지 승인만으로 상충 세부의 자동 교체가 허용되지는 않는다.

## 3. 승인 치수 전체와 측정 정의

다음 7개 기본형 값의 상태는 모두 **`USER_APPROVED_DESIGN_TARGET`**이다. 2026-11-02에 승인된 허구 캐릭터의 **제작 목표**이며, 기존 래스터를 자로 재어 얻은 물리 치수가 아니다. 생물학적 까치의 표준 치수라고도 부르지 않는다.

| JSON 필드 | 승인값 | 측정 시작·끝과 제외 범위 |
|---|---:|---|
| `base_body.standing_height` | **40 cm** | 중립으로 섰을 때 발바닥 지지면→해부학적 정수리. 갓·받침돌·전시 블록 제외. 꼬리 길이와 혼동 금지 |
| `base_body.trunk_length` | **24 cm** | 중립 측면의 어깨 뿌리→엉덩이/꼬리뿌리. 머리·목·꼬리 제외 |
| `base_body.folded_wing_length` | **40 cm** | 중립 측면에서 어깨의 날개뿌리→접힌 날개의 가장 긴 첫째날개깃 끝. 이미지 평면에 투영된 디자인 치수 |
| `base_body.extended_wing_length` | **60 cm** | 곧게 편 날개 뿌리→가장 긴 첫째날개깃 끝 |
| `base_body.wingspan` | **128 cm** | 펼친 왼 날개 끝→오른 날개 끝. 두 날개의 전체 폭이며 꼬리·오라 제외 |
| `base_body.tail_length` | **54 cm** | 엉덩이의 꼬리뿌리→가장 긴 꼬리깃 끝. 접힌 날개 끝에서 시작하지 않음 |
| `base_body.gat_added_height` | **10 cm** | 해부학적 정수리 위로 갓이 추가하는 높이. 갓 관의 전체 물체 높이·챙 지름과 같은 값이 아님 |

**승인된 파생 비율:** `folded_wing_over_trunk=40/24=1.6666666666666667`, `extended_wing_over_trunk=60/24=2.5`, `tail_over_trunk=54/24=2.25`. 상태는 `USER_APPROVED_DERIVED_DESIGN_TARGETS`다.

**고정 개수:** 날개 **2**, 다리 **2**, 꼬리 **1**, 문장 소용돌이 **3**. 하나의 꼬리에 여러 깃이 갈라져 보이는 것을 여러 꼬리로 세지 않는다.

**신수형:** `divine_scale=2.5`가 승인된 무차원 배율이다. 같은 몸 전체를 균일하게 확대하며 날개/몸통·꼬리/몸통 비율을 바꾸지 않는다. 오라의 바깥 경계는 치수에서 제외한다. 몸만 키우고 날개를 짧게 남기거나, 오라로 누락된 날개·꼬리를 대신하지 않는다. 별도 신수형 머리·부리·발·갓 세부 cm를 새로 승인한 것으로 해석하지 않는다.

### 3.1 치수를 해석할 때 지킬 것

- 기본형의 40 cm와 갓 추가 10 cm를 같은 지면·중립 자세에 적용한 목표 표시높이는 산술상 50 cm다. **새 승인 치수 또는 현재 PNG 실측값이 아니다.** 일반 체고와 표시높이를 분리해 적는다.
- 접힌 길이 40과 편 길이 60은 같은 날개의 자세·투영 차이를 포함하는 디자인 정의다. 펼칠 때 깃이나 뼈를 늘려 다른 날개를 만드는 지시가 아니다.
- `wingspan=128`을 `2×60=120`으로 임의 수정하지 않는다. 반대로 차이 8 cm를 승인된 어깨 폭이라고 새로 등록하지 않는다.
- 몸통·날개·꼬리는 서로 겹치는 구조다. 24+40+54를 더해 전체 몸 길이라고 부르지 않는다.
- 비교는 같은 지면·같은 카메라 깊이와 보정된 정면/측면에서 한다. 돌 위의 조이, 비행 중 조이, 원근이 다른 인물 줄세우기는 실제 크기 증거가 아니다. 수진 160 cm와 비교할 때도 갓·받침을 포함해 조이를 크게 보이게 하지 않는다.
- lock의 `body_target_tolerance_percent=2`, `proportion_target_tolerance_percent=3`은 **후속 보정 모델 QA를 위한 제안 허용차**다. 생성 PNG가 ±2%/±3% 정확하다고 검증되었다거나 이번 문서에서 적용 시험을 통과했다는 뜻이 아니다.

### 3.2 아직 수치가 없는 항목

머리 높이·폭, 부리 길이·폭·각도, 눈 간격·눈구멍 비율·홍채 크기·흰자 면적, 목 길이, 개별 깃 개수·길이, 발가락/발톱 길이, 갓 챙 지름·두께·끈 길이, 문장 cm와 부착 오프셋은 **미측정/별도 승인값 없음**으로 둔다. 승인된 7개 값으로 이 숫자를 역산해 사실처럼 채우지 않는다. 정확 RGB/HEX·색온도·노출·PBR roughness/metallic/IOR·메시/리그 값 역시 알려진 값이 아니다.

## 4. 머리에서 발끝까지 고정 외형

아래 색과 재질은 원본을 직접 보고 적은 **정성 관찰**이다. 정확 샘플 색이나 실제 셰이더 수치가 아니다. 좌우는 화면 좌우와 캐릭터 좌우를 구분해 기록하고, 반대 시점을 만들려고 전체 래스터를 자동 좌우 반전하지 않는다.

| 부위 | 고정할 형태·색·표면 | 연기 중 바뀔 수 있는 것 / 금지 경계 |
|---|---|---|
| 정수리·얼굴 | 00의 성체 머리와 얼굴 비율. 회흑색·차콜 계열 작은 깃이 얼굴 면을 이루며 밝은 볼 패치·인간 귀·머리카락은 없음 | 머리 회전·기울임은 가능. 큰 머리/짧은 몸의 아기새 비율, 둥근 흰 볼, 새 종의 얼굴로 치환 금지 |
| 눈·눈꺼풀 | 금빛/호박색 홍채, 검은 동공, 작은 반사. 어두운 눈 주변·윗눈꺼풀과 눈썹 깃의 구조. 원본 얼굴의 배치와 비율 유지 | 시선·눈꺼풀·눈썹 깃으로 표현. 보는 방향 때문에 밝은 눈 영역이 드러날 수 있으나 눈알 자체를 키우거나 큰 흰 원으로 바꾸지 않음. 흰자 수치 한계는 미측정이며 새 시트의 밝은 영역을 얼굴 재설계 허가로 쓰지 않음 |
| 윗부리·아랫부리 | 회흑색의 각진 단단한 윗면, 작은 콧구멍, 노란 아랫면과 입 경계. 두 색의 분할과 00의 쐐기 형태 | 닫힘·개폐·시점 변화 가능. 전체 노랑/주황 부리, 가늘고 긴 바늘 부리, 사람 입술·치아 추가 금지. 열린 입 속 따뜻한 색은 연기 참고이며 윗부리 색을 바꾸지 않음 |
| 목 앞·옆 | 턱 아래부터 가슴으로 이어지는 어두운 겹깃. 아래로 모이는 V형 목깃 끝과 세로로 이어지는 목 | 숙임·미세한 돌림·늘어 보이는 투영 가능. 목이 사라진 둥근 참새형 몸으로 바꾸거나 목만 물리적으로 늘이지 않음 |
| 목 뒤·등 | 어두운 방향성 깃이 목 뒤에서 등과 꼬리뿌리 쪽으로 흐름 | 회전·깃의 미세한 겹침 변화 가능. 등 한가운데 흰 배 패치를 옮기거나 새 줄무늬를 만들지 않음 |

### 4.1 갓과 끈

- **관:** 높은 회흑색 관, 얇고 따뜻한 가장자리, 작은 사각·교차·직조 계열 표면. 특정 실제 직물·목재·금속 재료의 물성치로 확정하지 않는다. 새삼 매끈한 실크햇·양철통·두꺼운 밀짚모자로 바꾸지 않는다.
- **챙:** 넓고 얇으며 머리와 함께 원근이 바뀐다. 챙의 바깥 윤곽과 아랫면 질감이 읽혀야 한다. 고개를 숙였다는 이유로 챙을 새로 줄여 눈만 노출하지 않는다.
- **끈:** 황갈색/갈금색 끈이 양 볼을 따라 턱 아래로 이어진다. 고리 매듭과 가슴 앞의 두 끝·끝 장식을 유지한다. 수염·귀 장식·새 넥타이로 해석하거나 한쪽 끈을 복제해 세 줄로 만들지 않는다.
- **부착 관계:** 갓과 매듭은 고개/목의 움직임을 따라간다. 머리만 돌아가고 갓·끈이 원래 자리에 남거나 턱을 관통하는 파생은 보류한다. 실제 리그·충돌 시뮬레이션이 검증되었다는 뜻은 아니다.

### 4.2 세 소용돌이 문장과 각 면의 처리

고정 문장 원본은 금색 양각 테두리·소용돌이 선, 청록색 면, 위쪽 소용돌이 하나와 아래쪽 두 소용돌이, 원본 화면 **왼쪽으로 뻗는 긴 꼬리**로 구성된다. 오른쪽은 큰 원형 외곽으로 마무리되며, 그 바깥에 독립된 뾰족 꼬리를 새로 추가하는 지시가 없다. 정확 RGB·금속/칠 물성치는 미측정이다.

| 시점 | 문장 처리 |
|---|---|
| 앞면 | 승인 모델/포즈에서 화면 오른쪽 상가슴 쪽에 읽히는 몸통 부착 관계를 참고한다. 흰 깃·어두운 목/어깨 경계와 함께 확인한다. 문장을 날개 면에 붙여 날개와 같이 회전시키지 않는다 |
| 문장이 보이는 측면/3/4 | 같은 몸통의 같은 부착점을 원근에 맞춰 보여 준다. 보이는 위치를 맞추려고 반대 날개로 옮기거나 문장만 뒤집지 않는다 |
| 반대 측면 | 몸통·날개에 가려질 수 있다. 보이지 않는다고 반대편에 두 번째 문장을 복사하지 않는다. 정확한 입체 부착 오프셋·반대면 도면은 미측정/미제작이다 |
| 후면 | 원래 가슴의 문장이 가려지는 관계를 유지한다. 등 중앙이나 꼬리에 새 문장을 붙이지 않는다 |
| 날개 펼침 | 가슴 몸통에 남긴다. 펼친 날개와 접힌 날개에 문장을 하나씩 남기는 중복 금지 |
| 신수형 | 같은 문장·부착 관계를 유지한다. 오라·UI 구름으로 문장을 대체하거나 소용돌이 수를 바꾸지 않는다 |

**좌우 반전 금지 이유:** 이 문장은 비대칭이고 몸통 부착도 화면 방향과 무관한 캐릭터의 속성이다. 전체 그림을 뒤집으면 긴 꼬리 방향·소용돌이 방향·부착 면까지 달라질 수 있다. 새 방향이 필요하면 같은 정체성의 새 시점으로 검수하며, 반전 이미지를 승인 원본으로 자동 등록하지 않는다.

## 8. 연기·시선·미변경 경계

허용 변수는 표정·시선·제스처·포즈·승인된 시점 언어 안의 카메라·이야기에 맞는 조명이다. 고정 변수는 원본 정체성·성체/종·기본 뼈 길이와 비율·사지 수·문장/부착·갓/끈·팔레트다. 움직일 때 부위별 크기를 따로 늘이거나, 고개를 돌리는 대신 더 정면인 새 얼굴을 그려 붙이지 않는다.

장면 연기는 다음 순서를 따른다.

1. 화자 한 명이 짧게 말한다. 조이가 청자라면 해당 화자나 실제 단서로 시선·고개를 연결한다.
2. 청자의 반응은 대사 상태와 관계를 설명한다. 모든 인물이 동시에 카메라를 보거나 같은 큰 반응을 반복하지 않는다.
3. 사용자가 읽고 입력·선택하는 동안 글자·문장·입력 위치는 안정적으로 유지한다. 날개·갓·꼬리로 조작 영역을 가리지 않는다.
4. 실제로 확인된 결과 뒤에 맞는 짧은 반응을 제공한다. 도움 사용을 실패로 벌하지 않으며, 저장 전에 저장 성공·보상 전에 획득 성공을 연기하지 않는다.

발견에는 `J-E02`, 함께 고민에는 `J-E03`, 기다림에는 `J-E07`처럼 의미를 구분한다. TTS 재생·입력·평가·보상 상태의 소유권을 바꾸지 않고, 입 움직임을 실제 음성이 재생되었다는 증거로 삼지 않는다. 내부 ID를 대사나 사용자 이름으로 인쇄하지 않는다.

모션은 읽기·입력을 방해하는 반복 장식으로 만들지 않는다. 화면 밖/백그라운드에서는 정지하고, 동작 줄이기에서는 같은 정보와 결과를 안정된 포즈·텍스트로 전달한다. 취소·건너뛰기·복귀 때문에 실제 학습 상태를 잃지 않아야 한다. 이 절은 앱 전달 요구이며 현재 스프라이트·리그·영상·기기에서 검증한 결과가 아니다.

## 9. UI 초상·전신·알파 내보내기 요구

### 9.1 현재 파일 상태

| 승인 시트 | 현재 규격 | 알파 상태 | 완료로 볼 수 없는 것 |
|---|---|---|---|
| 모델 | 2172×724 RGBA | manifest의 α 범위 0–255 | 한 마리 독립 전신 PNG, 보정된 정투영/실측 모델 |
| 8표정 | 1774×887 RGBA | manifest의 α 범위 0–255 | 개별 8개 UI 초상, 얼굴 일치·각 셀의 가장자리 검수 |
| 6포즈 | 1599×984 RGBA | manifest의 α 범위 0–255 | 개별 6개 전신, 날개/꼬리 끝과 실제 UI 배치 검수 |

완전 투명 픽셀을 포함하는 RGBA라는 사실은 실제 UI 배경에서 깨끗한 가장자리·불투명한 몸 내부·적정 여백을 검증했다는 뜻이 아니다. RGB인 04 참고 이미지의 배경을 투명 PNG라고 부르지 않는다.

### 9.2 초상과 전신은 별도 결과물로 검수

- **UI 초상:** 대화의 얼굴·갓·턱끈·표정을 읽는 용도다. 원본 얼굴 비율을 유지하며 머리를 가로로 늘이거나 눈을 키워 작은 크기 가독성을 해결하지 않는다. 초상에서 다리·꼬리가 안 보이는 것은 의도된 프레이밍이지만, 그 초상으로 전신 구조 통과를 주장하지 않는다.
- **전신:** 갓 윗끝·챙·발끝·날개 끝·꼬리 끝이 캔버스 안에 모두 들어와야 한다. 투명 여백 때문에 몸체를 과도하게 작게 배치하지 않되, 꼬리 오류를 숨기려고 자르거나 발을 바닥에 잘라 붙이지 않는다. 그림을 찌그러뜨리지 않는 전체 비율 맞춤을 사용한다.
- **펼친 날개:** 두 어깨 뿌리, 긴 비행깃 끝, 꼬리와 다리가 구분되는 시야를 확보한다. UI에 맞춘 잘라내기가 필요하더라도 전신 검수용 원본과 분리해 기록하고 승인 없이 원본을 바꾸지 않는다.
- **방향별 배치:** 화자의 위치가 바뀌었다고 자동 반전하지 않는다. 시선만으로 해결 가능한지 먼저 보고, 새 시점이 필요하면 동일 얼굴·문장 부착·양쪽 구조를 별도 검수한다.
- **텍스트/UI:** 조이 문장은 몸통 소품이며 앱의 아이보리 구름 아이콘이 아니다. 실제 UI는 `ui_material_lock`의 구름·금색 CTA·짙은 녹색을 별도 사용한다. 캐릭터 PNG 안에 대사·이름표·CTA·가짜 완료 배지를 굽지 않는다.

### 9.3 알파·여백 기록 형식

후속 독립 PNG마다 원본/출력 SHA, 모드, 캔버스 크기, α 최솟값/최댓값, 완전 투명·부분 알파·불투명 픽셀 분포를 기록한다. 몸 내부가 불필요하게 반투명해졌는지, 흰/검정/황색 프린지나 낮은 알파 잔여가 바깥에 남았는지 실제 밝고 어두운 UI 배경에서 확인한다.

내용 경계는 `(left, top, right, bottom)`의 right/bottom 제외 좌표와 **좌/상/우/하** 여백을 함께 기록한다. 엄격한 `α>0` 경계와 `α>16` 등 명시한 보조 경계를 구분한다. 낮은 알파 잔여 때문에 캔버스 끝에 닿은 것과 실제 꼬리/발 잘림을 혼동하지 않는다. 기준값을 적용해 관찰했다고 실제 알파를 삭제·정리했다고 보고하지 않는다.

고정 여백 px·얼굴 표시 px·최종 export 배율은 현재 승인되지 않았다. 목표 UI의 실제 논리 크기와 기기 배율에 맞춰 후속 결정한다. 독립 PNG 42개 전체, Joy의 개별 8표정+6포즈, 립싱크·애니메이션, 320/390dp·100% 및 별도 200% 글자 QA·48dp 터치·동작 줄이기·알파 가장자리 검수는 현재 미완료다. 48dp는 조작 영역 요구이며 조이의 그림 자체를 반드시 터치 버튼으로 만들라는 뜻이 아니다.

### 9.4 공식 디자인 근거와 적용 판단

2026-11-03에 Apple 공식 [Images](https://developer.apple.com/design/human-interface-guidelines/images)와 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)의 Markdown 본문을 확인했다. 화면의 논리 크기와 래스터 픽셀·기기 배율을 구별하고, 의미 있는 짧은 반응과 모션 선택권을 제공하는 원칙을 이 전달 요구에 적용했다. 따라서 시트 해상도를 UI 표시 크기라고 부르지 않고, 반복 움직임 대신 실제 상태에 맞는 조이의 짧은 반응을 요구한다. 플랫폼 원칙을 이유로 고정 얼굴·재료·문장을 재설계하지 않는다. 공식 문서 확인은 실제 앱·기기 동작 검증이 아니다.
