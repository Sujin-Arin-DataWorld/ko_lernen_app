# 캐릭터 제작·외형·재질 검수 절차

2026-11-03. [공통 계약](README.md)과 각 캐릭터 명세의 실행 체크리스트다. 체크리스트 존재가 검수 완료는 아니다.

## 입력 기록 — 생성 전에

| 필드 | 반드시 기록할 내용 |
|---|---|
| 기준 | 저장소 기준SHA·CHARACTER_LOCK SHA·현재 명세 버전, 원본/연기/소품별 경로와 SHA |
| 인물 | 성인/소년형/연령8·12·기본형/신수형, 전신/초상/단독/장면 구분 |
| 수치 | 적용되는 기존cm/배율·측정 정의, 같은지면/깊이/원근 조건, 미측정 값 |
| 연기 | 조이·태고·도깨비는 실제 등록된 E/P ID와 시트 셀(4×2/3×2 읽기순)을 기록. 수진·탈선비·연이는 원본 파일/해당 포즈를 기록하며 없는 E/P ID를 만들지 않음. 현재 화자와 시선 목표, 얼굴/몸 중 바꿀 부위를 명시 |
| 장면·접촉 | [연기표](ACTING_MECHANICS.md)에 사건·대사 수신자·주된 초점·인물별 시선 목표·목/몸 연결·지지점·소품 쥔 손/부위/놓임·전환을 기록 |
| 고정/가변 | 외형·무늬·부착면·의상·종과 수량은 고정. 허용하는 관절·표정·빛·가림을 좁게 지정 |
| 제한 | 도구의 실제 입력 한도/편집 가능 영역, 원본이 빠지는지·기존 실패 컷을 재참조하는지 |
| 결과 | 원본파일 보존 위치, 신규파일 별도 이름·작업기록, 이전결과대체 여부 |

시트 전체 승인과 특정셀의 스프라이트 출고는 다르다. 원본을 여럿 붙였다는 사실로 형상 동일성이 보장되지 않는다.

## 단계 1 — 원본을 이해했는가

- [ ] 동일 인물 안에서도 외형 권위와 연기 시트·모델 보조·소품 권위를 분리했다.
- [ ] 머리/얼굴/표식/몸/팔다리/소품/팔레트/재질을 직접 원본에서 확인했다.
- [ ] 정면·측면·뒤모습 자료가 없는 영역은 ‘미확인’으로 표시했다.
- [ ] 시트 내 서로 다른 구슬·머리·문양·파일명/실제 자세 차이를 기록했다. 평균형을 만들지 않았다.
- [ ] 기본형/신수형·연령 변형과 장면별 크기 선택을 기록했다.
- [ ] 승인 수치와 없는 치수를 구별했다. 없는 값·HEX·PBR수치는 새로 승인한 것처럼 채우지 않았다.

## 단계 2 — 단독 외형 검수

- [ ] 가장 가까운 원본 방향과 비교했고 다른 투영의 픽셀 폭을 직접 나누어 cm/변화율로 부르지 않았다.
- [ ] 얼굴: 두상/눈썹/눈꺼풀·흰자/홍채·동공/코·부리/입/볼·주둥이/턱/귀를 각각 확인했다.
- [ ] 전신: 머리·목·어깨·등/허리·골반/후구·팔다리·손발·꼬리의 연결과 수량을 확인했다.
- [ ] 이마·볼·몸 줄무늬의 분기/흐름과 문장 모양·소용돌이 수·부착면을 확인했다.
- [ ] 옷깃/소매/허리띠/천·구슬/바지·감개·신발·방망이/부채가 원본과 같은 설계다.
- [ ] 털·깃·피부·머리카락·목재·천·짚·금속이 각각 다르게 읽힌다.
- [ ] 색상·질감·조명 때문에 생긴 차이와 물체 설계의 실제 변경을 구별했다.
- [ ] 명백한 실패 / 조건부 통과 / 미확인을 부위별로 기록했다. ‘전체적으로 닮음’ 한 줄로 덮지 않았다.
- [ ] 본인 외 별도 검토자가 실제 결과를 열었다. 사용자 승인·정본 승격과 구별했다.

## 단계 3 — 기술 출력 검수

- [ ] 파일시그니처·크기·모드·알파 범위·원본/출력 SHA 기록.
- [ ] 가시 bbox와 알파잔여 bbox를 분리. α1먼지/가시클리핑/정체성은 다른 검사.
- [ ] 밝은·어두운·체커 합성, 100%와 실제 전달 크기의 가장자리 확인.
- [ ] RGB프리뷰의 갈색/검정과 실제 투명도를 혼동하지 않음.
- [ ] 전체몸체가 α254이하처럼 약하게 투명하면 사실 그대로 기록. ‘완전불투명’으로 쓰지 않음.
- [ ] 단순원본 복사·승인 원본 포즈 추출·재생성 출력·새 스프라이트 등록을 구별.

## 단계 4 — 장면 통합 뒤 다시 검수

- [ ] 통합 대상 인물 모두 단계2 재검수. 단독 검수의 통과를 자동 승계하지 않음.
- [ ] 태고의 긴 몸통/종을 읽을 여백, 같은 지면의 수진과 크기관계가 보임. 어깨높이와 머리높이 구별.
- [ ] 다섯 인물/책/부채·방망이·문장이 겹쳐 정체성이 숨지 않음. 가림은 ‘고정 성공’이 아니라 미확인.
- [ ] 현재 화자/청자/대상에 시선이 이어짐. 전원 카메라 응시·무관한 눈동자 방향 없음.
- [ ] 최종 카메라에서 시선 목표가 읽힘. 좌표/프롬프트만 맞는 것을 통과로 취급하지 않음. 양눈·눈꺼풀·머리 투시를 함께 확인.
- [ ] 목 밑동·턱 아래 겹침·어깨·몸·접지가 자연스럽게 이어짐. 머리만 꺾거나 외형을 바꿔 경청을 해결하지 않음. 작은 고개 회전과 내려다보기 자체를 일괄 금지하지 않음.
- [ ] 사용자에게 부탁하는 컷은 동료끼리 눈맞춤만으로 사용자를 대화 밖에 두지 않음. 주된 얼굴/행동이 읽힘.
- [ ] 방망이·책·부채의 쥔 손/부위·지지·접촉/가림·손목/팔꿈치·접지/그림자가 납득됨. 모르는 kg/관절각을 실측했다고 쓰지 않음.
- [ ] 손을 얹는 휴식과 실제 들기를 구별. 낮은 방망이 방향만이 아닌 지지/접촉 검사. 전체 반전으로 쥔 손과 문장을 바꾸지 않음.
- [ ] 한 캐릭터를 빼거나 축소해 혼잡을 해결하지 않음. 필요한 구도 변경을 먼저 검토.
- [ ] 배경·의상·책·문장·좌우 방향이 앞뒤컷에서 이어짐. 같은 입력/첫 아의 페이지 위치 유지.
- [ ] 빛·오라·종이효과가 얼굴·털무늬·깃 구조를 가리지 않음.
- [ ] 새 흰자·부리색·곰형 가슴·3번째 날개/뿔·반대편 배지복제·새 목탈 구조가 없음.

## 단계 5 — 언어·UI·모션

- [ ] EN/DE 번역 때문에 미술 전체가 재렌더됐으면 캐릭터/그림부터 다시 검수.
- [ ] 승인 실제 구름·황금CTA를 다른 문장/로고로 교체하지 않음. 원본재사용/새조판/생성텍스트 상태를 기록.
- [ ] 원고 차례·도움·재시도·저장 미확인/실패/확인·복귀 상태를 분리.
- [ ] 정지PNG는 애니메이션/립싱크·Flutter·실기기 QA 완료가 아님.
- [ ] 입력/읽기 중 반복 움직임·다중 과장연기·강한섬광/흔들림 없이 reduced-motion대안을 같은 흐름으로 설계.

## 즉시 중지와 검수 범위

필수 외형 하나가 명확히 바뀌거나 장면 연기/소품 접촉이 반려되면 그 결과로 번역판/후속컷을 늘리지 않는다. 무늬가 가려지거나 기준뷰가 없어 모르면 부분검수다. 반려 이미지는 원본을 삭제하지 않고 상태/이유/해시를 남기며 기준이미지로 재사용하지 않는다. 단독 후보 조건부 통과는 새 정본 승인이나 전체 장면 출고가 아니다.

치수 비교를 통과했다고 말하려면 보정된 정면/측면·지면·카메라·스케일·측정점·결과를 제시한다. 현재 PNG의 DPI나 화면높이만으로 승인cm 준수를 인증하지 않는다. 기존 lock의2%/3%는 향후 보정 모델 QA 제안이지 모든 생성PNG를 통과시키는 허용오차가 아니다.
