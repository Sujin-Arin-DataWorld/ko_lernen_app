## 4. 허리·하체·발

- 남색 두꺼운 밧줄 허리띠의 여러 가닥·꼬임·매듭을 유지한다. 광택 금속/얇은 리본으로 교체하지 않는다.
- 원본 옆으로 늘어진 밝은 천·붉은 천·매듭 끝·밝은 구슬의 연결을 확인한다. 포즈상 가림과 삭제를 구별한다. 천의 결·가닥 경계는 명암으로 읽히되 검은 선으로 둘러싸지 않는다.
- 청록색 풍성한 바지는 넓은 부피·원본 반복 직물결·아래로 모인 바짓단을 유지한다. 몸을 움직일 때 주름의 시작점은 허리/무릎/모인단과 연결한다.
- 허리·골반·두 무릎·발목이 한 골격으로 이어진다. 쪼그림에서 다리가 짧아 보이는 것은 자세 투영이며 새 키가 아니다.
- 바지 아래 흰 다리 감개/밝은 천, 남색 감개, 따뜻한 베이지 짚신을 원본대로 구분한다.
- 짚신은 꼬인 짚/굵은 섬유 가닥과 발을 덮는 끈·앞코·바닥 두께로 읽힌다. 갈색 가죽 로퍼나 맨발로 바꾸지 않는다.
- 발 두 개와 발가락 앞쪽의 원본 노출, 접지 방향·체중지지를 본다. 흰 감개와 피부/짚이 융합하거나 발이 바닥에서 떠 있으면 실패.
- 발바닥/숨은 등/천 아래 해부학을 새로 확정하는 자료는 없다. 모르면 미확인으로 남긴다.

## 5. 방망이·기와·상징물

방망이는 같은 나무 소품이다. 몸과 함께 비균일하게 늘리거나 매 컷 다른 문양을 만들어서는 안 된다.

| 요소 | 고정 사항 |
|---|---|
| 외곽 | 굵고 길쭉한 각진 나무, 옹이/돌기, 손잡이와 넓은 머리의 차이 |
| 표면 | 따뜻한 갈색 나뭇결/깎인 면의 명암. 플라스틱·고무·검정 금속 재질 금지 |
| 문양 | 원본의 청록과 밝은 아이보리 소용돌이 면·배치·흐름. 도구의 새 구름 패턴 자동 생성 금지 |
| 손잡이 | 여러 번 감긴 굵은 밧줄과 원본의 구슬/연결 |
| 술 | 붉은색과 남색 천/술의 분리·겹침·매달린 중력방향 |
| 행동 | ‘낮게’라는 높이만 지시하지 않는다. 넓은 끝을 땅에 두고 위 마디에 손을 얹는 휴식 / 좁은 축을 실제 쥐어 드는 상태 / 내려놓고 안내를 구분한다. 쥔 손·접촉점·지지·팔꿈치/손목 부담을 기록하고 [소품 접촉 계약](ACTING_MECHANICS.md)을 따른다. 대화/오답 때 위협적으로 치켜드는 기본 반응 금지 |

사용자가 추가 지정한 도깨비 기와와512px 방망이는 [세션 사례](SESSION_FINDINGS.md)에 실제 경로/해시 근거를 남긴다. 해당 로컬 기와는 PR471의13PNG 목록에 들어 있다고 거짓 기록하지 않는다. 기와의 두 뿔·꽃띠·머리/볼/구름 무늬·오래된 청록 표면을 새 얼굴로 대체하지 않는다. 도깨비 기와·몸의 조끼 무늬·별도 신수배지는 서로 다른 자산이다. ‘모두 구름이니 같은 로고’로 평균내지 않는다.

## 8. 검수와 미확정

정면과 사용자 편안한 전신을 함께 대조하고 불일치가 있으면 한쪽의 임의 평균형을 만들지 않는다. 특히 머리띠 반복무늬·뿔수·눈썹·두상·귀고리·방망이를 먼저 확인한다. 단독 시선변경 후보 역시 원본 그대로 추출한 파일이 아니며 독립 최종 검수가 끝나지 않았다. 승인8표정/6자세에 자동 편입하지 않는다.

원본 같은 방향의 얼굴 → 상투/꽃띠/뿔 → 저고리/조끼/소매 → 손/방망이 → 밧줄/천/구슬 → 바지/감개/짚신 → 전체비율/투명경계를 순서대로 점검한다. 배지나 방망이를 보여주려 좌우반전하지 않는다. 각 장면에서 소품의 실제 들린 손·가림·보관상태를 명시한다. 자세·표정의 성공과 정체성·원본 치수 검증은 별도다.
