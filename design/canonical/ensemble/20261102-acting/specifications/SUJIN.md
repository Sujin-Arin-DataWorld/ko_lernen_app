# 수진 B2 — 머리부터 발끝까지의 일러스트 명세

작성 2026-11-03. 원본 관찰과 기존 승인 치수의 문서화다. 새 인물·팔레트·연기 에셋 승인이 아니다. [공통 계약](README.md), [치수 전수표](MEASUREMENTS.md), [검수 절차](QA.md)를 함께 적용한다.

## 1. 권위와 신체 기준

- 절대 외형 기준: [선택 B2 시트](../../20261102/assets/sujin/01-b2-selected.png). SHA-256 `2f9e367ef657ae82abe3ed0eefdd234cc997c6cdf281c416dbc6103c6d972c33`.
- 시트의 왼쪽 전신과 오른쪽 얼굴 두 뷰는 같은 성인 동료다. 이전 수진·사진 반영 후보·연이·플레이어 얼굴을 섞지 않는다.
- 성인 한국인 현대 동료이며 플레이어가 아니다. 플레이어의 이름이나 모노그램을 이 얼굴에 붙이지 않는다.
- 맨발 정수리160cm. 머리30.8 / 어깨36 / 위팔24 / 아래팔22 / 손15 / 양팔폭158 / 가랑이~맨발지면78 / 신발외곽길이23cm는 기존 값이다.
- 양팔폭158은 기존 정의36+2×(24+22+15). 이 수식을 생성 그림의 실제 측정 결과로 바꾸지 않는다.
- 머리카락·신발은 키에서 제외한다. 큰 머리의 스타일을 지킨다는 이유로 아동화하지 않고, 성인을 표현한다며 임의로 머리를 줄이거나 다리만 늘리지 않는다.
- 안면 랜드마크 비율과 보정된 직교 전신 참조는 미확정이다. B2를 같은 카메라 방향으로 대조하며 새 숫자를 추정하지 않는다.

## 4. 허리·바지·다리·발

- 회색의 하이웨이스트 와이드 바지. 허리 주름과 앞 중심·다리 두 갈래가 보인다.
- 중간 두께의 무광 직물로 무게가 아래로 떨어진다. 피부에 달라붙는 레깅스/청바지/치마로 교체하지 않는다.
- 골반·가랑이와 무릎의 위치를 보존한다. 웅크린 포즈의 화면 높이를 서 있는 키나 새 다리 길이로 계산하지 않는다.
- 바짓단과 두 신발을 구별한다. 발목 피부가 드러나는 양은 원본/포즈에 맞추고 임의 긴 양말을 만들지 않는다.
- 갈색 로퍼: 둥근 앞코·갑피의 가죽 면·스티치/이음·끈 없는 스트랩·낮은 굽과 밑창. 거울 광택이나 운동화/구두끈 추가 금지.
- 신발의 발등 볼륨과 바닥 접지, 발뒤꿈치·앞꿈치 방향을 보존한다. 발 두 개가 같은 모양으로 복제되거나 바지 끝에 떠 있으면 실패.
- 원본은 신발을 신은 전신이다. 맨발 발가락/발바닥을 새로 설계해 ‘정본’으로 기록하지 않는다.

## 6. 연기와 적용

수진의 새8표정/6자세 시트가 PR471에 등록됐다고 주장하지 않는다. 승인된9장은 조이·태고·도깨비 각3장이다. 수진은 B2를 고정한 후속 연기 제작 대상이다.

- 설명: 얼굴→책/소리 조각→플레이어 행동 대상으로 시선과 손을 연결.
- 경청: 현재 화자를 바라보고 어깨/손의 긴장을 줄임.
- 기다림: 입력 대상을 가리지 않고 같은 자리에 머묾. 눈을 크게 뜬 카메라 응시 반복 금지.
- 안도: 실제 사건 결과 확인 뒤 작은 입꼬리/눈꺼풀 변화. 저장 미확인인데 성공·완료 연기를 하지 않는다.
- 고개·표정 변경 허용은 얼굴 재설계 허용과 다르다. 눈·코·입 랜드마크가 보이지 않는 컷은 미확인으로 남긴다.
- 대화 얼굴과 전신은 같은 B2임을 별도로 비교한다. 얼굴 썸네일이 통과해도 전신 머리/어깨/다리 비율을 자동 통과시키지 않는다.

## 7. 이번 세션에서 남긴 실패 예방

전체 장면의 귀여운 얼굴을 다음 컷의 참조로 이어 쓰면서 성인 비율/헤어/의상 세부가 누적 변형될 수 있었다. source-matched 단독 생성 역시 원본에서 직접 잘라낸 바이트가 아니라 재그림이다. 단독 수진 후보는 독립 전신/얼굴 최종 검수가 끝나기 전에 문서 작성으로 전환되었으므로 승인 시트나 정본으로 세지 않는다. 새 PNG를 생성했다는 이유로 기존 B2를 교체하지 않는다.

## 8. 검수 중점

B2와 가장 가까운 방향으로 얼굴/단발/귀걸이 → 목/어깨 → 재킷과 니트 → 개인 책과 손 → 허리/양다리 → 바짓단/로퍼 → 전신 실루엣을 순서대로 본다. 원본에 없는 뒤통수/재킷 뒷판/신발 바닥은 미확인이다. 미감을 이유로 항목을 생략하지 않는다. [QA.md](QA.md)의 필수항목 하나라도 명백히 변하면 다음 장면으로 파생하지 않는다.
