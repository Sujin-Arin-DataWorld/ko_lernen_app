# 태고 원본과 새 시트 비교 판단

## 결론
기존 baekho.png는 이미 보존된 외형 기준과 SHA-256이 같다. 얼굴의 둥근 주둥이·회백색 털과 숯빛 무늬·푸른 눈·성체 체형을 유지한다. 새 표정8종/자세6종은 눈꺼풀·귀·목·시선과 몸의 힘이 더 다양해서 RPG 대화와 사용자 행동에 반응시키기에 적합하다. 새로운 종이나 더 어린 얼굴을 기본형으로 교체하지 않고, 원본 외형+새 연기 체계로 등록한다. 이 어울림 평가는 편집 판단이며 이미지의 물리 치수 실측은 아니다.

- baekho.png: 주 외형 기준 유지. RGB 원본이므로 검정 배경까지 가진 디자인 원본이며 즉시 투명 스프라이트가 아니다.
- exec-59fe7aff…: 정면 얼굴 확대 보조로 채택. 청색 눈·주둥이·무늬를 가까이 확인하기 좋다. 고정 무표정을 전 대화에 재사용하지 않는다.

- exec-d9e47a8d…: 투명 전신 서기 보조로 채택. 기본 baekho.png와 같은 바이트인 것은 아니므로 원본 정체성을 덮어쓰지 않는다.

- baekho3/4.png: 누운 자세 참고. RGB이며 같은 대기 응시가 반복된다. 새 쉬기 자세는 눈·목의 이완이 더 읽혀 연기 시트를 우선한다.

## 새 파일의 권한
새 시트9장은 사용자의 이번 승인 아래 **연기/조형 참고 정본**으로 등록한다. 파일별 자세·표정ID는 ACTING_CANON에서 관리한다. 얼굴·무늬는 기존 원본, 신체 치수는 기존 제작 목표가 우선한다. 실제 스프라이트 출고와 메시 수치 검증은 따로 통과해야 한다. 수진·탈선비·연이의 외형과 나이, 원본 구름·황금CTA는 그대로 계승한다.
