## 머리에서 발끝까지 고정
- 성체 백호. 긴 고양잇과 코등, 분리된 양쪽 수염주머니와 턱, 작은 둥근 호랑이 귀, 길고 각진 볼털 흐름을 유지한다. 곰의 짧은 코·둥근 몸통, 새끼의 큰 머리 비례로 바꾸지 않는다.
- 홍채는 층이 읽히는 청회색. 둥근 동공과 절제된 반사광을 보존한다. 눈 전체 발광·유리구슬 눈·눈 크기 확대·새 사람 눈썹으로 감정을 대신하지 않는다.
- 코는 분홍 갈색, 주둥이는 따뜻한 흰색, 가는 흰 수염. 입선·턱 열림은 고양잇과 형태 안에서 연기한다. 보호 장면에서 사용자에게 송곳니를 보이지 않는다.
- 털은 아이보리빛 흰색, 줄무늬는 차콜. 얼굴 짧은 털→볼의 방향 있는 작은 덩어리→가슴 털 흐름→짧은 몸털로 이어진다. 플라스틱 표면·솜털 구체·사자 갈기·과한 젖은 광택을 금지한다.
- 목은 어깨와 연결된다. 깊은 흉곽, 긴 몸통, 들어간 허리, 구별되는 골반, 성체 다리와 넓은 발을 유지한다. 네 다리와 긴 고리무늬 꼬리 한 개. 발톱은 휴식 시 노출하지 않는다.
- 청록 면·금색 테두리의 **세 소용돌이 표식**은 해부학적 왼쪽 가슴. 정면에서는 화면 오른쪽이다. 각도 때문에 가려진 표식을 반대편에 복제하지 않는다.
- 색/질감은 해당 이미지가 기준이다. 화면에서 추정한 HEX를 원본의 실측 색이나 물리 소재 수치로 발명하지 않는다.
- 기존 크기 설정: 축소 80/120/85cm(어깨/코~엉덩이/꼬리), 신수 2.25배 180/270/191.25cm. **이번 고택 목업은 신수 크기**로 수진 160cm보다 작은 호랑이로 만들지 않는다. 이 숫자는 연출 목표이며 래스터에서 실측 인증한 결과가 아니다.

## 검수

- 성체 정체성·얼굴·목–어깨·다리·꼬리: 현저한 이탈 없음.
- T-P03 초안의 관객 응시를 전방 아래 단서 시선으로 수정했다. 초안은 생성 폴더에 보존하며 정본 목록에 넣지 않았다.

- 정확한 cm, 줄무늬 픽셀 동일성, 사람 평가, 모든 배경에서의 alpha 가장자리, 실제 앱 크기의 표정 식별은 인증하지 않았다.
- 이 파일은 제작 **시트**이며 이미 추출된 개별 런타임 스프라이트 14장으로 보고하지 않는다.
