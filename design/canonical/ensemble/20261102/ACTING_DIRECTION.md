# 캐릭터 연기와 화면 배정 · 제작 제안

기준일 2026-11-02. 고정 외형·제작 치수는 [정본](CHARACTER_LOCK.json)을 따른다. 여기서는 **같은 얼굴로 어떤 감정을 어떤 행동에 연결할지** 제안한다. 새 표정/자세 이미지나 실제 앱 동작은 아직 제작하지 않았다.

## 1. 태고의 무표정 문제 진단

참고 폴더의 비 오는 회상, 귀가, 문 앞 장면과 기존 태고 표정 6종을 비교했다. 기존 시트에는 고개 기울임·작은 입 열림·눈 감기가 있어 표정이 전혀 없는 것은 아니다. 다만 다른 대사에서도 같은 정면 응시와 긴장된 눈매가 반복되면 감정 차이가 읽히지 않는다. 이것은 시각 연출에 대한 판단이며 캐릭터의 정신 상태를 진단하는 말이 아니다.

해결은 태고를 계속 웃게 하거나 다른 귀여운 얼굴로 바꾸는 것이 아니다. **시선 대상 + 눈꺼풀·귀 + 고개·목 + 몸의 힘**이 대사에 맞아야 한다. 현재 성체 얼굴·푸른 눈·주둥이·줄무늬를 유지한다. 입꼬리만 올린 여섯 장보다 기능이 다른 감정이 필요하다.

## 4. 수진·탈선비·연이의 역할

수진 B2는 S-E01 편안한 동행 / S-E02 집중해서 듣기 / S-E03 시범 설명 / S-E04 기대하며 기다리기 / S-E05 이야기 속 걱정 / S-E06 안도·기쁨을 준비한다. 손짓은 플레이어와 같은 사물을 가리키고, 답을 몰래 보여 주지 않는다. 후기에는 먼저 정답을 말하기보다 사용자의 읽기를 기다린다. 도움 요청에는 바로 반응하며 실망한 표정을 주지 않는다.

탈선비는 목재 탈을 살색 얼굴로 바꾸지 않는다. 원래 탈의 조각 형태를 유지하고 고개·상체·부채·손·시선 방향으로 익숙한 농담/집의 쇠락을 알아봄/제자에게 부탁함을 구분한다. 표정을 늘린다는 이유로 다른 탈이나 인간 입술을 만든 새 얼굴을 승인하지 않는다.

연이는 8세/12세를 같은 장면에서 섞지 않는다. 8세는 호기심·그리기·작은 자랑, 12세는 읽기·쓰기·주머니를 안고 생각하기·기록을 지키려는 조심스러움에 배정한다. 항상 과거 기억/기록 맥락이며 현재의 학습 결과에 살아서 반응하는 NPC가 아니다. 연이 이름·사적 소품·의도의 공개는 원고의 선행 사실을 따른다.

## 5. 화면별 화자·청자·사용자 행동

같은 배경 → 한 화자의 대사 → 청자의 짧은 반응 → 사용자의 행동 → 실제 결과에 대한 반응으로 이어간다. 매번 모든 동료를 정면 단체사진으로 배치하지 않는다. 아래 배정은 원고의 사건을 대체하거나 새 사건을 추가하는 것이 아니다.

## 6. 에셋 제작과 검수

첫 추가 연기 제작 제안은 태고 표정 8종+자세 6종, 다음 조이 6+6, 도깨비 8+6, 수진 6종과 필요한 손짓이다. 이는 아직 생성하지 않은 계획 수량이다. 신수형은 일반형 연기의 정체성을 공유하고 배율·오라만 분리한다. 태고의 감정 차이는 얼굴만 자른 64/96px 정도의 실제 UI 사용 크기에서도 검토하되 수치는 제작 검토 목표이며 실기기 통과를 의미하지 않는다.

각 출력은 같은 정본 PNG·치수·고정 특징을 참조한다. 표정 시트를 여섯 새 캐릭터로 재해석하지 않는다. 개별 PNG, 전체 전신, 표정 비교, 시선 방향을 따로 검토한다. 좌우 반전으로 비대칭 의상·줄무늬·소품이 바뀌지 않게 한다. 표정 시트 칸을 그대로 연속 애니메이션 프레임으로 사용하지 않는다.

## 7. 실제 앱으로 옮길 때의 반응

아직 구현하지 않은 제안이다. 트리거→현재 상태 확인→반응→안정된 대기 순서를 사용한다. 입장·말하기 시작/끝·사용자 선택·저장 확인 같은 이유가 있을 때 짧게 반응한다. 글자·답안·입력 기준선은 움직이지 않는다. 읽는 동안 전원이 반복 흔들리거나 동시 발화하지 않는다.

화자에게만 음성과 짧은 입 모양을 연결하고 청자는 한 번 시선/고개 반응 후 안정된다. 멈춤·음성 장애·동작 줄이기에서도 같은 대사·선택·결과를 제공한다. 잠깐 눈을 감는 이미지를 그렸다는 이유로 자연스러운 깜박임 애니메이션이 구현됐다고 쓰지 않는다.
