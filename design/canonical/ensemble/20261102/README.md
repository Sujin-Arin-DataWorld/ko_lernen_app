# 한글소리 캐릭터 정본 · 2026-11-02

**사용자 승인:** “수진은 이걸로 확정하고 다른 캐릭터들 이미지,제작치수 제안 전부 정본으로 올리고 커밋.”

수진 B2와 도깨비·탈선비·연이·조이·태고의 현재 교정 참조, 일반/신수형 제작 치수, 공통 조형·재질 기준을 고정한다. 첨부 구름과 황금 CTA 원본도 함께 보존한다. 이미지 27장은 재생성·재압축하지 않은 원본 바이트다. 이것은 **디자인 정본 승인**이며 기존 PNG의 모든 치수가 실측 검증됐다는 뜻은 아니다.

## 시작점

- [CHARACTER_LOCK.json](CHARACTER_LOCK.json): 캐릭터별 치수·특징·형태·고정/가변 조건. 경로는 이 폴더 기준이다.
- [치수·외형·이미지 스타일](CHARACTER_STANDARD.md): 사람이 읽을 정본 기준.
- [표정·몸짓과 화면 배정](ACTING_DIRECTION.md): 새로운 연기 에셋 제작을 위한 제안. 이 문서 작성만으로 새 이미지까지 승인되지 않는다.
- [새 세계관의 화면 구성](RPG_SCREEN_DIRECTION.md): 지정 폴더를 구도·재료 참고로 읽은 결과와 실제 이야기/소유 경계.
- [에셋·해시 목록](ASSET_MANIFEST.json) · [사용자 승인 범위](CANONICAL_APPROVAL.json) · [159장 참고 목록](REFERENCE_FOLDER_INVENTORY.json).

## 승인 범위

수진은 [B2 원본](assets/sujin/01-b2-selected.png)의 얼굴·단발·현대 복장·재질을 유지한다. 이전 수진은 [10월31일 패키지](../../sujin/20261031/README.md)에 이력으로 남기며 새 제작 기준을 대체하지 않는다. 사진 반영 후보는 포함하지 않는다.

연이는 기존 8세와 사용자 선택 후기 12세를 분리한다. 원본에 15세라고 적힌 파일을 12세로 바꾸지 않았다. 연이는 과거 기억·기록 속 인물이며 현재 고택에 살아 돌아오는 설정으로 바꾸지 않는다.

조이는 원래 성체 외형과 긴 비행깃·꼬리 기준을 함께 따른다. 표정/자세 시트의 작은 프레임을 전체 날개 길이 기준으로 삼지 않는다. 신수형 오라는 체격과 별도다. 기존 시트에 여백·알파 경계·구조 문제 등이 남으면 독립 스프라이트 제작 QA에서 수정해야 한다. 정본 참조 승인과 모든 잘라낸 스프라이트의 출고 승인은 구별한다.

이미 알려진 세 날개 오류본, 이전 두 소용돌이 배지, 짧은 날개 비교판, 다른 수진 후보, 지정 참고 폴더의 바뀌는 캐릭터·재해석된 건축은 승격 대상에서 제외한다. 원본을 삭제하지 않는다.

## 이번 작업의 경계

캐릭터 정본·치수·필수 UI 재료와 연기/화면 제안을 저장한다. 새로운 앱 목업 생성, HTML·Figma·Flutter 수정, 실제 계정의 학습/건축/엽전 변경, 원격 push·main 병합·배포는 수행하지 않는다. 27장 보존은 개별 스프라이트 분리·3D 리깅·실기기 합성 완료가 아니다.
