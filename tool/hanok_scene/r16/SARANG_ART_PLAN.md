## 1. 이번 결정

사용자가 지정한 목표 이미지를 시각 판정 기준으로 유지한다. 사랑채의 밝기를 일괄 조정하거나 색상 종류를 늘리는 것으로 목표 재현을 대신하지 않는다. **부위마다 밝은 면·중간 바탕·짙은 결·접합부 음영이 차지하는 위치와 면적을 맞춘다.**

미술감독, 재질 아티스트, 조명·컬러 디렉터가 목표·R7·R9와 제공된 SPEC을 독립적으로 검토했다. 이번 결과는 실행 계획이며 새 결과물의 시각 승인 기록이 아니다.

- 범위: **사랑채만**. 11동 전체 제작·조감도 제작은 보류.
- 고정: 711개 건축 메시의 형태·이름·계층·UV·기존 노멀·부재 속성·공정 연결.
- 목표: 검정 외곽선 없이 풍부한 원목의 결과 색 변화, 청먹 기와의 큰 곡면, 따뜻한 석재, 깊이 있는 창호와 부드러운 빛.
- 기존 목재를 전체 주황색이나 전체 밝은 베이지로 묶는 처리 중단.
- R7은 진단 비교본이며 미술 정본이 아니다. R8/R9의 창백한 목재는 실패 사례다. R10 렌더 프로세스는 중단했고 결과 파일이 생성되지 않았다.

## 3. 무엇이 잘못되었나

### 확인된 원인

1. `refine_sarang.py`와 `sarang_calibrated.py`는 기존 목재 결과에 공통 RGB 곱셈을 누적했다. 부재의 실제 면·결·접점 역할을 설계하기 전에 전체 색을 움직였다.
2. `sarang_wood.py`의 `original` 입력은 원시 나뭇결 이미지가 아니다. `wood-node-probe.json`에서 입력은 **HS2 amber timber through original grain**이며, 상류에는 R6 팔레트·휘도·갈색 재매핑이 이미 들어 있다.
3. 이를 다시 RGB→휘도로 바꾸고 밝은 3색에 재배분했다. 부재별 변주와 결을 같은 ramp 좌표에 합산해 밝은 판재에서 결의 대비까지 압축할 수 있는 구조가 되었다.
4. R9는 배율 2.1→1.0만 바꿨다. `restoredOriginalGrainRange: true`는 코드가 기록한 값으로, 실제 결 대비 회복을 입증하지 않는다. 시각 검토에서는 회복 실패로 판정한다.
5. R7→R8→R9에서는 조명과 카메라를 유지했다. **이 구간의 탈색·평탄함을 조명이나 AgX 변경 탓으로 돌리지 않는다.**

### 아직 검증하지 않은 가설

- 초기 장면의 전방 Fill 900W와 지면 발광 0.65가 접촉부 깊이를 약하게 만들 가능성.
- 높은 sheen·넓은 bevel·미세 범프의 조합이 기와 표면을 잘게 반짝이게 만들 가능성.

이 두 항목은 한 변수씩 비교한 뒤 판정한다. 확인된 목재 문제와 혼동하지 않는다.

## 5. 제미나이 SPEC 적용 방식

**자료를 사용한다.** 호박빛 목재·청먹 기와·미색 석재·따뜻한 창호, 무테 경계, 판재 변주, 부드러운 빛이라는 목표를 채택한다. 숫자는 적용 후 화면으로 검증할 시작값이다.

| SPEC 내용 | 이번 제작에서의 결정 |
|---|---|
| 목재 `7A3E14 / B86B28 / D4893B`, 밝은 모서리 `FFE3A8`, 틈새 `2C140B` | 어두운 결·중간 바탕·밝은 면·접점의 관계를 잡는 기준으로 사용. 모든 목재를 밝은 색 하나로 치환하지 않음 |
| 개별 부재·island 변주 | 기존 `P18 source member id`와 객체·island 정보를 검증해 일정한 부재색을 부여. 조립 단계가 바뀌어도 색과 결이 고정됨 |
| Voronoi·Noise·Bevel | 목재는 성장결, 돌은 광물면, 기와는 구운 점토 곡면에 맞춰 별도 사용. 전 재료에 동일 패턴·크기 적용 금지 |
| 높은 sheen·높은 roughness | 일괄값을 완성 규칙으로 고정하지 않음. 난간·마루·절단면·기와·돌의 반응을 같은 빛에서 구분 |
| 백토 끝면 분리 | 이미 존재하는 4개 기와 끝 객체의 228개 조각을 사용. 감사에서 실패한 자동 면 선택을 재사용하지 않음 |
| 따뜻한 주광·실내 반사광 | 색·방향의 출발점으로 사용. 현재 목재 검수 중에는 조명 고정, 이후 접지와 실내 반사광만 분리 검수 |
| 100% 동일 출력·통째 Combined bake | 실제 검증 전 보장하지 않음. 정지 렌더 품질 확정 후 360도·공정 분리·실제 뷰어 검증을 별도로 수행 |

색관리에서는 장면 선형값과 표시색을 구분하고, 노출·AgX를 재질과 동시에 바꾸지 않는다. [Blender 색관리](https://docs.blender.org/manual/en/4.5/render/color_management.html)

Sheen은 미세 섬유·먼지의 반응을 표현하는 성분이다. 모든 소재의 입체감을 일괄 개선하는 값으로 취급하지 않는다. [Blender Principled BSDF](https://docs.blender.org/manual/en/4.0/render/shader_nodes/shader/principled.html)

## 6. 실제 제작 순서와 단계별 통과 조건

### A. 원본 결·마스크 추적

- 원시 이미지/성장결 입력, `P18 real cut face`, `P18 cut UV`, 부재 ID를 추적한다.
- 재색칠된 최종 RGB를 다시 원본이라고 부르는 연결을 제거한다.
- 새 후보의 재질 그래프에 필요한 입력만 명시적으로 연결한다. 보정 노드를 계속 덧붙이는 방식 종료.
- **통과:** 옆면 길이결과 절단면 연륜이 원래 부재 위치에 있으며 구조·공정 보존 검사 통과.

### B. 목재 관계 복구 — 조명·카메라 고정

독립 제어층: **넓은 기본 색면 / 부재별 일정한 변주 / 원본 결 대비 / 국소 색조 / 접합부·모서리 / 거칠기·미세 요철**.

- 결과 부재 변주를 한 ramp 좌표에 합치지 않는다.
- 난간·창살은 형태 우선, 하부 판재는 결 우선으로 묘사 밀도를 다르게 한다.
- 마구리는 객체 이름뿐 아니라 기존 면 마스크로 분리한다.
- **통과:** 같은 화면에 밝은 난간 윗면, 중간 밝기 기둥, 짙은 난간 밑, 결과 판재색이 함께 보이는 하부 판벽이 공존.
- **실패:** 전체 베이지/주황 덩어리, 매끈한 박공, 동일 세로줄, 밝아질수록 사라지는 결. 실패 영역만 재조정.

### C. 기와·돌·회벽 — 목재 고정

- 기와의 넓은 곡면과 골을 우선하며 미세 노이즈는 축소 화면을 방해하지 않도록 제한.
- 돌의 윗면·측면·접점을 나누고 광물색과 기공의 크기를 구분.
- 회벽은 주변 재료를 받쳐 주는 조용한 면으로 유지.
- **통과:** 축소 화면에서도 네 재료가 분리되고 확대 시 새로운 재료 정보가 나타남. 형상·기와 간격·돌 윤곽 변경 없음.

### D. 접지·실내빛 — 재질 고정

- 필요할 때 기존 기준 렌더의 재질색·직접광·간접광·발광 패스를 함께 저장해 원인을 확인.
- 지면 발광 0.65→0만 바꾼 비교로 접지 영향 확인. 결과가 어두워졌다는 이유로 전체 노출을 올리지 않음.
- 다음으로 Fill, 창호 발광, 실내 Area를 각각 분리해 조정.
- **통과:** 오른쪽으로 부드러운 접지 그림자, 읽히는 처마 내부, 문 가까운 마루의 국소 온기, 발광 안에서도 선명한 창살.

### E. 사랑채 전체 검수·출력

- 목표와 후보를 같은 표시 크기로 나란히 비교. 원본 크기 차이나 표시 배율을 재료 차이로 오판하지 않음.
- 전체 화면과 대표 6영역 확대를 함께 검수. 미세 결만 보고 전체 인상을 승인하지 않음.
- 구조·UV·노멀·공정 바인딩 검사와 시각 검수를 각각 기록.
- 통과 후 최종 해상도, 사선·반대편 확인, 공정 표시의 색·결 고정 여부를 검수.
- GLB·앱 출력은 이 네이티브 결과의 검수 후 별도 전달 단계. 이번 계획으로 완료 처리하지 않음.

## 7. 검토 의견의 합의와 차이

| 담당 | 독립 판단 | 반영한 결정 |
|---|---|---|
| 환경 미술감독 | R7/R9의 중간 밝기가 답이 아님. 같은 부재에서 밝음·중간·어두움의 위치 관계 필요 | 10개 실제 영역의 면·결·접점 지시와 대표 6곳 검수 |
| 재질 아티스트 | 누적 재매핑이 결의 대비와 원본 색 변화를 압축 | 원시 결 입력 추적, 변주·결·국소 마스크를 독립 제어 |
| 조명·컬러 디렉터 | R7→R9 변화는 목재에 귀속. 접지 약화는 별도 조명 가설 | 목재 교정 중 조명 고정, 이후 한 변수씩 접지·실내빛 비교 |

순서에 대한 차이: 조명 담당은 접지 실험을 먼저 하는 안을 제시했다. **이번 사용자 지적의 직접 원인이 목재 재매핑으로 확인됐으므로, 종합 계획은 같은 조명에서 목재 복구를 먼저 검증한다.** 접지 가설은 D단계에서 별도로 확인한다.

## 8. 다음 세션 시작 조건

- 현재 사용자 요청은 **미술팀 계획 수립**이다. 계획 제출 뒤 임의로 추가 채색·렌더를 시작하지 않는다.

- 다음 구현은 위 A→B→C→D→E 순서와 영역별 통과 기준을 따른다. 실패 영역과 속성을 명시하고 전체 밝기 조절 반복으로 돌아가지 않는다.
