2026-10-09에 현재 파일과 원격 main을 대조한 결과다. HTML 목업의 예시 잔액은 실제 계정 데이터가 아니다. 한옥 원본은 새 정본으로 바뀔 예정이라는 최신 지시에 따라 수정하지 않았다.

## 실제 지급 규칙

|---|---:|---|
| 정본 듣기·스몰토크 콘텐츠 수업 | 그날 첫 완료 20, 두 번째 10, 이후 0 | 정본 콘텐츠 ID와 저장된 완료 시각이 있어야 한다. 모든 문제를 시도해 완료해야 한다. 모두 정답이어야 한다는 조건은 없다. 열기·중도 종료는 지급 근거가 아니다. |

| 새 건설 가능 공정 | 공정마다 40 | 학습 진도로 새롭게 자격을 얻은 사랑채/B2 공정마다 한 번 지급한다. 일일 학습 30엽전 한도와 별개다. |
| 이미 보상받은 같은 수업·단원 | 0 | 정본 ID별 평생 한 번 처리한다. 당일 한도 이후의 새로운 완료도 소비된 ID로 기록된다. 다음 날 같은 완료를 다시 실행해 지급받을 수 없다. |

실제 카탈로그 스냅샷은 듣기 186개, 스몰토크 209개, 코스 단원 48개다. 예시 수업은 `smalltalk.a1.weather.outside` / “밖의 날씨” / “Das Wetter draußen”, 4문항이다. 제목·문항 수·파일 해시는 `content-demo.json`에 있다.

첫 학습이 건설 자격까지 열면 20+40을 함께 받을 수 있다. 여러 공정이 한 번에 열리면 40이 여러 번 더해질 수 있다. 화면의 20/10/40 세 장은 지급 원인을 나눠 보여주는 예시다. 앱 연결 시 확정 원장의 실제 합계와 항목을 표시해야 한다.

근거: `lib/services/yeopjeon_service.dart:203`(콘텐츠), `:252`(코스), `:299`(기한 복습), `:443`와 `:611`(일일 예산), `:507`(공정 지원). `lib/features/content_learning/content_lesson_screen.dart:731`(완료 호출). `lib/services/yeopjeon_learning_checkpoint.dart:62`(코스 완료 정산).

## 건설 규칙

한 공정 비용은 40엽전이다. 현재 구매 분류는 `sarangchae`와 `b2`; 서비스의 최대 공정은 각각 16과 34다. 일두고택의 모든 건물이 각각 엽전 구매 항목인 것은 아니다.

`buildNext`는 학습으로 열린 공정 수가 이미 지은 수보다 많고, 지갑 잔액이 40 이상이어야 실행된다. 잔액 -40과 소유 공정 +1을 함께 저장한다. 엽전이 많아도 학습 조건을 건너뛰지 못한다. 보상 연출이 자동으로 건설비를 쓰지 않는다.

근거: `lib/models/yeopjeon_wallet.dart:29`, `lib/services/yeopjeon_service.dart:350` 이후 건설 분기. 누락 지급 복구·초기 이전 데이터 기준선·중복 방지·계정 병합 검증도 같은 서비스와 지갑 원장에 있다.

## 이미지·영상·스킬 검토 범위

사용자의 generated_images 폴더에서 10월 2–9일 생성 또는 수정 기록에 해당하는 480개 파일을 기록했다. 이미지 471개 파일은 SHA-256 기준 430종, 영상 9개 파일은 8종이다. 이 대화에서 새로 만든 보상 보드는 이 원본 스냅샷 숫자에 포함하지 않았다. 파일 시간은 작업 이력을 찾는 기준이며 승인이나 저작 시각의 확정 근거는 아니다.

10월 2–3일 이미지 193종, 10월 4–9일 초기 이미지 229종을 15개 접촉 시트로 시각 검토하고, 동시 작업으로 추가된 8종도 별도 시트로 확인했다. 8종 영상의 주요 프레임을 확인했다. 모든 영상의 음성을 전부 청취했다는 뜻은 아니다. 사용자가 제공한 `http://127.0.0.1:8770/audit.html?page=23`의 268개 항목도 교차 대조했다.

설치·활성 플러그인 33개와 캐시/로컬 `SKILL.md` 737개 파일은 조사 스냅샷의 서로 다른 숫자다. 캐시에 있다는 이유로 737개 모두 활성 스킬이라고 하지 않는다. 10월10일 최신 요청까지 20개를 선정했다. 여기에는 추천 도구 검토와 Web Animations API에 원칙만 적용한 ECC 모션 참조도 포함된다. 정확한 적용 범위는 `audit/skill-inventory.json`의 reason/usage에 표시했다.

한옥 교체 전 현황만 읽기 전용으로 조사했다. C안 작업 공간의 개인 한옥 이미지 281개 중 159개는 알파가 있고, 73개는 불투명한 흰 모서리를 가진다. 전체 한옥 일괄 변환은 최신 사용자 지시로 보류했으며, 기존 정본 파일은 변경하지 않았다. 알파가 있다고 모든 가장자리 품질이 검증됐다는 뜻은 아니다. 상세 목록은 `audit/hanok-alpha-inventory.json`이다.
