# Lernen 화면별 검증

## 기준

- 시작 SHA는 691646faac575834e05a894a82ebd7afaa920f38입니다. Hören, Grammatik, Nuancen, Alltagsszenen의 네이티브 구현은 PR #474의 변경을 포함합니다.
- 독일어 100%로 확인했습니다. Wortpakete는 430×932, 이전 콘텐츠는 402×874 및 확보된 430×932 캡처를 표시했습니다. 특정 상태 테스트의 기본 크기가 다르면 실제 캡처 크기를 표시합니다.
- Flutter 위젯 렌더에서 캡처했습니다. 시스템 안전 영역, iOS와 Android 실기기, 시스템 오디오와 햅틱은 별도 검증 대상입니다. 동일한 데이터·상태인지 확인이 남은 캡처는 미검증으로 표시했습니다.
- 원본 SHA는 리사이즈 이전 파일의 SHA-256입니다. 여러 화면이 합쳐진 PNG는 보드 전체를 해시했고 개별 화면의 2pt·픽셀 판정은 보류했습니다. Figma 프레임과 원본 승인 근거를 각각 기록했습니다.
- Wortpakete PNG는 Lanczos로 430×932에 맞췄습니다. 숫자는 RGB 평균 절대 차이(0–255)와 RGB가 하나라도 다른 픽셀의 비율입니다. 사진 텍스처, 원본에 합성된 글꼴, 안전 영역과 공통 내비게이션을 모두 포함합니다.
- Wortpakete 레벨 선택 원본의 헤더는 y=42부터, A1–C2 원본은 y=0부터 시작합니다. 위젯 비교는 무인셋 기준이며 시스템 영역 차이를 실제 화면 배치와 분리합니다.
- A1의 하단 패널 상단은 무인셋 위젯 캡처에서 약 y=862, Figma에서는 약 y=831입니다. 원본·Figma의 홈 인디케이터와 공통 앱 내비게이션의 안전 영역 처리를 분리해 기록합니다.
- 캡처와 대조 이미지는 C:/dev/hangulsori/_codex_artifacts/lernen-parity-20261109에 보관합니다. Wiederholen은 사용자 승인 근거 확인 전 후보입니다.
