# Hangul Sori · 최종 승인 C 디자인 계약

계약 ID: `c-approved-visual-20261005-v1`. 사용자가 2026-10-05에 첨부하고 **최종 승인 메인과 Einleitung**이라고 지정한 8장(메인 5탭 + Einleitung 7페이지)이 화면 외형의 최우선 기준이다. 새 Flutter 화면과 목업은 이 문서의 소재·컴포넌트·간격을 공유한다.

**이미지 승인, 소스 구현, 측정 추정은 구별한다.** 이미지의 외형은 승인됐다. `current-source-exact`는 현재 Flutter 코드의 정확한 dp/sp 값이다. `raster-measurement`는 사람이 PNG 경계를 읽은 px 값이며 그림자·안티앨리어싱 때문에 ±3px 판독 오차가 있다. 이미지로부터 기기의 DPI, 실제 fontSize, 베지어 곡선이나 독립 레이어를 복구했다고 주장하지 않는다.

메인 원본은 1846×777이며 화면별 비교 영역은 약 350×756이다. Einleitung은 각각 853×1844이며 기존 원본 조각에서 확인한 내용 폭은 `x=53, width=747`이다. 기기 바깥 배경·금속 테두리·Dynamic Island는 **프레젠테이션 프레임**이다. 실제 Flutter는 OS SafeArea를 사용하며 가짜 기기 프레임·시각·배터리를 UI에 넣지 않는다.

갤러리의 390 비교 배율은 `390 ÷ 내용 영역 폭`이다. 이는 원본 비율 비교이며 dp 추출이 아니다. 앱의 고정 간격 토큰을 화면 너비에 비례해 모두 확대하지 않는다. 그림은 원본 비율을 유지하고, 넓이가 바뀌면 자연 높이가 바뀐다.

`reference/*.png`는 첨부 원본을 바이트 그대로 보존했다. Einleitung 7장은 생성 폴더 원본과 SHA-256까지 일치한다. 예전 1672×941 C 보드는 기존 그림 아틀라스의 출처로 남기며 최신 5탭 배치의 기준으로 사용하지 않는다. 승인 변경은 기존 파일 교체가 아니라 새 계약 버전으로 기록한다.

## Einleitung 공통 외형

녹청 꽃무늬 배경, 밝은 구름 로고, 황동 브랜드·단계, 원본 페이지별 진행 점, 큰 장면, 아래 한지 설명, 황동 CTA, Zurück, 하단 파도와 꽃의 순서다. 선택 점은 입체 금색이고 다른 점은 녹청 안쪽·금색 테두리다. 01에는 뒤로가기가 없으며 07에는 선택한 동행 이름이 CTA에 반영된다.

기존 원본 장면은 공통 `x=53, y=275, width=747`에서 시작하며 페이지별 높이는 다르다. `02=980`, `03=1068`, `04=930`, `05=1017`, `06=983`px이다. **이 차이를 모두 같은 heroHeight로 바꾸지 않는다.** 기존 46개 조각의 원본 사각형·비율·해시는 원장에 담았다. 장면은 BoxFit.contain/AspectRatio로 표시한다. 제목·꽃·갓·손·책·한옥이 들어 있는 원본을 수직으로 늘이거나 임의의 cover로 자르지 않는다.

Flutter 현재 프레임은 최대 폭 600dp, SafeArea, 스크롤 본문, 아래 CTA이다. 본문 안쪽 `(14,12,14,16)`, 아래 CTA 영역 `(14,8,14,6)`dp, 헤더 `(18,10,18,8)`dp이다. 이 값들은 **현재 구현**이며 승인 이미지의 큰 장면 배치·추가 버튼과의 차이는 다음 절에 따로 명시했다.

## 소스와 승인 시안의 차이: 명시적 미완료 항목

현재 `c_onboarding.dart`의 02–06은 설명 아래에 별도 녹청 미리보기 CTA를 추가하고, 다음 CTA도 페이지별 문구를 사용한다. 승인 비트맵은 02·05·06에 그 추가 버튼이 없고 하단은 Weiter이다. 03은 장면 속 Anhören, 04는 장면의 Vorschau가 별도 위치다. 이 차이는 **최종 시안과 일치 완료로 판정할 수 없다**. C 담당자는 기존 실행 경로를 유지하면서 버튼 위치·문구를 이 최종 시안에 맞춰 통합한다.

승인 원본 02·06·07에는 진행 점이 6개, 01·03·04·05에는 7개가 그려져 있다. 현재 Flutter는 모든 페이지에서 7개를 렌더한다. 실제 여정은 7단계이며, 이미지에 그려진 점 수를 콘텐츠 단계 수로 취급하지 않는다. 이 시각적 차이도 통합 검수에 남긴다.

현재 Flutter Einleitung 헤더는 HANGUL SORI를 쓰며 승인 이미지에는 EINLEITUNG이 있다. 07의 추가 Details 텍스트 버튼도 승인 이미지에 없다. 접근 경로 보존과 외형 일치를 함께 설계해야 한다. 본 문서화 작업은 공유 Flutter 파일을 변경하지 않았다.

독일어가 그림에 합쳐진 원본은 `bakedUiText`로 기록한다. 원본 독일어 위에 영어를 포개거나 그림 전체를 확대해서 접근성 글자 확대가 완료됐다고 판정하지 않는다. 동적 설명·Semantics는 EN/200%를 지원할 수 있지만 **그림 속 독일어 교체·큰 글자 버전의 승인까지 완료된 것은 아니다**. 재생성 없이 사용할 수 있는 장면 범위는 C 담당자가 원본 조각과 대조해 확정한다.

## 상태와 동작

기본·눌림·선택·포커스·disabled·busy·error·retry를 같은 소재 위에서 표현한다. SoriPressable이 키보드·포커스·누르기 취소를 담당한다. 빠른 중복 탭 방지는 소비자의 busy 상태와 기존 서비스가 담당하며 SoriPressable 자체는 탭 콜백을 중복 차단하지 않는다. CMaterialAction의 pressScale=.99, 표면 깊이 4dp, 표면 전환 120ms를 사용한다. SoriPressable의 눌림·복귀 시간은 각각 150/250ms이며, 모션 감소일 때 해당 애니메이션을 생략한다. 비활성 CTA는 조작을 막고 이유를 인접 텍스트/Semantics로 알려야 한다. 에러와 빈 데이터는 별도 상태다.

도깨비의 게임 접촉 반응은 승인된 별도 계약(100ms 상승·150ms 유지·900ms 감소, 최대 3dp)을 따른다. 소개 액자의 고정 큰 프레임·16장 불꽃·기존 변신 영상, 탈선비 6포즈·무음 부채 영상, 나전 상자의 개봉 → 단일 보상품 → 설명·저장된 XP·CTA → 문화 이야기는 원래 승인 계약을 유지한다. 이 정적 간격 문서에서 새 보상·새 애니메이션을 승인하지 않는다.

## Flutter와 종합코스 목업 적용

새 화면은 메인 스타일을 기본으로 한다. 입문 홍보 장면의 큰 글자·큰 캐릭터 비율을 모든 학습 카드로 복제하지 않는다. 종합코스는 같은 녹청·한지·책·도장·황동/녹청 CTA를 사용하며 바깥 12dp, 보드 안쪽 12dp, 제목 22sp, 본문 16sp, 카드 간격 10dp, CTA 최소 54dp를 공유한다. 한글·단어·평가·첫 시도·도움·저장 상태는 기존 콘텐츠·서비스에 연결한다.

HTML의 dp 상당 고정 간격은 px 토큰, sp 상당 글자는 rem을 사용한다. 200% 검수에서 고정 여백까지 두 배로 만들지 않는다. 그림 슬롯은 비율·역할로 결정한다. 상세 화면의 Back/진행 헤더는 해당 흐름에 필요한 native control이며 기존 메인 탭으로 오인되게 만들지 않는다.

코스 목업의 48유닛·30학습 단계·902태스크·224명시 참조 ID는 별도 [콘텐츠 연결표](../c_course_mockup_20261005/connections.html)에서 계속 확인할 수 있다. 시각 간소화는 자료 삭제를 뜻하지 않는다. 본격 실행·저장·평가·보상은 실제 Flutter 통합 단계에서 검증한다.
