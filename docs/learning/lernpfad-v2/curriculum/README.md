2026-10-23. 사용자 지정 [교육과정 원본](../reference/CURRICULUM_FOUNDATION_TO_C2.md) 1~14장을 구체화하고 [역사·첫걸음 원본](../reference/HISTORY_AND_FIRST_STEPS.md)을 사건·자료·학습 행동에 연결한 파생 설계다. **원본은 변경하지 않았다. 앱 디자인·화면 작업은 이 묶음에 포함하지 않는다.**

이 묶음은 학습 목표·단원 설계·기존 콘텐츠 배정과 첫 제작 대본이다. 전 구간의 실제 수업·음성·문항이 모두 제작됐다는 뜻이 아니다. 문법 배치·예문·평가 명세는 저작 후보이며 교원 감수·EN/DE 학습자 관찰 상태는 미완료다. 구간을 표시했다는 이유로 언어 능력이나 인증을 부여하지 않는다.

## 기존 콘텐츠 처리

[GRAMMAR_ALLOCATION.csv](GRAMMAR_ALLOCATION.csv)는 원문 모든 열을 그대로 보존하고 새 설계 열을 추가한다. 원 `review_status`는 그대로이며 새 배정이 교원 승인으로 덮어쓰지 않는다. 같은 표기의 다른 기능·같은 키의 재사용을 합치지 않는다. C2.2에는 문법 개수를 늘리기 위해 새 희귀 표현을 억지로 배정하지 않았다.

[COURSE_BINDINGS.psv](COURSE_BINDINGS.psv)의 48개 연결은 제목/목표에 대한 명시적 저작 판단이다. 예를 들어 첫 인사 코스의 기존 `concept_hangul_batchim` 준비 조건을 구어 인사의 필수 조건으로 이식하지 않는다. `a1_10_health_safety`의 현재 제목은 사과이므로 ID만 보고 의료 단원으로 배정하지 않는다. 원 코스를 이동·삭제하거나 기존 접근을 막지 않는다.

[EXISTING_TASK_CANDIDATES.csv](EXISTING_TASK_CANDIDATES.csv)의 712개는 문법 키 연결, 190개는 Phase 문맥 후보다. 후자는 해당 단원에서 적합한 문항이라고 판정한 것이 아니다. [EXISTING_CONTENT_CANDIDATES.csv](EXISTING_CONTENT_CANDIDATES.csv)는 개별 scenario/Smalltalk ID와 어휘팩·Smalltalk 범주·Cloze 주제 매핑을 구별한다. 범주 연결은 개별 문항 적합성 증거가 아니다. 게임의 성공 연출이나 재방문만으로 숙달·추가 보상을 만들지 않는다.

작업공간 루트에서 `rtk proxy python -X utf8 tool/check_curriculum_design.py`를 실행한다. 원고 수정 후 파생 CSV/JSON 갱신에는 `--write`를 사용한다. 쓰기 대상은 이 폴더의 파생 파일뿐이다.

검사 내용: 원본 해시·356행 누락/중복·336 새 도입/20 재사용 보존·단원 선행 그래프 순환·참조 존재·40자모 첫 도입·입문 확인 표적의 미학습 자모·첫 받침 확인 범위·기존 과제 ID·48개 코스 연결·보충 ID. [DESIGN_AUDIT.json](DESIGN_AUDIT.json)에 실제 입력 해시와 검증 경계를 남긴다. 구조 검사 성공을 언어 품질·학습 효과·실행 앱 검증으로 확대하지 않는다.
