## 구간별 제작 계약

각 행은 여러 작은 단원이다. 공통 산출물은 입장 준비, 새 학습/재사용, 실제 설명·시범, 목적 있는 활동, 다른 상황의 확인, 다음 구간의 재등장 ID와 검토 상태다. 아래는 제작 순서이며 출제 완료 목록이 아니다.
