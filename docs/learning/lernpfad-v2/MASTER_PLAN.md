## 데이터와 진도 계약

- 새 카탈로그는 구간·목표·선행 능력·활동·확인·이야기 연결을 정의한다. KP와 콘텐츠 ID 유지.
- 단일 읽기 판정기가 선택 레벨·기존 증거·복습·준비 상태에서 다음 활동과 진도를 계산한다.
- 기존 CoursePracticeContext와 적격성 검사를 사용하며 UI 성공 플래그는 숙달이 아니다.
- CourseMastery v5 유지. 버전 확장 기록은 기존 CourseProgressService의 직렬화·계정 경계에서 관리한다.
- 선택·위치·도움·재개와 명시적 새 수행 증거를 구분한다. 별도 잔액/임의 mastered 플래그 금지.
- F0는 A1 증거가 아니다. 상위 탐색 기록을 소급 승격하지 않는다. 새 확인의 허용 평가 범위는 시작 시 고정한다.
- 필수 단원 수가 분모다. 대체 활동은 한 번만, 선택 이야기·장식·반복은 제외한다.
- 미제작 필수 단원이 있으면 전체 완료 금지. 말하기·쓰기 미평가는 연습/미확인으로 남긴다.
- 개정 전 성취는 보존하고 새 기준 재확인을 별도 표시한다.
- 같은 작업 ID로 재시도하며 원본 증거 후 확장 저장 전 종료를 복구한다. 미완료 참조는 숙달 제외.
- 보관 한도로 원본이 없으면 확장 메타데이터로 복구하지 않는다. 근거 보관 정책을 검증한다.
- UI 되돌리기와 구버전 앱 사용은 별도다. 구버전 쓰기·백업·복원·계정 삭제 영향을 검사한다.
