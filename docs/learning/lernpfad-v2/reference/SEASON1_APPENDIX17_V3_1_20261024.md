## 17.1 설계 원칙

1. **메인은 수준과 무관, LQ는 곁이야기.** 핵심 단서와 결말은 초보도 번역·그림·음성으로 끝까지 본다(v3.0 §5). LQ는 같은 집의 *다른 쪽 얼굴*을 한국어로 만나는 선택 콘텐츠다.
2. **수준은 “추천”이지 “잠금”이 아니다.** 모든 LQ는 도움 모드(번역·그림)로 열 수 있다. 다만 한국어 수행 증거는 도움 사용 여부에 따라 분리 기록한다(CURRICULUM §12.2 접함 / 도움으로 수행 / 독립 수행 / 유지·전이).
3. **스포일러 게이트는 건물 완공이 아니라 “이야기를 본 여부”.** 본편의 증거·반전을 다루는 LQ만 `requires_story_seen`을 건다. 해당 에피소드를 직접 보거나 `story_journal`에서 복기하면 열린다. 건물을 다 짓지 않아도 된다.
4. **새 단서 0개.** LQ·EV·MQ는 S1-E01~E12에 새 증거를 보태지 않는다. 기존 단서를 다시 비추는 **재조명**, 또는 증거가 아닌 감정의 **메아리**만 허용한다. 필수 단서의 유일한 경로가 되지 않는다.
5. **한 퀘스트에 새 요소 하나.** 새 글자·새 어휘·새 문법·새 조작을 한 문제에 동시에 처음 투입하지 않는다(CURRICULUM §10.2).
6. **같은 사건을 열두 번 반복하지 않는다.** 수준이 오를수록 같은 질문(“이 집에서 무슨 일이 있었나”)을 *다른 렌즈*로 다루되, 건물과 장면은 분산한다.
7. **웃음과 존중의 균형.** 도깨비는 놀림감이 아니다. 코미디는 그의 으스댐을 건드리되, 연이와 기다림에 관한 대목은 진지하게 다룬다.
8. **번역으로 이해한 것은 한국어 증거가 아니다.** 사건 이해(번역·그림)와 언어 수행(한국어)을 화면과 저장 모두에서 분리한다.

## 17.3 레벨 퀘스트 16편

**공통 블록 규칙:** 모든 LQ는 `필요 → 시범 → 도움 연습 → 상황 사용 → 결과`(CURRICULUM §10.2) 순서를 따른다. 보상은 *기존 카탈로그만* 사용하며(`existing_catalog_only`), 같은 학습 성과에 엽전을 중복 지급하지 않는다. 퀘스트 카드는 도깨비 퀘스트 카드(v3.0 §14.C P1)에 표시하되, 의뢰자 표식은 의뢰하는 NPC의 것을 쓴다.

### LQ-01 · F0.1 · 「첫 장의 소리」

- **앵커:** 사랑채 착공 전~착공 · 탈선비의 임시 책 수업(v3.0 §4-01)에 붙음
- **훅:** 넓고 빈 사랑마당. 탈선비의 낡은 책은 첫 장이 비어 있다. 도깨비는 “글자 없는 책은 불쏘시개로도 못 쓴다!”고 투덜댄다.
- **흐름:** ① 책 첫 장에 흐릿한 *소리 자국*이 떠오르고 크리스티안이 따라 소리 낸다. ② 탈선비가 입 모양과 함께 ㅏ·ㅓ·ㅗ를 보여 준다(한 묶음 2~3글자). ③ 들은 소리와 모양 잇기, 첫소리 ㅇ 자리에 모음을 놓아 ‘아’ ‘오’ 조립. ④ 조이가 물어다 주는 소리 조각을 맞출 때마다 책 쪽이 한 장씩 밝아진다. ⑤ 크리스티안이 처음으로 한 글자를 읽는다.
- **핵심 한국어:** 아, 오 (확장: 어, 우). 도움 표현 `안녕하세요`는 뜻을 아는 도움 표현으로만 쓰고 자모 학습 완료로 기록하지 않는다.
- **학습 증거:** 소리-모양 연결(도움으로 수행). 독립 수행은 *새 결합*에서만 기록.
- **스토리 기능:** 1화 “한국어 첫 소리”와 사랑채 중간 beat(“탈선비가 첫 글자 읽기에 반응”)를 보강. **단서 영향 없음.**
- **접근성:** 소리 반복 재생·입 모양 애니·그림 응답. 오디오 불가 시 입 모양과 자막 표기로 대체. 로마자는 요청 시 임시 보조일 뿐 해독 증거로 기록하지 않는다.
- **책갈피:** “허허, 소리가 먼저이고 글자는 그 소리의 옷이라네.”

### LQ-02 · F0.2 · 「도깨비의 푯말」

- **앵커:** 창고 착공 · 자재가 뒤섞여 호통치는 장면(v3.0 §4-02)
- **훅:** 도깨비가 자재 상자에 직접 푯말을 써 붙였는데 글자가 이리저리 뒤섞여 있다. “내가 쓴 건 맞다! 글자가 제멋대로 도망간 게야!”
- **흐름:** ① 그림 속 도구를 보고 뜻을 안다. ② 이미 배운 자모로 이루어진 낱말 소리·뜻·표기 연결. ③ 흩어진 글자 조각을 짜 맞춰 푯말 고치기. ④ 고친 푯말을 해당 상자에 붙이면 정리 완료.
- **낱말(2개 묶음으로 분리):** `나무 · 도구 · 마루` / `바구니 · 소나무 · 모자` (받침 없는 글자만, 한 묶음 3어휘)
- **학습 증거:** 의미를 배운 낱말을 읽고 그림에 연결. 비단어 사용 시 “뜻 없는 소리 연습”임을 고지.
- **스토리 기능:** 창고 코미디 beat 보강. 도깨비의 글 서툼을 *가볍게 암시* — 후반 성장 장치(v3.0 §2)의 씨앗. 창고 중간의 *낡은 상자(S1-E03)는 건드리지 않는다.* **단서 영향 없음.**
- **접근성:** 낱말 읽어 주기, 그림 하이라이트, 글자 조각 확대.
- **책갈피:** “글자는 도망가지 않네. 자리를 바꿔 앉았을 뿐이지.”

### LQ-03 · F0.3 · 「문에 이름 달기」

- **앵커:** 중문간채 착공 · 크리스티안의 “We already built a gate!” 항의 뒤(v3.0 §4-03)
- **훅:** 안쪽 길에 이름표가 없어 수진이 안채 쪽으로 가려다 헛걸음한다. 도깨비 왈 “길을 모르면 글자가 알려 주면 되지!”
- **흐름:** ① ‘아래 칸’이 있는 글자(받침)를 처음 본다 — 문, 방, 길. ② 첫소리 ㅇ과 받침 ㅇ의 차이를 `마당`으로 확인. ③ 이름표를 해당 장소에 붙이면 미니맵 길 안내가 열린다(안쪽 동선 탐색 = 중문간채 중간 beat와 연결). ④ 도깨비가 `마당` 이름표 앞에 한참 서 있다.
- **낱말:** 문(ㄴ) · 방(ㅇ) · 길(ㄹ) · 마당(ㅇ). 새 받침은 한 번에 많아야 둘.
- **스토리 기능:** 문턱·출입의 의미(v3.0 §4-03 주제) 예고. 이름표는 **미니맵·UI 표지**로만 표시하고 *맵 위 소품은 추가하지 않는다*(사랑마당을 비워 두는 V2 원칙).
- **접근성:** 소리·그림·번역 병행. 글자 크기 조절.
- **책갈피:** “문 하나에도 이름이 있으면 길이 되는군.”

### LQ-04 · F0.4 · 「처음 쓴 낱말」

- **앵커:** 사랑채 완공 · 등불이 켜지는 장면(v3.0 §4-01 완공)
- **훅:** 도깨비가 “드디어 이 집에 불이 켜지는구나!” 외친 뒤 사랑채 책상 위에 빈 쪽지 한 장이 놓인다. 탈선비: “자, 이 집의 첫 쪽지를 써 보세.”
- **흐름:** ① 두벌식 입력의 기초(ㅈ ㅣ ㅂ이 한 음절로 모이는 과정). ② 본 뒤 쓰기 → 일부 가리고 쓰기. ③ 낱말 `집 · 책 · 밥`(받침 ㅂ·ㄱ 계열). ④ 띄어쓰기의 첫 원리로 `이 집` 두 낱말을 쓰면 쪽지가 완성된다.
- **스토리 기능:** 크리스티안이 한국어로 *처음 쓴 낱말은 `집`*이다. 쪽지는 사랑채 책상에 보존되고, **최종 사랑채 장면에서 같은 쪽지가 다시 열린다**(“나는 집을 잊은 적이 없다”를 읽기 직전). **감정 메아리(echo)이며 증거가 아니다.** 편지 내용을 암시·누설하지 않는다.
- **학습 증거:** 도움 없이 새 단어 입력은 *독립 수행*으로, 보고 따라 쓴 것은 *도움으로 수행*으로 분리.
- **책갈피:** “처음 쓴 낱말이 ‘집’이라니, 허허, 좋은 시작일세.”

### LQ-05 · A1.1 · 「문지기 도깨비」

- **앵커:** 중문간채 중간 · 안쪽 동선 탐색(v3.0 §4-03 중간)
- **훅:** 문 앞을 막아선 도깨비. “이 문을 지나려면 누군지 밝혀라!” 수진은 웃으며 “들어가도 돼요?”를 가르쳐 준다. (집터의 경계를 지키는 도깨비의 성격을 코미디로 보여 주는 장면. 수호기와는 언급하지 않는다.)
- **흐름:** ① 문이 열리지 않는다(필요). ② 탈선비가 소개 틀을 시범. ③ 크리스티안과 수진이 번갈아 소개 연습. ④ 조이·태고가 차례로 문 앞에서 소개하고, 도깨비가 일부러 못 알아듣는 척하면 `다시 말해 주세요`로 되묻는다. ⑤ 문이 열린다.
- **핵심 한국어:** `저는 ○○예요/이에요.` `이름이 뭐예요?` `누구예요?` `다시 말해 주세요.` `한국어를 몰라요.` 은/는은 자기소개 맥락에서만.
- **전이 확인(CURRICULUM A1.1):** 처음 보는 NPC에게 소개하고, 다른 물건을 요청하고, 못 들었을 때 되묻는다. 소개문을 외워 재생하는 것만으로 통과하지 않는다.
- **스토리 기능:** 중문간채 코미디 beat. **단서 영향 없음** (S1-E04 “문을 넘는 인영”은 완공 beat이며 이 퀘스트와 분리).
- **책갈피:** “이름을 묻고, 다시 묻는 것도 훌륭한 말하기라네.”

### LQ-06 · A1.2 · 「도깨비 공사 시간표」

- **앵커:** 아랫채 착공 (v3.0 §4-04, “하루 일과·묻고 재확인” 담당)
- **훅:** 도깨비가 공사 시간을 마음대로 통보한다. “내일 새벽에 모여라! 모레는 쉰다!” 크리스티안은 영어로 항의하다가 탈선비의 도움으로 한국어로 확인한다.
- **흐름:** ① 시간표 화면에서 몇 시, 무슨 요일인지 읽는다. ② `몇 시예요?` `무슨 요일이에요?`로 확인. ③ 시간이 맞지 않으면 다른 시간 제안: `내일 아침 아홉 시에 만나요.` ④ 도깨비의 하루 일과를 듣고 정리(마당을 둘러보고, 저녁에 달을 본다).
- **전이 확인(A1.2):** 일정 정보를 듣고 약속을 잡되 시간이 맞지 않으면 다른 시간을 제안하고, 잘못 이해했으면 확인해서 고친다.
- **스토리 기능:** 아랫채 착공의 *보자기 매듭 발견*(S1-E05 시작)과 **분리**. 이 퀘스트의 물건은 일꾼 도구뿐이다. **단서 영향 없음.**
- **책갈피:** “시간을 묻는 이는 약속을 지키는 이가 되지.”

### LQ-07 · A2.1 · 「배탈 난 도깨비」

- **앵커:** 남측 측간 중간 (v3.0 §4-05 “사용 순서·주의 표현”) · 쉬어 가는 코미디 회차
- **훅:** “나는 그런 게 필요 없지!”라고 으스대던 도깨비가 홍시를 몰래 먹고 배탈이 났다. 조이가 걱정되어 크리스티안을 끌고 온다.
- **흐름:** ① `어디가 아파요?` `언제부터 아팠어요?`로 증상을 묻는다. ② 생활 수준의 조언: `따뜻한 물을 마셔 보세요.` `오늘은 쉬어야 해요.` `차가운 건 먹으면 안 돼요.` ③ 도깨비가 반박하면 조건을 바꿔 제안(원하는 조건이 안 되면 대안). ④ 도깨비가 결국 측간 앞으로 달려간다.
- **핵심 한국어:** -아/어 보세요, -아/어도 되다, -(으)면 안 되다, -아/어야 하다.
- **전이 확인(A2.1):** 문제 상황과 해결 요청을 연결하고, 조건이 맞지 않으면 대안을 선택한다.
- **주의:** 의료·위생 설명은 일반 생활 수준에 머문다 [감수 필요]. 판타지 연출은 판타지로 표기한다.
- **스토리 기능:** 도깨비의 “필요 없다”가 무너지는 생활 코미디. **단서 영향 없음.**
- **책갈피:** “아플 때 아프다고 말하는 것도 공부일세.”

### LQ-08 · A2.2 · 「안마당에서 들은 이야기」

- **앵커:** 안채 중간 · 어린 연이의 생활 기억 직후(v3.0 §4-06)
- **게이트:** `S1-E06` 중간을 본 뒤
- **훅:** 비어 있던 안마당에 소리 조각 세 개가 남아 있다 — 웃음소리, 발걸음, 장난치는 소리. 수진과 크리스티안이 하나씩 모은다.
- **흐름:** ① 소리 조각마다 도깨비에게 `이런 적이 있어요?` `그때 어땠어요?`로 묻는다. ② 도깨비는 퉁명스럽게 답한다(“논 게 아니라 지킨 게다!”). ③ 크리스티안이 너무 직설적으로 말해 도깨비가 입을 닫으면, 오해한 부분을 다시 설명하고 사과한다(`제가 잘못 말했어요. 미안해요.`). ④ 소리 조각을 보관함에 둔다.
- **핵심 한국어:** -(으)ㄴ 적이 있다, -게 되다, -(으)면서, -는데(배경), -(으)ㄹ게요.
- **전이 확인(A2.2):** 상황을 설명하고 상대가 잘못 이해한 부분을 다시 설명한다.
- **스토리 기능:** E06 “내가 네 가족 하면 되겠다”를 *대신 말해 주지 않는다*. 도깨비가 “그 아이”라는 말을 하다 말고 헛기침하는 정도로 멈춘다. **E06 재조명(감정), 새 정보 없음.**
- **책갈피:** “말이 닿지 않았을 땐 다시 말하면 된다네.”

### LQ-09 · B1.1 · 「꽃이 피기까지」

- **앵커:** 안채곳간채 완공 · 마당의 작은 꽃 한 구역이 활기를 찾는 장면(v3.0 §4-07)
- **게이트:** `S1-E07`
- **훅:** 조이가 꽃구역의 기억 날짜를 넘겨 가며 “어? 순서가 헷갈려!”라고 한다. 도깨비는 “물 주느라고 밤을 새웠다”고 생색낸다.
- **흐름:** ① 씨를 심은 날 → 싹 → 비 → 시듦 → 다시 핀 날의 장면 카드를 순서대로 놓는다. ② 각 변화의 원인을 연결한다. ③ 수진에게 보내는 짧은 일지/메시지로 꽃이 어떻게 피었는지 설명한다. ④ 수진의 추가 질문(`언제 물을 줬어요?`)에 정보를 보완한다.
- **핵심 한국어:** -다가, -자마자, -고 나서, -았/었더니, -느라고. **발신인 추측은 하지 않는다**(사실과 추측의 본격 분리는 LQ-10).
- **전이 확인(B1.1):** 일어난 일을 상대에게 설명하고 추가 질문에 정보를 보완한다.
- **스토리 기능:** S1-E07 씨앗 주머니 **재조명**. 새 단서 없음. 꽃구역은 기억 재현이며 500년 보존 실물이 아니다.
- **책갈피:** “순서를 아는 이는 이야기를 잃지 않는다네.”

### LQ-10 · B1.2 · 「누가 뭐라고 했나」

- **앵커:** 곳간채 중간 · 세 물건 비교 미니게임(v3.0 §4-09)과 나란히 제공되는 *증언 정리 모드*
- **게이트:** `S1-E07` + `S1-E08` 착수(장부 일부가 드러난 뒤)
- **훅:** 조이, 도깨비, 수진이 같은 장부를 두고 서로 다르게 말한다. 크리스티안은 누가 무엇을 말했는지부터 정리해야 한다.
- **흐름:** ① 세 사람의 진술 카드를 읽고 `조이가 ○○라고 했어요`처럼 전달한다. ② 질문·제안·명령을 간접인용으로 구분. ③ 내 판단은 따로 표시한다(`~인가 봐요`, `~나 봐요`). ④ **같은 장부를 두 번 본 것은 독립 증거 두 개가 아니다** — 중복 카드는 한 장으로 합쳐진다(v3.0 §7 증거 운영 규칙을 규칙 체험으로).
- **핵심 한국어:** -다고/-냐고/-자고/-(으)라고 했어요, -나 보다/-(으)ㄴ가 보다.
- **전이 확인(B1.2):** 서로 다른 설명을 비교해 확인된 사실과 추측을 구분하고, 이유를 붙여 선택한다.
- **스토리 기능:** E08 “발신자가 여러 명일 수 있음” 상태를 *그대로 유지*. 결론을 앞당기지 않는다. `아직 확실하지 않아요`를 도깨비에게 말하는 것이 퀘스트의 감정적 출구.
- **책갈피:** “들은 말과 본 것은 서로 다른 서랍에 넣게.”

### LQ-11 · B2.1 · 「두 기록을 나란히」

- **앵커:** 안사랑채 착공~중간 ① · 탈과 책의 기억(v3.0 §4-10)
- **게이트:** `S1-E08`, `S1-E09`
- **훅:** 조이가 가져온 곳간채 장부 사본과 탈선비의 낡은 공부책. 둘 다 연이와 가까운 기록 같지만 서로 말하는 바가 다르다.
- **흐름:** ① 두 자료의 공통점·차이·한계를 표로 정리한다. ② “꽃이 핀 해에 도깨비 기분이 좋았다 → 꽃 때문?”처럼 *상관을 원인으로 단정하는 문장*을 고쳐 쓴다. ③ 역사 해설 카드에서 **실제 역사(무오사화 등)와 이 이야기의 창작**을 구분 표시한다. ④ 두 자료를 근거로 판단을 말하고, 판단과 사실을 분리해 설명한다.
- **핵심 한국어:** -는지, -(으)며, -에 따라, -(으)로 인해, -는 바람에.
- **전이 확인(B2.1):** 두 자료의 공통점·차이·한계를 설명하고 자신의 판단을 근거와 구분해 말한다.
- **금지:** 태고·조이의 조각난 기억(E10)과 신수의 진실을 *미리 암시하지 않는다.* 역사 해설은 [감수 필요].
- **스토리 기능:** E09 탈·공부책 **재조명**.
- **책갈피:** “두 기록이 어긋날 때가 읽는 이의 일이 시작되는 때라네.”

### LQ-12 · B2.2 · 「사랑채 토론 — 연이는 도둑인가」

- **앵커:** 사랑채 · 처음 복원한 공부 자리. 크리스티안의 “She looked scared, not greedy.”(v3.0 §4-04) 이후
- **게이트:** `S1-E05` (E10을 보았는지에 따라 대사 분기)
- **훅:** 도깨비는 여전히 “책을 들고 떠났다”고 화가 나 있다. 수진이 사회를 맡아 토론 자리를 연다. 태고는 판단을 유보한다.
- **흐름:** ① 학습자가 입장을 고른다(의심 / 이해 / 조정). ② 상대의 주장을 왜곡하지 않고 되말하기(`~라는 말씀이죠?`). ③ 반론에 따라 주장을 고치거나 근거를 보강한다. ④ 합의안 작성: 어떤 조건이면 입장이 바뀌는가를 문장으로 쓴다.
- **분기:** **E10 전**은 ‘모르는 상태의 의혹 토론’, **E10 후**는 ‘그날 우리가 몰랐던 것’을 돌아보는 회고 토론. 두 분기 모두 *정답을 확정하지 않는다.*
- **핵심 한국어:** -는다면, -더라도, -는 한, -는 듯하다, -(으)ㄹ 모양이다, -나 싶다.
- **전이 확인(B2.2):** 반론을 듣고 주장을 수정하거나 근거를 보완하며, 합의안을 작성한다.
- **스토리 기능:** E05 **재조명**. 도깨비의 분노를 *비웃지 않고*, 말이 닿는 방식을 보여 준다.
- **책갈피:** “이기는 말보다 닿는 말을 찾게.”

### LQ-13 · C1.1 · 「수령 장부 보고서」

- **앵커:** 곳간채 완공 이후 · 원본·사본·추정 표시를 분리한 창작 기록(v3.0 §4-09)
- **게이트:** `S1-E08`
- **훅:** 수진이 “이걸 자료로 정리해 줄 수 있어요?”라고 부탁한다. 도깨비도 듣겠다고 하지만 “어려운 말은 모르겠다”고 미리 말해 둔다.
- **흐름:** ① 자료를 출처별로 나눠 주장·방법·한계·신뢰도를 정리한다. ② 직접 인용과 바꿔 쓰기를 구분하고 출처를 표시한다. ③ **같은 내용을 두 번 쓴다** — 수진을 위한 보고문과 도깨비를 위한 쉬운 설명. ④ ‘다음에 확인할 기록’ 목록을 만든다(곳간채 완공 beat의 결론과 일치).
- **핵심 한국어:** -에 관하여, -기에 앞서, -는 가운데, -는 듯하다.
- **전이 확인(C1.1):** 여러 자료를 근거와 한계가 드러나게 통합하고 비전문 청자에게 핵심을 쉽게 설명한다.
- **금지:** 발신인을 *확정*하지 않는다. 자유 글쓰기는 연습·포트폴리오이며 자동 숙달 인증이 아니다(CURRICULUM §12.3).
- **책갈피:** “아는 것을 쉽게 말하는 이가 진짜 아는 이일세.”

### LQ-14 · C1.2 · 「돌려서 말하는 법」

- **앵커:** 사당 착공 · 도깨비가 차분히 사당 영역을 다뤄 달라고 부탁하는 장면(v3.0 §4-11)
- **게이트:** `S1-E08`, `S1-E10`
- **훅:** 도깨비는 “발신인이 그 아이일지도 모른다”는 말에 예민하다. 크리스티안은 *증거가 아직 부족하다*는 사실을 전해야 한다.
- **흐름:** ① 같은 정보를 세 청자(도깨비·수진·태고)에게 다르게 전한다. ② 도깨비에게는 존중을 지키되 숨기지 않는다. ③ 상대가 함축을 오해하면 확인 질문으로 회복한다. ④ 높임·문체를 일관되게 유지하고, 필요할 때만 전략적으로 바꾼다.
- **핵심 한국어:** -는데도 불구하고, -(으)ㄹ뿐더러, -기에 따라, -는 이상, -다가는, -다기에/-길래.
- **전이 확인(C1.2):** 같은 정보를 두 종류의 청자에게 다르게 설명하고, 함축을 오해했을 때 확인 질문으로 회복한다.
- **사당 원칙:** 코미디를 최소화한다. 유물 훼손·파헤침·‘숨겨 둔 편지’ 연출 금지(v3.0 §15.5). 도깨비의 마지막 대사는 `…알겠다. 확인하자.` 정도로 *섣부른 확언 없이* 멈춘다.
- **스토리 기능:** E08→사당 중간 **교차 확인**의 *말하기 준비*. 새 증거 없음.
- **책갈피:** “돌려 말하는 것과 속이는 것은 다른 일이라네.”

### LQ-15 · C2.1 · 「그 말의 무게」

- **앵커:** 안채 · 연이의 한마디 “그럼 내가 네 가족 하면 되겠다.”(S1-E06)
- **게이트:** `S1-E06`
- **훅:** 도깨비·태고·탈선비·조이·수진이 각자 기억하는 *그 말*이 조금씩 다르다. 억양, 앞뒤 상황, 도깨비의 반응까지.
- **흐름:** ① 같은 말의 가능한 해석을 나열한다 — 아이의 농담 / 위로 / 제안 / 약속. ② 증언마다 **화자 신뢰도**(기억 재현은 불완전하다)를 표시한다. ③ 확정할 수 없는 부분을 구분해 표시한다. ④ 어떤 해석을 택했는지, 왜 그렇게 택했는지를 다른 사람에게 풀어 설명한다.
- **핵심 한국어:** -(으)ㄴ들, -기로서니, -되, 중의성·아이러니의 해석. 옛말은 이해용 확장으로만 제공.
- **전이 확인(C2.1):** 같은 발화의 가능한 해석을 문맥 근거로 비교하고, 확정할 수 없는 부분을 구분한다.
- **스토리 기능:** 피날레의 “내게도 가족이 있었구나”를 더 풍부하게 만드는 **메아리**. 정답 하나로 닫지 않는다. 태고는 *전지적 화자가 되지 않는다*.
- **책갈피:** “같은 말도 듣는 마음에 따라 다른 말이 되는 법이지.”

### LQ-16 · C2.2 · 「새 쪽」

- **앵커:** 최종 사랑채 이후 · 후일담
- **게이트:** 시즌 결말
- **훅:** 탈선비의 책 맨 뒤에 비어 있는 쪽이 하나 생긴다. 편지에 있던 “먼 훗날 이 글을 읽는 사람”에게 응답하듯.
- **흐름:** ① 처음 보는 복합 자료(연이의 세 물건, 장부, 편지의 학습용 풀이)를 읽는다. ② 짧은 발표 또는 글로 재구성한다. ③ 수진·탈선비의 비판 질문에 답한다. ④ 도깨비를 위한 짧은 버전으로 다시 쓴다. ⑤ 마지막으로 책의 ‘새 쪽’에 **다음 사람에게 남기는 글**을 쓴다.
- **전이 확인(C2.2):** 처음 접한 복합 자료로 발표 또는 글을 만들고, 비판 질문에 답한 뒤 다른 청자를 위한 짧은 버전으로 재구성한다.

- **책갈피:** “이제는 자네가 가르치는 쪽이로군.”

## 17.4 계절 이벤트 5편

**운영 규칙:**

- 달력 연동은 *선택*. 계절 주간에 앱 안에서 열리고 놓쳐도 `기억 다시 보기`로 언제나 재방문한다.
- 보상은 도감·꾸미기 상태뿐. **엽전 중복 지급 없음.** 알림 문구는 환영형(죄책감 유발 금지).
- 한 이벤트를 **초급(A1~A2) / 중급(B1~B2) / 상급(C1~C2)** 3단으로 참여한다. F0는 낱말 읽기·소리 맞추기 한 가지로 가볍게 참여한다.
- 이벤트는 **새 단서를 추가하지 않는다.** 연이의 세 물건은 해당 에피소드를 본 뒤에만 계절 장식으로 등장한다.
- **후일담 변형(Post-ending variant):** 시즌 결말 이후 같은 이벤트에 연이의 편지 속 계절 한 줄이 *메아리*로 더해진다 (봄의 꽃, 여름의 처마, 겨울의 혼자 지킴).

## 17.6 트리거와 데이터 계약 확장

### 17.6.1 신규 트리거 제안 (v3.0 §5.2의 4개에 추가)

| 트리거 코드 | 조건 | 처리 |
|---|---|---|
| `LEARN_BAND_RECOMMENDED` | 학습 구간이 LQ의 추천 구간에 도달 | 의뢰 카드에 *추천 표시*만 한다. 잠금 해제가 아니다 |
| `SEASON_WINDOW` | 계절 이벤트 기간 | 이벤트 카드 노출. 기간 이후에도 `기억 다시 보기`로 접근 |
| `STORY_SEEN` | 해당 `story_event_id` 재생 완료 또는 `story_journal` 복기 | 스포일러 게이트 해제 |

### 17.6.2 JSON 필드 확장 예시 (신규 제안, 저장소에 존재한다고 주장하지 않음)

```json
{
  "story_event_id": "S1-LQ-05",
  "quest_type": "LEVEL_QUEST",
  "learning_band": "A1.1",
  "recommended_band_only": true,
  "building_catalog_name": "중문간채",
  "stage_id": null,
  "trigger_type": "STRUCTURE_MILESTONE",
  "requires_story_seen": [],
  "spoiler_tier": 0,
  "evidence_impact": "none",
  "mandatory_story_fact": false,
  "npc_ids": ["dokkaebi", "talsunbi", "sujin", "joi"],
  "clue_id": null,
  "help_modes": ["translation", "picture", "audio_off_visual"],
  "localizations_required": ["de", "en", "ko"],
  "replayable": true,
  "reward_policy": "existing_catalog_only",
  "fallback_access": "story_journal"
}
```

- `evidence_impact`: `none` / `echo`(감정 메아리) / `reexamine`(기존 단서 재조명). **`new_clue`는 허용하지 않는다.**
- `spoiler_tier`: 0 = 전부 열림 / 1 = 해당 건물 중간 이후 / 2 = 해당 에피소드 완료 이후 / 3 = 시즌 결말 이후.
- 이벤트 ID 네임스페이스: `S1-LQ-nn`, `S1-EV-nn`, `S1-MQ-nn`. 기존 앱 ID와 겹치지 않으며 마이그레이션은 별도 작업이다.
- 학습 증거는 *기존 앱 로직*이 소유한다. 퀘스트 완료가 숙달 표시를 직접 만들지 않는다(CURRICULUM §13-5).

## 17.8 출시 전 점검 (v3.0 §12.1 체크리스트에 추가)

- [ ] 11동·128공정·4막·33접점·12단서 수치가 바뀌지 않았다.
- [ ] 모든 LQ·EV·MQ가 한국어 초보·건물 미완공·오디오 불가 상태에서도 *이야기로는* 접근 가능하다(번역·그림 도움 모드).
- [ ] 스포일러 게이트는 건물 완공이 아니라 `STORY_SEEN`으로만 건다.
- [ ] 새 단서가 없고, 연이의 편지 낭독과 도깨비의 오해 해소 순서(v3.0 §7.1)를 앞당기지 않았다.
- [ ] 연이 소품에 수호기와·신수 문양·공식 인장을 쓰지 않았고, 사당을 발굴 장소로 쓰지 않았다.
- [ ] 한 퀘스트에 새 글자·새 어휘·새 문법·새 조작이 동시에 처음 나오지 않는다.
- [ ] 번역으로 이해한 내용을 한국어 독해 증거로 기록하지 않는다.
- [ ] 보상이 기존 카탈로그만 사용하고 중복 지급되지 않는다(idempotent).
- [ ] 실제 역사 해설과 창작이 라벨로 구분되고 [감수 필요] 항목이 해소되었다.
- [ ] 도깨비를 조롱하는 대사 없이, 연이와 기다림에 관한 대목은 진지하게 다룬다.
- [ ] 계절 이벤트를 놓쳐도 손해나 죄책감 문구가 없다.
- [ ] 한국어 대사·학습 문장은 DE/EN 정본 번역과 함께 G3 감수를 거쳤다.

**게이트 연계:** G1(128공정 매핑)이 끝나면 앵커 접점을 실제 `stage_id`에 재배치한다. G3(장면 대사)에서 LQ 대사와 책갈피를 검수한다. G4(플레이 검증)에서 *무과금·미완공·F0/상급·오디오 불가·접근성* 조합을 LQ별로 확인한다.
