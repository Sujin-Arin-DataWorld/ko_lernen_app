# 한글소리 전체 교육과정 제안 — 완전 입문부터 C2.2까지

작성일: 2026-10-23 · v0.1 · 사용자 검토용 교육 설계안

목적: 라틴 문자에 익숙하고 한국어를 전혀 모르는 성인이 과부하 없이 시작하여, 생활 의사소통에서 전문적·정교한 언어 사용까지 성장할 수 있도록 전체 학습 범위와 순서를 먼저 정한다. 이후 일두고택의 사건·인물·퀘스트를 이 교육과정에 연결한다.

이 문서는 제안이다. 앱 콘텐츠·진도·평가·보상은 변경하지 않았다. 아래 배치와 분량은 교수 설계 판단이며 공식 CEFR 문법 등급표 또는 능력 인증이 아니다.

## 1. 전체 구조와 명칭

**완전 입문 F0 → A1.1 → A1.2 → A2.1 → A2.2 → B1.1 → B1.2 → B2.1 → B2.2 → C1.1 → C1.2 → C2.1 → C2.2.**

- F0는 앱의 문자·소리 준비 과정이다. CEFR의 공식 추가 등급을 만들었다는 뜻이 아니다. 한글을 읽을 수 있는 학습자는 필요한 부분만 보충한다.
- A1~C2는 기존 앱의 여섯 수준을 유지한다. `.1/.2`는 각 수준의 전반·후반을 보여 주는 새 표시 체계 제안이다. 한 구간은 여러 단원과 복습으로 구성되며 한 번의 수업이 아니다.
- **한국어 표준 교육과정 1~6급, TOPIK 시험 등급, CEFR A1~C2는 서로 다른 체계다.** 앱의 여섯 수준을 곧바로 한국어 1~6급 또는 TOPIK 성적으로 인증하지 않는다. 한국어 표준 교육과정의 생활→사회→전문 영역 범위와 CEFR의 수행 목표를 각각 참조한다.
- C2는 한자·고문·사극 말투를 모두 암기하거나 원어민 억양을 복제하는 과정이 아니다. 복잡한 정보를 정밀하게 이해하고, 상황에 맞게 재구성하고, 의미 차이를 표현하는 과정으로 설계한다.
- 읽기·듣기·말하기·쓰기는 별도로 관찰한다. 읽기만 빠른 사람, 한국어를 듣고 말하지만 글자를 모르는 사람을 동일한 경로에 가두지 않는다.

## 3. 완전 입문 F0: 글자를 배우면서 이미 참여한다

### 3.1 두 흐름을 병행한다

**문자 흐름:** 소리와 모양 연결 → 음절 블록 조립 → 단어 읽기 → 받침과 연결 발음 → 짧은 문장.

**의사소통 흐름:** 그림·행동·번역으로 상황 이해 → 인사·선택·도움 요청을 음성으로 경험 → 익힌 단어로 짧게 참여 → 문장으로 확대.

첫날의 `안녕하세요`, `감사합니다`, `다시 말해 주세요`는 음성·의미 단위의 도움 표현으로 쓸 수 있다. 해당 표현을 보여 줬다는 이유로 그 안의 모든 자모·문법을 배웠다고 기록하지 않는다. 복잡한 받침이나 모든 자음 대립의 정확한 발음을 A1 대화 시작 조건으로 두지 않는다.

### 3.2 준비 과정을 네 묶음으로 보여 준다

| 묶음 | 배우는 것과 순서 | 가능한 활동 | 아직 요구하지 않는 것 |
|---|---|---|---|
| F0.1 소리와 첫 글자 | 한글은 소리를 나타내는 글자이고 음절 단위로 모아 쓴다는 원리. 기본 모음 ㅏ·ㅓ·ㅗ·ㅜ·ㅡ·ㅣ를 작은 묶음으로, 첫소리 ㅇ의 자리, 세로·가로 모음 배치 | 들은 소리와 모양 연결, 아·오 등의 블록 조립, 그림으로 응답 | ㄱ부터 ㅎ까지 이름 암송, 문장 읽기, 조사 선택 |
| F0.2 받침 없는 글자와 단어 | ㄴ·ㅁ 같은 소수 자음부터 익히고 ㄱ·ㄷ·ㄹ·ㅂ·ㅅ·ㅈ·ㅎ 등 기본 자음 확대. 자음+모음 결합. 배운 글자만으로 된 낱말의 의미·소리·표기를 연결 | 나무·모자 등의 단어를 의미 소개 후 조립·읽기, 캐릭터의 물건 표지 맞추기 | 처음 보는 단어의 뜻까지 추측하기, 글꼴 모양 외우기로 정답 맞히기 |
| F0.3 글자 확장과 첫 받침 | ㅑ·ㅕ·ㅛ·ㅠ, ㅋ·ㅌ·ㅍ·ㅊ, ㄲ·ㄸ·ㅃ·ㅆ·ㅉ를 분산 도입. ㅐ·ㅔ 및 자주 쓰는 합성 모음. 받침 ㅁ·ㄴ·ㅇ·ㄹ부터; 첫소리 ㅇ과 받침 ㅇ의 차이 | 이미 배운 소리의 새 결합 읽기, 배운 물건의 표지 찾기, 이름표 조립 | 평음·격음·경음을 한 번에 완벽히 발음하기, ㅐ·ㅔ 청취만으로 엄격하게 선별하기 |
| F0.4 읽기에서 첫 문장으로 | 받침 ㄱ·ㄷ·ㅂ 계열과 끝소리의 기본, 쉬운 연음, 남은 모음과 자모 복습, 자주 쓰는 단어, 띄어쓰기의 첫 원리, 두벌식 입력의 기초 | 익힌 짧은 단어를 읽고 행동하기, 본 뒤 쓰기→일부 가리고 쓰기, 짧은 메시지 따라 구성 | 모든 겹받침·음운 변동 암기, 자유 작문, 조사 미세 차이 시험 |

각 행은 여러 짧은 단원이다. F0.3~F0.4는 A1.1의 쉬운 대화와 병행할 수 있다. 출제기는 전체 F0 완료 여부보다 **그 문제에 필요한 자모·단어·규칙을 실제로 배웠는지** 확인해야 한다.

### 3.3 자모와 발음 범위가 빠지지 않도록 관리한다

| 범위 | 첫 도입 | 이후 숙달 |
|---|---|---|
| 기본 모음 ㅏㅓㅗㅜㅡㅣ | F0.1 | F0.2부터 실제 단어·문장 |
| 기본 자음 ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ | F0.1의 ㅇ, F0.2 기본 자음, F0.3의 ㅊㅋㅌㅍ | A1 전체에서 문맥과 위치에 따른 소리 |
| ㅑㅕㅛㅠ / ㄲㄸㅃㅆㅉ | F0.3 | A1~A2의 듣기·발음 재방문 |
| ㅐㅔㅒㅖㅘㅙㅚㅝㅞㅟㅢ | F0.3~F0.4의 별도 작은 단원 | A1.1까지 모든 표기 접촉 확인. 비슷한 소리의 철자 구분은 익힌 어휘로 연습 |
| 받침 ㅁㄴㅇㄹ, ㄱㄷㅂ 계열 | F0.3~F0.4 | A1.1 단어, A1.2 연결된 말 |
| 겹받침 ㄳㄵㄶㄺㄻㄼㄽㄾㄿㅀㅄ | A1.1~A1.2에서 실제 고빈도 단어부터 | 드문 결합은 참고 읽기 자료로 유지, 해당 단어가 필요한 후속 단원에서 재학습 |
| 연음, 비음화, 유음화, 구개음화, 된소리되기, 거센소리되기, ㅎ 관련 변화 | 쉬운 연음 F0.4, A1의 익숙한 단어에서 듣기 우선 | A2에서 규칙 비교, B1 이후 유창성과 실제 발화로 확장 |
| ㄹ·ㅅ·ㅎ 등의 환경에 따른 실현, 의의 문맥별 발음 | 관련 단어를 만날 때 설명 | 한 가지 영문 철자 대응으로 고정하지 않음 |

현대 자음 19개·모음 21개를 모두 다루되, **처음 보았음 / 도움으로 읽음 / 혼자 새 결합을 읽음 / 이후에도 유지됨**을 분리한다. 40개를 한 화면에 제시한 것은 학습 완료가 아니다.

### 3.4 문자 단원에서 A1 과제로 넘어가는 기준

- 이미 배운 자모로 구성한, 외운 적 없는 짧은 음절 결합을 읽거나 소리와 연결한다. 비단어를 사용할 때는 뜻이 없는 소리 연습이라고 알려 준다.
- 의미를 이미 배운 짧은 낱말을 읽어 해당 그림·물건과 연결한다.
- 사용한 도움 표현의 뜻을 알고 상황에 맞게 선택한다. 이 능력과 독립적 발화를 구분한다.
- 모르는 글자가 나오면 듣기·분해·다시 보기로 돌아갈 수 있다.
- 대화 시작은 허용한다. 특정 읽기·쓰기 과제만 해당 선행 능력에 따라 조절한다.

## 4. A1 — 짧은 말로 일상에 참여한다

### A1.1 나와 바로 앞의 세계

1. **인사와 대화 회복:** 인사, 이름 확인, 감사·사과, 이해 못 했다고 말하기, 천천히·다시 요청하기.
2. **나와 사람:** 이름·출신·언어·소속·직업의 기초, 나·상대·가까운 사람 소개. 호칭은 실제 관계와 함께.
3. **사물과 존재:** 이것·그것·저것, 사람·물건·장소 이름, 있어요/없어요, 어디예요, 위치의 기초.
4. **원하는 것을 선택하고 요청:** 음식·음료·생활 물건, 색·크기 등 눈에 보이는 특징, 주세요, 기본 수량.
5. **기초 문장 구조:** 명사+이에요/예요와 아니에요, 동사·형용사의 해요체 기초, 서술어가 끝에 오는 기본 구조, 문맥상 명확한 주어 생략.
6. **조사 첫 사용:** 은/는의 자기소개·화제, 이/가의 존재·누가 질문, 을/를의 기본 목적어를 **서로 다른 단원에서** 도입. 에는 먼저 장소와 함께, 이후 기능 확장. 화제와 주어의 미묘한 대비 문제는 뒤로 둔다.
7. **어휘·수:** 가족·사람·집·물건·음식·기본 동작·상태. 고유어 수와 한자어 수를 용도별로 작게 시작하며 단위 명사도 필요한 것부터.
8. **문자·소리:** F0의 남은 글자 보충, 기본 받침·쉬운 연음, 익힌 단어 읽기, 한글 입력·띄어쓰기 기초.

듣기·읽기: 매우 짧은 질문·응답, 이름표·간단한 메뉴·장소 표지에서 필요한 정보 찾기.

말하기·쓰기: 짧게 소개하고 상대에게 되묻기, 원하는 것 요청하기, 이름·짧은 항목 입력, 틀을 활용한 첫 메시지.

**전이 확인:** 처음 보는 인물에게 배운 표현으로 소개하고, 다른 물건을 요청하고, 못 들었을 때 다시 묻는다. 소개문을 그대로 외워 재생하는 것만으로 통과하지 않는다.

### A1.2 나의 하루와 간단한 약속

1. 시간·요일·날짜·가격·수량·단위, 집과 동네, 교통, 일과, 취미, 기본 건강·도움 요청.
2. 에/에서, 부터/까지, (으)로, 에게/한테의 빈번한 기능을 상황별로 나누어 익힌다.
3. 현재·과거 -았/었어요, 가까운 계획 -(으)ㄹ 거예요, 안/못과 -지 않다/-지 못하다의 기본 차이.
4. -고의 단순 연결, -아/어서의 쉬운 순서·이유, -지만, -기 전/-(으)ㄴ 후. 의미와 사용 조건을 한 번에 모두 시험하지 않는다.
5. -고 싶어요, -(으)ㄹ 수 있어요, -(으)세요, -(으)ㄹ까요, 기초 비교 보다, 하고/와·과, 도/만.
6. 기본 높임과 공손한 말끝, 자주 쓰는 불규칙 활용을 실제 동사에서 조금씩; 격식체는 인사·안내 등 사용 장면과 함께.
7. 짧은 문장에서 받침과 이어지는 소리 듣기, 부정·숫자·시간을 놓치지 않기, 짧은 어절 단위 입력.

듣기·읽기: 시간·장소가 담긴 짧은 음성, 약속 메시지, 간단한 시간표·안내·영수증.

말하기·쓰기: 어제 한 일과 오늘 일정, 간단한 약속 잡기·변경, 위치 안내, 짧은 일기·메시지.

**전이 확인:** 일정 정보를 듣고 약속을 잡되 시간이 맞지 않으면 다른 시간을 제안한다. 길이나 시간을 잘못 이해하면 확인해서 고친다.

## 5. A2 — 익숙한 생활 문제를 스스로 해결한다

### A2.1 예약·이동·쇼핑과 생활 문제

1. 예약·변경·취소, 여행·숙소·교통, 구매·교환, 집안일, 병원·약국에서 기본 증상 설명, 날씨와 계획.
2. -(으)면, -거나/(이)나, -아/어도 되다, -(으)면 안 되다/-지 말다, -아/어야 하다의 조건·선택·허가·금지·의무.
3. -아/어 주세요, -아/어 주다, -아/어 보다, -(으)려고, -기로 하다를 통한 요청·시도·목적·결정.

**전이 확인:** 일어난 일을 상대에게 설명하고, 추가 질문에 정보를 보완해 공동 해결안을 만든다.

듣기·읽기: 익숙한 토론·보도·후기를 이해하고 주장·이유·출처를 분리.

**전이 확인:** 서로 다른 설명을 비교해 확인된 사실과 추측을 구분하고, 이유를 붙여 선택하며 반대 의견에도 응답한다.

**전이 확인:** 반론을 듣고 주장을 수정하거나 근거를 보완하며, 오해가 생긴 표현을 설명하고 합의안을 작성한다.

## 8. C1 — 전문성과 관계를 고려해 유연하게 소통한다

### C1.1 학업·업무의 복잡한 정보 조직

5. 자료의 주장·방법·한계·전제·신뢰도를 구분하고, 직접 인용·바꿔 쓰기·출처 밝히기.
6. 긴 발표를 의미 단위로 조직하고 즉석 질문에 답하며 설명 수준을 조절.

듣기·읽기: 관심 전문 분야의 강의·회의·분석 기사·보고서에서 논지와 암시를 파악.

말하기·쓰기: 구조 있는 발표·질의응답·보고서·제안서. 필요한 분야 지식은 학습 자료에 제공한다.

**전이 확인:** 여러 자료를 근거와 한계가 드러나도록 통합하고, 비전문 청자에게 핵심을 쉽게 설명한다.

### C1.2 미묘한 의도·관계·문체 조절

1. 복잡한 협의·갈등·설득, 체면과 관계, 완곡한 거절·이견, 암시·거리 두기·평가·유머.
2. -는데도 불구하고, -(으)ㄹ뿐더러, -기 나름이다, -기에 따라, -는 이상, -다가는 등의 양보·조건·책임 표현.
3. -다기에/-자기에/-길래와 전달·경험의 관점, 상대가 아는 정보와 새로운 정보의 배치.
4. 같은 내용을 동료 대화·공식 이메일·발표·대중 설명으로 바꾸기. 높임과 문체의 일관성·전략적 전환.
5. 반론을 인정하면서 주장 정밀화, 여러 사람의 이해관계와 말의 의도를 정확히 중개.
6. 말끝·휴지·억양이 주는 확신·거리감, 자연스러운 상호작용과 자기 수정.

듣기·읽기: 긴 대화·토론·평론에서 직접 말하지 않은 입장과 관계를 문맥에 근거해 해석.

말하기·쓰기: 상대·목적·매체에 맞춘 협의, 편집과 재작성, 여러 관점을 담은 설득문.

**전이 확인:** 같은 정보를 두 종류의 청자에게 다르게 설명하고, 함축을 오해했을 때 확인 질문으로 회복한다.

## 9. C2 — 복잡한 의미를 정밀하게 다루고 새롭게 표현한다

### C2.1 관점·함축·표현의 미세 차이

1. 복잡하고 추상적인 논의, 비평·서사·풍자, 불명확하거나 상충하는 정보, 제도적 문어의 정의·전제·예외.
2. 긴 문장의 중첩 범위와 인용의 층위, -(으)ㄴ들, -기로서니, -는 한이 있어도, -되 등의 미세한 논리·태도.
3. 과장·축소·반어·아이러니·중의성, 관용·상징·화자의 신뢰도. 해석이 복수일 때 근거와 불확실성을 표시.
4. 어휘의 어감·결합·뉘앙스, 장르·시대·세대별 표현 차이. 방언·옛말은 이해용 선택 확장으로 제공.
5. 빠르고 자연스러운 상호작용의 핵심을 따라가되 모든 지역·세대의 말을 완벽히 이해해야 한다는 목표는 두지 않는다.
6. 복잡한 내용을 정확하고 쉽게 풀어 설명하고 왜 특정 해석을 택했는지 밝힌다.

듣기·읽기: 장르가 다른 복잡한 자료를 읽고 듣고, 논리·태도·함축·미학적 효과를 구분.

말하기·쓰기: 정밀한 비평·분석, 여러 해석의 비교, 표현의 효과를 설명하는 논의.

**전이 확인:** 같은 발화·문장의 가능한 해석을 문맥 근거로 비교하고, 확정할 수 없는 부분을 구분한다.

### C2.2 종합·창작·정교한 중개

1. 여러 출처·장르의 정보를 재구성해 일관된 설명·논증·이야기 만들기.
2. 주장 강도·범위·예외·어조·리듬·관점을 의도적으로 선택하고 편집하는 능력.
3. 초급에서 배운 문법까지 다시 써서 명료함·압축·효과를 조절. 희귀 문법의 새 목록을 계속 늘리는 것으로 수준을 증명하지 않는다.
4. 전문 발표·즉석 질의응답·합의 형성, 정교한 보고·비평·에세이·서사 중 목적에 맞는 장르.
5. 여러 사람·자료 사이의 의미를 보존한 중개, 문화적 전제를 설명하고 오해를 풀기.
6. 자기 글과 말의 효과를 점검하고, 같은 뜻을 대상·매체에 맞춰 다시 표현하며 수정 이유를 설명.

듣기·읽기: 복합 자료를 통합하고 서로 양립하지 않는 주장·빠진 정보·확실성의 차이를 보존.

말하기·쓰기: 복잡한 주제를 명료하고 유연하게 표현, 응답에 따라 즉석 재구성, 정밀한 편집.

**전이 확인:** 처음 접한 복합 자료로 발표 또는 글을 만들고, 비판 질문에 답한 뒤 다른 청자를 위한 짧은 버전으로 다시 구성한다. 작품 완성만으로 언어 능력을 자동 인증하지 않는다.

## 10. 라틴 문자에 익숙한 학습자의 부담을 줄이는 설계

### 10.1 국적 대신 실제 경험을 확인한다

영어·독일어 사용자를 주요 대상으로 삼되, 유럽 전체가 같은 문자나 발음 체계를 쓴다고 가정하지 않는다. 시작 시 선호 설명 언어, 한글 읽기 경험, 한국어 청취·회화 경험을 짧게 확인한다. 다중언어 경험은 활용 가능한 자원이다.

| 낯선 요소 | 지원 방법 | 피할 방법 |
|---|---|---|
| 음절 블록 | 글자 조각이 모여 한 음절이 되는 과정, 좌우·상하 배치, 정상 글꼴로 되돌아 읽기 | 장식 도형을 외운 것만으로 한글 읽기로 판정 |
| 소리와 철자 | 실제 한국어 음성과 입모양·조음 설명, 천천히/자연스럽게 듣기, 여러 화자에게 전이 | ㄱ=g/k, ㄹ=r/l처럼 한 영문 철자와 완전히 같다고 설명 |
| 영어·독일어 간 차이 | 설명 언어별로 오해하기 쉬운 유사음을 검토하고 실제 수행에 맞춰 도움 제공 | 모든 학습자에게 영어식 발음 안내만 제공 |
| 서술어 끝자리·어순 | 배운 단어로 역할과 서술어를 표시하고 단순 문장부터; 독일어 종속절 경험은 보조 비교만 | 영어·독일어 문장을 단어 순서만 뒤집으면 한국어가 된다고 설명 |
| 조사 | 필요한 역할 하나→비슷한 상황 두 개 비교→다른 장면 전이 | 처음부터 은/는·이/가·을/를·에·에서를 한 번에 골라 맞히기 |
| 주어 생략 | 대화에서 이미 알려진 사람이 누구인지 보여 주기 | 모든 문장에 나/당신을 반드시 넣기 |
| 높임·대우 | 해요체로 출발하고 상대·관계·상황에 따라 확대 | 말투 체계 전체 암기, 반말을 무조건 더 쉬운 초급으로 취급 |
| 수·단위 | 하나의 필요에 맞춰 수 체계를 도입하고 이후 비교 | 두 수 체계와 모든 단위를 첫 단원에 제시 |
| 로마자 | 요청 시 임시 보조로 제공하고, 한국어 음성·한글 인식으로 점차 이동 | 상시 로마자만 보고 맞힌 것을 한글 해독으로 기록 |
| 현대 텍스트 | 먼저 기본형과 관계를 이해, 이후 흔한 줄임말·이모티콘의 맥락 | 최신 유행어 목록을 필수 기초 어휘로 고정 |

### 10.2 한 번의 짧은 학습은 이 순서를 기본으로 한다

1. **필요를 만난다:** 인물이 이름을 묻거나 물건을 잘못 가져온다. 상황은 그림·번역으로 이해 가능하다.
2. **가르쳐 준다:** 목표 소리·단어·표현을 의미와 함께 시범으로 보여 준다.
3. **도움을 받아 해 본다:** 따라 고르기·조립·짧은 발화, 오류 원인을 알려 주는 피드백.
4. **도움을 줄여 써 본다:** 그림·화자·물건을 바꿔 같은 능력을 사용한다.
5. **행동 결과를 본다:** 인물이 이해하고 반응하거나 장면이 달라진다.
6. **나중에 다시 꺼낸다:** 같은 퀴즈의 위치를 외우는 대신 다른 날·상황에서 재사용한다.

새 문자, 새 어휘, 새 문법, 새로운 게임 조작을 한 문제에 동시에 처음 투입하지 않는다. 예를 들어 새 조사를 배우는 문제의 낱말과 버튼 조작은 이미 익숙한 것으로 구성한다.

**초기 파일럿 가설:** 입문 미니 단원은 새 글자 2~3개, 또는 새 표현 틀 1개와 새 어휘 3~5개 정도로 시작한다. 이는 과학적으로 확정된 상한이나 모든 수준의 고정 분량이 아니다. 과제 소요 시간·힌트 사용·지연 회상·이탈·주관적 부담을 확인해 조정한다. 익숙한 단어의 활용 확장과 완전히 새로운 개념은 같은 한 개로 세지 않는다.

틀렸다고 에너지·생명·건축물을 잃지 않는다. 듣기 재생과 설명 재확인은 벌점 없이 제공한다. 배운 내용을 꺼내 쓰는 단계에서만 도움 사용 여부를 정확히 기록한다. 속도 제한은 선택 도전으로 두고 기본 숙달 조건으로 쓰지 않는다.

## 11. 같은 사건을 수준별로 참여시키는 방법

예: 캐릭터가 잘못 전달된 물건을 돌려주려 한다. 미스터리의 큰 사실과 결말은 번역·그림·도움을 통해 초보도 이해할 수 있다.

| 단계 | 한국어로 수행하는 일 | 실제 학습 증거 |
|---|---|---|
| F0 | 이미 배운 물건의 단어와 소리·표지를 연결 | 소리·문자·의미 연결. 번역으로 읽은 사건 설명은 한국어 독해 증거가 아님 |
| A1 | 이거/저거, 누구 것인지, 위치·수량을 확인 | 짧은 질문과 응답, 관련 낱말 읽기 |
| A2 | 물건 특징과 마지막 위치·시간을 설명하고 요청 | 간단한 경위와 상황에 맞는 요청 |
| B1 | 서로 다른 진술의 순서·이유·출처를 비교 | 인용·추측·사실의 분리와 연결된 설명 |
| B2 | 여러 증거로 대안을 비교하고 반론에 답변 | 근거·한계·논증과 상호작용 |
| C1 | 불확실한 자료를 출처별로 정리하고 다른 청자에게 전달 | 복수 자료 통합, 적절한 문체와 중개 |
| C2 | 상충하는 관점과 함축을 보존해 정밀한 설명·서사로 재구성 | 정교한 해석·편집·즉석 재구성 |

이 표는 활동 설계 예시다. 한 사건을 열두 번 반복하거나 C2 문제를 풀어야 일두고택 첫 시즌을 끝낼 수 있다는 뜻이 아니다. 사건은 변하고 학습 기능은 다시 등장한다. 일두고택은 돌아오는 이야기의 중심이며, 새로운 고택은 새 인물·갈등·자료를 제공한다. 고택 개수와 언어 등급을 1:1로 묶지 않는다.

문화·역사 용어는 초반에 이야기 이해용 번역으로 접할 수 있다. 접했다는 이유로 능동 어휘 시험에 넣지 않는다. 실제 역사와 창작의 구분은 기존 HISTORY_AND_FIRST_STEPS.md를 따른다.

## 12. 진도·과제 허용·평가 원칙

### 12.1 출제 전 확인할 선행 조건

과제마다 필요한 자모, 음절 구조, 의미를 배운 어휘, 목표 문법 기능, 듣기/읽기/입력 방식, 관계·말투, 이미 익힌 조작을 명시한다.

`수진이가 전화_ 했어요`처럼 여러 정답 가능성과 문맥 문제가 생기는 빈칸을 초보에게 던지지 않는다. 무엇을 측정하는지 먼저 결정하고 자연스러운 문장·문맥·허용 답을 검토한다. 조사 사용을 측정한다면 문장 해독과 어휘·과거형이 선행되어야 한다. 목표 밖의 새 항목은 도움을 제공하고 평가 대상에서 제외한다.

### 12.2 완료와 숙달을 분리한다

- **접함:** 콘텐츠를 보거나 들었다.
- **도움으로 수행:** 번역·보기·힌트를 사용해 해결했다.
- **독립 수행:** 목표 능력에 대한 정답 유도 없이 새로운 예에서 수행했다. 재생 허용 여부 등 조건은 과제마다 명시한다.
- **유지·전이 확인:** 시간이 지난 뒤 또는 다른 상황에서도 수행했다.

이야기는 도움을 받아 계속할 수 있다. 언어 숙달 표시는 실제 증거만 반영한다. 객관식으로 알아보는 능력과 자유롭게 말하는 능력을 같은 것으로 기록하지 않는다.

### 12.3 구간을 마칠 때 확인할 것

각 구간의 전이 과제에서 (1) 뜻·정보를 이해했는가, (2) 목적을 달성했는가, (3) 배운 표현을 상황에 맞게 사용했는가, (4) 어려움을 확인·수정했는가를 본다. 기능별로 결과를 남기고 취약한 부분만 다음 학습에 보충한다.

음성 인식의 일치 점수만으로 발음·유창성·상호작용 전체를 인증하지 않는다. 아직 신뢰할 수 있는 평가가 없는 자유 말하기·글쓰기는 연습·포트폴리오 및 명시적 미평가 상태로 제공한다. 독립적인 생산 능력 확인이 필요한 단계는 교사 검토 등 검증된 방식이 준비된 범위에서만 숙달로 표시한다. 자동 채점 기능을 새로 구현했다는 뜻이 아니다.

## 14. 이번에 정한 범위와 다음 제작 단위

이번 제안은 전체 범위, 큰 순서, 입문 구조, 기능별 목표, 대표 표현, 전이 기준을 정하는 교육과정 설계다. 수백 개 문법·어휘의 최종 단원 배치, 모든 예문·오답·음성·퀘스트 대본 제작은 별도 작업이다.

다음 제작 단위는 **F0.1~F0.2와 A1.1의 첫 의사소통 단원**이다. 한 단원마다 `목표 → 선행 능력 → 새 글자/어휘/표현 → 시범 → 연습 → 다른 상황에서 사용 → 복습 → 확인 가능한 증거`를 작성한다. 이후 A1을 완성하고 A2~C2를 순서대로 구체화한다. 전체 상위 지도가 있으므로 이후 고택·캐릭터 에피소드는 이 지도에 연결할 수 있다.

## 15. 사용한 근거와 스킬의 적용 범위

- [국립국어원·문화체육관광부, 한국어 표준 교육과정(2020)](https://m.korean.go.kr/front/etcData/etcDataView.do?etc_seq=657&mn_id=46): 상황·기능·언어기술·언어지식 및 문화와 수행 중심의 큰 틀을 참조. 특정 문법을 위의 세부 구간에 배치한 것은 이 문서의 제안이다.
- [Council of Europe, CEFR Companion Volume 소개](https://www.coe.int/en/web/education/-/common-european-framework-of-reference-for-languages-learning-teaching-assessment-14): Pre-A1, 음운 능력, 매개와 온라인 상호작용 등 폭넓은 수행 관점을 참조. 공식 환산표로 사용하지 않는다.
- [온라인 세종학당 입문 강좌](https://www.iksi.or.kr/lms/crse/crseApply.do?crseNo=121341): 자모·받침·연음과 표현 학습을 다루는 입문 범위의 비교 자료. 해당 강좌의 문항이나 교재를 복제하지 않았다.
- 현재 로컬 교육과정: `tools/content_factory/cefr_matrix/{phases,ko,taxonomy}.json`, `assets/data/{learning_phases,curriculum_manifest}.json`. 현재 파일과 과거 기억을 대조했고 수치·명칭은 현재 파일에서 확인했다.
- Superpowers brainstorming: 기존 목표·제약을 바탕으로 문서화하고 별도 검토자가 중요한 설계 빈틈을 확인한다.
- 사용자 지정 performance-optimization: 소프트웨어 성능 측정 스킬이다. 앱 프로파일링이나 속도 개선을 수행하지 않았다. 이 문서의 학습 부담 가설은 별도 사용자 관찰로 검증하며, Core Web Vitals나 실행 시간 수치를 학습 효과의 증거로 사용하지 않는다.

시간·어휘 수·정답률에 보편적인 합격선을 임의로 붙이지 않았다. 총 학습 시간, 각 작은 단원의 분량과 합격 판정 수치는 초기 학습자 검증 및 과제별 채점 설계에서 보정한다.

## 16. 검토 상태

2026-10-23 별도 설계 검토 에이전트가 입문 선행 조건, 부담, 등급 체계 구분, 학습 증거와 이야기 완료의 분리, 기존 30개 Phase와 새 표시 구간의 충돌을 읽고 중요한 미해결 설계 질문이 없다고 보고했다. 이는 설계의 일관성 검토이며 한국어 교원의 항목별 감수, 실제 초보 학습자 관찰, 앱 구현·기기 검증이나 사용자 승인을 대신하지 않는다.
