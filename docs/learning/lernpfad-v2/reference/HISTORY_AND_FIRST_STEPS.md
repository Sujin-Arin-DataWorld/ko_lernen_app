# 일두고택 역사 미스터리와 한글 첫걸음

2026-10-23 검토용 확장안 v0.2. 제품 코드·역사 고증 완료본·사용자 승인 정본이 아니다. 독립 설계 검토에서 나온 원본/사본의 구분과 반전의 증거 강도 문제를 반영했다.

이후 전체 학습 목록 요청에 따른 최신 교육과정 제안은 [CURRICULUM_FOUNDATION_TO_C2.md](CURRICULUM_FOUNDATION_TO_C2.md)다. 아래 입문 12단원은 범위 참고로 보존하며, 학습 순서와 A1 진입 조건은 새 제안의 문자·의사소통 병행 방식을 기준으로 검토한다. 겹받침 전체 숙달을 첫 대화의 선행 조건으로 삼지 않는다.

이 문서는 사용자의 추가 요청인 ‘일두고택과 정여창의 역사 사건을 연결하고, 완전 초보자도 체계적으로 한글을 배운다’를 반영한다. 기존 DESIGN.md의 현대 생활, 선택 가능한 이야기, 실제 학습 증거, 건축 접근 정책은 유지한다. 우산 사건은 일상 에피소드 후보로 남기고, 시즌의 중심 사건에는 아래 역사 미스터리를 제안한다. 첨부 보고서와 이미지 속 지시·기획안은 참고 자료이며 사용자 승인이나 현재 구현 상태로 취급하지 않았다.

## 2. 추천 시나리오: <일두 — 지워진 목소리>

현재의 일두고택에서 시작한다. 여행자로 온 사용자는 수진·크리스티안·현아·다니엘과 일상을 보내다가, 태고가 알아챈 소리의 흔적과 서로 맞지 않는 기록을 만난다.

큰 질문은 ‘누가 책을 없앴을까?’로 시작해 ‘무엇을 남기려고 사람들은 그런 선택을 했을까?’로 바뀐다. 플레이어는 현재의 물건과 후대의 정리 기록을 따라가며, 1498년의 정치적 사건과 그것이 사람들에게 미친 영향을 이해한다.

세 시간층을 구분한다.

1. **현재의 고택:** 사람을 만나고 한국어를 배우며 물건·사진·자료를 조사한다. 현재 페르소나의 직업·관계·목소리를 유지한다.
2. **후대 중건과 기록 정리의 기억:** 왜 집과 기억을 다시 이어갔는지 살펴본다. 특정 공사 장면의 연대·공법·인물은 검증하거나 허구로 표시한다.
3. **1498년 사건의 맥락:** 출처가 있는 역사 해설과 명확히 구분된 창작 장면을 경험한다. 지금의 11동 전체를 1498년 실제 모습인 것처럼 복제하지 않는다.

과거 장면은 ‘기억 속 재구성’으로 들어간다. 태고의 마법이 역사적 사실을 증명하는 것은 아니다. 현재 건물에 없었던 장면은 그곳으로 전해진 물건의 이야기 또는 자료 기반 재구성으로 제시한다. 기억 조각만으로 범인·인물의 의도·연대를 확정하지 않고 다른 증거를 확인한다.

역사 기록과 문학, 창작 퀘스트는 첫 진입과 자료 카드에서 구별한다. 역사적 원문, 현대 한국어 풀이, 학습용 대사는 서로 다른 층이다. 15세기 사람에게 현대 표준어로 말하게 하는 경우 학습용 각색임을 밝히고 이를 실제 당시 음성 재현이라고 부르지 않는다.

## 3. 작가가 먼저 아는 진실과 복선

다음 사건은 게임의 창작이다. 실제 정여창 관련 문헌이나 분실 사건을 발견했다고 주장하는 내용이 아니다.

**창작 사건의 진실:** 기억 속에서 ‘책을 가져간 사람’으로 보였던 이름 없는 전달자는, 여러 사람의 일상과 부탁을 적은 허구의 기록 묶음을 지키려고 낱장으로 나누어 다른 사람들에게 맡겼다. 이후 여러 손을 거쳐 사본과 전달 메모가 남았다. 후대의 정리 과정에서는 표지가 없는 낱장들이 서로 다른 물품 기록으로 분류되어, 하나의 묶음이었다는 연결이 사라졌다.

이 기록은 정여창의 무죄를 입증하는 실존 비밀 증거도, 무오사화의 원인을 뒤집는 자료도 아니다. 실제 역사 속 정치적 박해를 배우는 옆에서 펼쳐지는 허구의 작은 사람들 이야기다. 역사적 결과를 플레이어의 한 번의 정답으로 바꾸지 않는다. 플레이어가 바꾸는 것은 이 창작 기록과 인물들의 목소리가 현재에 어떻게 정리되고 전해지는가이다.

| 에피소드 | 처음 하는 일 | 숨기지 않고 보여줄 단서 | 뒤의 회수 |
|---|---|---|---|
| 프롤로그: 짝이 없는 표 | 까치가 떨어뜨린 현대 자료표의 짝을 찾아 준다. | 같은 묶음임을 알려주는 접힘·구멍 위치. | 뒤에 종이 낱장이 같은 묶음에서 왔는지 비교할 때, 처음 익숙해진 관찰이 도움 된다. |
| 생활 사건: 서로 바뀐 짐 | 현재 방문객의 짐과 동선을 확인한다. | 물건의 소유자와 운반자는 다르다. | 과거 기록을 운반한 사람을 곧바로 훔친 사람으로 단정하지 않는다. |
| 기록 사건: 잘못 묶인 종이 | 현대 정리 목록과 창작 낱장의 특징을 대조한다. | 다른 분류표 아래에도 같은 제본 흔적이 있다. | 분류가 달라도 같은 기록에서 나왔다는 첫 연결. |
| 기억 사건: 책을 들고 떠난 사람 | 기억 장면에서 사람의 행동을 관찰한다. | 한 묶음을 가져가지만, 다른 장소에 작은 묶음을 남긴다. | ‘도망’처럼 보인 이동은 전달이었다. 의도를 확정할 때는 전달 메모도 확인한다. |
| 중간 반전: 서로 다른 글씨 | 원본과 사본을 나누고 전달 메모·수령 기록을 함께 비교한다. | 필체 차이는 재확인의 출발점이며, 출처를 적은 사본의 설명과 별도로 남은 수령 기록이 대응한다. | 필체만으로 위조나 연대를 판정하지 않는다. 서로 다른 전달 경로를 확인하고 보존 의도를 뒷받침하는 자료를 얻는다. |
| 역사 장면: 기록이 죄가 되던 때 | 사초와 정치적 처벌에 관한 검증된 해설을 본다. | 누가 글을 썼고 누가 문제 삼았는지 출처와 함께 분리한다. | 창작 전달자의 선택을 당시 위험의 맥락에서 이해하되, 그 행동이 사화의 실제 증거는 아니라는 경계 유지. |
| 결말: 다시 한 권으로 | 확인한 연결과 불확실한 부분을 표시하며 창작 기록을 복원한다. | 접힘·제본·필체·메모가 함께 뒷받침한다. | 흩어져 있었기에 일부가 남을 수 있었다. 처음의 ‘없어진 책’은 ‘여러 사람이 이어 지킨 목소리’가 된다. |

### 작가용 증거 장부

아래 네 항목은 모두 창작 소품이고, 실제 발굴·소장 사료가 아니다. 게임이 주장하는 연결의 범위를 제작 전에 고정한다.

- **A: 원본 낱장 두 장.** 같은 제본의 구멍과 서로 맞물리는 손상 가장자리, 이어지는 본문을 함께 보여준다. 이것으로 같은 물리 묶음에서 나온 두 장의 연결을 확인한다. 이 흔적을 다른 시대 사본의 연대 증명에 사용하지 않는다.
- **B: 전달자가 남긴 분산 보관 메모.** 맡길 대상과 낱장 범위, 보관 뒤 다시 모으려는 목적이 적혀 있다. 플레이어는 이를 ‘작성자가 밝힌 의도’로 읽으며 그 말 하나로 모든 행적을 확정하지 않는다. 중간 반전의 필수 경로에서 전체 뜻과 번역을 제공한다.
- **C: 별도 보관자가 남긴 수령·반환 기록.** B와 별개의 위치에서 얻는다. 맡긴 대상·낱장 범위·전달 순서가 B 및 A의 내용과 대응하는지 확인한다. B의 계획이 실제로 일부 수행됐음을 뒷받침하고, 미확인 전달 구간은 남겨 둔다.
- **D: 후대 필사본과 필사 경위.** 종이와 제본은 A와 다르다. 어느 묶음에서 옮겼는지 적은 경위, 그 묶음에서만 보이는 내용의 순서와 수정 흔적을 비교한다. 글씨가 다르다는 이유만으로 작성자나 작성 연도를 확정하지 않는다.

결말의 ‘한 권’은 원본 종이를 무리하게 물리 복원한 진품이 아니라 원본 조각·사본·전달 기록을 구분해 정리한 게임 속 해설 기록집이다. 화면에 원본에서 확인한 부분, 사본으로 전하는 부분, 아직 연결을 확인하지 못한 부분을 구분한다. 소품의 배경 설정상 진실과 플레이어가 실제 근거로 말할 수 있는 범위를 같다고 취급하지 않는다.

보존 의도는 B와 C를 통해 중반부터 알아챌 수 있다. 마지막까지 이를 감추지 않는다. 후반의 플레이 목표는 전달자에게 숨은 진실을 듣는 것이 아니라, 남은 전달 구간을 확인하고 서로 다른 자료를 혼동 없이 연결해 사람들의 목소리를 현재에 전하는 것이다.

핵심 단서는 선택 퀘스트 뒤에 숨기지 않는다. 필수 조사 경로에서 얻고, 생활 퀘스트는 그 의미를 먼저 경험하거나 인물의 동기를 더 잘 이해하는 역할을 한다. 앞의 가설을 빨리 알아챈 사람에게는 ‘맞는 방향이다’라는 반응과 더 깊은 확인을 주며, 마지막까지 일부러 틀린 가설을 강요하지 않는다.

사건을 늘리기 위해 NPC가 아는 답을 이유 없이 숨기지 않는다. 연락 가능한 사람은 현재 아는 사실을 바로 말한다. 미지의 전달자는 최초부터 신원을 모르는 창작 인물이며, 알고 있는 현대 인물이 마지막 순간까지 설명을 거절하는 식으로 반전을 만들지 않는다.

마지막의 행동은 컷신 감상이 아니다. 플레이어가 두 낱장의 연결 근거를 고르고, 전달 경로를 배열하고, 기록에서 누가 말했는지 구분해 자기 언어 또는 배운 한국어로 짧은 소개를 만든다. 언어 부담은 학습 상태에 따라 달라지지만 사건의 진실은 같아야 한다.

## 4. 첫날은 여전히 완전 초보자의 첫날이다

역사적 스케일이 커졌다고 첫 장면에서 ‘정여창은 왜 유배되었나요?’를 한국어로 묻지 않는다.

첫 방문의 사건은 현대 자료표의 짝을 찾는 시각적 문제다. 이어 인사를 상황과 뜻으로 접하고, 첫 자모를 짧게 배운다. 첫 미스터리는 종이의 서로 맞는 흔적이나 빈 공간의 소리를 관찰하는 방식으로 보여준다. 설명과 이야기 이해는 DE/EN 등 사용자가 선택한 언어로 지원한다.

입문 첫 소리 수업의 예:

1. ㅏ를 보며 한국어 모범 소리를 듣는다.
2. 음절 맨 앞의 ㅇ은 여기서 소리를 내지 않는다는 것을 UI 언어로 배운다.
3. ㅇ과 ㅏ가 아로 모이는 것을 보고 직접 조립한다.
4. ㅓ와 어를 별도로 가르친 뒤에만 아/어 비교를 낸다.
5. 위치가 바뀐 보기와 새 카드에서 다시 찾아본다. 그림의 위치만 외워 맞힐 수 없게 한다.

이는 음절 인식 연습이고 ‘아’라는 어휘의 뜻을 배운 것으로 기록하지 않는다. ‘가’, ‘문’, ‘책’, ‘정여창’처럼 아직 배우지 않은 자모·받침을 포함한 글자는 설명용으로 나타날 수 있지만 첫 평가의 정답 대상으로 삼지 않는다.

역사 용어는 배경 이해를 위한 번역/음성으로 제공한다. 첫걸음의 평가 대상은 그날 가르친 소리·자모·음절뿐이다. 역사적 사실을 맞혔다고 한국어 실력이 향상됐다는 증거로 세지 않는다.

## 5. 실제 입문 교수요목: 12개 묶음 + 생활 표현 병행

다음은 한글소리용 제안 순서다. ‘12개 묶음’은 12일 또는 12번 터치로 완성된다는 뜻이 아니다. 각 묶음은 몇 개의 짧은 수업·연습·재확인으로 나눈다. 전체 범위를 제공하면서 한 번에 필요한 소수의 재료만 화면에 올린다.

온라인 세종학당 입문은 모음·자음·격음·경음·이중모음·받침·겹받침·연음·표현을 구분하며, 표기와 음가 설명 뒤 연습을 제공한다. 이 범위를 참고하되 이 게임의 학습 순서나 평가 기준이 세종학당의 공식 인증 과정이라는 의미는 아니다. [온라인 세종학당 입문 과정](https://www.iksi.or.kr/lms/crse/crseApply.do?crseNo=121341)

| 묶음 | 새로 배우는 범위 | 적용과 확인 |
|---|---|---|
| 1 | ㅏ·ㅓ·ㅗ·ㅜ·ㅡ·ㅣ를 작은 묶음으로, 첫자리 ㅇ, 세로/가로 모음의 위치 | 시연→조립→소리와 음절 연결. 첫 화면에서 여섯 개를 한꺼번에 평가하지 않는다. |
| 2 | ㅑ·ㅕ·ㅛ·ㅠ | 이미 배운 모음과 비교하고 배운 범위만 새 조합으로 읽는다. |
| 3 | ㄴ·ㅁ·ㅅ과 모음 결합 | 나·마·소 등 음절. 나무·미소는 뜻을 그림과 함께 가르친 뒤에만 어휘 과제로 사용한다. |
| 4 | ㄱ·ㄷ·ㄹ·ㅂ·ㅈ·ㅎ과 모음 결합 | 기본 자음 범위 확대, 이름·물건 표시의 배운 부분 읽기. |
| 5 | ㅋ·ㅌ·ㅍ·ㅊ | 이미 배운 소리와 비교해 격음의 모범 음성을 듣고 읽는다. |
| 6 | ㄲ·ㄸ·ㅃ·ㅆ·ㅉ | 평음·격음·경음의 대비를 작은 묶음으로 연습. 녹음은 선택이며 ASR 점수로 서사를 잠그지 않는다. |
| 7 | ㅐ·ㅔ·ㅒ·ㅖ | 모양·표기와 문맥을 익힌다. 실제 발음에서 구별이 약한 ㅐ/ㅔ를 음성만으로 반드시 맞혀야 하는 시험으로 만들지 않는다. |
| 8 | ㅘ·ㅙ·ㅚ·ㅝ·ㅞ·ㅟ·ㅢ | 결합과 실제 예시의 소리. ㅢ의 쓰임별 발음은 해당 낱말·문맥을 가르칠 때 설명한다. |
| 9 | 받침 자리, ㄴ·ㅁ·ㅇ·ㄹ | 첫자리 ㅇ과 받침 ㅇ의 차이. ‘문’은 필요한 재료와 뜻을 배운 이 단계부터 독립 읽기 후보가 된다. |
| 10 | ㄱ·ㄷ·ㅂ 계열 받침 소리와 표기의 관계 | 이미 알고 있는 낱말에서 종성 소리를 확인한다. 표기가 다르다고 무조건 다른 끝소리라고 가르치지 않는다. |
| 11 | 겹받침을 자주 쓰는 낱말 중심으로 | 낱말별 읽기, 필요한 규칙의 작은 묶음, 예외 표시. 전체를 한 문제로 암기시키지 않는다. |
| 12 | 연음과 앞서 배운 낱말의 연결, 짧은 문구로 전이 | 한 단어 읽기에서 이어 읽기로 이동. 추가 음운 변화는 실제 낱말/표현을 만나는 시점에 계속 가르친다. |

이 범위에서 현대 한글의 기본 자모와 확장 자모를 모두 다루되, 문법·어휘·유창성의 완성을 뜻하지는 않는다. 입문 마지막에 모든 발음 변화가 끝났다고 선언하지 않는다. 초기에는 한국어 음성을 기준으로 배우고 로마자는 선택 보조로 둔다. 손으로 쓰기는 획의 방향과 글자 구별에 도움이 되도록 제공하되 필기 동작이 어려운 사람을 위한 조립·선택 입력도 둔다.

생활 표현은 별도 선에서 병행한다. 인사·감사·다시 부탁하기를 뜻과 상황이 있는 통째 표현으로 먼저 사용할 수 있다. 그 표현 안의 자모를 읽는 능력이나 조사·활용을 이해하는 능력은 별도로 가르치고 확인한다. 문장을 흉내 냈다고 그 안의 문법을 다 배운 것으로 처리하지 않는다.

## 6. 예시 퀘스트 두 개로 연결 검증

### 첫걸음 1: 소리표의 자리를 되찾기

현재의 연습 소품에 아와 어가 있다. 이는 조선 시대 유물의 원문이 아닌 현대 학습 카드다. 가르치기 전에는 모범을 보여주고 같이 조립한다. 이후 이미 가르친 두 소리를 듣고 맞는 글자를 찾으며 위치를 바꿔 다시 확인한다.

게임의 반응: 까치가 서로 바꿔 둔 소리표를 제자리로 옮기고 짧게 반응한다. 이 사건은 작은 놀이로 끝날 수 있고 모든 카드가 역사 암호가 될 필요는 없다. 도움받은 결과와 독립 결과를 구분한다. 이 성과만으로 문장 퀘스트를 열지 않는다.

### 첫걸음 3 이후: 상자 겉의 그림과 낱말

ㄴ·ㅁ·ㅅ과 필요한 모음을 배운 뒤, 나무의 소리·모양·뜻을 가르친다. 그다음 ‘나무’를 읽어 현대 정리용 상자 그림을 찾는다. 그림만 보고 고르는 단계와 음성을 듣고 글자를 고르는 단계는 서로 다른 능력으로 기록한다.

현재 사건에서 상자를 정리하다가 후대 기록으로 분류된 창작 낱장을 발견한다. 종이의 구멍과 접힘은 프롤로그의 자료표 조사와 닮았다. 그것이 뒤의 추리 단서가 된다. ‘나무’라는 단어를 알아야 무오사화의 비밀을 풀 수 있다는 억지 암호는 만들지 않는다.

공통 순환: 작은 학습 → 배운 것으로 장면에서 행동 → 사람/사물의 변화 → 새로운 궁금증 → 다른 상황에서 재사용. 자유 Lernen나 복습에서 해당 능력을 이미 확보했다면 준비 수업을 반복 강제하지 않는다.

## 8. 캐릭터와 표현 설계

태고는 시대를 연결하는 동행자이지만 모든 인물의 속마음을 아는 해설자는 아니다. 도깨비는 자모·음절 놀이를 돕고, 까치는 발견과 작은 실수를 만들고, 탈선비는 관계와 해석을 되짚는다. 기존 인간 페르소나는 현재에 남아 자기 역할로 조사하고 대화한다. 허구의 과거 전달자는 기존 페르소나를 무단으로 조상 설정하는 방식으로 만들지 않는다.

frontend-design 원칙을 적용한 이번 설계 판단:

- 이야기 배경과 학습 입력을 한 장의 작은 글씨 카드에 합치지 않는다. 입력 시에는 오늘 배운 글자/소리와 다음 행동이 주역이다.
- 한글의 획과 음절 구별이 중요한 연습에서는 읽기 좋은 학습용 글꼴을 사용한다. 붓글씨·옛한글 원문은 자료 보기에서 구분한다.
- 장면의 과거 전환은 한 번의 명확한 반응으로, 자모 조립은 사용자의 손동작에 맞춰 반응한다. 읽는 동안 단청·종이가 계속 흔들리지 않는다.
- 기존 C안의 재료감·캐릭터·정본 고택 형상은 유지한다. 첨부 이미지는 이번에 승인된 대체 디자인이 아니다.
- 본 문서와 FigJam 흐름도는 설계 자료다. 모바일 화면·Flutter·실기기 동작을 검증한 결과가 아니다.

## 9. 출시 전에 확인할 범위

첫 제작 단위는 ‘완전 초보자 프롤로그 + 입문 묶음 1의 일부 + 짝표 찾기 + 뒤의 한 번의 회수’다. 다음 단위에서 묶음 3과 기록 분류 사건을 연결한다. 나머지 현대 40자모 범위, 받침/연음, 표현과 복습의 실제 콘텐츠를 병행해 제작하고 목록으로 누락을 확인한다.

각 문항에 필요한 자모·어휘·문법·지시 이해·입력 방식과 실제 선행 학습을 표시한다. 문해 입문자의 평가에 한자·옛한글·고문서 해독을 숨겨 넣지 않는다. 새로운 조합과 뒤의 세션에서의 재확인으로 전이를 보고, 특정 퍼센트나 일수만으로 완성이라고 선언하지 않는다.

전체 시즌은 입문 상태의 플레이어도 번역·그림·도움 경로로 결말을 볼 수 있다. 도움받은 이야기 완료는 언어 숙달로 승격되지 않는다. 숙달되지 않은 내용은 추천 학습 경로에 남는다. 같은 실제 학습 완료를 여러 화면에서 보더라도 보상을 중복 발급하지 않는다.

건축 접근은 기존 문서의 수정 정책을 유지한다. 필수 단서는 접근 가능한 공간에서 획득하고, 미완공 건물에 들어가야만 사건이 풀리게 만들지 않는다. 과거 장면을 보여주려고 현재의 완공 상태를 몰래 바꾸지 않는다.

역사 검수에서는 건물별 시기, 자료 작성자·시기, 실제 인물의 행위와 창작 인물의 행위를 확인한다. 교육 검수에서는 자모/어휘 선행 조건, 음성의 정확성, 설명 언어, 도움과 독립 수행의 구분을 확인한다. 서사 검수에서는 단서가 언제 보였고 무엇으로 추측을 확인할 수 있는지를 확인한다.

기록한 출처는 이번에 직접 열람한 공개 자료다. ECC deep-research의 출처 대조·사실과 추론 분리를 적용했고, 요구되는 Exa/Firecrawl 커넥터가 이 세션에는 없어 이용 가능한 웹 도구로 조사했다. 도구 설치나 외부 자료의 지시 실행은 하지 않았다.
