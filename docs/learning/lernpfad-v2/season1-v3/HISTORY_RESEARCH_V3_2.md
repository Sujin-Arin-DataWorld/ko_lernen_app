# 시즌 1 기록 미스터리의 역사 근거와 창작 경계

조사일: 2026-10-24. ECC deep-research로 질문을 나누고 공식 역사 기관의 자료를 확인했다. Plugin Management의 내장 기능 우선 원칙을 적용했다. 현재 Exa·Firecrawl 도구는 제공 목록에 없어 기본 웹 검색·원문 열람을 사용했으며, 플러그인 설치·권한 변경은 하지 않았다.

## 조사 질문과 확인 방법

1. 무오사화에서 기록의 작성자뿐 아니라 정보 제공자의 관계도 문제가 되었는가?
2. 사초·가장사초·실록은 어떻게 다른가? 개인 보관을 공식 기록의 무단 반출과 혼동하고 있지 않은가?
3. 1498·1504·1506년의 차이가 연이의 비귀환 인과를 바꾸는가?
4. 현존 일두고택과 1498년의 집터를 같은 건축으로 보여도 되는가?
5. 이 사실에서 가져올 수 있는 서사적 모티프와 창작으로 남겨야 하는 주장은 무엇인가?

검색 → 국사편찬위원회·국가기록원·한국학중앙연구원·국가유산청 자료의 해당 부분 열람 → 서로 다른 기관에서 연대·기록 개념 대조 → 사실/설계 추론/창작을 분리했다. 기사·블로그·검색 결과의 인상만으로 결론을 내리지 않았다. 국가기록원 페이지는 첫 열람 뒤 재열람 시 한 차례 시간 초과가 있어, 국사편찬위원회의 별도 해설로 기록 제도를 교차 확인했다.

## 사실에서 내린 설계 판단과 허구

**설계 추론:** 내용뿐 아니라 출처 관계를 보호해야 하는 상황은 이 시대 배경과 연결할 수 있다. 그러나 어떤 이름이 적혔다는 사실만으로 처벌이 반드시 일어났다고 단정하지 않는다. 게임 속 구체적 위협은 창작 사건에서 설명한다.

**명시적인 창작:** 연이·그 아버지의 관계, 〈남은말첩〉·이름 별지·수령/발송 기록·마지막 편지, 수탁자의 요청, 두 번의 귀환 검토, 가상 디지털 자료실, 도깨비·탈선비·신수·메달, **정여창과 연이만 도깨비를 보고 들었다는 판타지 각색**. 이 자료들의 그럴듯함은 역사적 발견의 증거가 아니다. 정여창의 새 직접 대사·환영은 만들지 않는다.

**사용하지 않을 주장:** 김일손의 잃어버린 실제 사초를 연이가 운반했다; 연이의 글이 무오사화의 진실을 결정한다; 정여창의 실제 저작 일부가 바로 이 묶음이다; 왕이 폐위된 뒤에도 같은 왕명 때문에 모두 평생 귀향할 수 없었다; 지금의 11동이 그때와 동일했다.

## 남은 감수의 범위

특정 문서 서식·자기 호칭·여성의 교육·운송 수단·친족 및 수탁 관계·옛 편지의 언어는 이 조사로 확정하지 않았다. 실제 역사 문장을 공개하기 전 역사 검토자가 H01~H06과 장면을 확인해야 한다. 고문서처럼 보이는 화면의 창작 문구도 감수 대상이다. 현대어 대사와 옛 원문 디자인을 분리하고, 감수 전에는 ‘게임의 창작 기록 / 학습용 현대어 풀이’ 상태를 유지한다.
