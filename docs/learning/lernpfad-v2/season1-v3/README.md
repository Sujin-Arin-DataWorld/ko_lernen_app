# 시즌 1 v3.0 · 교육과정 연결 계획 자료

2026-10-24 사용자 세계관을 바탕으로 작성한 **제작 계획**이다. 앱 디자인·구현·신규 아트·128행 원장 이관을 실행한 자료가 아니다.

먼저 [전체 제작 계획](../../../superpowers/plans/2026-10-24-ildu-season1-v3-curriculum.md)을 읽는다. 사용자 [v3.0 보존 사본](../reference/SEASON1_V3_20261024.md)이 이야기 기준이고, [교육과정 원본](../reference/CURRICULUM_FOUNDATION_TO_C2.md)과 기존 curriculum 목표·평가 계약이 배울 범위를 정한다. 문서의 상태 표기와 계획자의 새 제안을 구별한다.

**후속 집필:** [세계관·인물·교육 통합 보강본 v3.2](WORLD_BIBLE_V3_2.md)이 이번 요청의 작가용 답이다. 곁기록, 평생의 귀환 선택, 도깨비의 의심과 선물, 과거 두 인간/현재 기억 공간만의 가시성, 마지막 편지를 현재에 잇는 경로를 정했다. 실재 사료·모든 수업 제작·앱 공개를 완료했다는 뜻은 아니다.

`AP-1`은 전체 계획 §3.1의 스포일러 없는 현대 대체·본편 재사용 규칙이다. `AC-1`은 [기존 수행 확인 계약](../curriculum/ASSESSMENT_CONTRACT.md)이다. CSV의 episode는 문법을 배우거나 레벨을 통과하기 위한 잠금이 아니다. 본편을 아직 보지 않은 상급자와 게임을 원하지 않는 사람에게 같은 목표의 현대 활동을 제공한다.

원 356행 문법→GRAMMAR_ALLOCATION의 unit_id→UNIT_STORY_MAP을 따라 연결한다. 문법의 새 도입/재사용, 기존 KP/content ID, 선택 목표와 독립 수행을 보존한다. 후속 제작 항목·담당·검증·공개 기준은 전체 계획 T1~T12에 있다.

현재 준비한 연결표와 미래 작업의 체크박스를 구별한다. v3.0의 연이는 살아남아 긴 삶을 살며 선물을 보낸 인물이다. 이전 STORY_LEARNING_LINKS의 병사 전달자·현대 자료 정리 프롤로그는 비교 이력이며 새 본편의 작가용 진실로 사용하지 않는다.
