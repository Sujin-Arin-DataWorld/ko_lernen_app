# Lernpfad v2 구현과 공개 경계

이 문서는 실행 가능한 첫 묶음의 계약이다. 전체 교육과정 완성이나 학습 효과 검증을 뜻하지 않는다. 전체 요구 사항은 [MASTER_PLAN.md](MASTER_PLAN.md), 남은 제작·검증은 [WORK_QUEUE.md](WORK_QUEUE.md)에 있다.

## 진입과 되돌리기

- `/path/v2`: 선택한 구간의 목표 → 현재 활동 진행과 기능별 확인 → 다음 활동 → 구간 탐색·자유 학습·일두고택.
- `/path/foundation`: 첫 입문 사건. `/path/v2`에서 실제 수업을 열고 돌아오면 저장된 결과를 다시 읽는다.
- `/path/legacy`: 기존 경로. `LERNPFAD_V2` 빌드 플래그의 기본값은 false이다. 검증 전 기존 `/path`를 공개 전환하지 않는다.
- 개발 확인: `flutter run --dart-define=LERNPFAD_V2=true`. 기존 앱 초기화·계정 진입 조건은 그대로 적용된다.
- 새 UI에서 이전 경로로 돌아가도 확장 기록은 삭제하지 않는다. 구버전 앱의 백업·복원 동작까지 검증되었다는 뜻은 아니다.

## 데이터와 성취

`assets/data/lernpfad_v2.json`은 입문 네 구간과 A1.1~C2.2의 목표 및 기존 과제 연결을 정의한다. 원 KP ID·과제 ID·콘텐츠 해시는 바꾸지 않는다. `tool/build_lernpfad_v2.py`로 생성하며 `--check`로 원본 변경에 따른 불일치를 검사한다.

기존 902개 과제의 연결은 실행 가능한 과제 링크다. 구간 전체의 네 기능·어휘·발음·말투·전이 수업을 모두 만들었다는 의미가 아니다. 모든 구간의 `coverage`는 partial이다. 화면의 분모는 **현재 연결된 필수 활동 수**이며 전체 구간 이수율이나 CEFR 달성률로 표시하지 않는다. 미제작 부분을 단일 가짜 단원으로 세지도 않는다.

기존 과제는 `PhaseTaskScreen`의 가르치기·연습·확인과 원 평가 서비스를 사용한다. 현재 내용과 일치하는 평가 근거만 읽는다. 잘못 푼 시도는 완료에서 제외한다. 점수가 없는 생산 활동은 연습으로만 기록하며 독립 능력으로 올리지 않는다. 원본 근거가 없어지면 확장 기록으로 이를 복원하지 않는다.

첫 입문 수업은 ㅇ·ㅏ·ㅓ를 가르치고 아·어의 글자 결합을 확인한다. 소리 듣기는 선택할 수 있다. 음성 장애가 있어도 문자 연습은 가능하며 이를 듣기 근거로 올리지 않는다. 도움이나 확인 단계의 오답 이후에는 해당 시도를 지원받은 수행으로 남긴다. 독립 확인도 **학습한 두 글자 조합을 찾는 범위**이며 처음 보는 단어 해독이나 A1 인증이 아니다.

선택 레벨과 구간은 새 기록에 별도로 저장한다. 기존 배치·라이브러리 필터는 다른 의미이므로 자동으로 덮어쓰지 않는다. 새 기록이 없는 이용자는 입문 목표부터 보되 어떤 구간도 직접 선택할 수 있다. 문법 의존 관계에서 유도한 `preparationTaskIds`는 준비 활동 제안이며 새로운 잠금이나 숙달 규칙이 아니다.

## 저장 소유권

`CourseProgressService`가 기존 직렬 큐에서 새 기록을 읽고 쓴다. CourseMastery v5의 형식과 저장 경로는 유지한다. 확장 영역은 `kl_lernpfad_v2_<encoded-owner>` version 1이며 guest와 uid 이름 공간을 구분한다. 계정 epoch와 로컬 데이터 수명 lease로 이전 계정·삭제 전 화면의 저장을 차단한다.

첫 수업의 위치·도움·원 답변·내용 해시·평가 범위·시작 시각·시도 ID를 한 키에 저장한다. 완료 receipt와 이야기 결과가 별도 쓰기 사이에 갈라지지 않는다. 쓰기 실패 시 성공 화면을 먼저 표시하지 않고 같은 시도로 재시도한다. 결과를 확정하지 못한 네이티브 쓰기는 다음 읽기에서도 다시 확인한다. 두 화면이 같은 수업을 열었을 때는 마지막으로 읽은 커서를 비교해 새 위치나 도움 상태를 덮어쓰지 않는다.

현재 확장 기록은 **이 기기에만 저장**된다. 클라우드 병합·게스트 계정 전환 이관·구버전 복원 호환은 아직 구현·검증 중인 후속 게이트다. 이를 숨긴 채 기본 출시하지 않는다. 기존 초기화 루프는 새 `kl_` 영역도 제거하고 진행 중인 쓰기를 기다린다.

기존 Phase 기록의 300 한도는 전체 원 근거 한도가 아니라 반복 이력 한도이다. 현재 메인은 과제·개정별 최신 기록과 각 평가 결과 대표 기록을 보존한다. `phase_attempt_retention_test.dart`를 회귀 검사에 포함한다. 새 입문 receipt의 장기 보존·크기 정책은 전체 구간 확장 전에 별도로 설계한다.

## 캐릭터 정본

2026-10-23 사용자가 지정한 여섯 폴더는 [CHARACTER_SOURCES.json](CHARACTER_SOURCES.json)에 원 경로·현재 SHA-256과 함께 기록했다. 이전 일반 `도깨비` 폴더 대신 이번에 지정한 세 도깨비 폴더를 기준으로 한다.

첫 수업은 까치 기본 자세와 펼친 날개 자세의 **원본 바이트 그대로**를 사용한다. 후자는 완료 결과가 저장된 뒤에만 표시한다. 기존 페르소나 11명의 런타임 이미지도 지정한 `Persona` 원본과 해시가 같다. 백호·도깨비의 나머지 파일은 출처 등록 단계이며 아직 새 에피소드에 모두 연결된 것은 아니다. 외형·성격·관계·음성 정본을 각각 보존한다. 미디어가 보상을 지급하지 않는다.

## 검증 범위

- Python: 356행 원본 대응, 902개 연결, 16구간 목표, 선언된 의존 그래프 무순환, 390개 기능·발음·어휘 등 교차 참조 행, 실제 캐릭터 13개 런타임 파일의 원본 해시.
- Dart: 구간 선택, 지원·독립 수행 분리, 개정 내용, 기록 재시도·충돌·계정·삭제·실패 복구.
- Flutter widget: 실제 공통 C안 위젯과 앱 폰트, 독일어 320dp/200% 글자, 경로→수업→저장→복귀.
- `evidence/`: 위 위젯 실행의 렌더 캡처. 실제 폰·브라우저 설치, 원격 CI, 사용자 관찰 또는 승인 목업 일치 증거가 아니다.

렌더 캡처 재생성: `CAPTURE_LERNPFAD_EVIDENCE=1` 환경 변수로 `flutter test test/lernpfad_screen_test.dart`를 실행한다. 새 정본 PNG의 비율·원색·투명도를 유지하며 해상도별 디코드만 제한한다.

공식 확인: 2026-10-23 [Flutter 접근성](https://docs.flutter.dev/ui/accessibility), [W3C 집중 지원](https://www.w3.org/WAI/WCAG2/supplemental/objectives/o5-user-focus/). 긴 설명을 분리하고, 중단 위치와 다음 행동을 보존하며, 48dp 입력·큰 글자·동작 줄이기를 검증 항목으로 사용한다. 이 자료는 재미나 학습 효과를 입증하는 근거가 아니다.

최종 코드 리뷰에서 확인한 저장 실패 후 지원 이력 누락, 문항이 줄어든 개정의 재개 실패, 오답 원 응답 미보존은 회귀 테스트와 함께 수정했다. 저장이 해결되기 전에는 새 답을 받지 않으며, 정오답·문항·순서·지원 여부를 최종 답 맵과 별도로 보존한다. 오래된 내용의 커서는 새 내용의 길이로 폐기하지 않고 재시작할 수 있도록 남긴다.

리뷰에서 범위를 보류한 전체 교육과정/이야기 제작, 클라우드/구버전 이관, 지연·새 맥락 확인은 완료한 것으로 간주하지 않는다. `WORK_QUEUE.md`의 P1/P2/P3-C/P3-R/P6/P7/Q07/Q10/Q11에서 계속 관리한다. 물리 기기·발음·재미·승인 디자인 일치도 별도 검증 대상이다. 원본 대응과 캐릭터 바이트는 별도 Python 검사로 확인했고, 리뷰어가 이를 독립 재검증했다는 주장은 하지 않는다.
