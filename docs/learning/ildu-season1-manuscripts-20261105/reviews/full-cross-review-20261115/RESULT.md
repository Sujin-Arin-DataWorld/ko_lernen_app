## 주요 교정

- **입문·A1:** 익히지 않은 산출 요구와 화자·물건 지시를 정리하고, 새 자료의 답이 번역이나 모델에서 먼저 드러나는 부분을 고쳤습니다. A1.2에서는 짧은/긴 부정, 이동 목적/준비 의도를 각각 직접 써 보게 했습니다. 도움을 본 수행은 지원 연습으로 남깁니다.
- **A2:** 도움 요청, 허락, 정정, 거절에 필요한 실제 학습자 차례와 자료를 보완했습니다. 연락을 전화로 좁히거나 원문의 호칭·관계·사물 뜻을 바꾸는 번역을 바로잡았습니다. 상위 레벨 선선택 시에도 현대 자료의 준비 단계가 빠지지 않게 했습니다.
- **B1·B2:** 인용의 화자와 전달 경로, 자료군, 약속과 가능성, 규정과 출처를 분리했습니다. 각 기능의 새 과제와 답안 가림 범위를 명확히 했으며, 지원 시범 자체를 독립 성취로 계산하지 않습니다.
- **C1·C2:** 사람 수와 사진·물건 수, 접수와 완료, 결과 부재와 측정 미실시, 미상과 확인 행위를 구별했습니다. 번역에 추가된 지연·중단·약속 같은 추론을 제거하고 문장 수·역할·포트폴리오 맥락과 밑줄 예시를 맞췄습니다.
- **이야기·번역:** 기존 사건 공개 조건과 현대 역할 경로를 유지했습니다. 정본 요약·본편·학습용 추가 대사의 출처를 구분하고, 조이의 미설정 성별과 독일어 du/Sie 관계를 불필요하게 바꾸지 않도록 했습니다.

## 검증 결과

100개 단원 ID와 16개 구간, 원래 공개 조건, 고정 출처 4개, 첫 책 정본 대사 9개, 표 구조·로컬 링크·답안 접기 구조·색인 해시를 대조했습니다. 세 역할의 단원별 현재 판정 300개와 공통 문서 판정 18개가 모두 유효합니다. 수정 뒤 오래된 SHA의 통과는 채택하지 않았습니다.

214개 검토 항목을 수정 후 독립 검토 근거로 닫았고 미해결 항목은 0개입니다. 이 수에는 여러 역할이 같은 문제를 각각 지적한 항목이 포함되므로 서로 다른 오류 214개라는 뜻은 아닙니다. [검증 JSON](FINAL_VALIDATION.json)은 구조 검사와 의미 검토의 역할을 구분하며, [편집 기록](EDITOR_DECISIONS.json)은 각 항목을 현재 파일·검토자 근거에 연결합니다.

원본 폴더와 기준 ZIP 170파일을 그대로 보존했습니다. 앱·음성 기준 2,308파일에는 변경·누락이 없고, 기본 작업공간의 630개 변경과 기존 앱 워크트리의 707개 변경 및 스테이징도 유지됐습니다. 근거는 [보존 검증](PRESERVATION_VALIDATION.json)에 있습니다. 앱 구현·데이터·이미지·음성 합성·업로드·배포는 수행하지 않았습니다.
