## 진행자용 답과 운영 메모

이 구획은 응답 전 학습자에게 보여 주지 않는다. 문제를 진행할 때 해당 문제표만 남기고 앞의 시범, 뒤의 카드 활동과 이 답 부분을 가린다. 도움을 요청하면 해당 모형을 보여 주며, 그 뒤 응답은 도움 연습으로 구별한다. 속도나 조각을 집는 순서는 정답 기준이 아니다.

| ID | 자극·답·반응 |
|---|---|
| P1 / P2 | 모형을 따른 답은 아 / 어. 둘 다 ㅇ 왼쪽·모음 오른쪽. ㅓ의 짧은 획이 왼쪽을 향해도 모음 자리는 오른쪽이다. |
| I1 / I2 | 어 / 아. 둘 다 ㅇ 왼쪽·모음 오른쪽. 로마자만 쓴 응답은 한글 조립으로 세지 않는다. |
| 소리 시범 | 기존 참조 S-A와 아, 이어 S-EO와 어를 함께 제시한다. |
| L1 / L2 | L1은 S-EO → 어, L2는 S-A → 아. 보기 어 / 아에서 첫째, 둘째. 참조 키·전사·답은 숨긴다. |
| T1 | 별도 목표 카드 **아**, 다음 **어**를 한 장씩 보여 준다. 처음 배치 어 / 아에서는 오른쪽→왼쪽, 바꾼 배치 아 / 어에서는 왼쪽→오른쪽. 수진은 맞으면 해당 카드와 목표를 나란히 놓고, 다르면 목표와 두 카드를 함께 비교하도록 돕는다. 문자 형태 찾기다. |
| T2 | 배치 어 / 아에서 S-A, 다음 S-EO만 들려준다. 답 아→어, 위치 오른쪽→왼쪽. T1의 목표 카드는 가린다. L1–L2와 다른 소리 차례이며, 이미 배운 음절의 소리 대응이다. T1 대신 고르는 대안이다. T1 목표·답을 이미 보았다면 T2를 새 독립 확인으로 세지 않고 노출 뒤 연습으로 구별한다. |
| 반복·도움 | “다시 들을까요? / Would you like to hear it again? / Möchtest du es noch einmal hören?”라고 묻고 동의하면 **바로 직전 표본**을 반복한다. 다른 표본으로 바꾸지 않는다. 답이나 모형을 보여 준 뒤의 선택은 도움 연습이다. |

- 소리가 없으면 L1–L2·T2를 미루고 I1–I2·T1을 진행한다. 안내: “소리 확인은 나중에 해도 돼요. / You can come back to the sound check later. / Du kannst den Lautvergleich später machen.” 실제 승인 파일과 키의 대응·재생·청취는 이번 원고 교정에서 검증하지 않았다.
- 스몰토크의 따라 말하기·비언어 선택, 글자 조립, 형태 찾기, 소리 대응은 서로 다른 활동이다. 인사의 자연스러운 억양·미소를 오류로 판정하지 않는다. 카드 선택을 발화로, 문자 전사를 읽은 것을 청취로 기록하지 않는다.
- 아의 도움 조립 뒤 탈선비가 한 번 돌아오는 사건은 독립 읽기·발음 인증이 아니다. 반복·중단·재개로 귀환을 취소하거나 다시 각성시키지 않는다. 첫자리 ㅇ 설명을 받침 ㅇ까지 넓히지 않는다. 수진과의 인사 역할극은 기존 관계를 바꾸지 않는다.
