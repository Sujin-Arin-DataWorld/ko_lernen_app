## 두 가지 짧은 연습 / Two short exercises / Zwei kurze Übungen

### P2 · 이름을 다시 부탁하기 / Ask for the name again / Noch einmal nach dem Namen fragen

Ask **다시 말해 주세요.** (“Could you say that again?”), then check the repeated name. / Übe die Situation, dass du den Namen nicht verstanden hast. Bitte mit **다시 말해 주세요.** („Kannst du das bitte noch einmal sagen?“) um Wiederholung und frage dann zur Bestätigung nach dem Namen.

## 스몰토크 — 질문을 놓쳤을 때 / A missed question / Die Frage nicht verstanden

**S1 · 도움을 보며 대화하기.** 연습 이름 **민수 / 하린** 중 하나를 골라요. 질문을 잘 들었으면 바로 이름을 말해요. 질문을 놓쳤으면 같은 질문을 다시 부탁해요. 아래는 민수를 고른 예예요. / Choose the practice name **민수** or **하린**. If you heard the question clearly, give your name straight away. If you missed it, ask for the same question again. The example below uses 민수. / Wähle den Übungsnamen **민수** oder **하린**. ## 다른 상대에게 해 보기 — 학습자 카드 / Try with another partner / Mit einem anderen Gegenüber üben

**T1 · 내 연습 이름: 하린.** 이번에는 다른 상대가 먼저 인사해요. 인사와 자기소개를 하고 상대 이름을 확인해요. 잘 들었으면 바로 확인하고, 놓쳤으면 같은 이름을 다시 부탁해요. 상대 카드와 모범답은 계속 가려 두세요. / **Your practice name: 하린.** This time another partner greets you first. Return the greeting, introduce yourself and check the name you hear. If you heard it clearly, check it straight away; if you missed it, ask for the same name again. Keep the partner’s card and model answers hidden. / **Dein Übungsname: 하린.** Diesmal begrüßt dich ein anderes Gegenüber zuerst. Erwidere die Begrüßung, stelle dich vor und frage zur Bestätigung nach dem gehörten Namen. Wenn du ihn verstanden hast, frage direkt nach; sonst bitte um Wiederholung desselben Namens. Die andere Rollenkarte und die Musterantworten bleiben verdeckt.

다음 실제 만남에서도 원하는 이름으로 인사하고, 필요할 때 다시 부탁해 볼 수 있어요. / At a future meeting, you can greet someone using a name of your choice and ask again when you need to. / Bei einem späteren Treffen kannst du mit einem Namen deiner Wahl grüßen und bei Bedarf nachfragen.

## 진행자용 답과 운영 메모

이 구획은 응답 전에 학습자에게 보여 주지 않는다. 학습자에게는 해당 문제나 자기 역할 카드만 제공한다. 이름의 소리·표기는 사전에 익힐 수 있지만, 어느 이름이 상대 카드의 이름인지와 완성 답은 미리 보여 주지 않는다. 소리가 없으면 대본·상대 발화의 글을 제공해 문자 이해/대화 연습으로 진행하고, 청취 성공으로 기록하지 않는다.

| T1 · 반복 요청 뒤 / Asked to repeat / Nach einer Bitte um Wiederholung | 민수예요. | I’m Minsu. | Ich bin Minsu. |
| T1 · 맞는 이름 확인 / Correct name checked / Richtiger Name nachgefragt | 네. | Yes. | Ja. |
| T1 · 다른 이름 확인 / Wrong name checked / Anderer Name nachgefragt | 민수예요. | I’m Minsu. | Ich bin Minsu. |

I1은 ‘이름을 놓친 상황’의 재요청 역할 연습이다. 실제로 못 들었다는 증거를 만들거나 잡음·빠른 발화로 실패를 유도하지 않는다. T1에서는 잘 들었다면 재요청을 생략할 수 있다. 잘못 확인한 이름에 정정 정보를 준 뒤 다시 맞춘 경우는 도움 뒤 이름 확인으로 구별하되, 대화를 회복한 행동 자체는 인정한다. 두 과제 모두 확인 뒤 실제 “네” 응답까지 기다린다.

- 이름 일치와 인사·요청·확인의 기능을 본다. 저는의 생략/추가, 한 번 더 말해 주세요, 이름을 되말하는 하린 씨?·유나예요? 같은 자연스러운 확인을 하나의 모범 문장과 다르다는 이유로 오답 처리하지 않는다. 다른 말끝을 사용한 의사소통 성공과 이번 목표 예요/이에요 산출은 구별한다. 이름만 말해도 뜻이 전해졌다면 전달 성공은 인정하되 목표 말끝을 썼다고 하지 않는다.
- I1·I2에서 다른 연습 이름을 택하면 한 이름은 모음 끝, 다른 이름은 받침 끝이 되도록 카드 교환을 돕는다. 한 유형만 실제로 사용했다면 두 유형을 모두 확인했다고 기록하지 않는다. 상대 이름+씨예요의 예요는 씨 뒤의 형태이므로 모음 끝 이름으로 자기소개한 증거를 대신하지 않는다.
- 말하기가 부담되면 연습 이름·응답 카드 선택이나 비언어 확인으로 참여할 수 있다. 선택·지목은 자유 발화 또는 말하기 인증이 아니다. 실제 자기 이름·성별·국적은 필요하지 않다. 정답이나 상대 카드를 미리 본 응답은 지원 연습으로 구별한다.
- 씨는 여기서 상대 이름 뒤의 호칭이며 식물의 씨와 다른 쓰임이다. 모든 호칭·조사·의문문·높임 문법을 새 필수 범위로 늘리지 않는다. 독일어 du는 이 편한 모임의 관계에 맞춘 것이며 모든 첫 만남이나 한국어 주세요가 du/Sie 중 하나와 항상 같다는 규칙이 아니다.
- 실제 소리·발음·학습자 관찰·생활 대화·24시간 뒤 회상은 이번 원고 검산으로 확인되지 않는다. 다음 실제 만남의 제안은 이미 생활 전이를 수행했다는 기록이 아니다.
