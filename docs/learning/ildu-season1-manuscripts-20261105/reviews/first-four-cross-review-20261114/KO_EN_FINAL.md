## 읽기 범위와 현재 바이트

`BRIEF.md`, `EDIT_BRIEF.md`, `EDITOR_REPORT.md`, `REVISION1_SHA.json`을 전부 읽었다. `LEARNER_VIEW_REVISION1.md` 505줄을 전부 읽은 뒤 각 원고의 진행자·집필자 구획을 전부 읽었고, 추출본에 포함된 본문이 각 revision1 원고의 해당 전체 접두부와 일치함을 확인했다. 따라서 네 원고를 빠짐없이 읽었다. `REVISION1.diff`도 L1–711을 모두 읽었다.

학습자 지시와 차례별 제공 자료의 범위를 구분해 조립 답·가능한 발화·대응·대화를 도출하고 답표와 대조했다. 전편 검토에는 답표도 포함되므로 **블라인드 학습자 시험이 아니다**. 소리 문항은 키/전사에 따른 문자상 예상 응답이며 실제로 소리를 듣고 푼 것이 아니다.

## 나머지 F0 과제의 실제 텍스트 풀이

아래 S-*는 검토자·진행자가 보는 참조다. 학습자는 준비된 표본만 받으며, 이번 검토에서는 실제 표본을 듣지 않았다.

| 과제 | 실제 제공 자료를 따라 만든 응답 | 판정 |
|---|---|---|
| sound-signs 첫 아 복원; P1/P2 | 지시대로 ㅇ 왼쪽+ㅏ 오른쪽 → **아**; 모형 P1/P2를 따라 **아/어**. | 지원 복원/조립. 독립 발음·읽기 인증 아님. |
| sound-signs L1/L2 | S-EO, S-A → **어/아**, 보기 어/아의 **1/2**. | 문자상 대응 일치. |
| sound-signs T1 | 시작 어/아에서 진행자가 아→어 제시 → **오른쪽→왼쪽**. 교환한 아/어에서는 **왼쪽→오른쪽**. | 자극과 목표가 있어 풀 수 있음. |
| sound-signs T2 | 시작 어/아에서 S-A→S-EO → **아→어, 2→1**. | T1을 먼저 본 경우 새 독립 응답으로 세지 않음. |
| sound-signs 인사 | 수진 `안녕하세요.` → 내가 **안녕하세요.** 또는 **고개 끄덕임** → 수진 `반가워. 이제 카드도 같이 보자.` | 지원 인사와 비언어 선택을 구별. |
| above-below P1/P2/P3 | 모형 조립 **오/우**; P3 S-U와 오/우 → **우, 2번**. | 지원 활동으로 적합. |
| above-below L1/L2 | S-O, S-U → **오/우**, 보기 우/오의 **2/1**. | 문자상 대응 일치. |
| above-below T1 | 보기 어/우/아/오; 문자 목표 우→아→오→어 → **2→3→4→1**. 소리 대안 S-U→S-A→S-O→S-EO도 같은 카드·위치. | 문자/소리 대안 및 선노출 구별 적합. |
| above-below 감사 | 반환된 카드에 **감사합니다.** 또는 **고마워.** → 수진 `응. 여기 두면 잘 보이겠다.` | 둘 다 상황에 맞음. 말없이 뜻만 확인하는 선택도 허용. |
| straight-lines P1/P2/E1 | 모형 조립 **으/이**. 같은 말 반복을 원하므로 E1에서 **다시 말해 주세요** 선택. | E1은 뜻 지원 선택이며 자유 발화 아님. |
| straight-lines L1/L2 | S-I, S-EU → **이/으**, 각 보기의 **2/1**. | 우 미학습 시 L2는 먼저 가르친 지원 대조. |
| straight-lines 재요청 스몰토크 | S-I 뒤 **다시 말해 주세요.** 또는 **한 번 더 말해 주세요.** → 수진 `응. 한 번 더.` → **같은 S-I** → **이 카드**. | 답을 제공한 지원 시범. 실제 청취 성공 아님. |
| straight-lines T1-1–6 | 보기 이/우/아/으/어/오; S-U→S-EO→S-I→S-A→S-EU→S-O → **우→어→이→아→으→오**, 위치 **2→5→1→3→4→6**. 문자 대안 목표도 같은 순서로 각 카드에 대응. | 여섯 항목 모두 일치. 소리 없는 경우 문자 경로만 성립. |
| 모든 F0 반복 요청 | 예: sound-signs L1 뒤 반복 선택 → **S-EO**; above-below L2 뒤 → **S-U**; straight-lines T1-2 뒤 → **S-EO**. | 직전 표본을 유지한다. 답이나 모형 제공 뒤에는 도움 응답으로 구분. |

각 단원의 소리 시범은 **아→어 / 오→우 / 으→이**와 해당 문자 동시 제시로 연결된다. 후속 나·너, 고·구, 느·니는 선행 자음을 배운 뒤의 참조이며 이번 조립·소리 확인에는 포함되지 않는다. 단어 뜻이나 24시간 회상 과제도 추가되지 않았다.

## A1의 실제 응답과 상대 턴

`나`는 검토자가 실제로 작성한 학습자 텍스트 응답, `상대`는 원고의 차례별 상대 발화다. 모든 기본 흐름과 허용 기준은 진행자 구획과 일치한다.

| 과제·분기 | 입력 → 실제로 작성한 응답과 끝까지 이어진 턴 | 확인 |
|---|---|---|
| P1 | 하린 카드/모형 → 나 **안녕하세요. 하린이에요.** | 받침 ㄴ 뒤 이에요, 지원 연습. |
| P2 | 상대 `안녕하세요. 하린이에요.` → 나 **다시 말해 주세요.** → 상대 `하린이에요.` → 나 **하린 씨예요?** → 상대 `네.` | 반복 대상은 같은 이름. |
| S1 질문을 들음 | 상대 `이름이 뭐예요?` → 나 **민수예요.** → 상대 `민수 씨예요?` → 나 **네.** | 불필요한 재요청 없음. |
| S1 질문을 놓침 | 상대 `이름이 뭐예요?` → 나 **다시 말해 주세요.** → 상대 **이름이 뭐예요?** → 나 **하린이에요.** → 상대 `하린 씨예요?` → 나 **네.** | 같은 질문을 반복하고, 선택한 하린 카드에 맞게 이름도 일치. |
| S1 말하지 않는 선택 | 나 **하린 카드 지목** → 상대 `하린 씨예요?` → 나 **끄덕임**. | 참여 가능. 목표 말끝 사용·말하기로 세지 않음. |
| L1 | 대본 3번에서 수진 요청, 4번에서 크리스티안 자신의 이름 반복 → **크리스티안**. | KO `자기 이름`, EN `their name`로 화자가 특정됨. |
| L2 | 대본 2번·4번의 동일 이름 → **크리스티안** 또는 **Christian 이름 카드**. | 이름 일치. 철자 독립 해독을 강요하지 않음. |
| L3 | 두 이름을 비교 → **같음 / Stayed the same**. | 새 부정 문법 산출 불필요. 대본 읽기 풀이. |
| I1 기본 | 내 카드 준 → 나 **안녕하세요. 준이에요.** → 상대 `안녕하세요. 유나예요.` → 나 **다시 말해 주세요.** → 상대 `유나예요.` → 나 **유나 씨예요?** → 상대 `네.` | 준 받침 뒤 이에요. 실제로 못 들었다는 증거가 아니라 지정된 재요청 역할 수행. |
| I2 | 민수로 카드 교환 → 나 **안녕하세요. 민수예요.** → 상대 `안녕하세요.` | 모음 끝 이름에 직접 예요. 씨예요를 이 증거로 대신하지 않음. |
| I1 자연스러운 대안 | 나 **안녕하세요. 저는 준이에요.** → 상대 `안녕하세요. 유나예요.` → 나 **한 번 더 말해 주세요.** → 상대 `유나예요.` → 나 **유나예요?** → 상대 `네.` | 저는 추가·재요청 대안·이름 확인 대안 모두 수락 범위. |
| I1 틀린 이름 회복 | 상대 `유나예요.` → 나 **하린 씨예요?** → 상대 **유나예요.** → 나 **유나 씨예요?** → 상대 `네.` | 교정 뒤 확인으로 분류. 첫 응답부터 맞았다고 기록하지 않음. |

## 회귀·정본·수준 확인

- **KO–EN의 새 중요 회귀를 발견하지 못했다.** 지원 시범의 완성 문장은 유지하면서 독립 문항·상대 카드·답을 분리했고, 필수 학습자 행동과 음성 없는 경로는 영어에도 있다. 진행자가 실제 자료를 차례별 제공해야 하는 과제를 학습자 카드만으로 소리까지 판정할 수 있다고 주장하지 않는다.
- sound-signs의 정본 표시 KO 인용 9개는 수정 전과 바이트상 같은 문자열이다. 앞 검토에서 읽은 P-7 출처의 파일 SHA도 `24ec73c1051da05702aac1d0257339cb10059d6cc4ea05cb5c7fb585deb64bcb`로 유지되었다. 첫 아 복원 뒤 한 번 귀환, 이후 반복·중단 시 귀환 보존 및 이야기 대사의 번역 지원 원칙이 남아 있다.
- 네 편의 none/none 조건과 LQ-01/LQ-05 접점, 도깨비의 기존 지인 관계를 재설정하지 않는 역할극, 정본 인용/새 집필 구분을 확인했다. 새 소유·보상·역사·엔딩 조건은 보이지 않는다.
- F0는 여섯 모음의 배운 음절 조립·대응 범위다. A1은 인사·이름·예요/이에요·재요청·확인을 유지한다. 긴 이야기 문장의 문법이나 씨의 모든 용법을 필수 산출로 확대하지 않는다.
