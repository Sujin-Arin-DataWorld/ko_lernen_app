## 절대 경계

- BOOK 내부의 지정 원고와 검토 기록/인덱스만 쓰기 허용. 앱 체크아웃과 원본 출처에는 읽기만 가능하다.
- 앱 화면/코드/데이터/음성/원본 음가 표본/스토리 음성/합성/업로드/유료 외부 호출/커밋/푸시는 실행하지 않는다. Beyond Humanizer를 쓰지 않는다.
- 기존 ID, 공개 조건, 인물 관계, 정본 대사와 새 집필의 구분을 유지한다. 역사·소유·엽전·엔딩·레벨 통과 조건을 새로 만들지 않는다.
- 탈선비는 첫 아 복원 뒤 한 번 귀환한다. 도움 조립은 독립 능력 인증이 아니다. 반복·중단·재개로 귀환을 취소하지 않는다.
- 고택 캐릭터 대사는 읽기 전용. 듣기 참조를 글로 읽은 것을 실제 청취로 기록하지 않는다. 음원이 없으면 문자/대본 풀이만 검증하고 청취는 미검증으로 남긴다.
- 지원 연습, 정답 노출, 독립 확인, 선택 응답, 자유 발화, 실제 24시간 뒤 회상을 구별한다. 자연스러운 대안 표현을 하나의 모범답과 다르다는 이유로 오답 처리하지 않는다.
- 한국어의 생략을 번역하면서 성별·국적·사건 원인·행위자를 임의로 더하지 않는다. DE du/Sie와 EN 관계 거리는 장면 맥락에 맞춘다.
- 다른 에이전트를 생성하지 않는다. `rtk`/`rtk proxy`를 사용한다.

## 절차

1. 한영·한독 두 검토자가 같은 수정 전 스냅샷을 독립적으로 읽는다. 서로의 보고를 먼저 읽지 않는다. 이 단계에서는 원고를 수정하지 않고 각자 자기 보고서만 쓴다.
2. 각자는 학습자에게 보이는 지시·자료만으로 모든 닫힌 과제의 답과 열린 과제의 실제 응답을 만들어 낸다. 답표와 대조하기 전 도출 근거를 적는다. 답이 지시 옆에 노출되거나 자극·상대 반응이 없으면 이를 기록한다. 텍스트 풀이와 실제 소리 검증을 구분한다.
3. root가 두 언어 의견과 정본·학습 계약을 통합한다. 별도 원고 편집 담당 한 명만 네 원고를 수정한다. 서로 동시에 같은 원고를 편집하지 않는다.
4. 두 언어 검토자가 수정본 전편과 diff를 재독한다. 원고 작성자가 자기 수정을 독립 승인으로 계수하지 않는다. 오류가 있으면 범위를 특정해 수정·재검토한다.
5. 실제 수정 SHA·과제 풀이·남은 청취/사람 감수 경계를 기록한다. 인덱스와 연속성 기록을 갱신하고 앱/음성 미변경, 다른 96단원 미변경을 확인한다.
