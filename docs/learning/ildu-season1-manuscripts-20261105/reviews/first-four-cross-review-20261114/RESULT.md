# 첫 책 세 단원과 A1.1-01 교정 기록

검토 범위는 F0.1.sound-signs, F0.1.above-below, F0.1.straight-lines, A1.1-01 네 편이다. 2026-11-14에 시작해 11-15에 이어 작업했다.

**네 원고 교정과 Astra Max 한영·한독 교차 재검토 완료.** 두 언어 역할이 각각 수정 전 원고 전편을 읽고 과제를 텍스트로 풀었다. 별도 편집 담당자가 원고를 수정한 뒤, 두 역할이 수정본 전편과 diff를 다시 읽고 답을 재계산했다. 최종 재검토에서 발견한 독일어 질문 한 곳도 교정하고 두 역할이 변경분을 확인했다. 이번 모델 원고 검토에서 남은 필수 수정은 0건이다.

지원 시범은 볼 수 있게 유지했다. 혼자 확인하는 구획에는 문제와 자기 역할 정보만 두고, 답·소리 참조 키·상대 카드는 문서 뒤의 진행자 구획으로 옮겼다. 필요한 지시와 음성 없는 대안은 한국어·영어·독일어로 제공한다. 이는 원고 구획의 교정이며 앱 화면의 가림 기능을 구현한 것은 아니다.

## 실제로 풀어 본 범위

| 검증 | 결과와 해석 |
|---|---|
| 입문 조립 12문항 | 각 조각 쌍에서 음절과 배치를 도출해 12/12 답표와 일치 |
| 카드 찾기와 여섯 항목 누적 대응 | 제공할 목표·카드 위치를 다시 계산. 여섯 항목의 답은 우→어→이→아→으→오, 고정 배열에서 2→5→1→3→4→6 |
| A1 대화 | 바로 답하기, 질문 재요청, 이름 재요청, 이름 정정 뒤 회복, 비언어 선택의 차례를 끝까지 텍스트로 수행 |
| A1 이름 말끝 | 준이에요와 민수예요를 확인. 민수는 이미 본 모델 이름이므로 새로운 이름 해독이나 미학습 형태 전이까지 검증했다고 하지 않음 |
| 마지막 한독 교정 | “누가 자기 이름을 다시 말했어요?”에 대응하는 DE에 `eigenen` 추가. 크리스티안의 자기소개 반복과 수진의 상대 이름 확인을 구별해 유일한 답 유지 |
| 정본·범위 | P-7 한국어 인용 9개 보존. 기존 네 단원 ID·공개 조건·첫 아 복원 뒤 한 번 귀환·학습 범위 유지 |

답을 도출하고 진행자 답과 대조한 **모델의 텍스트 검증**이다. 실제 음원을 듣거나 초보 학습자에게 시험한 결과가 아니다. 소리 문항은 참조 키·전사와 예상 답의 대응만 검산했다. 실제 음가·파일 연결·발음·청취·사람 감수·학습자 관찰·생활 수행·24시간 뒤 회상은 별도다.

## 변경 경계

100개 원고 중 지정한 4개만 변경했고 다른 96개는 시작 시 SHA와 같다. 전체 단원 ID, 목차·인벤토리의 현재 해시, 네 원고의 표·링크 검사에 오류가 없다. 관련 검토 기록과 원고 인덱스·연속성 문서도 갱신했다.

앱·음성·원본 출처는 수정하지 않았고 합성·업로드·앱 빌드·커밋·푸시를 실행하지 않았다. 읽기 전용 앱 체크아웃은 `codex/season1-runtime-integration-20261103`, HEAD `f369fe2ce3c36475e295b2369f0e5ae83939b867`이다. 기존 기준 파일 2,308개(그중 음성 34개)의 변경·누락 0, Git 상태는 시작 때와 동일하다. 이 해시 검사는 기준 목록의 파일만 다루며 모든 ignored/generated 경로의 바이트 검사는 아니다.
