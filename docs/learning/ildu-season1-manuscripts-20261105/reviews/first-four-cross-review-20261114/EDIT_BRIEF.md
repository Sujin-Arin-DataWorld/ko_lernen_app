# 네 단원 원고 교정 담당

`BRIEF.md`의 정확한 범위와 절대 경계를 그대로 따른다. 이번 담당자만 네 원고를 쓴다. 다른 에이전트는 자기 검토 보고서만 작성한다. 앱·음성·원본 출처·다른 96단원에는 쓰지 않는다.

## 입력

- `KO_EN_INITIAL.md`, `KO_DE_INITIAL.md`의 전편 독립 검토와 구체 수정 제안

## 편집 결과

수정은 `BOOK/manuscripts/`의 네 원고에 직접 반영한다. 단순 제안 문서로 끝내지 않는다. 자연스러운 기존 문장과 정본 인용을 보존하면서 다음 실제 문제를 해결한다.

1. 지원 시범·예문·완결된 듣기 대본과 독립 확인을 분리한다. 독립 문항의 답·정답 전사·상대 이름·완성 예시가 같은 줄/학습자용 카드에 먼저 보이지 않게 한다. 학습자 자료와 진행자용 답/비공개 역할 카드를 명시적으로 나눈다. 필요하면 문서 끝 `## 진행자용 답과 운영 메모`에 답을 모은다. 과제 전에는 모델과 정답 부분을 가리는 간단한 KO/EN/DE 지시를 제공한다. Markdown 원고의 읽는 순서를 고치는 것이며 앱 화면을 설계하지 않는다.
2. 모든 과제에 지시·자료·풀 수 있는 목표·상대의 실제 반응·답 또는 열린 수락 기준을 넣는다. 현재 한국어만 있는 필수 안내를 EN/DE에도 제공한다. 학습자 지시에 자극 자체를 없애 답을 낼 수 없게 만들지 않는다.
3. sound-signs의 카드 찾기 목표를 구체화한다. 글자를 보고 찾는 형태 대조와 실제 음가를 듣는 소리 대응을 구별한다.
4. straight-lines의 여섯 음절 누적 소리 대응을 원래 배정표에 맞게 완결한다. 필요한 자극 순서·보기·반복 규칙·미준비 시 대안·답표를 원고에 담되 실제 음원을 생성/재생/교체하지 않는다. 아직 배우지 않은 ㄴ·ㅁ·느·니는 이 단원의 평가에 넣지 않는다. FOUNDATION의 후속 참조 느·니와 현재 다음 편의 니·무가 다르다는 것은 집필자 메모에 정확히 남기며 다음 편을 수정하지 않는다.
5. A1의 자기소개 예요/이에요 설명, 실제 반복→확인→응답 차례, 필요한 재요청과 이미 잘 들은 경우의 선택을 명료하게 한다. 개인정보는 선택한 연습 이름으로 대체 가능. 자기 카드와 상대 카드/진행자 정보는 분리한다. 선택·지목은 말하기 인증이 아니며, 대본 읽기는 청취 인증이 아니다. 예요/이에요 두 유형은 배운 범위의 모델과 과제로 점검하되 필수 문법 범위를 넓히지 않는다.
6. A1 현대 듣기는 한 화자 한 차례씩 표기한다. 기존 수진·크리스티안의 관계를 새 첫 만남으로 바꾸지 않는다. 처음 소개하는 상황의 역할 연습임을 세 언어 모두 알게 한다. 독일어 du/Sie는 관계에 맞게 일관되게 한다.
7. 원어민다운 자연스러움은 과장된 새 수사나 많은 대사를 뜻하지 않는다. 네 원고를 다시 읽고 어색한 한국어·영어·독일어를 고친다. 처음 배우는 사람의 안내를 내부 평가 용어로 채우지 않는다. 답을 하나의 완성 문장으로 고정하지 않으며 필요한 목표 형태와 의사소통 성공을 구분한다.
8. 이야기 조건·인물·P-7 정본 인용·처음 아 복원 뒤 귀환 순서를 유지한다. 원고 마지막의 복귀가 새 학습 성취/공정/보상/저장 구현 완료를 선언하지 않게 한다.
9. 문서 머리의 오래된 ‘검토 전’ 상태는 `교정 원고. 이번 검토 범위는 [네 단원 검토 기록](../reviews/first-four-cross-review-20261114/RESULT.md) 참조. 실제 음가 청취·사람 감수는 별도.`처럼 현재 기록으로 연결한다. 최종 RESULT는 root가 쓴다. 사람이 통번역했다고 주장하지 않는다.

독립 확인/전이 항목에 추적 가능한 짧은 문항 ID를 둔다. 불필요한 시험 수·24시간 지연 문항·새 스토리·발음 평가를 추가하지 않는다. 원고의 현 범위에서 필요한 완결성이 목적이다.

## 제출

수정 뒤 네 편을 다시 읽고 새 문자/문장 답을 직접 재계산한다. `EDITOR_REPORT.md`에 파일별 변경, 1차 소견별 처리, 과제 검산, 남은 제약, 현재 SHA를 기록한다. 검토자 둘에게 넘길 수정본은 완료 후 건드리지 않는다. root가 before와의 전체 diff와 학습자용 추출본을 만들고 두 검토자에게 재검토를 요청한다. 하위 에이전트는 만들지 않는다.
