# 2026-11-14 마지막 지정 변경분 KO–DE 교차 검토

검토자: middle_nov14. 부모 편집자가 지정한 두 변경분과 C1.1-05/06의 수정 학습 문항·듣기만 읽었다. **원고 수정은 하지 않았으며 이 보고서만 저장했다.** 초기 A1 전문 검토의 뒤에 추가된 역할 카드는 이번 별도 범위로 기록한다. 실제 음성·렌더·학습 수행은 검증하지 않았다.

## A2.1-03 — 매일 어휘 한 행

- 읽은 SHA-256: `3de74e41d279b2f7dec71357c99dfe6c352d30a26ea775eec84c25a8c51bc71f`.
- 실제 읽은 범위: 49–53행, 대상 새 행 51.
- KO 매일(하루도 빠짐없이 되풀이됨), 예문 ‘이 버스는 매일 와요’와 DE `jeden Tag: Dieser Bus fährt jeden Tag`를 대조했다. 버스 운행의 일별 빈도를 자연스럽게 전달하며 출발 시각이나 배차 간격을 덧붙이지 않는다.
- **대상 행 의미 일치. 추가 수정 제안 없음.** 이 SHA의 나머지 원고 전문을 새로 검토한 것은 아니다.

## A1.2-03 — 못/지 못하다 새 역할 카드

- 읽은 SHA-256: `161453de0be32bbb6a84558078125f19cb027efac5c74555ac368a47fc268c21`.
- 실제 읽은 범위: 50–82행. 새 역할 카드 65–78행, 학습 지시 67/69/71행, 모델 76행.
- 앞 주말 기록은 책을 읽지 않기로 선택한 경우다. 새 카드는 사진을 보려 했지만 집에 두고 와 볼 수 없었던 다른 경우이며 DE `hast sie aber zu Hause gelassen`는 ‘잊었다’라는 추가 원인을 만들지 않는다.
- 못→지 못하다 순서로 **두 문장을 모두 산출**하도록 세 언어에서 요구한다. `어제 사진을 못 봤어요 / 어제 사진을 보지 못했어요`는 모두 `Ich konnte mir die Fotos gestern nicht ansehen`와 일치한다. 선택하지 않음과 불가능의 이유가 뒤섞이지 않는다.
- 답은 원고의 `<details>` 안에 별도로 놓였다. 실제 앱에서 접혀 보이는지 확인한 것은 아니다.
- **새 카드 의미·과제·답 일치. 추가 수정 제안 없음.** 앞 보고서의 `fa4b035a…` 이후 변경분은 이 새 SHA·지정 구간에서만 독립 대조했다.

## C1.1-05 — 문항·듣기 최초 대조

- 최초 확인 SHA-256: `10460c8868ca513914e2bd81e4fcf50d9b666f71d103a65b42015fcb266c280b`.
- 실제 읽은 범위: 21–76행. 자료와 어휘를 문항의 근거로 읽고 시범·듣기·독립 과제·전이 조건을 대조했다.
- 원본의 ‘무편집 상태’와 ‘최초 촬영·보관 이력’, 시제품의 크기·조립 확인과 아직 하지 않은 하중 검사, 접수와 수리 완료를 구별하는 구조를 확인했다. 활착은 제공된 뜻풀이에 근거하며 새 잎만 본 상태에서 뿌리를 확인했다고 결론내리면 안 된다.
- **발견·전달 1(42행):** `noch ungeprüfte Fassung`은 KO 검토 중인 문서를 아직 미검토인 것으로 바꾸었다. 진행 중인 검토로 수정 요청.
- **발견·전달 2(74행):** 활착의 모델을 실제 해당 식물의 상태 확정으로 읽지 않도록 정의 문장임을 명시하고, 새 잎만으로 충분한지와 필요한 관찰을 묻도록 수정 요청.

## C1.1-06 — 문항·듣기 최초 대조

- 최초 확인 SHA-256: `0e59ada00679772b39981e2466db3c42463e7c00e69b87fc8ce710fa71f651df`.
- 실제 읽은 범위: 19–73행. 자료와 어휘를 문항의 근거로 읽고 시범·듣기·독립 과제·전이를 대조했다.
