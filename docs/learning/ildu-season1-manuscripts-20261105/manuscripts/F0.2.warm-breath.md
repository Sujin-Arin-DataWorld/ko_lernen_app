# F0.2.warm-breath · 작은 입김, 다른 첫소리

**A breath and a different initial · Ein Atemzug und ein anderer Anfangslaut**

집필 상태: KO·EN 본문 및 DE 초고. 독립 교차 검토 전.

## 소리와 모형 배우기

| 항목·쓰임 | KO | EN | DE |
|---|---|---|---|
| ㅎ · 첫소리 자음 | 하에서는 ㅎ이 왼쪽, ㅏ가 오른쪽이에요. 아의 첫자리 ㅇ은 소리가 없지만 여기의 ㅎ은 소리가 나요. | In 하, ㅎ is on the left and ㅏ on the right. Initial ㅇ in 아 is silent; ㅎ here has a sound. | Bei 하 steht ㅎ links und ㅏ rechts. Das anlautende ㅇ in 아 ist stumm; ㅎ hat hier einen Laut. |
| 호·허·흐 · 음절 모형 | 호는 ㅎ 아래에 ㅗ, 허는 ㅎ 오른쪽에 ㅓ, 흐는 ㅎ 아래에 ㅡ를 놓아요. | Put ㅗ below ㅎ for 호, ㅓ to its right for 허, and ㅡ below it for 흐. | Setze für 호 das ㅗ unter ㅎ, für 허 das ㅓ rechts daneben und für 흐 das ㅡ darunter. |
| 다시 · 반복을 나타내는 부사, 뜻 지원 | 다시 말해 주세요. | Please say that again. | Sag das bitte noch einmal. |
| 천천히 · 속도를 나타내는 부사, 뜻 지원 | 천천히 말해 주세요. | Please speak slowly. | Sprich bitte langsam. |

다시와 천천히는 같은 뜻이 아니다. 같은 내용을 또 듣고 싶으면 다시, 말하는 속도를 낮추고 싶으면 천천히를 쓸 수 있다. 이번에는 **같은 소리를 다시 듣는 요청**을 직접 주고받는다. 미학습 글자를 독립 해독하거나 두 문장을 모두 외워야 하는 조건은 없다.

## 도움 연습

완성 모형과 해당 소리를 **하→호→허→흐** 순서로 제시한다. 모형을 둔 채 조각 **ㅎ/ㅏ**, **ㅎ/ㅗ**, **ㅎ/ㅓ**, **ㅎ/ㅡ**를 한 블록으로 모은다. 지시: **“같은 모형을 만들어 봐요. / Build the same block. / Bilde denselben Silbenblock.”** 답은 하·호·허·흐다.

별도 대조 시범에서는 **아→하**, **으→흐**를 한 쌍씩 듣는다. 음량을 차이의 단서로 만들지 않는다. 학습자가 다시 듣기를 선택하면 방금 제시한 같은 표본을 반복한다. 아직 확인하지 않은 후·히를 이 단계의 시범으로 대신 내지 않는다.

## 다른 조합 확인

**EN** Look at 후 and 히 separately. For each, select sound A, B or C. Then hide the completed models and build from ㅜ + ㅎ and ㅣ + ㅎ. If a recording is unavailable, do the building part and return to the sound choice later.

**DE** Sieh dir 후 und 히 einzeln an und wähle jeweils Hörbeispiel A, B oder C. Decke dann die fertigen Vorbilder ab und bilde je einen Silbenblock aus ㅜ + ㅎ und ㅣ + ㅎ. Fehlt die Aufnahme, kannst du die Zeichen zusammensetzen und die Höraufgabe später nachholen.

| 자료와 지시 | 집필자용 정답과 근거 |
|---|---|
| 표기 **후**를 보고 소리 A 후 / B 우 / C 호 중 고른다. | **A**. 첫소리 ㅎ과 모음 ㅜ다. |
| 표기 **히**를 보고 A 이 / B 하 / C 히 중 고른다. | **C**. 첫소리 ㅎ과 모음 ㅣ다. |
| **ㅜ / ㅎ**을 모형 없이 조립한다. | **후**, ㅎ 위·ㅜ 아래. |
| **ㅣ / ㅎ**을 모형 없이 조립한다. | **히**, ㅎ 왼쪽·ㅣ 오른쪽. |

소리 보기는 학습자에게 A/B/C로만 보이고 전사는 공개하지 않는다. 뒤 조립은 앞에서 본 음절의 구조 확인이다. 오답이면 **“첫자리를 다시 들어 봐요. / Listen to the initial again. / Hör dir den Anfangslaut noch einmal an.”**와 해당 모형을 제공하고 같은 문제로 돌아간다. 공개된 답을 본 이후는 지원받은 확인이다. 표본 재생 실패는 오답이 아니며 실제 발음·호흡량은 평가하지 않는다.

## 현대 듣기 대본 — 부탁 뒤에는 실제 반복

현대 학습 모임. 수진이 이미 배운 **하**를 들려준다. 크리스티안은 한 번 더 듣고 싶어 한다. 문장 내용은 번역을 지원하며, 새 음절 후·히의 첫 확인과 섞지 않는다.

| 화자·행동 | KO | EN | DE |
|---|---|---|---|
| 수진 | 하. | 하. | 하. |
| 크리스티안 | 다시 말해 주세요. | Please say that again. | Sag das bitte noch einmal. |
| 수진 | 네. 하. | Of course. 하. | Klar. 하. |
| 크리스티안 | 아, 네. 고마워요. | Ah, yes. Thank you. | Ah, ja. Danke. |
| 수진 | 한 번 더 들어도 돼요. | We can listen once more if you like. | Wir können es gern noch einmal hören. |

실제 소리 자료를 만들 때 두 하에는 같은 학습 표본을 사용한다. 확인 질문: **“부탁한 뒤에 다른 소리를 들었어요? / Did he hear a different sound after asking? / Hat er nach seiner Bitte einen anderen Laut gehört?”** 답 **아니요 / No / Nein**. 같은 하가 반복된다. 문장 번역만 읽었다면 실제 청취 성취로 세지 않는다.

## 스몰토크 — 내게 필요한 만큼

수진이 **“한 번 더 들을래? / Would you like to hear it once more? / Möchtest du es noch einmal hören?”**라고 묻는다.

| 내 말 | 수진의 반응 |
|---|---|
| “네. 다시 말해 주세요.” / “Yes. Please say it again.” / „Ja. Sag es bitte noch einmal.“ | “좋아.” / “Sure.” / „Gern.“ → 방금 들은 같은 소리를 실제로 반복한다. |
| “아니요. 괜찮아요.” / “No, that’s all right.” / „Nein, danke. So ist es gut.“ | “그럼 여기서 이어 가자.” / “Then let’s continue from here.” / „Dann machen wir hier weiter.“ |

어느 선택도 오답이 아니다. 잘 들렸더라도 연습을 위해 다시 요청할 수 있다. 표현을 고르기·가리키기·따라 말하기는 선택이며 마이크나 녹음은 필수가 아니다.
