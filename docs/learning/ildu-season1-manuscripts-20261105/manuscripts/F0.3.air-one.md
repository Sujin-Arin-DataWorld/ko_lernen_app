## 둘째 작은 활동 — 다와 타

**KO** 잠깐 쉬었다가 이어도 돼요. 이번에는 앞의 가/카를 치우고 다/타 두 소리만 먼저 들어요.

## 현대 듣기 — 잠깐 쉬는 동안

현대 학습 모임. 수진이 크리스티안에게 쉬는 동안 커피를 권한다. 커피 사진과 뜻은 먼저 제공한다. 말을 거절해도 상대가 자연스럽게 받아들이는 장면이다.

**질문 / Question / Frage:** “크리스티안은 지금 커피를 마시겠다고 했어요? / Did Christian accept the coffee for now? / Hat Christian das Angebot angenommen, jetzt Kaffee zu trinken?” 보기 A 네 / Yes / Ja, B 아니요 / No / Nein. **답 B.** 지금은 괜찮아요라는 대답과 수진의 수락 반응이 근거다. 커피를 평소 싫어한다는 사실은 이 대화로 알 수 없다. 실제 음성이 없으면 대본 이해로 남긴다.
