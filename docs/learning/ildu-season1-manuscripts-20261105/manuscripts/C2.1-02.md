# C2.1-02 · 규칙이 닿는 범위

## 독립 과제와 전이 / Independent task and transfer / Selbstständige Aufgabe und Transfer

**새 자료.** 동네 기록실은 회원 여부와 관계없이 열람 신청을 받는다. 원본을 직접 보려면 담당자의 확인이 필요하다. 누구나 사본 안내를 받을 수 있다. 안내를 이미 받아 본 사람이 18명이고 원본 확인을 마친 사람은 5명이다. 민호가 원본 열람 여부를 확인하고 레나가 안내를 고친다. / **New material.** Anyone can ask to consult the archive, regardless of membership. Minho checks original access. Lena revises the guidance. / **Neues Material.** Die Anmeldung zur Einsicht ist auch ohne Mitgliedschaft möglich. ### 편집회의에서 한 번 더 / One more editorial pass / Noch eine Redaktionsrunde

**새 자료 / New material / Neues Material** 문제의 초고는 이미 18명에게 이메일로 보냈어요. 기록실은 원본 열람 시간을 오후 2시로 새로 안내하려 해요. 오전 신청자 중에는 오후에 올 수 없는 사람도 있어요. / The faulty draft has already been emailed to eighteen people. The archive is preparing new instructions for original access at 2 p.m. Some morning applicants cannot come in the afternoon. / Der fehlerhafte Entwurf ging bereits per E-Mail an 18 Personen. Das Archiv bereitet einen neuen Hinweis zur Originaleinsicht um 14 Uhr vor. Einige Personen mit Vormittagsanmeldung können nachmittags nicht kommen.

**과제 / Task / Aufgabe** -는다는으로 바로잡을 기존 명제를 밝히고, -는 마당에와 -느니만큼의 관련형으로 기존 수신자에게 다시 알려야 하는 이유를 말해요. 이 기록실에서 원본을 볼 수 있는 사람의 요건을 -이라야로 표현해요. / Identify the faulty claim using -는다는.
