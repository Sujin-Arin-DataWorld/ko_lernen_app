## 지원과 듣기 · 한 장을 내보내기 전 / Before putting up the sign / Vor dem Aushang

**지원 / Guided practice / Übung mit Hilfe** C의 ‘같은 방’, ‘늘’, ‘확인한다’ 각각에 어떤 추가 근거가 필요한지 표시하세요. 공개 안내와 내부 수정 메모 중 어디에 D의 조건을 기록할지 정해요. / Mark what would be needed to support “the same room,” “always” and “confirms” in C. Entscheide, ob die Vorgaben aus D auf den Aushang oder in die interne Notiz gehören.

**시범 답 / Sample / Beispiel** ‘같은 방’에는 사진 속 공간과 주민이 본 공간을 연결하는 자료가 필요해요. ‘늘’에는 중간에 용도가 바뀌지 않았음을 보여 주는 기록이 필요해요. ‘확인한다’는 두 출처가 실제로 같은 사실을 서로 뒷받침할 때 쓸 수 있어요. D의 요청은 당사자와 볼 수정 메모에 남겨요.

**EN** “The same room” requires evidence connecting the room in the photo to the one the resident saw. “Always” requires evidence that its use did not change in between. “Confirms” fits when two sources support the same claim. Record D's request in the draft notes for the participant to review.

**DE** Für „derselbe Raum“ fehlt ein Beleg, der das Foto mit dem Raum aus der Erinnerung verbindet. „Durchgehend“ verlangt Belege dafür, dass sich die Nutzung in der Zwischenzeit nicht änderte. „Bestätigt“ passt, wenn beide Quellen dieselbe Aussage stützen. Halte die Bitte aus D in der internen Notiz zur Durchsicht fest.

### 새 쪽 포트폴리오 · S1-END 이후 / Portfolio after S1-END / Portfolio nach S1-END

후일담에서 남기고 싶은 결과물 하나를 골라요. 앞 단원에서 쓴 설명, 창작, 합의 메모 중 하나면 돼요. 읽는 사람이 처음 만나는 정보에 밑줄을 긋고 필요한 맥락 한 줄을 보태요. 고친 문장 옆에 이유 한 줄을 쓰고, 아직 답하지 않은 질문을 남겨요. 다음에 연습할 일은 직접 골라요.

EN: Choose one piece for the epilogue: an explanation, a fictional scene or a mediation note from an earlier unit. Underline what readers encounter for the first time and add one line of context. Write a reason beside one revision, leave an open question, and choose what you'd like to practise next.
