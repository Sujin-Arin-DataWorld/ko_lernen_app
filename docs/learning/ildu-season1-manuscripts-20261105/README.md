# 일두고택 시즌1 — 입문부터 C2.2까지

입문부터 C2.2까지, 16구간 100단원의 한국어 원고와 영어·독일어 번역을 모았습니다. 각 단원에서 일두고택 장면을 읽고, 필요한 단어와 예문을 익힌 뒤 현대 듣기 대본과 짧은 대화로 표현을 써 봅니다. 상위 단원은 시간선, 인용, 자료 비교, 협상, 중개, 편집으로 이어집니다.

고택 캐릭터의 대사는 이야기로 읽습니다. 입문 문자 단원에는 소리·글자 대조와 말뜻을 이해하는 지원을 두었습니다. 아직 공개되지 않은 고택 장면이 있는 단원은 현대 역할 자료부터 시작할 수 있습니다. 듣기 코너는 이번 원고에 담긴 대본입니다.

2026년 11월 14일에 남은 64단원을 써서 100단원 초고를 갖췄습니다. Astra Max 한영·한독 역할이 교차 검토한 범위는 위 기록에서 확인할 수 있습니다. C2.1-01·02와 C2.2 전편은 두 역할이 원고 전체를 읽었으며, 나중에 바뀐 부분은 해당 검토 기록에서 확인할 수 있습니다. 당시 나머지 원고에는 일부 언어 검토와 사람 감수, 학습자 난이도 검증이 남아 있었습니다.

11월 15일에는 F0.1 세 단원과 A1.1-01의 원고를 고쳤습니다. 별도 Astra Max 한영·한독 역할이 수정 전후 전편을 읽고 과제를 직접 텍스트로 풀었으며, 마지막 독일어 질문 수정도 재확인했습니다. 자세한 범위와 최종 원고는 위의 네 단원 교정 기록에 있습니다. 앱·음성은 변경하지 않았고, 실제 청취·사람 감수·학습자 관찰은 별도로 남아 있습니다.

이후 진행한 100단원 전수 검토의 현재 판정은 위의 전체 검토 결과와 단원별 행렬을 기준으로 확인합니다. 원고 끝의 집필자 메모와 이전 검토 문서는 각 작성 시점의 기록입니다. 최신 판정은 현재 파일의 SHA-256과 연결된 한영·한독·교육과정 검토 기록을 따릅니다. 모델의 텍스트 검토는 사람 감수, 실제 청취, 학습자 난이도·회상 검증을 대신하지 않습니다.

지원 자료와 실제 과제를 통해 수용·산출·상호작용·중개를 연결한다는 설계 원칙은 [유럽평의회의 행동 중심 접근 설명](https://www.coe.int/en/web/common-european-framework-reference-languages/the-action-oriented-approach)을 참고했습니다(2026-11-05 확인). 한국어 어휘와 문법은 프로젝트의 원래 배정표와 단원에서 수행할 행동을 함께 보고 배치했습니다.
