# 첫 콘텐츠 묶음 — 제작·검토용 대본 초안

2026-10-28. v3.5 이야기의 한국어 입문 적용 제안. 실제 음성·그림·Flutter 구현·교원 감수는 아직 없다. 아래 항목 ID는 제작 문서 안의 하위 활동 제안이며 런타임에 등록된 ID가 아니다.

## A. 연이의 공부책 첫 장 / LQ-01

기존 단원: `F0.1.sound-signs`, `F0.1.above-below`. 순서: 수진·조이가 도움 → 첫 아 복원 → 탈선비 각성 → 후속 글자 시범. 탈선비가 각성 전에 강의하지 않는다.

### 상황과 대사

| 순서 | 인물·행동 | 한국어/의미 안내 |
|---|---|---|
| 1 | 조이가 공부책 첫 장의 흩어진 조각을 가리킴 | 수진: “여기, 글자 한 조각이 비었네. 같이 맞춰 볼까?” 이야기 뜻은 선택한 EN/DE로 제공 |
| 2 | 언어가 필요 없는 두 도형으로 선택→자리 선택 시범 | 안내 KO: “조각을 고르고, 놓을 자리를 골라요.” EN: “Choose a piece, then choose its place.” DE: “Wähle ein Teil und dann seinen Platz.” |
| 3 | 수진이 감수 음성 아를 들려주고 ㅇ+ㅏ를 시범 | KO: “여기서는 ㅇ이 소리를 내지 않아요. ㅇ 옆에 ㅏ를 놓으면 아가 돼요.” EN: “Here, ㅇ is silent. Put ㅏ beside it to make 아.” DE: “Hier ist ㅇ stumm. Setze ㅏ daneben. So entsteht 아.” |
| 4 | 플레이어가 아를 조립. 시범을 보며 도움받아도 됨 | 현실 학습자는 원하면 아를 직접 말함. 함께 읽기 도움에서는 감수 음성/자막을 제공. 마이크 권한·발음 점수 요구 없음 |
| 5 | 극중 아바타가 복원한 첫 아를 읽고 탈선비 각성 | 도움 경로에서도 아바타의 낭독이라는 이야기 원인을 유지. 실제 학습자의 발화를 감지했다고 연출하거나 발음 합격으로 기록하지 않음. v3.5 각성 대사와 원본 캐릭터 사용 |
| 6 | 각성한 탈선비가 다음 조각을 안내 | 아를 먼저 충분히 경험한 뒤 어를 별도 시범. `F0.1.above-below`에서 오·우를 별도 시범 |
| 7 | 사용자가 원하는 때 재생을 요청 | “다시 들려주세요” 기능을 실제 재생에 연결. 한국어 전체를 읽어야 누를 수 있게 하지 않음 |

### 문항과 회복

- `A-P1`: 아 모형이 보이는 상태에서 ㅇ·ㅏ 조립. 도움 연습으로 기록.
- `A-I1`: 어도 가르친 뒤, 모형 없이 익힌 두 음절의 조각 배치 확인. 이 단계는 아/어 범위의 문자 인식이며 새로운 낱말 해독이 아니다.
- `A-L1`: 실제 감수 음성 아/어를 듣고 표기를 고르는 활동은 문자 조립과 다른 항목. 사용할 음성이 없으면 미평가.
- 오답 피드백: “짧은 획의 방향을 다시 볼까요?”와 정지된 시범. 같은 문항에 정답을 보여 준 뒤 성공하면 도움 연습. 새 독립 문항과 구분.
- 잠깐 나갔다 돌아오면 글자 학습 위치와 각성 장면 재생 상태를 확인해 복귀. 각성 장면을 다시 봐도 보상은 다시 지급하지 않음.
- 다음 날 같은 자리 외우기로 해결되지 않도록 조각 순서·보기 위치를 바꿔 재확인. 오·우를 가르치기 전에는 그 둘을 오답 보기에 넣지 않음.

결과 표현: “첫 글자를 되살렸어요.” / EN “You restored the first letter.” / DE “Du hast das erste Zeichen wiederhergestellt.” 추가로 한국어 전체를 읽거나 말할 수 있다고 표시하지 않는다.

## B. 창고의 푯말 / LQ-02

기존 단원: `F0.2.tree-and-hat` 및 기본 자음 단원. 목표 범위는 문자 결합과 이번에 배운 단어 뜻. 실제 대상 확인에는 제작된 그림이 필요하다.

### 선행 확인

나무·모자의 글자와 첫 뜻을 먼저 가르친다. 도구·마루를 사용할 때에는 이미 배운 ㄷ·ㄱ·ㄹ·ㅜ·ㅏ 등을 확인하고 해당 단어의 뜻과 감수 음성을 별도로 제공한다. 자모를 배웠다는 이유로 낱말 뜻까지 아는 것으로 보지 않는다.

살아 있는 나무와 복원용 목재는 서로 다른 뜻이다. 첫 수업의 나무 그림 평가를 목재 상자 분류로 몰래 바꾸지 않는다. 원 단원의 식물 뜻 연습을 남기고, 창고 사용 전에 재료 뜻을 별도 하위 활동으로 소개하거나 그 활동에서는 도구·모자처럼 이미 배운 뜻만 사용한다.

### 실제 활동

1. 도깨비가 푯말이 서로 바뀐 물건을 보여 줌. 수진이 EN/DE로 상황을 짧게 설명.
2. 모자 한 개의 그림·모자 음성·표기를 함께 보여 주며 시범.
3. 도움 연습에서는 같은 모자를 골라 푯말을 옮김.
4. 별도 확인에서는 모양·색이 다른 모자를 제시하고 나무/모자 중 고름. 시범 그림을 재사용한 위치 암기와 구분.
5. 감수 음성만 듣고 두 그림 중 고르는 문항은 다른 항목으로 제공. 소리가 들리지 않으면 뜻 설명·그림으로 참여하되 듣기는 미평가.
6. 도구·마루도 같은 계약으로 먼저 가르친 뒤 창고 장면에서 사용. 한 번에 15개 단어를 필수 암기로 묶지 않음.
7. 도깨비가 “이제 찾기 쉽겠군.”이라고 반응하고 정리한 푯말이 남음. 이 장면 자체는 새 역사 단서를 생성하지 않음.

### 짧은 구어 경로

뜻부터 알려 준 “주세요”를 물건 요청에 사용한다.

- 시범: 수진이 모자를 가리키며 “모자 주세요.”
- 도움 연습: 요청 음성을 선택하거나 직접 말하기 → 상대가 모자를 건넴.
- 새 상황: 다른 모자를 고른 뒤 필요한 요청을 선택. 목적 있는 표현 사용 연습이며 자유 말하기 합격은 아님.
- “감사합니다”의 뜻·음성과 함께 감사할 수 있음. 감사합니다를 아직 읽지 못해도 참여.
- 추후 현대 페르소나의 물건 돌려주기 장면에서 같은 기능을 재사용. 실제 연결할 기존 콘텐츠 ID는 개별 내용 대조 후 확정.

결과는 정리된 물건과 확인 범위를 각각 기록한다. 창고 단서는 원 세계관의 건물·시점 조건이 맞을 때 원 사건 시스템에서 공개하며, 이 수업 완료에 새 단서 플래그를 덧붙이지 않는다.

## C. 문·방·길과 첫 집 쪽지 / LQ-03~04

### LQ-03

- 기존 `F0.3.first-finals`에서 ㄴ·ㄹ 등 받침 자리와 문·길의 소리·뜻을 먼저 소개.
- 기존 `F0.3.silent-or-sounding`에서 방·마당과 처음 ㅇ/받침 ㅇ의 차이를 시범.
- 지도에서는 뜻을 이미 배운 문·방·길·마당의 표지를 놓음. 미학습 한자·건물명·역사 용어는 EN/DE 설명.
- 독립 확인은 다른 미니맵 배열에서 같은 뜻의 대상을 찾기. 역사적 공간 구획의 정답을 한국어 능력과 합치지 않음.
- 도움으로도 이름표를 달고 다음 장면을 볼 수 있음. 학습 도움·미확인 능력은 그대로 기록.

### LQ-04

기존 `F0.4.closed-endings`, `first-input`, `space-and-place`에 하위 활동을 추가/개정한다. 집·이 집이 목표다. 기존 나무·모자 입력 기능과 기록을 삭제하지 않는다. **정식 쪽지 장면은 v3.5의 사랑채 완공 조건을 유지**한다. 완공 전에는 일반 입력 연습만 제공하고 LQ 완료·정식 쪽지·건축 완료 상태를 미리 만들지 않는다.

| 활동 | 실제 지시와 반응 | 확인 범위 |
|---|---|---|
| 뜻·소리 | 집 그림과 음성 집. “여기서 집은 사람이 사는 곳이에요.” 의미는 EN/DE로도 제공 | 뜻의 첫 소개 |
| 입력 시범 | ㅈ→ㅣ→ㅂ을 입력해 집이 만들어지는 모습. 사용자 키보드에서는 실제 한글 조합을 시범 | 한글 입력의 조작 경험 |
| 도움 연습 | 모형 집을 보고 입력. 오타면 지우고 다시 입력하도록 시범 | 따라 입력 |
| 제한 회상 | 앞에서 배운 집 그림을 보고 모형 없이 집을 입력하거나 조각으로 구성 | 가르친 낱말의 제한된 회상. 자유 작문 아님 |
| 띄어쓰기 | 지시어 이의 뜻을 먼저 설명하고 이 집 시범 후 입력 | 해당 문구의 단어 경계. 한국어 띄어쓰기 전체 숙달 아님 |
| 이야기 사용 | 플레이어의 집 쪽지를 보관하고 피날레의 기존 회수 지점에 연결 | 이야기 상태. 추가 필수 단서/보상 없음 |

키보드 대안으로 조각 구성·선택 후 배치를 제공한다. 입력과 조각 구성은 같은 증거 이름으로 뭉치지 않는다. 어떤 대안을 써도 같은 쪽지 장면으로 이어지며 능력 기록만 구분한다.

## D. A1.1 첫 소개 / LQ-05

도깨비에게 새로 자신을 소개하는 상황으로 기존 `A1.1-01`의 인사·이름·재요청 목표를 사용한다. 수진을 처음 만난 낯선 사람으로 다시 설정하지 않는다.

| 인물 | 대사 초안 | 기능 |
|---|---|---|
| 도깨비 | “너는 누구냐?” | 이야기 대사. 이 말투를 입문자의 생산 필수형으로 가르치지 않음 |
| 수진 | “이름을 말해 주면 돼. 같이 해 볼까?” | 선택 언어로 의미·시범 도움 |
| 시범 플레이어 | “안녕하세요. 마야예요.” | 받침 없는 이름의 예. 사용자 이름을 마야로 고정하지 않음 |
| 다른 시범 | “수진이에요.” | 받침 있는 이름의 이에요 예 |
| 플레이어 | “저는 {이름}이에요/예요.” | 자기 소개. 자기 이름의 한글을 모르면 음성·선택 예시·도움으로 참여 |
| 도깨비 | 자신을 소개하는 짧은 원 대사 | 이후 잘 못 들은 상황을 만들 때 실제 음량·접근성을 고의로 떨어뜨리지 않음 |
| 플레이어 | “다시 말해 주세요.” | 상대가 실제로 같은 말을 다시 함 |

이 대본은 관계·말투·EN/DE·허용 응답에 대한 교원/언어 검수가 필요한 초안이다. 버튼 선택과 대본 따라 말하기를 독립 발화 능력으로 기록하지 않는다.

## 제작자가 항목마다 채울 표

| 필드 | 작성 내용 |
|---|---|
| 안정된 단원 ID / 하위 활동 ID | 기존 단원은 유지. 새 활동 ID는 런타임 중복 여부 확인 후 확정 |
| 교육 목표와 이번 의미 | 자모·낱말 뜻·표현 기능·입력 가운데 실제로 확인할 것 |
| 이미 배운 자모·단어·조작 | 보기·오답·음성 대사까지 확인 |
| 이야기 장면·LQ·공개 조건 | 새로운 필수 단서 없이 같은 사실로 연결 |
| KO/EN/DE | 안내와 인물 대사의 관계 말투 구분 |
| 음성·시범 그림·새 확인 그림 | 실제 파일 ID/원본/권리/감수 상태 |
| 시범·도움·독립 문항 | 정답·허용 답·오답 이유·회복·건너뛰기 |
| 평가 범위 | 문자/의미/듣기/제한 입력/미평가 발화 구분 |
| 다음 회수 | 후속 단원 ID와 구체적 다른 상황/다른 날 문항 |
| 저장·보상·재생 | 기존 소유자, 저장 실패 복귀, 재처리 시 중복 방지 |

본문의 구체적인 새 대사·보충 활동·미디어 구성은 작성자의 제안이다. v3.5의 기존 결정으로 소급해 표시하지 않는다.
