## 이야기와 학습의 연결

문지기 도깨비는 **중문간채 중간**의 `LQ-05`다. 첫날 이미 만난 도깨비를 모르는 사람으로 되돌리지 않고 놀이로 소개의 필요를 만든다. 01의 핵심 기능을 배우면 실제 본편 준비 상태에서 만날 수 있으며, 6단원 모두 정답·실명 공개·녹음 제출을 문 통과 조건으로 추가하지 않는다. 도움·대리 소개로도 이야기에 참여할 수 있지만 해당 생산 능력은 별도 미평가다.

중문 **완공**의 `S1-E04` 폭풍·인영과 기억30%는 별도다. A1.1 활동을 끝냈다고 12공정·기억30%·엽전·새 단서를 생성하지 않는다. 솟을대문 빗장 수리는 시즌 끝에 남긴다. 학습 복습에서 되풀이한 장면은 본편 완료·보상을 중복 지급하지 않는다.

민수·하린은 임시 연습 이름이다. 실명·출신을 말하지 않아도 되며, 서로 다른 카드 묶음의 출신 정보는 실제 NPC·사용자 설정을 바꾸지 않는다. 역할 카드 이름의 감수된 한글 표기만으로 예요/이에요를 고르고 로마자 마지막 글자·국적에서 받침을 추측하지 않는다.
