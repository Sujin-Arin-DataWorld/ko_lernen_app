# A1.1 집필 검토와 남은 제작

최종 문서 범위: 6단원, 91개 제작 문항(P29 / I31 / R31), 문법 배정15행. [독립 모델 검토](A11_INDEPENDENT_REVIEW.md)는 `MODEL_MANUSCRIPT_REVIEW_PASS`, [구조 검사](STRUCTURAL_QA.json)는 `MODEL_STRUCTURAL_QA_PASS`다. 사람 교원·원어민·학습자 검수와 앱 검증은 별도다.

## 검토로 고친 것

- **R에서 정답 형태를 미리 알려 주던 지시**를 뜻 중심으로 바꿨다. 의·이랑/랑·하고·제·아니요·도·이거예요를 지시문에 적고 그 형태를 무단서 회상했다고 기록하지 않는다. 같은 뜻의 대체 표현은 의사소통 성공과 목표 관찰을 나눈다.
- **격식 소개 문항**은 이름만 듣고 풀 수 있는 선택에서 말투 식별로 바꿨다. 하린이에요/하린입니다가 둘 다 공손하되 일상·격식의 차이가 있음을 전체 음성 시범으로 먼저 지도한다. R은 민수입니다의 새 이름·화자 조합이다.
- **아니요+이름 정정과 이거예요+지목**을 이/가 아니다 생산으로 세지 않도록 목표·요구 문법을 분리했다. 실제 명사 부정은 06-I01/R01의 소유 정정에서 확인한다.
- 허용 답은 **현재 건넨 물건**을 정확히 가리키게 했고, 제작자 상황의 미확정 조사를 고쳤다. 읽어요 음성 선택에는 단어 정답 라벨 대신 음성 A/B를 쓴다.
- 뒤 회수 참조는 같은 목표 안에서도 해당 R 차례로 연결했다. 이름 질문·격식 말투·이랑/랑·하고가 첫 번째 일반 R 하나로 잘못 합쳐지지 않게 했다.
- 03-P06의 모자 낱말 듣기 회수는 존재·위치 발화 목표와 분리했다. 해당 낱말-대상 확인의 같은 범위 뒤 문항은 이번 패키지에 미제작이므로 두 후속 참조를 null로 남겼다. 가방 부재 문장을 그 낱말 회수의 유지 근거로 대신 연결하지 않는다.

## 구조·원본 확인

6개 원래 단원 ID, 15개 문법 원행과 생산12/이해3 구분, 91개의 고유 문항 ID·요구 메타데이터·뜻/형태·삼언어 안내·도움·후속 문항 참조를 검사했다. P/I/R·CSV·JSON이 일치하고 실제 가르침 참조는 모두 존재한다. 보호 원본 **76개 파일의 SHA-256이 시작 기록과 같음**을 확인했다. 원래 앱 WIP를 원고 결과로 취급하지 않는다.

기준 source HEAD는 `6fadd838e2a8ad378b92b38d06d86541782a7db8`. 커리큘럼 checkout 밖에서 문서만 작성했다. 기존 입문1~4와 v3.5를 고치지 않았다.

## 남은 실제 제작·검수

1. 한국어 교원의 목표·문항 난도 확인, 영어·독일어 사람 감수.
2. 실제 이름·격식·유무·요청·연음 녹음, 그림과 위치·소유자 카드 제작 및 대사·선택지 연결 확인.
3. R 마지막 노출 시각·도움 전파·공유 형태 프라이밍, 실제 학습자의 준비·부담·수행 관찰. 24시간은 운영 가설이다.
4. 열린 말하기 평가자·원 응답·네 축 rubric, 앱의 저장·재시도·복구·사실 공개·중복 보상 방지 검증.

지금은 대사·문항을 제작할 수 있는 상세 원고다. 실제 녹음·플레이·독립 발화·장기 유지·앱 출시가 검증됐다는 뜻은 아니다.
