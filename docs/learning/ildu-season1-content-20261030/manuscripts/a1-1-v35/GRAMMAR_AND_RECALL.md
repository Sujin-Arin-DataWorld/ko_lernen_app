# A1.1 원래 문법 배정과 실제 회수

`SOURCE_UNIT_CONTRACTS.json`의 6개 단원과 원래 `GRAMMAR_ALLOCATION.csv` 15행을 보존한다. 새로운 문법 등급·진도·단원 ID를 등록하지 않았다. source_row는 배정표의 원래 행 식별값이다. 아래 항목은 집필 커버리지이며 학습자의 성공·교사 승인 표가 아니다.

| source_row | 기능 | 원래 단원 | 실제 문항의 중심 | 범위·판정 |

`source_row 3`의 전체 대비 기능 등 배정표의 넓은 형태군은 이후 나선형 재등장 범위다. 현재 원고가 각 형태군 모든 용법을 완성했다는 뜻은 아니다. 15행 각각에서 이번 기능을 다루는 실제 문항이 존재한다는 의미다.

## `review_in`을 실제 문항과 미제작 슬롯으로 구분

| 원 목표 | 실제로 집필된 뒤 회수 | 아직 제작하지 않은 목적지 |
|---|---|---|
| 01 인사·이름 | 02-I05 / 02-R05 새 역할 이름·출신 소개 | A1.2-06 |
| 01 재요청 | 04-I04 / 04-R04 같은 말을 다시 부탁, LQ05 실제 반복 | A1.2-06 |
| 02 선택 소개·화제 | 05-I07 / 05-R07 소유물 반환 뒤 새 카드 소개 | A2.1-01 |
| 03 유무·위치 | 06-I06 / 06-R06 정정 뒤 다른 선반의 물건 보고 | A1.2-02 |
| 04 부탁 | 06-I04 / 06-R04 제한 부탁에서 재사용 | 원래 지정 A1.2-04·A2.1-02는 미제작 |
| 05 소유 | 06-I01 / 06-R01 잘못 건넨 물건 정정 | 원래 지정 A2.1-02·B1.2-01은 미제작 |
| 06 정정·도·만 | 06-R01–05 다른 날 재확인 | A1.2-06·A2.2-06 |
| F0.2 모자 뜻 | 03-P06 다른 모자 사진+음성 | 실제 입문2 원 기록이 없으면 준비 활동으로 처리 |

원래 목적지 밖의 추가 회수는 원 배정을 바꾼 것이 아니다. 단순히 목적지 ID가 존재한다고 장기 복습이 제작 완료된 것으로 세지 않는다. 05의 새 카드와 06의 새 선반 자료·R용 녹음은 제작 명세이며 아직 실제 미디어가 아니다. 회수 간격과 도움 이력은 실제 시행 시 확인한다.

## 보충 4개

SUP-A1-REPAIR는 01·04·LQ05에서 같은 내용의 실제 반복으로 연결한다. SUP-A1-EXIST는 03의 화자 기준 위치·전체 확인한 칸·가려진 미확인 칸을 구분한다. SUP-A1-REQUEST는 물건 주세요, 다시 말해 주세요, 보세요/앉으세요를 서로 다른 작은 활동으로 나눈다. SUP-A1-HANGUL은 03의 선택 읽어요 3문항으로 한 낱말만 보충하며 회화 진입의 필수 문턱이 아니다.
