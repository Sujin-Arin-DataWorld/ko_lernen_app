# A1.1 공통 운영·도움·복습 원고

집필 문서다. 이 파일과 6개 단원 원고의 `context`는 **제작자용 상황·녹음 지시**이다. 그 안의 정답, 한국어 음성 원문, 영어·독일어 뜻풀이를 독립 확인 화면에 모두 노출한다는 뜻이 아니다. 학습자에게는 해당 역할 카드·공간 그림과 선택한 설명 언어의 지시만 제공한다. `model_or_answer`, 허용 답, 피드백은 최초 응답 전 숨긴다. 앱 화면이나 제어 기능은 구현하지 않았다.

## P / I / R 진행

P는 시범·도움 연습이며 독립 성공 수가 아니다. I는 시범과 다른 카드·자료·화자·목적의 상황 사용이다. 이름 소개 등 반복 형태를 사용하는 과제는 배운 표현의 제한된 재사용이지 새로운 어휘 전이나 자유 담화 전체의 증거가 아니다. I 중 객관 문항은 듣기·읽기 각각의 범위만 확인한다. 열린 발화는 평가자와 원 응답이 있을 때만 네 축을 판정한다.

각 단원은 작은 활동 단위로 멈췄다가 이어 갈 수 있다. P29·I31·R31을 한 번에 모두 치르게 하지 않는다. 각 목표 준비 상태를 확인하고 필요한 시범만 제공한다. 같은 목표의 보기 선택·말하기·조립 대안은 한 목표의 대안이지 세 번의 완료·보상이 아니다. optional-read 3문항과 입문2 회상 P06은 선택 보충이다.

문항마다 `taught_by`의 뜻·전체 소리·필요한 조작을 먼저 배운다. ORAL-START는 글자 해독을 보증하지 않는다. 읽기 문항 A1.1-05의 과·와는 미니 준비에서 익힌 단어 표기와 소리를 따로 연결한다. 읽기 준비가 없으면 음성·번역 지원으로 이해할 수 있지만 읽기 독립 성공으로 승격하지 않는다. 전체 받침 수업을 끝내야 대화를 시작할 수 있는 관문을 만들지 않는다.

## 재시도와 오답 판정

같은 문항의 상황·입력·선택지를 유지한 채 해당 오류에 맞는 짧은 도움을 준다. 도움 없이 시도한 원 응답은 보존하고, 도움 뒤 응답으로 덮어쓰지 않는다. 사실·의미가 맞는 자연스러운 은/는·이/가·조사 생략·정중한 대체 표현은 의사소통 성공과 **이번 목표 형태 관찰**을 나누어 기록한다. 카드 이름·대상·소유자를 잘못 전달했을 때만 그 정보 오류를 짚는다.

단원별 피드백 표에는 **일어났을 때만 사용할 오류별 후보**가 있다. 예를 들어 인사 뒤 어미만 다른 응답에 ‘다른 이름이 나왔다’는 문구를 쓰지 않는다. 자동 채점기가 없으므로 피드백을 모든 열린 답에 일괄 적용하지 않는다. 맞는 답을 모형과 다르다는 이유로 틀렸다고 판정하지 않는다.

같은 음성 재생도 횟수·시점을 기록한다. 듣기 과제에서 정답 한글 자막, 번역, 역할 이름 음성 비교 도움을 열었다면 그 효과를 별도로 남긴다. 정답을 알려 주는 도움과 단순 조작 도움을 같은 것으로 처리하지 않는다. 이름의 받침은 **감수된 한글 표기**로 판단하고, 라틴 문자 마지막 글자나 국적에서 추정하지 않는다.

## 다음 날 R의 실제 제시 순서

1. 직전 관련 노출·도움·정답 공개 시각을 읽는다. 첫 학습 뒤 24시간뿐 아니라 **같은 목표를 마지막으로 본 뒤 경과 시간**을 남긴다. 최소 24시간 제안은 운영 초안이며 최적 간격을 보증하지 않는다.
2. 그날 해당 목표의 시범·정답·전체 학습 대본을 다시 보여 주기 전에 R을 시작한다. 새 녹음 화자와 바뀐 역할 카드·물건 배열을 사용한다. 감수된 실제 녹음이 없으면 제작 문항이며 시행 완료가 아니다.
3. 같은 목표의 첫 R만 첫 회수 후보이다. 앞선 R의 보기나 피드백에 이름·예요·있어요 등이 나왔다면 뒤 R을 새 독립 냉회상으로 부르지 않는다. `leak_keys`의 문법뿐 아니라 공유 어휘·문형·음성·뜻풀이도 실제 운영에서 전파한다. `leak_keys`는 출발용 태그이고 완전한 노출 추적 구현이 아니다.
4. 같은 날 여러 R을 하고 싶으면 첫 확인 뒤 연습·전이·재확인으로 기록한다. 정답을 보고 다시 맞힌 것을 24시간 유지로 계산하지 않는다.
5. 도움을 열어도 대화는 끝까지 갈 수 있다. R을 건너뛰어도 기억 수치·완성 건물·첫 집 쪽지를 지우지 않는다. 다음 날 문지기 이야기를 다시 해도 `LQ-05`의 사실·보상을 복제하지 않는다.

열린 수행의 네 축은 정보 이해, 목적 달성, 적절한 사용, 확인·수리다. 각 축은 도움 필요 / 일부 수행 / 이 과제에서 독립 수행 / 미평가로 기록한다. 평가자 없는 발화는 미평가이며 0점도 합격도 아니다. 인식 선택·ASR 전사·캐릭터의 미소만으로 독립 발화를 판정하지 않는다.

## 번역 규칙

앱 안내는 독일어 `du`를 사용한다. 극중 존대 한국어를 어른에게 하는 연습 대사의 독일어 풀이에는 `Sie`가 가능하다. 수진과 친한 사이의 대화, 도깨비가 플레이어에게 하는 말은 `du` 관계다. 친구는 성별·연애 관계를 자동 설정하지 않는다. 영어·독일어 번역은 의미·화행을 전달하는 집필 초안이며 사람 원어민·한국어 교사 검수 승인이 아니다.
