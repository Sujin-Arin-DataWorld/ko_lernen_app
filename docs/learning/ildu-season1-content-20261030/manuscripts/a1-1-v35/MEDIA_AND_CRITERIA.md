# 녹음·그림·선택지 제작과 판정 명세

91개는 **제작 문항** 수이다. 실제 녹음·이미지·화면·저장 구현은 만들지 않았다. 아래 자료를 감수하고 연결하기 전에는 앱에서 시행하거나 전이·유지를 확인했다고 말하지 않는다. 언어 안내와 대사 초안은 문서에 모두 있다.

## 제작자 원문과 학습자 노출 분리

`CONTENT_SOURCE.json`의 scene/teach는 지도용 대본이다. `AUTHORING_ITEMS.json`의 context는 촬영·역할 카드·오디오 제작 지시이며 정답이 들어갈 수 있다. `prompt`만 상황 사용의 학습자 안내 후보이다. I/R 시작 전 model_or_answer·도움·피드백·허용 예를 보이지 않는다. 듣기 문항의 녹음 한국어 원문이나 뜻풀이를 자막으로 먼저 보이면 듣기 독립 확인이 아니다. 역할 카드의 이름·출신 정보는 목적에 필요한 자료지만 들은 이름 자체의 정답 자막은 아니다.

영어·독일어 번역을 사용했다고 모든 목표가 도움 수행인 것은 아니다. 조작 지시의 번역과 평가하려는 이름·문장의 정답 뜻풀이를 구분해 기록한다. 소유자 이름표를 읽기 어렵다면 미리 익힌 역할 카드 음성 이름을 사용할 수 있고, 그 경우 독립 문자 해독을 주장하지 않는다.

## 필수 자료 묶음

| 자료 | 구체적인 제작 내용 | 다른 날·전이 조건 |
|---|---|---|
| 이름 역할 카드 | 민수/하린 감수된 한글 표시, 같은 이름의 전체 음성. 민수예요·하린이에요, 누구예요, 다시 말해 주세요 | R은 다른 녹음 화자·새 상대. 기존 고정 인물의 이름·기억을 바꾸지 않음 |
| 자기소개 카드 | 나라 한국/독일, 언어 한국어/영어의 뜻·음성 준비. 각 문항 context에 적힌 **해당 묶음만**의 사실 | 같은 이름을 다른 임시 카드에서 쓸 때 새 카드임을 설명. 실제 수진·사용자 국적 설정 아님 |
| 격식 녹음 | 하린이에요. / 하린입니다.의 전체 소리 대비, 이름이 무엇입니까? | R 새 목소리·민수입니다. 격식/일상 두 소개 모두 공손함. 말투 이해만, 발화 필수 없음 |
| 위치 선반 | 화자 표시, 가까운 칸/먼 칸. I01은 가까이 가방/멀리 모자, R01은 가까이 모자/멀리 가방. I03은 가까운 흰 칸 모자/먼 갈색 칸 가방 | R은 다른 방·다른 선반·반대 카메라. 화자 기준 거리를 유지하고 색만 외워 풀지 않게 함 |
| 존재·부재 칸 | 빈 칸 전체를 확인한 장면과 내용 모르는 가려진 칸을 별개로 제작 | 보이지 않음≠없음. 부재는 확인된 칸 범위로만 진술 |
| 요청 물건 | 마시는 물, 우산, 읽는 책. 마시는 차는 자동차 사진과 섞지 않음 | P 물 요청→I 우산→R 책. R 새 상대의 물건 위치·건넴 방식 변경 |
| 동작 | 물/차 마시는 그림, 보기/앉기 시범. 실제 섭취·신체 동작 필수 아님 | 번역·행동 시범은 준비 단계에서. 새로운 동작명 시험 없음 |
| 소유자 태그 | P수진/I하린/R민수 소유 가방; 수진이 대신 들고 있음. 내 역할 카드 태그와 실제 소유 태그 구별 | R 새 가방 배치·운반자 위치. 들고 있는 사람을 주인으로 추측하지 않음 |
| 명사 연결 | 책과 모자 / 모자와 책, 배운 표기·소리 | 이해만 확인. 과/와 필수 생산으로 올리지 않음 |
| 도·만 역할 | 선행 수진의 모자 소유 사실 + 내 카드도 모자. 물·우산 제안 + 카드상 하나만 필요 | 선행 사실·제외할 선택지가 실제로 있어야 기능이 성립 |
| 선택 읽어요 | 책 읽는 동작, 읽어요 표기, [일거요] 음성. 비교 있어요 [이써요]도 먼저 학습 | 정확한 표기 그대로; [일거요]를 철자 답으로 제출시키지 않음 |

### 듣기 선택 문항의 실제 녹음 원문

| 문항 | P 녹음 | I 녹음 | R 녹음 |
|---|---|---|---|
| 01-P/I/R02 | 민수예요. | 민수예요. | 하린이에요. |
| 02-P/I/R02 | 민수는 한국 사람이에요. | 하린은 한국 사람이에요. | 민수는 한국 사람이에요. |
| 02-P/I/R03 | 하린입니다. | 하린입니다. | 민수입니다. |
| 02-P/I/R04 | 이름이 무엇입니까? | 이름이 무엇입니까? | 이름이 무엇입니까? |
| 03-P/I/R03 | 저기 가방이 있어요. | 여기 모자가 있어요. | 저기 가방이 있어요. |
| 03-P06 | 모자 | 해당 없음 | 해당 없음 |

이 표는 녹음 발주 원문이다. R에서 어휘가 같아도 다른 화자로 다시 녹음하며, 어휘 유지·낯선 화자에 대한 제한된 청취 재확인이지 새로운 문법 전체의 전이가 아니다. R의 정확한 발화 속도·음질·휴지·오답 쌍 난도는 녹음 뒤 검사한다. 준비 단계의 비교 이름 음성을 응답 직전 다시 들으면 그 도움도 기록한다.

선택 읽어요 과제의 제작자 키 `[일거요]`/`[이써요]`는 녹음 발음 지시다. 실제 응답 선택지는 **음성 A / 음성 B**(Audio A/B, Aufnahme A/B)로 제공한다. 버튼에 읽어요·있어요라는 답을 써 두고 같은 철자를 찾게 하지 않는다. 이름·물건·말투 선택의 삼언어 문구는 각 문항 `choice_labels`에 실제로 작성했다. 이름 카드의 음성 이름 도움을 다시 열었다면 청취 비교 도움으로 남긴다.

## 열린 응답 판정 예

| 실제 응답 | 의미 판단 | 목표 형태 판단 |
|---|---|---|
| 저는 하린입니다. | 하린의 정체 전달 가능 | 예요/이에요 이번 목표는 미관찰, 격식 어미 직접 생산을 강요하지 않음 |
| 여기 가방 있어요. | 위치·존재 전달 가능 | 이/가 생략. 의미 오답으로 만들지 않음 |
| 차 마셔요. | 그림이 차를 마시는 경우 행동 전달 가능 | 를 미관찰 |
| 하린 거예요. | 해당 소유자 태그와 일치하면 소유 전달 | 의 직접 생산 미관찰 |
| 수진하고 같이 있어요. | 동행자 정보 전달 | 이랑/랑 과제면 그 형태는 미관찰, 하고 과제면 관찰 |
| 저는 모자가 있어요. | 내 모자 소유 사실 전달 | 선행 동일 사실에 더하는 도는 미관찰 |
| 물 주세요. | 물 부탁 목적 달성 가능 | 다른 물건 제외를 명시하는 만은 미관찰 |
| 제 모자가 없어요. | 보이는 남의 모자를 돌려주는 장면에서는 의도와 어긋날 수 있음 | 유무와 소유 정정을 다시 지도. 문장 자체를 항상 틀린 한국어라고 부르지 않음 |

동의어·다른 정중한 표현·상황상 적절한 질문은 실제 의미와 관계로 판정한다. 미완성 발화·대명사·가리키기도 상황에서 이해됐는지 확인하되 사용하지 않은 문법 생산을 창작해 기록하지 않는다. 단일 예상 답 문자열과 ASR 결과만으로 자유 발화 통과를 확정하지 않는다.

## 원본과 참고의 우선순위

현행 6개 단원 범위는 `UNITS.psv`, 기능별 생산/이해 구분은 `GRAMMAR_ALLOCATION.csv`, 평가 범위는 `ASSESSMENT_CONTRACT.md`를 따른다. 이야기 앵커와 단서 공개는 v3.5를 따른다. 3438… 첨부의 A1.1-02 이동·03 가격·05 수량·06 음식 순서는 현행 같은 ID에 덮어쓰지 않고 향후 해당 기능 단원 참고로만 남긴다. 3488…의 ‘집’→‘이 집’ 쪽지 변경과 A1.1 완료→E04 결합도 채택하지 않는다. 기존 첫 `집` 쪽지는 그대로다.

제공된 PDF 교재의 페이지·저작물 인용을 이번에 새로 검증한 것으로 주장하지 않는다. 이 패키지의 대사·문항은 현행 범위와 제공 시나리오를 토대로 새로 쓴 후보이며 교재 정본 문항을 전재한 것이 아니다. 전문 시공 지식·실제 문화재 복원 공법을 학습자 정답 전제로 삼지 않는다.
