## 이번에 정리한 핵심

**첫 ‘집’ 쪽지 → 마지막 편지 → 두 번의 대답 → 열린 문**이 한 줄로 이어진다. 도깨비의 “다 왔다, 연아. 내가 다 받았어.”와 “연아. 이제 문은 고쳐 놨다.”를 모두 지킨다. 플레이어의 “다녀왔습니다.”는 집 안의 동료들을 향한다. 쿠키는 연이와의 약속을 다시 미완으로 만들지 않고 다음 전달의 가능성을 남긴다.

A1.1은 중문간채 **중간**의 문지기 역할 놀이이며, 완공의 E04·폭풍·기억30%와 분리했다. 전체 레벨에서는 어려운 언어를 배우기 위해 이미 공개된 사랑채·안채·곳간채를 다시 찾는다. 레벨 상승으로 단서를 선공개하지 않는다. 초보자의 번역·그림·지원 낭독 경로와 고급 학습자의 분석 경로는 같은 본편 사실과 결말로 이어진다.

v3.5 24행 AP-1의 **128/128 완공을 결말 진입 조건으로 쓰지 않음**을 보존했다. 피날레 기억100%는 서사 연출이며 한국어 숙달·실제 공정·재화 소유를 대체하지 않는다. C2.2 `LQ-16`은 결말 뒤 선택 포트폴리오다. 단원100개는 서로 다른 언어 기능의 장면 집필 범위이지 결말을 보기 위한 강제 목록이 아니다.

## 정본 보존과 편집 제안

정본은 v3.5, 교육 목표는 현재 PSV/문법 배정표, 정확한 공정 정체성은 R16 계약을 따른다. 두 새 첨부의 18스테이지 편성·기존 ID 재배정·`이 집` 쪽지·A1.1 끝과 E04 결합은 현행 파일에 덮어쓰지 않았다. 기존 입문1~4 상세 원고는 그대로 보존했다.

각 공정의 **숫자 sequence에 장면을 붙이는 세부 배치**는 제작 제안이다. 기본 착공·중간·완공 의미와 단서 공개는 정본에 근거한다. 실제 앱의 기존 `requiredCourseUnitIds` 배열은 복사해 비교 자료로만 보존했다. 현재 누적 과정 조건과 F0 사랑채 완공·AP-1을 실제 제품에서 일치시키는 일은 별도 통합 과제다.

A의 긴 태고 대사는 3초에 담기 어려워 직전 본편에 보존했다. B의 긴 세 대사는 부록에 남기고 10초용으로 압축했다. B의 새 쪽·먼 지붕은 요청받은 변주이고, 정본537행의 현대 연락 한 컷은 별도로 보존한다. 실제 녹음·편집을 측정한 10초 완성 영상은 아니다.
