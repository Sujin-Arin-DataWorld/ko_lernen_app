# 입문 3 미디어와 출처

문서용 제작 참조다. 그림·음성을 생성/녹음하거나 앱에 연결하지 않았다. 기존 캐릭터·한옥·R16 배치와 정본 에셋은 바꾸지 않는다.

## 그림/뜻 자료

| 개념·낱말 | 시범/새 사례 조건 |
|---|---|
| TEA · 차 | 현대 학습 소품인 차 한 잔과 찻잎. 커피/탈것 추측이 필요한 불명확한 갈색 액체 사진은 피하고 선택 언어로 tea/Tee라는 뜻을 함께 제공. 고택의 과거 단서 아님. |
| SEED · 씨 | 씨 한 알과 같은 종류가 싹트는 과정의 현대 식물 학습 사진. 주머니·매듭·꽃씨 선물·발신인·연이 흔적은 없음. 첫 씨 사진의 뜻을 선택 언어로 설명. |
| DOG · 개 | 문자 목걸이 없는 반려견 전체 사진. T1/T2는 형태가 다른 개, I1/R1은 배운 범주의 다른 개. 사람을 부르는 표현이나 욕설 문맥 없음. |
| ABOVE · 위 | 상자를 기준물로 고정한 현대 학습 그림. 공이 상자보다 위에 떠 있는 위치, 아래 위치, 옆 위치 세 선택 지점이 서로 명확함. T/R은 크기와 관찰구도만 변경. 실제 고택 건물 위치 변경 아님. |
| NIGHT · 밤 | 현대의 어두운 밤하늘과 잠든 동네 참고 사진. 폭우·도주 인영·과거 기억 없음. 고택 실제 시간 진행을 자동 변경하지 않음. |
| DOOR · 문 | 열고 닫는 문짝/출입구가 보이는 한옥 참고 사진. 정답 지점은 문짝/개구부이며 중문간채 건물 전체나 마당을 가리키지 않음. 다른 각도와 다른 문 사례 분리. |
| HORSE · 말 | 현대 학습용 말 전체 사진. 기수·신분·역사 사건·낱말 자막 없음. 말=동물의 뜻만 설명. |
| SOUTH · 남 | 북쪽이 위인 작은 설명용 방향도에서 남쪽을 뜻 안내로 표시. 방향 맞히기/지명 읽기 없음. 새 고택 지도·건축 방향으로 채택하지 않음. |
| MOUNTAIN · 산 | 특정 산 이름을 요구하지 않는 현대 산 사진. 고택 과거 산사태의 증거로 사용하지 않음. |
| PATH · 길 | 문에서 이어지는 뚜렷한 보행로의 사진/지도. 선택 지점은 열린 마당 전체가 아닌 길의 중간 선분. 실제 R16 배치를 재설계하지 않는 콘텐츠 참조. |
| ROOM · 방 | 벽/바닥 경계로 실내임이 분명한 빈 한옥 방 참고 사진. 사적 공간을 무단 탐색하는 행동 없음. 방 전체 내부가 정답 지점. |
| BALL · 공 | 문자·숫자 없는 단색 놀이 공 사진. 위 위치 그림의 물건과 연결할 수 있으나 공 표기 읽기는 11단원에서 따로 지도. |
| RIVER · 강 | 두 강둑과 흐르는 물이 보이는 현대 강 사진. 바다/옛 전달 경로 추리·새 단서 없음. |
| COURTYARD · 마당 | 건물로 둘러싸인 열린 한옥 마당 사진. 방 내부/문짝/좁은 보행로와 다른 넓은 열린 영역을 지시. 고택 현재 공정 상태를 가짜 완공으로 바꾸지 않는 별도 참고 그림. |

각 개념의 T1은 첫 지도, T2는 설명을 동반한 다른 구도/사례, I1은 확인용, R1은 다음 날 새 구도/사례다. 개념의 속성을 바꾸지 않으며 미학습 다른 뜻을 오답으로 넣지 않는다. 그림 위의 정답 한글·로고·번호는 숨긴다. 설명 언어로 뜻을 함께 제공한 경우에는 설명→표기 연결이며 독립 시각 인식으로 주장하지 않는다.

MAP-T / MAP-I / MAP-R: 현재 정본 배치를 보존한 콘텐츠 참조로 출입문 개구부/실내 방 안쪽/보행로 중간/열린 마당 영역을 분명히 구별한다. T=교사가 이름표와 대상 대응을 함께 시범, I=정답 한글을 숨긴 같은 공간의 다른 관찰 구도/표시 지점, R=재방문용 다른 사진 구도. 이 문서는 미니맵 UI나 R16 건축 배치를 설계/수정하지 않는다. 실제 도면 사용이 준비되지 않았으면 별도 설명 그림에서 연습하며 고택 이동 해금을 실행했다고 주장하지 않는다.

ABOVE의 위치 선택지 ABOVE/BELOW/SIDE는 제작 참조이며 학습자에게 내부 영문 코드를 표시하지 않는다. 상자 위/아래/옆의 그림 지점을 선택한다. ㅇ 역할 선택 A/B의 실제 삼언어 문구는 11단원에 있다.

미니 활동에서는 같은 화자의 비교 녹음으로 시작한다. 정답을 음량·길이·잡음·화자 성별로 추론하게 하지 않는다. 첫소리 소리를 자모 이름이나 영어/독일어 철자값과 동일하다고 가르치지 않는다. 비교는 실제 음절 전체 음성으로 한다.

거센소리/된소리는 호흡량·목 조임·큰 소리만으로 정의/채점하지 않는다. 종성 ㄹ과 초성 ㄹ, 초성 ㅇ과 종성 ㅇ을 실제 음성에서 따로 확인한다. 일반 읽기→소리는 ABC의 정답+같은 모음/다른 초성+같은 초성/다른 모음으로 구성한다. 10단원 첫 확인은 새 받침의 유무+모음 대조, 세 받침을 모두 배운 뒤에는 같은 첫소리/모음에서 ㅁ·ㄴ·ㄹ 소리를 대조한다. 10단원 R과 11단원 I/R은 받침 없음/다른 배운 받침을 포함한 ABCD로 받침을 실제로 들어야 고를 수 있게 한다.

ㅐ·ㅔ는 본 원고에서 표기 확인을 채점한다. ㅚ·ㅟ는 표준 발음에서 허용되는 다른 실현을 검토한 뒤 음성별 허용 범위를 정한다. 단모음/이중모음 중 하나만 입 모양으로 강요하지 않는다. 발음 자동 합격/녹음 점수는 없다.
