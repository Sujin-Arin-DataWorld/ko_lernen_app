# 입문 3-10 · 아래에 놓는 받침, 문과 길

Final consonants, a door and a path · Endkonsonanten, eine Tür und ein Weg

기존 ID `F0.3.first-finals` · 2026-10-29 집필 후보 · 앱 디자인/코드 미변경

## 목표와 순서

받침 ㅁ: 밤 시범 → 남 확인 / 받침 ㄴ: 문 시범 → 산 확인 / 받침 ㄹ: 말 시범 → 길 확인

한 작은 활동의 시범 → 해당 P 두 문항 → 해당 I 두 문항을 마친 뒤 다음 작은 활동으로 간다. 작은 활동 사이에 멈출 수 있다. 본문 뒤의 뜻 보충을 먼저 재생해 새 조합의 첫 확인 정답을 노출하지 않는다. R은 다음 날 재방문 시 다른 시범·대사보다 먼저 제공한다.

미학습 자모/뜻은 읽기 점수에 넣지 않는다. 설명 언어로 뜻과 안내를 볼 수 있고 긴 한국어 대사 읽기나 실제 발화를 통과 조건으로 만들지 않는다. 도움·첫 독립 확인·재노출·유지 후보는 [공통 규칙](README.md)을 따른다.

이 장면에서 출입 전 묻고 답을 기다리는 행동을 소개한다. 한국 전체/모든 한옥에 같은 성별 출입 규범이 있다고 일반화하지 않는다. 들어가도 될까요는 뜻·음성 도움 청크이며 문법 통과 관문이 아니다. 중문간채 중간의 LQ-05 문지기 소동/자기소개는 A1.1에 남긴다.

플레이어·표현 시범은 모델/아바타 음성을 듣거나 뜻을 보고 선택하는 참여도 허용한다. 실제로 말하지 않았으면 발화 성공으로 기록하지 않는다. 다시 듣기·멈춤·거절 선택은 불이익이 없고 원래 시도와 별도로 남긴다.

## 다음 날 복습 R

R 시작은 [공통 문구](COMMON_COPY.md)의 C-REVIEW/C-REVIEWHELP. 최초 지도시각과 마지막 관련 노출시각을 별도로 기록한다. 처음 배운 뒤24시간이 지났어도 바로 앞 수업에서 다시 봤다면 최근 간격을 남기고 짧은 간격 연습으로 구분한다. 기록 밖 노출이 없었다고 단정하지 않는다. 같은 R 안의 첫 응답과 재노출 뒤 연습을 구분한다.

아직 배우지 않은 목표의 R은 제공하지 않는다. 다른 받침을 포함한 기본 보기는 그 받침을 실제로 배운 뒤에만 사용한다. 10·11단원 표의 조건부 세 음성 보기는 일부 받침만 배웠을 때의 실제 대안이며, 서로 다른 받침 소리 대조와 다른 범위로 기록한다. 대체 보기를 쓴 시도에서는 그에 적힌 정답 버튼을 사용한다.
