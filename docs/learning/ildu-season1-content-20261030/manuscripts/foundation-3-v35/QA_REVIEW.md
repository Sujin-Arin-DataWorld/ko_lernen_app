# 입문 3 문서 검토 기록

2026-10-29 · 모델 문서 검토이며 사람·교원·원어민 승인이 아니다.

## 범위와 상태

기존 11개 단원 ID를 유지하고 196문항(P70/I61/R65)을 작성했다. KO/EN/de-DE 대사·지시·도움·오답·마무리와 다음 날 복습을 포함한다. 새 공식 단원이나 보상 단위를 추가하지 않았다. 실제 그림·음성·앱 연결은 만들지 않았다.

삼언어 문구 검토자와 교육/이야기 검토자가 각각 읽기 전용으로 원고를 검토했다. 수정 후 해당 범위를 다시 확인하여 문구는 `MODEL_QA_PASS`, 교육/이야기는 문서 범위 통과로 보고했다. 이 판정은 실제 학습자의 성취·발음·지연 기억을 확인한 결과가 아니다.

## 부분 학습과 복습

작은 활동을 일부만 학습했을 때도 다른 미학습 받침을 복습 보기에 넣지 않도록 조건부 보기를 작성했다. 10단원 R의 기본 ABCD는 ㅁ·ㄴ·ㄹ을 모두 배운 경우에만 제공한다. 각 문항에는 필수 받침 중 하나라도 미학습인 경우의 실제 ABC 보기·정답 버튼·한정 범위가 있다. 11단원도 ㅁ·ㄴ 중 하나라도 미학습인 경로에는 ㅇ 유무/모음 대안이 있다. 대체 보기의 궁을 포함한 음성 대본을 명세에 포함했다. 서로 다른 받침 소리 대조와 같은 증거로 합치지 않는다.

처음 지도한 시각과 마지막 관련 노출시각·실제 간격을 따로 기록한다. 도움의 목표별 승계, 같은 세트의 재노출, 늦은 첫 독립 확인과 유지 후보 구분을 각 R과 공통 안내에 남겼다.

## 구조 검증
