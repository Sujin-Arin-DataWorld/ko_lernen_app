# 입문 4-6 · 처음 남기는 쪽지

The first note · Der erste Zettel

## 목표와 실제 진행

새 시범·도움 연습 P, 별도 확인 I, 다음 날 R을 구분한다. 이 문서의 제목·목표·정답 전사는 제작자용이며 첫 확인/R 전에 정답 자막으로 노출하지 않는다. 긴 한국어 안내는 선택한 설명 언어로 볼 수 있다.

## 이 단원에서의 첫 낱말 순서

입력 방법 시범은 익힌 한 음절 아로만 한다. **I01의 첫 집 회상 시도를 먼저 제공한 뒤**, 필요하면 P01 집 모형 도움으로 같은 목표를 이어간다. I01 전에는 집 표기·자모 묶음·로마자·정답 키 순서를 먼저 보여 주지 않는다. 방법 시범만으로 복잡한 키보드 조작을 통과시킬 필요는 없다. 조각 선택으로 같은 이야기 참여가 가능하다.

집이 완성형으로 확정되면 아래 쪽지 상태를 확인한다. 그다음 P02의 연습 오타, P03/P04 나무·모자 모형 입력, P05 오타 수정으로 진행한다. 이후 I02/I03 바다·다리, I04 준비된 집 오타를 제공한다. 따라서 이 원고의 첫 낱말 입력은 집이며 다른 낱말 연습이 앞서지 않는다. P01은 집 도움이 필요한 분기이고 이미 스스로 입력한 경우 필수 복사를 강요하지 않는다.

## LQ-04 · 첫 집 쪽지를 남기는 상태

학습자가 입력/조각으로 완성한 집은 먼저 연습 초안이다. **실제 사랑채 완공과 기존 이야기 준비 상태가 확인된 경우에만** 등불 원문 → 아바타가 같은 집을 쪽지에 씀 → 보관 확인 → 탈선비 책갈피 순서로 진행한다. 이렇게 원문 도깨비 대사는 극중 쪽지 작성 앞에 있고, 첫 회상 확인의 답을 미리 주지는 않는다.

완공 전이면 N-WAIT로 초안을 보존한다. 보관 실패/미확인이면 N-PENDING이며 보관 완료 사실을 만들지 않는다. 저장이 성공한 단 하나의 집 쪽지를 피날레 직전 다시 열어 보며, 연습·수정·다음 날 복습으로 새 쪽지·새 단서·중복 엽전을 만들지 않는다. 사람이 직접 발화하지 않아도 아바타 낭독/표현 음성으로 같은 장면에 참여할 수 있으며 실제 발화 근거와 분리한다.
