# 입문 4-5 · 글자는 두고 소리를 잇기

Keeping the spelling, linking the sounds · Die Schreibung behalten, die Laute verbinden

기존 ID `F0.4.linked-sounds` · 2026-10-29 문서 집필 후보 · 앱 디자인/코드 미변경

## 목표와 실제 진행

새 시범·도움 연습 P, 별도 확인 I, 다음 날 R을 구분한다. 이 문서의 제목·목표·정답 전사는 제작자용이며 첫 확인/R 전에 정답 자막으로 노출하지 않는다. 긴 한국어 안내는 선택한 설명 언어로 볼 수 있다.

이 장면의 재요청은 가까운 수진에게 하므로 DE du. 이/에의 뜻은 예시 문장 번역으로 돕고 이번 점수는 소리 연결/표기 보존에 한정한다. 겹받침·ㅎ의 전체 규칙은 필수 통과 범위가 아니다.

표현 음성/설명 언어 선택으로도 참여할 수 있다. 실제로 말하지 않았다면 발화 성공으로 기록하지 않는다. 선호 응답은 정답/오답이 없고 다시 듣기/시범을 고르면 실제 같은 자료를 제공한다.
