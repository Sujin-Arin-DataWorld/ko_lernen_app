# 입문 4 원고 검토 기록

2026-10-29 · 문서 집필 후보 v1.0

## 작성 범위

기존 7개 단원 ID를 유지하고 117개 제작 문항(P44/I34/R39)을 작성했다. 선택 회상 5분기와 도움 대안을 포함한 수이며 학습자가 전부 수행해야 하는 분량이 아니다. 각 원고에 KO/EN/de-DE 대사·지도·문항·정답·도움·오답·다음 날 복습이 있다. 실제 그림·음성·앱 기능은 제작/연결하지 않았다.

## 모델 교차 검토

삼언어 문구 검토자와 교육/이야기 검토자가 각각 읽기 전용으로 검토하고 수정 범위를 다시 확인했다. 문구 모델 검토는 `MODEL_QA_PASS`, 교육 문서 검토는 중요한 잔여 결함 없음으로 보고했다. 사람·원어민·교원 승인, 실제 음성 청취나 학습자 성취 검증과는 별도다.

| 확인한 문제 | 반영한 수정 |
|---|---|
| 자모 조각만으로 목/곰·낮/잔·집/빚이 모두 가능 | 해당 I/R에 목표 음성과 ‘그 낱말을 조각으로 만들기’ 지시를 명시. 의자와 연음 표기의 숨긴 모형 순서 과제에도 목표 음성을 붙임 |
| 같은 ㅢ·요청 표기를 먼저 노출한 뒤의 R도 첫 확인으로 표현 | D04-R02와 D07-R04를 기본 순서의 재노출 뒤 연습으로 명시. 목표/규칙/보기 노출은 문항 ID를 넘어 승계 |
| 받침 위치 선택에 소리/순서 피드백 사용 | 위치 선택 전용 LINK-POS 피드백 연결. 듣고 표기/읽고 소리/음절 순서도 각각 구분 |
| 띄어쓰기 선택·구성·수정에 같은 동작 지시 | SPACE-C 선택, SPACE-B 구성, SPACE-E 경계 수정 문구로 분리 |
| 물 주세요의 물과 사진을 달라는 대상 혼동 | 사진은 뜻 도움, 역할 장면의 요청/응답 대상은 마실 물로 통일. 실제 학습자의 음용 행동은 통과 조건이 아님 |
| 낮의 독일어 뜻이 맑은 날씨로 좁아짐 | 해가 뜬 뒤부터 지기 전의 시간으로 맞춰 흐린 낮도 포함 |

## 구조 확인과 원본 보존

117개 ID·자극·보기·정답·삼언어 지시·도움/오답 코드가 JSON·CSV·MD에서 일치한다. 작은 활동별 기학습 자모/받침, 조립 목표 단서, 필요한 읽기 음성 대본, 상대 링크·표 구조를 확인했다. 동음 오답 여부는 알려진 해당 표기의 발음 설명을 비교한 문서 점검이며 실제 녹음 청취 검증이 아니다.

앱 핵심 파일, 기존 입문1~3 원고, v3.5 원문 등 보호 파일 53개의 SHA-256이 유지됐다. 확인한 체크아웃 HEAD는 `6fadd838e2a8ad378b92b38d06d86541782a7db8`이며 기존 WIP 45경로를 보존했다. 최종 검증·산출물 해시는 [SOURCE_AND_QA.json](SOURCE_AND_QA.json)에 기록한다.

## 첫 쪽지의 보존 경계

입력 방법 시범 뒤 첫 낱말은 집이다. I01에서 기억으로 해 보거나 같은 목표의 P01 도움을 받을 수 있다. 실제 사랑채 완공·기존 이야기 준비·쪽지 보관 성공을 각각 확인하고 원문 순서로 등불 → 집 쪽지 → 책갈피를 사용한다. 미완공이면 초안, 보관 미확인이면 pending이다.

나무·모자/바다·다리와 오타 수정은 뒤의 연습이다. 이 집과 모자 주세요/물 주세요는 별도 문구이며 원래 집 쪽지를 덮어쓰지 않는다. 피날레에는 동일 쪽지를 다시 열어 보며, 지금 편지 내용·새 단서·숙달 인증·건축 완료·중복 엽전을 만들지 않는다. 도움/독립/지연 후보와 입력 방법·필기·실제 발화를 분리한다.

## 남은 제작과 검증

한국어 교원, EN/de-DE 사람 검토, 실제 음성 녹음·청취, 그림 제작/권리, 입문자의 자판·이해·부담·지연 기억 관찰, 앱 저장/쪽지 보관/보상/기기 검증은 남아 있다. 이 원고 검토를 그 검증들의 완료 근거로 쓰지 않는다.
