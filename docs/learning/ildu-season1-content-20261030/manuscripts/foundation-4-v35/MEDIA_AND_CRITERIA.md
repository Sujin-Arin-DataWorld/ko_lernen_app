# 입문 4 미디어·출처·판정 기준

제작 명세이며 실제 그림·음성을 만들거나 앱을 수정하지 않았다. T1/T2는 지도용, I1은 확인용, R1은 다음 날 다른 사례/구도다. 정답 한글·로고를 그림에 넣지 않는다. 그림 대신 뜻 설명을 쓰면 의미 설명→표기 대응으로 기록한다.

인물 대사와 표현 청크는 각 단원 삼언어 표 전체가 별도의 녹음 대본이다. 왜요/예/재요청·입력 확인·물 요청과 6단원 NOTE 표의 등불/쪽지/책갈피 원문도 포함한다. 아래 낱말 목록만 녹음한 것을 전체 대사 제작 완료로 보지 않는다.

음성 선택 A/B/C의 전사는 제작자용이다. 정답을 음량·길이·잡음·화자 차이로 알아내게 하지 않는다. 옷/낮의 발음 도움 [옫]/[낟], 문이/옷이/밥이/집에의 [무니]/[오시]/[바비]/[지베]는 발음 설명이며 철자 정답을 바꾸는 지시가 아니다. TTS/녹음 입력 원문은 옷·낮·문이·옷이·밥이·집에로 유지하고 실제 녹음을 교원이 청취해야 한다.

왜/웨·괘/궤, 얘/예·걔/계, 희/히·늬/니처럼 같은 소리가 될 수 있는 표기를 오디오 오답 쌍으로 쓰지 않는다. 2·3·4단원 I/R은 표기 확인이다. 소리를 경험한 사실과 표기 확인 성공을 청각 변별·발음 합격으로 합치지 않는다.

## 입력과 띄어쓰기 판정

- D06의 완성형 결과는 집/나무/모자/바다/다리다. 조합중 입력은 채점하지 않는다. NFC로 같은 한글 표기인 조합/완성형은 동일하게 볼 수 있지만 원 응답은 보존한다. 라틴 키 전사나 영어/German 뜻을 한글 정답으로 인정하지 않는다. 입력모드/장치 실패는 한국어 지식 오답이 아니다.

- 키보드 입력과 자모 선택은 방법을 구분한다. 모형을 보며 복사, 제한 회상, 준비된 오타 수정도 각각 구분한다. 자모 선택 성공을 두벌식 자판 숙달, 입력 성공을 필기/자유 작문/실제 발화로 인정하지 않는다.

- D07은 정답 문구의 단어 경계를 본다. 이 집/모자 주세요/물 주세요의 공백 경계를 유지해야 한다. 연속 공백은 하나로 정규화할 수 있으며 두 칸을 썼다는 이유만으로 의미상 같은 경계를 오답 처리하지 않는다. 공백을 모두 지워 비교하면 목표가 사라지므로 그렇게 하지 않는다. 원 응답·표면 차이는 별도 보존한다.

- 선택지/조각 문항의 순서·자리만 확인한 결과를 모형 없는 텍스트 생산과 합치지 않는다. 그림/번역 뜻 도움 사용 여부도 기록한다. 다음 날에는 같은 내용/방법의 이전 독립 근거와 최근 노출 간격을 확인한다.

## 두벌식 키 참조 — 제작자 전용

| 낱말/음절 | 키 참조 |
|---|---|
| 아 | d → k |
| 집 | w → l → q |
| 나무 | s → k → a → n |
| 모자 | a → h → w → k |
| 바다 | q → k → e → k |
| 다리 | e → k → f → l |

표준 두벌식의 제작자용 키 참조. 실제 장치/IME/접근성 도구에서 확인하기 전 키보드 동작 완료라고 하지 않는다. 학습자에게 라틴 키 암기를 요구하지 않고 한글 자모 면/조각 대안을 제공한다. 삭제키 횟수/IME 조합중 상태를 정답 기준으로 삼지 않는다.
