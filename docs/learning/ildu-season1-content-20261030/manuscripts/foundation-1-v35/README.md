# 입문 1 세 단원 — v3.5 실제 콘텐츠 원고

2026-10-28 · 집필본 v1.0 · 콘텐츠 문서만 작성

앱 코드·런타임 데이터·디자인·원본 세계관은 변경하지 않았다. 본문은 바로 검토할 수 있는 실제 대사와 문항이며, 음성 파일·그림·앱 동작을 제작하거나 교원/학습자가 승인한 상태는 아니다. 이야기의 기존 대사는 `원문`, 새로 쓴 학습 대사와 안내는 `집필`로 구분한다.

## 읽기 순서

| 기존 단원 ID | 이번 제목 | 새 글자와 목표 | 구어 경험 | 원고 |
|---|---|---|---|---|
| F0.1.sound-signs | 공부책의 첫 소리 | ㅇ·ㅏ·ㅓ / 아·어의 소리 경험·모양·좌우 조립 | 안녕하세요 | [01](01_FIRST_SOUND.md) |
| F0.1.above-below | 첫 장에 더한 두 소리 | ㅗ·ㅜ / 오·우의 소리 경험·상하 조립 | 감사합니다 | [02](02_TWO_MORE_SOUNDS.md) |
| F0.1.straight-lines | 두 선과 첫 여섯 글자 | ㅡ·ㅣ / 으·이와 앞의 네 음절 재사용 | 다시 말해 주세요 | [03](03_TWO_LINES.md) |

각 단원은 시범 → 도움 연습 4문항 → 별도 확인 4/6/9문항 → 이야기 결과 → 다른 날 복습 4/6/8문항이다. 구어 활동은 각 단원에 별도로 있다. 이 수는 집필한 활동 수이며 학습시간·숙달·효과의 검증값이 아니다. 필요할 때 중단하고 같은 단원에서 이어갈 수 있다. 누적 확인을 한 번에 끝내야 하는 시간제한·진행 관문으로 쓰지 않는다.

단원 ID를 유지하며 100단원 수를 늘리지 않는다. 원고의 `U1-P01` 같은 코드는 집필·검토 참조용이고, 앱에 등록된 새 문항 ID나 사용자에게 보여 줄 이름이 아니다. 별도 확인의 I는 '독립으로 시도할 기회'라는 뜻이며 실제 도움 사용·응답에 따라 결과를 구분한다.

## 장면·언어 계약

- 대상: 한국어 글자를 처음 배우는 성인. EN 또는 de-DE 설명으로 이야기와 조작을 이해한다. 한국어 안내는 제작 의미 기준이지 왕초보가 독해해야 하는 문제 지문이 아니다.
- 장소: v3.5 P-7, 사랑채 착공 전 공부책. 주인공은 사용자의 아바타다. 수진은 단짝 동료다. 탈선비는 첫 아의 극중 낭독 뒤에만 말한다.
- 말투: 수진→플레이어는 친한 반말, 탈선비→플레이어는 원문에 따른 인자한 옛 말투, 앱 설명은 해요체. 독일어 앱 안내·수진→플레이어·탈선비→플레이어는 du. 학습자가 탈선비에게 하는 재요청의 독일어 의미는 Sie로 정한다. 이는 장면별 저작 선택이며 한국어 요체=Sie라는 문법 규칙이 아니다.
- KO가 학습/이야기 의미의 기준이다. EN과 DE는 같은 사건·선택권을 직접 현지화한다. 이름·성별·직업·보상·역사 사실을 새로 만들지 않는다. `{이름}`은 세 언어에서 그대로 보존하며 학습자의 이름을 한글로 해독하는 시험은 없다.
- 원문 재회 대사는 이야기 이해용이다. 독일어/영어 뜻 안내로 읽어도 된다. 이 대사를 한국어로 읽어야 글자 수업을 계속할 수 있는 조건은 없다.
- ㅗ가 책의 다른 조각으로 언급되더라도 2단원 시범 전에는 답 보기나 채점 대상으로 쓰지 않는다. ㅡ·ㅣ도 3단원 이전에는 평가하지 않는다. 받침·자음 확대·이중모음·역사 용어는 세 단원의 평가 범위 밖이다.
- 아·어 등의 소리는 이 과정에서 음절 읽기의 예다. 감탄사·머뭇거림·대답 등의 뜻이나 글자의 이름 전체를 동시에 가르치지 않는다. 이는 한국어 단어 뜻·자유 읽기·발음 숙달 확인이 아니다.

## 문항 읽는 법과 정답 경계

- 모든 표의 `자료·보기·정답`은 제작자용이다. 듣기 문항에서 `읽는 소리=어` 같은 정답 설명, 파일 참조 코드, 전사, 정답 의미 번역을 학습자 지문에 노출하지 않는다.
- P(연습)는 완성 모형·시범을 제공한다. I(별도 확인)와 R(다른 날 복습)는 정답 완성 모형을 처음부터 보여 주지 않는다. 조립 문항은 필요한 낱조각만 제공하며 해당 조각들이 어느 위치에 놓이는지가 확인 대상이다.
- 조립의 허용 답은 최종 글자 구조다. 조각을 집은 순서, 마우스·터치·키보드, 드래그와 선택→자리 선택은 정답 기준이 아니다. 글자를 돌리거나 뒤집어 다른 자모로 만드는 행동은 과제에 넣지 않는다.
- 자모를 수평으로 나열한 `ㅇㅏ`를 완성 음절 `아`와 같은 결과라고 채점하지 않는다. 입력을 요구하지 않으므로 한글 키보드·타이핑 숙련도는 측정하지 않는다.
- 문항을 내기 전에 그 문항의 모든 보기·조각을 이미 가르쳤는지 확인한다. 빈 응답은 C-NOANSWER, 소리 재생 실패는 C-NOAUDIO이며 정오답 판정 대상이 아니다.
- I/R에서 도움·정답 시범·오답 뒤 정답 피드백을 본 경우 **공개된 목표와 구조·음성-표기 짝**의 뒤 응답까지 지원받은 연습으로 보존한다. 문항 ID가 다르다는 이유로 독립 상태를 새로 주지 않는다. 예를 들어 U1-H02는 아·어 두 짝을 공개하므로 그 세트의 뒤 아·어 확인에도 영향을 준다. 첫 오답과 도움 사용은 지우지 않는다. 다른 배치 재시도도 같은 두 음절의 재인이지 새 단어 전이가 아니다.
- 같은 세트에서 어떤 음절을 이미 조립·선택해 보거나 정답을 보았다면 그 목표의 뒤 응답은 재노출 후 수행임을 남긴다. R에서 목표별 첫 응답과 후속 연습을 구분하고, 전체 R 정답 수를 모두 '사전 재노출 없는 지연 독립 성공'으로 합치지 않는다. 필요한 재학습은 즉시 제공하되 공개한 목표의 뒤 문항은 연습으로 전환한다.
- 정답 위치도 채점 기준이 아니다. 원고의 보기 순서는 각 묶음 안에서 섞었으며, 후속 구현에서 순서를 바꾸면 선택지 내용에 연결된 정답도 함께 보존해야 한다. 음성보다 위치를 외워 해결할 수 있는 고정 규칙을 만들지 않는다.
- T(가르침)와 P(연습)를 했다는 이유만으로 이후의 I 응답이 자동으로 도움 시도가 되는 것은 아니다. 확인 단계에서 실제로 쓴 도움과 원 응답을 구분해 기록할 제작 명세다. 현재 앱의 자동 판정 구현을 변경한 것이 아니다.
- 듣기 목표에서는 정답을 알려주지 않는 동일 음성 재생을 허용한다. 재생 횟수는 남길 수 있으나 '첫 소리 한 번에 알아들음'으로 주장하지 않는다. 해당 목표의 글자 모형·정답 전사를 열면 그 듣기 확인은 지원받은 시도다.

## 다음 날 복습

첫 학습 완료 뒤 **최소 24시간 후**의 재방문을 이 원고의 초기 복습 시점으로 제안한다. 정확한 최적 간격이 입증됐다는 뜻은 아니다. 더 늦게 돌아와도 벌점 없이 같은 R 묶음을 사용한다. 같은 날이면 복습 연습으로 제공할 수 있지만 지연 유지 증거로 분류하지 않는다.

1. 재회 대사만 짧게 읽고 R로 들어간다. 정답을 먼저 들려주는 장면·음절 자막·준비 시범은 앞에 재생하지 않는다.
2. 소리/보기/조각 순서는 원고의 R 순서를 쓴다. 앞서 본 정답 위치를 그대로 따라갈 수 없게 한다.
3. 도움은 언제든 선택할 수 있다. 도움을 보거나 틀린 목표는 짧게 다시 가르친다. 그 과정에서 공개한 목표의 뒤 문항까지 재노출 후 연습으로 구분하며 지연 독립 성공으로 바꾸지 않는다.
4. 최초 학습의 독립 응답과 이번 독립 응답이 같은 내용·목표 범위에서 연결될 때만 그 범위의 지연 유지 근거 후보가 된다. 최초가 도움받은 시도였다면 이번 성공은 늦게 확인한 첫 독립 수행이지 이미 유지가 증명된 것은 아니다.
5. 이야기 각성·책갈피·단원 완료 수·엽전을 다시 만들지 않는다. 복습을 못 해도 원 이야기 진행을 취소하지 않는다.
6. 2/3단원의 누적 문항은 그 선행 단원을 실제로 학습한 경우에만 제공한다. 도움 경로로 건너온 경우 해당 문항은 준비 연습부터 제공하고 그날 처음 배운 소리의 지연 확인이라고 하지 않는다.

## 음성 제작 대본과 범위

| 참조 | 읽을 한국어 | 사용 |
|---|---|---|
| S-A | 아 | 1단원 첫 시범·확인·복습 |
| S-EO | 어 | 1단원 두 번째 시범·확인·복습 |
| S-O | 오 | 2단원 이후 |
| S-U | 우 | 2단원 이후 |
| S-EU | 으 | 3단원 이후 |
| S-I | 이 | 3단원 이후 |
| O-HELLO | 안녕하세요 | 1단원 구어 경험 |
| O-THANKS | 감사합니다 | 2단원 구어 경험 |
| O-REPEAT | 다시 말해 주세요 | 3단원 구어 경험 |

이는 녹음/TTS 검수용 대본 참조이며 실제 미디어 파일 ID가 아니다. 아·어·오·우·으·이는 중립적인 단독 음절로 녹음한다. 감탄·신음·망설임 연기를 섞지 않는다. 보기마다 음량·잡음·속도 차이를 정답 단서로 쓰지 않는다. 실제 소리 비교·조음 적정성·화자별 음성은 한국어 교원/발음 검수 전까지 `EVIDENCE_REQUIRED`다.

로마자는 정답이나 발음 등가표로 쓰지 않는다. EN의 자모 설명에서 `eo/eu`, DE의 철자 조합을 한국어와 똑같은 소리라고 가르치지 않는다. 듣기를 할 수 없는 학습자는 조립·뜻 안내·자막으로 이야기에 참여하며 듣기/실제 발화는 미평가로 남긴다.
