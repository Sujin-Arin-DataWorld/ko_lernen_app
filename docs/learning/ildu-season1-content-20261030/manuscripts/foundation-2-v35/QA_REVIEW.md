# 입문 2 원고 검토 기록

2026-10-29 · 문서 제작 후보 v1.0

## 이번에 만든 범위

기존 입문 2의 7개 단원 ID를 유지하며 v3.5 창고 착공 푯말 장면에 연결했다. 각 단원에는 실제 KO/EN/de-DE 장면 대사, 가르치기, 문항·정답, 도움·오답 문구, 상황 참여와 다음 날 복습이 있다. 총 102문항은 P 도움 연습 34개, I 별도 확인 31개, R 복습 37개다. 낱말 보충은 공식 단원을 늘리지 않는다.

대사·문항이 사용할 그림은 28개 참조로 명세했으며 실제 파일은 생성하지 않았다. 음성도 읽기 대본과 제작 조건을 적은 상태다. 앱 코드·앱 디자인·기존 학습 데이터·입문 1 원고·사용자 세계관 원문은 수정하지 않았다.

## 모델 교차 검토와 반영

서로 다른 두 검토자가 읽기 전용으로 삼언어 문구와 교육/이야기 계약을 각각 검토하고, 수정된 범위를 다시 확인했다.

| 검토에서 확인한 문제 | 반영한 수정 |
|---|---|
| 첫 다섯 단원의 읽기→소리 보기가 같은 모음이라 첫소리만으로 선택 가능 | 20개 I/R 문항을 3음성 ABC로 변경. 정답과 함께 같은 모음·다른 첫소리, 같은 첫소리·다른 모음 보기를 각각 제공. 정답 위치 분산, R 순서 변경 |
| LQ 앞 대사가 낱말-대상 대응을 미리 말함 | 정답을 알려 주지 않는 정리 요청으로 변경. 탈선비 책갈피 원문과 마무리는 활동 뒤에만 사용 |
| 첫 학습 뒤 24시간만으로 최근 재노출 간격이 불분명 | 최초 지도시각과 마지막 목표별 관련 노출시각·실제 간격을 분리. 최근 노출 뒤 24시간 미만은 짧은 간격 연습으로 구분. 37개 R 범위와 공통 규칙에 반영 |
| EN/DE의 수진 대명사가 성별을 단정 | 성별을 덧붙이지 않는 지시로 수정 |
| 도깨비 첫 등장 일부에서 단수/복수 청자 불일치 | 플레이어+수진에게 하는 첫 등장 지시는 ihr, 개별 재생 질문은 du로 고정 |
| 보충 이후 마무리가 같은 보충을 앞으로 예고 | 2·3·6단원에 보충 참여 완료형과 미참여 예고형 문구를 각각 제공 |
| 일부 DE 문구와 제작 안내가 부자연스럽거나 불일치 | 다음 음절 안내, ABC 표기, 글자·낱말 공통 음성 실패 문구를 수정 |

삼언어 문구 검토의 최종 판정은 `MODEL_QA_PASS`이며, 교육/이야기 검토는 문서 범위 통과다. 둘 다 모델 검토에 한정하며 인간·교원·원어민 승인을 뜻하지 않는다. 최종 구조 검사와 원본 보존 결과는 [SOURCE_AND_QA.json](SOURCE_AND_QA.json)에 기록한다.

## 보존한 이야기와 학습 경계

- 목재인 나무, 일하는 물건인 도구, 완성 목재 바닥 공간인 마루를 서로 구분한다. 마루는 다른 완성 한옥의 참고 사진이다.
- 살아 있는 나무와 목재인 나무는 다른 의미로 따로 가르친다. 다리는 물을 건너는 구조물만 다룬다.
- 7개 단원의 완료는 창고 8공정 완공·기억 20%·빈 씨앗 주머니·S1-E03·보상 지급을 자동 생성하지 않는다.
- 도움받은 수행, 첫 독립 수행 후보, 재노출 뒤 연습, 지연 유지 후보를 분리한다. 선택 레벨과 이야기 진도는 그 결과로 자동 변경하지 않는다.

## 남은 제작·검증

한국어 교원 감수, EN/de-DE 사람 검토, 실제 그림·음성 제작/권리 확인/청취 감수, 완전 입문자의 이해·부담·회상 관찰은 남아 있다. 앱 연결·저장·기기 동작은 이번 범위가 아니다. 이 문서 검토를 해당 검증의 완료 근거로 쓰지 않는다.
