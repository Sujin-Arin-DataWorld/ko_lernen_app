# 입문 2-6 · 나무와 모자, 그리고 목재

A tree, a hat, and timber · Ein Baum, ein Hut und Holz

기존 단원 `F0.2.tree-and-hat` · 2026-10-28 집필 후보 · 앱/디자인 미변경

## 목표와 진행 순서

배울 낱말: **나무 · 모자**. 표기·소리·뜻을 각각 연결한다. 같은 낱말의 다른 뜻을 자동으로 아는 것으로 취급하지 않는다.

첫 방문: 장면 → 뜻/소리/모형 지도 → P01–P04 → I01–I04 → 상황 참여 → 뜻 보충과 P05–P06 → 마무리. 다음 날에는 아래 R을 시범보다 먼저 제공한다.

공통 원칙은 [전체 안내](README.md)의 도움·노출·독립·저장·지연 규칙을 함께 적용한다. 정답 노출 뒤에는 같은 문항과 입력을 유지하고 다시 시도할 수 있다. 빠르기·드래그·실제 발화를 통과 조건으로 만들지 않는다.

모자의 뜻을 배운 뒤에만 명칭 요청을 제공한다. 수진이 실제 모자/학습 소품을 건넨다. 듣고 따라 하거나 표현 음성을 선택해도 참여하며 자유 말하기·조사 숙달로 기록하지 않는다. 모자 주세요 전체의 미학습 글자 해독을 요구하지 않는다.

플레이어·시범은 아바타/표현 음성으로 듣거나 뜻을 보고 선택하는 참여도 허용한다. 실제로 발화하지 않았으면 발화 성공으로 기록하지 않는다. 듣기·그림 참여·자발 발화를 분리하고 녹음은 필수가 아니다.
