# 입문 2-2 · 두 상자와 새로운 첫소리

Two boxes and new initials · Zwei Kisten und neue Anfangszeichen

기존 단원 `F0.2.two-boxes` · 2026-10-28 집필 후보 · 앱/디자인 미변경

## 목표와 진행 순서

새 첫소리: **ㄱ · ㄷ**. 직접 시범: **가 · 고 · 다 · 도**. 첫 조합 확인: **구 · 디**. 뜻·실제 발음 점수와 구분한다.

첫 방문: 장면 → 뜻/소리/모형 지도 → P01–P04 → I01–I04 → 상황 참여 → 뜻 보충과 P05–P06 → 마무리. 다음 날에는 아래 R을 시범보다 먼저 제공한다.

공통 원칙은 [전체 안내](README.md)의 도움·노출·독립·저장·지연 규칙을 함께 적용한다. 정답 노출 뒤에는 같은 문항과 입력을 유지하고 다시 시도할 수 있다. 빠르기·드래그·실제 발화를 통과 조건으로 만들지 않는다.

| 도깨비·네 뒤 | 좋다. 같은 시범을 다시 보아라. | All right. Watch the same example again. | Gut. Sieh dir dasselbe Beispiel noch einmal an. |
| 도깨비·아니요 뒤 | 좋다. 그럼 다음으로 가 보자꾸나. | All right. Let's continue, then. | Gut. Dann machen wir weiter. |

네/아니요는 의미와 음성으로 가르치는 응답이다. ㅔ·ㅛ 등 미학습 문자를 해독하게 하지 않는다. 아니요를 오답이나 불성실로 기록하지 않는다. 네 뒤에는 실제 동일 시범을 제공한다.

플레이어·시범은 아바타/표현 음성으로 듣거나 뜻을 보고 선택하는 참여도 허용한다. 실제로 발화하지 않았으면 발화 성공으로 기록하지 않는다. 듣기·그림 참여·자발 발화를 분리하고 녹음은 필수가 아니다.
