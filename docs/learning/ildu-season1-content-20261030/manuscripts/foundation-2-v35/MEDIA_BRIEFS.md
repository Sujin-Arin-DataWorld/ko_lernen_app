## 인물 대사·참여 청크

각 단원 KO/EN/DE 열이 대본 원문이다. 선택한 설명 언어로 뜻을 제공하며 한국어 긴 대사를 독립 읽기 통과 조건으로 만들지 않는다. 한국어 표현 음성 네·아니요·주세요·모자 주세요·다시 말해 주세요, 실제 선택 이름 음성은 별도 제작/적절성 확인이 필요하다. 이름 음성이 없으면 해당 듣기를 미평가로 둔다.

감수 음성과 필요한 그림이 준비되기 전에는 듣기/새 그림 검증을 완료했다고 보고하지 않는다. 모델 문구 검토와 교원·원어민·학습자 검토는 별도다.
