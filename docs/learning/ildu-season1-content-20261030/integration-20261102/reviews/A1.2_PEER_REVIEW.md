## 필수 전달 조건

**material.response_scope를 실제 문항 자료와 함께 표시해야 이 판정이 유지된다.** 이 필드를 숨긴 화면에 유한 accepted_answers를 연결해 자유 문장 전체를 오답 처리하면 재검토가 필요하다. 다른 자연스러운 표현은 자유 역할 수행/별도 검토 경로에 남긴다. 고정형 입력 통과를 자유 대화·발음·실생활 전이 인증으로 확대하지 않는다.

I는 정답 모델이 기본 숨김이며 도움 노출 뒤는 독립 증거와 분리한다. R은 다음 날 현대 새 자료이며 본편 공개를 잠그지 않는다. 역할 수행은 unscored다. 가상 원 가격·거리·일정은 실제 경제/가격/시설 정책/출입권을 부여하지 않는다. 고택 장면은 원래 공개 상태를 따르고 새 단서·미래 진실을 추가하지 않는다.
