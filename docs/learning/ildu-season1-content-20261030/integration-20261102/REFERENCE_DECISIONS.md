# 기존 콘텐츠 재사용 판단

## 연결의 의미

`UNIT_CONTENT_LINKS.json`의 각 참조는 기준 main `646c4658e70f594ab234a172679e29122d0f0e66`에서 확인한 실제 ID·원본 파일 해시를 포함한다. 이 표는 집필 연결 명세이며 새 앱 등록표·자동 실행 목록·평가 엔진이 아니다. `SOURCE_MANIFEST.json`의 출처와 함께 읽는다.

| 영역 | 선택 방법 | 실행 전 조건 |
|---|---|---|
| 코스 | 기존 `COURSE_BINDINGS.psv`의 복수 대응 | 48코스·86세그먼트·30단계와 스토리 단원은 다른 목록. 코스 전체와 한 단원 목표를 같다고 보지 않음 |
| 문법 | 배정표의 실제 `legacy_task_ids`를 902개 단계 문항에서 확인 | 형태 참고 자료. 원래 예문의 어휘·평가 범위를 확인한 뒤 사용. 새 상세 패킷이 기능 시범·연습을 담당 |
| 단어 | 목표의 정확한 표면형과 출처 뜻 비교 | 수준 열과 ID 접두사가 다를 수 있어 ID 이름만으로 수준을 판단하지 않음. 동형어·뜻이 다르면 제외 |
| 시나리오·듣기 | 원문을 읽고 맞는 기능 일부를 명시적으로 선정 | 현대 인물·관계·장소 유지. 듣기와 시나리오가 같은 원문이면 별도 독립 대본으로 세지 않음 |
| 스몰토크 | 기존 명시적 코스 연결과 목표 어휘 교집합 | 선택적 관련 자료 후보. 전체 표현·관계·후속 반응 및 선수 지식을 실행 전에 재확인 |
| Cloze·Satz | 확인한 어휘 ID에 대한 실제 `sourceVocabId` 연결 | 선택적 재연습 후보. 문장 전체 선수 지식·뜻·정답 노출 확인 필요. 원문 자동 듣기가 있다면 독립 회상으로 계산하지 않음 |
| 입문 게임 | 기존 원고의 글자·음절 조립·구별 문항 | 기존 A1~C2 게임 풀 전체를 초보자에게 연결하지 않음. 준비된 글자만 사용 |

재사용할 원문이 맞지 않으면 `authored_packet_or_not_applicable`로 표시한다. 새 원고의 `A1.2-…/A2.1-…/A2.2-…` 문항 ID는 이 폴더에 존재하는 문서 ID다. 앱에 등록된 ID라고 표시하지 않는다.

## 원문을 보고 좁힌 시나리오

예를 들어 `home_morning_routine`은 물건의 위치 찾기에 연결하고 소유 확인 전체로 확대하지 않았다. `umbrella_weather`는 우산의 소유·함께 사용하기를 재연습한다. `meeting_time`은 시각을 잘못 들은 부분의 확인이며 변경 약속 단원 전체를 대신하지 않는다. `group_chat_photo_permission`은 사진 허락에, `favorite_drama_chat`은 시작 이후 기간에, `package_wrong_door`는 보이는 근거와 소유 확인에 연결한다. 기존 코스에 속한다는 이유로 선정하지 않은 장면은 단원별 `excluded_broad_course_ids`로 남긴다.

일부 데이터의 `canonicalScenarioId`는 현재 시나리오 ID와 직접 일치하지 않는 별도 메타데이터다. 이 작업에서는 그것을 새 자동 조인 키로 사용하지 않았다. 일치하지 않는다는 이유만으로 기존 콘텐츠를 삭제하거나 고장으로 판정하지 않는다.

## 동형어와 번역 수정 제안

**A1.2-04의 개·병은 수량 표현**이다. 기존 `vocab_a1_0628`의 개는 dog/Hund, `vocab_a1_0680`의 병은 illness/Krankheit이므로 해당 단원에서 제외했다. 두 단어에 딸린 게임도 이 조인 경로로 불러오지 않는다. 필요한 수량 표현은 새 원고의 실제 `teach_targets`와 문항으로 연결한다. 없는 런타임 수량 단어 ID를 만들지 않았다.

`vocab_a1_0759`의 아니다는 일반 명사 부정인데 독일어가 학생이 아님으로 좁아져 있다. `vocab_a2_0264`의 걸리다는 이번 단원에서 걸려 있는 상태인데 독일어 괄호가 시간 의미 dauern을 섞는다. [수정 제안](TRANSLATION_PATCHES.json)에 원문과 제안을 별도로 남겼다. 관련 단원 검토본에는 실행 전 별도 적용이 필요하다고 표시한다. 원본 CSV는 그대로 보존했다.

## 한옥 연결

52단원은 LQ-01~08의 이야기 접점에 연결한다. 기존 R16의 11동128공정은 전체 카탈로그 맥락 참조로 함께 제공하며 각 행의 `in_this_delivery`로 이번 학습 구간과 후속 구간을 구분한다. 단원의 서사적 착공·중간·완공 언급만으로 실제 공정 번호를 발명하지 않는다. 그래서 단원 연결의 `process_id`는 null이며, 128공정 참조 표에만 기존 정확한 ID가 있다.

공정 이미지·건물 형상·원본 해시는 보존한다. 소유·가격·통화 지급·기존 공정 자격·마이그레이션은 이 패키지에서 정하지 않는다. 이야기 공개 조건은 기존 본편 상태가, 건축 소유는 기존 건축 시스템이 판단한다.
