## 재생성·검증

저장소 루트에서 실행한다. 소스는 작업 디렉터리의 최신 파일을 임의로 섞지 않고 위 기준 SHA의 Git blob으로 읽는다.

```powershell
rtk proxy python -X utf8 docs/learning/ildu-season1-content-20261030/integration-20261102/build_package.py
rtk proxy python -X utf8 docs/learning/ildu-season1-content-20261030/integration-20261102/validate_package.py
```

`build_package.py`는 기존 34개 통합 패킷과 연결표·검토본을 재생성한다. 새 18개 저자 원고를 덮어쓰지 않는다. 기존 패키지의 119개 동결 파일은 수정하지 않는다. 이 폴더의 `.gitattributes`는 기록한 SHA-256과 Git에 저장되는 원고 바이트가 같도록 줄바꿈 자동 변환을 막는다.

정적 PASS는 개수·언어 필드·정답 ID·출처·동결 파일·R16 ID 검사 결과다. 새 18단원과 변경한 공통 문구는 작성자 외 모델의 의미 검토와 수정 재확인을 별도로 기록했다. 사람 원어민·교사 승인, 녹음 청취, 학습자 실험, Flutter·기기 검증은 수행하지 않았다. 기존 100단원 서사에서 그대로 인용한 문구는 기존 QA 상태를 유지하며 이번 검토로 자동 승격하지 않는다.
