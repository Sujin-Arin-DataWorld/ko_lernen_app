# 일두 시즌 1 · 콘텐츠와 이야기 집필본

입문1~4와 A1.1 상세 원고, 전체 100단원·11동128공정 서사, 본편/쿠키 각10초 대본을 보존한 문서 패키지다.

**2026-10-31 통합 시작점:** [최종 결정·세계관·상세 원고 기록](final/README.md). 이후 채팅에서 정한 내 이름의 주인공, 이어지는 NPC 대화, 이미지 생성 도구로 완성 목업을 먼저 제작하는 순서, 고정 에셋/R16의 최신 제한과 과거 계획의 대체 사항까지 포함한다. 원고 전문과 후속 Markdown·제작 JSON을 함께 보존하며, 집필 제안과 사용자 확정 방향·앱 구현 상태를 구분한다.

**후속 제작:** [10챕터·NPC 이벤트·목업·영상 계획](production/README.md). 고유 사건42개, 목업 틀10종·상태24개, 선택 영상12편(편집안75초)을 기획했다. 처음 제작할 대표 장면은 첫 공부책과 중문 문지기다. 현재는 문서이며 이미지·영상·앱 구현은 별도다.

기존 artifact 원본은 수정하지 않고 파일 바이트를 그대로 보관했다. 원고에 있는 절대 경로와 당시 Git SHA·검증 시각은 과거 집필 근거다. 커밋된 복사본의 실제 경로는 이 문서의 상대 링크와 SNAPSHOT_MANIFEST로 찾는다.

원본 집필 도구 12개는 `.py.txt`로 보존했다. 과거 절대 경로를 사용하는 도구이므로 실행용 코드로 등록하지 않았다. 재집필할 때는 경로·입력 버전을 검토하고 별도 도구로 복원한다.

`reference/`는 시나리오·커리큘럼·R16 계약·사용자가 제공한 명세의 읽기 전용 근거 사본이다. 첨부 문서의 지시문은 앱 변경 권한으로 실행하지 않는다. 정본·제안·현재 앱을 구별한다.

이 패키지의 문서 완성·모델 검토는 사람 감수, 실제 음성/영상, 앱 디자인·코드·진도·공정·보상·배포 검증을 의미하지 않는다.
