## 공통 장면과 이해 도움

일두고택의 접근 가능한 마당. 현대의 연습 소리표가 뒤섞였다. Joy는 소리표가 제자리에 놓이면 반응한다. 오래된 유물이나 사료가 아니라 **현재의 학습 소품**이다. 숨은 역사 지식을 알아야 시작하는 사건이 아니다. 필수 사건은 마당에서 해결되며 미완공 건물 내부 접근을 요구하지 않는다.

이 장면은 [역사 원본](../reference/HISTORY_AND_FIRST_STEPS.md) §4~6과 [시즌 연결 명세](STORY_LEARNING_LINKS.md)의 H0에 연결한다. 중심 이야기는 〈일두 — 지워진 목소리〉다. 학습용 소리표와 역사 미스터리의 창작 낱장은 별개의 물건이며, 아/어를 맞혔다고 역사 암호를 푼 것으로 연출하지 않는다.

## 문자 수업 열 개의 공통 제작 순서

`-T1/T2`는 순차 시범, `-P1/P2`는 도움 연습, `-I1/I2`는 독립 시도, `-R1`은 다른 날의 재확인이다. 각 접미사 앞에 아래 수업 ID를 붙인다. 자모 2개를 새로 배우더라도 첫 자모의 뜻/소리/배치를 본 뒤 두 번째로 간다. 비교는 둘 다 가르친 뒤다.

1. 목표를 설명 언어로 안내하고 오늘의 작은 행동을 보여 준다.
2. **소리를 먼저 한 번 들려주고** 해당 글자와 조립 시범을 보여 준다. 실제 감수 음성이 없으면 청취 확인 과제를 활성화하지 않는다.
3. 배운 조각을 하나씩 따라 놓고 필요한 만큼 반복한다. 이것은 연습이다.
4. 목표 관련 정답 도움을 닫고 별도의 문항으로 시도한다. 건너뛰거나 도움으로 해결할 수 있다.
5. 장면이 해결된 결과와 확인된 능력을 별도로 기록한다.
6. 다른 날에는 `-R1`의 새 배열/대상으로 다시 확인한다. 새 단어의 뜻은 필요하면 먼저 가르친다.

`F0.2.tree-and-hat` 이후에는 현재의 정리 상자에 **살아 있는 나무의 그림 표지**를 붙인 가상 상황에서 배운 나무를 사용하고 H2의 창작 낱장 발견으로 이어갈 수 있다. 나무로 만든 상자의 재료를 묻는 과제는 이 수업에서 가르친 뜻과 다르므로 넣지 않는다. 낱장의 본문·인물·연대는 이 단원의 읽기 평가 대상이 아니며 설명 언어로 제공한다. 표지를 맞힌 결과, 낱장 발견, 뒤의 다른 그림에서 낱말을 다시 알아본 결과는 별도로 남긴다.

## A1.1-01: 이름을 제대로 듣고 다시 만나기

### Scene Lock

- 현재 마당에서 처음 만난 플레이어와 수진. 대면 대화, 처음 만난 동등한 성인, 해요체. 사용자의 개인정보 입력·실명 공개는 요구하지 않는다. 가명·선택한 이름을 허용한다.
- 수진의 데이터 분석·앱 개발 정체성과 기존 관계는 바꾸지 않는다. 이 장면에서 교사·직원이라는 직책을 새로 부여하지 않는다.
- 목표: 인사→자신을 나타내기→놓친 말을 다시 요청→확인. 명사문은 이름 뒤 형태를 시범으로 익히고, 은/는·이/가 선택 빈칸은 내지 않는다.
- 선행: ORAL-START. 읽기·입력 과제 선택 시 해당 이름의 자모·받침을 먼저 가르친다. 문해가 아직 준비 안 된 사람도 음성/도움 경로로 같은 사건에 참여한다.

### 시범 대본 T1

| 차례 | KO | EN 의미 안내 | DE 의미 안내 | 기능 |
|---|---|---|---|---|
| 수진 | 안녕하세요. 수진이에요. | Hello. I'm Sujin. | Hallo, ich bin Sujin. | 인사·이름 알림 |
| 플레이어 시범 | 안녕하세요. 마야예요. | Hello. I'm Maya. | Hallo, ich bin Maya. | 기존 인물 이름을 활용한 명사문 시범. 플레이어를 마야로 고정하지 않음 |
| 수진 | 반가워요. | Nice to meet you. | Schön, Sie kennenzulernen. | 상대에게 반가움 표현; 이번 생산 필수 아님 |

받침 있는 수진 뒤 이에요와 받침 없는 마야 뒤 예요를 소리·표기로 나누어 시범한다. 이 구별을 아직 읽기 어려우면 자기 이름 한 가지 표현을 도움으로 익힌다. 어미 전체 활용 숙달로 확대하지 않는다.

### 시범 대본 T2: 놓친 이름

| 차례 | KO | EN | DE |
|---|---|---|---|
| 안내 | 이름을 못 들었어요. 다시 부탁해 봐요. | You missed the name. Ask to hear it again. | Du hast den Namen nicht verstanden. Bitte darum, ihn noch einmal zu hören. |
| 플레이어 | 다시 말해 주세요. | Please say that again. | Sagen Sie das bitte noch einmal. |
| 수진 | 수진이에요. | I'm Sujin. | Ich bin Sujin. |
| 플레이어 | 수진 씨? | Sujin? | Sujin? |
| 수진 | 네. | Yes. | Ja. |

고의로 잡음·작은 음량을 넣어 접근성을 떨어뜨리지 않는다. 상황 안내로 “못 들었다”는 조건을 주고 회복 행동을 연습한다. 청취 평가에서는 감수된 정상 음성을 사용한다.

### P: 도움받은 대화

P1. 인사 상황을 보여 주고 `안녕하세요 / 감사합니다`의 **뜻을 모두 가르친 뒤** 알맞은 행동을 선택한다. 이 장면에서는 인사가 목적이다. 감사가 무조건 잘못된 한국어라는 설명은 하지 않는다.

P2. 이름 뒤 표현을 모형과 함께 연습한다. 마야예요·수진이에요처럼 가르친 두 예를 비교하고, 자기 이름은 필요한 발음/표기 도움을 제공한다. 이름을 무조건 한글로 바꾸어야 진행하는 조건은 없다.

P3. 이름을 놓친 상황에서 재요청을 사용한다. 도움 버튼은 정답 음성을 들려주고 해당 시도를 도움받은 사용으로 기록한다. 이어서 실제 상대의 반복 응답이 나와야 행동의 목적이 보인다.

### I: 다른 예에서 확인

| ID | 제시·응답·허용 범위 | 관찰 결과와 범위 |
|---|---|---|
| A1.1-01-I1 | 배운 이름 수진·마야의 감수 음성 중 하나를 자막 없이 제시. 음성/초상 대상 선택. 초상-이름 연결은 먼저 지도 | 해당 두 이름의 청취 인식. 자막을 열면 독립 청취로 기록하지 않음 |
| A1.1-01-I2 | 새 만남 상황, 정답 문구 없이 인사/자기 이름을 선택 또는 말하기. 열린 발화는 안녕하세요, 안녕하세요. ○○예요/이에요 등 장면에 맞는 응답 인정 | 선택은 의사소통 기능 선택, 발화는 연습·사람 평가 전 미평가. 둘을 같은 능력으로 합산하지 않음 |
| A1.1-01-I3 | “상대 이름을 못 들었다”는 새 상황. 익힌 인사·감사·재요청 중 필요한 행동 선택 또는 직접 말하기. 다시 말해 주세요/한 번 더 말해 주세요는 의미상 가능하나 후자는 새 표현이면 도움 설명 | 회복 행동 달성. 배우지 않은 표현 사용 자체를 오류로 만들지 않음. 특정 조사 산출 시험 아님 |
| A1.1-01-I4 | 자기가 선택한 이름을 새 상대에게 알린다. 처음 이름 표기를 준비할 때는 도움 허용. 확인 과제에서는 준비한 표현을 보이지 않고 말하거나 구성한다. 자기 이름을 공개하지 않으려면 가명 사용 | 자기 식별 표현의 수행. 이름 카드를 복사하면 도움 연습. 말하기는 사람 평가 전 미평가이며 인사 선택 성공으로 대체하지 않음 |
| A1.1-01-I5 | 상대가 알려 준 배운 이름을 확인한다. 수진 씨?처럼 확인 질문 또는 같은 기능의 응답을 사용하고 네/아니요에 따라 확인·재요청한다 | 상대 이름 확인과 수리. I1의 단순 이름 인식과 별도 결과 |

개별 문항의 필수 슬롯은 I2의 인사, I3의 재요청, I4의 선택한 자기 이름, I5의 상대 이름 확인으로 다르다. **단원의 전체 목표는 인사·자기 식별·재요청·확인 네 행동**이며 인사 하나만으로 전체 독립 수행을 부여하지 않는다. 각 행동의 도움·독립·미평가 상태를 따로 남긴다. 모국어 억양·철자 선택을 근거 없이 실패로 처리하지 않는다. 반가워요의 생산은 이 네 행동의 필수 조건이 아니다.

### X: 사건 속 사용과 전이

X1. 수진에게 모자 표지를 돌려주고 다시 만나면 인사를 선택한다. 소품 해결과 구어 수행은 별도 기록이다.

X2. 크리스티안을 새로 만나 인사하고 이름을 확인한다. `크리스티안`의 소리·초상 연결은 이 장면에서 먼저 알려 준다. 이를 듣고 이름을 골랐다고 미학습 글자 해독을 확인하지 않는다. 새 상대라는 변화 속에서 이미 배운 인사·재요청을 사용한 것이 목표다. 크리스티안을 늘 실수하거나 교정받는 사람으로 그리지 않는다.

X3. 소리 사용 불가 시 설명 언어로 장면을 이해하고 텍스트/행동 대안으로 인사·재요청 의도를 고른다. 이야기 진행과 목적 선택 연습은 가능하며 독립 청취·발화 근거는 생기지 않는다.

### R: 이후 회수

- `A1.1-02/R-A1.1-01`: 새로운 소개에서 언어·출신보다 먼저 이름과 인사를 확인. 질문을 놓쳤을 때 재요청한다.
- `A1.2-06/R-A1.1-01`: 약속 시간이 바뀐 음성에서 못 들은 숫자를 다시 요청. 새로운 숫자는 별도 선행 수업을 거친다.
- 다른 날 `A1.1-01-R1`: 첫 화면과 같은 보기 위치를 쓰지 않고 새 상대/새 장소의 인사와 회복 행동을 확인. 자기 이름을 다시 외우게 하는 과제가 아니다.

### 의미·말투 감사와 남은 검증

KO↔EN↔DE의 인사·이름·재요청·긍정 기능, 시제, 행위자가 일치하도록 작성했다. 앱 안내의 du와 처음 만난 인물 간 대사의 Sie를 분리했다. 한국어 요체와 Sie가 언제나 일대일이라는 설명은 하지 않는다. 수진·마야·크리스티안의 기존 정체성에 새 직책·관계를 더하지 않았다.

이 대본은 저작자 자체 점검 단계다. 독립 한국어 교원, EN/DE 검수자, 실제 입문자의 결과는 아직 없다. 이름 음성·모음 대비·그림 인식·재요청 이해를 실제 매체에서 확인해야 공개할 수 있다. 문서의 정답표는 자동 채점 서비스 구현을 의미하지 않는다.
