# 가르친 범위와 확인된 능력을 구별하는 계약

## 시작 조건

모든 실제 문항은 `item_id, objective_id, content_revision, taught_by, required_symbols, required_words_and_senses, required_grammar_functions, required_control, modality, relationship, help_policy, accepted_response_policy, evidence_scope, later_probe_id`를 가진다. 요구 어휘는 표제어뿐 아니라 **뜻과 활용형**, 문법은 표면 형태뿐 아니라 **현재 기능**을 기록한다. 제안서의 대표 예문을 그대로 독립 평가에 넣지 않는다.

`ORAL-START`는 설명 언어 선택, 음성·대안 선택, 한 번 눌러 응답하는 조작 시범을 뜻한다. 한국어 글자를 읽는 능력을 요구하지 않는다. 구어 덩어리로 익힌 안녕하세요·감사합니다·다시 말해 주세요를 문자 해독 근거로 승격하지 않는다.

각 문항의 준비 판정은 요구 능력마다 `이미 확인됨 / 이번 활동에서 가르침 / 도움으로 수행 / 아직 준비 안 됨`을 읽는다. 미준비면 짧은 준비·도움받고 계속·나중 보충을 제공한다. 단원 ID나 선택 레벨만으로 준비됐다고 추정하지 않는다. 이야기 지문에 새 말이 있으면 번역·시범으로 이해시키되 그 말을 평가 범위에 넣지 않는다.

## 활동과 근거

| 활동 | 기록할 것 | 기록하면 안 되는 것 |
|---|---|---|
| 시범 보기·정답 따라 놓기 | 접함, 어떤 시범을 봤는지 | 독립 해독·쓰기 합격 |
| 번역·정답 예시를 보며 대화 해결 | 도움받아 목표 수행, 이야기 결과 | 자유 발화·어휘 회상 합격 |
| 자막 없이 감수된 음성 듣고 대상 선택 | 해당 소리/의미의 청취 식별, 재생 횟수와 도움 | 발화·문법 생산·전 구간 숙달 |
| 한글을 보고 대상 선택 | 해당 글자의 인식 또는 배운 단어 의미 연결 | 듣기 능력 |
| 새 조합을 정답 공개 없이 조립 | 익힌 자모의 결합; 사용한 힌트 | 자유 작문·발음 확인 |
| 모사·복사 입력 | 입력 조작·복사 연습 | 보지 않고 쓰기 |
| 뜻·상황만 보고 배운 표현 재구성 | 제한된 어휘/문장 재구성 | 자유 담화 능력 전체 |
| 열린 말하기·글쓰기 | 연습/포트폴리오; 평가자 있을 때 rubric과 원 근거 | ASR 결과·캐릭터 반응만으로 독립 통과 |
| 새 상황·새 화자에서 나중에 수행 | 목표별 전이·유지 시도와 조건 | 보기 순서만 바꾸고 생활 전이라 주장 |

재생만 반복하는 도움과 정답을 보여 주는 도움을 나눈다. 정답 노출·번역·모형 음성·시범 동작·첫 글자 제공은 무엇이 평가 목표인지에 따라 별도 도움으로 기록한다. 예를 들어 듣기 문제의 한글 자막은 청취 독립성을 바꾸지만 읽기 과제의 상황 그림은 항상 정답 도움인 것은 아니다. 항목별 도움 효과를 사전 선언한다.

## 네 가지 결과

1. **학습 활동 완료**: 정해진 가르침·연습 흐름을 경험했다.
2. **도움받아 수행**: 목적을 달성했지만 목표 관련 도움을 사용했다.
3. **독립 수행 확인**: 활동 시작 시 허용된 평가 범위 안에서 원 응답과 평가 기준을 충족했다.
4. **나중에도 유지·다른 맥락에서 사용**: 원 독립 시도와 연결된 별도 시도다. 시간만 지났다는 이유로 자동 부여하지 않는다.

일반적인 자동 80% 합격선을 만들지 않는다. 객관 문항은 실제 요구 항목별 성공 여부를 남기고 중요한 오류를 합산으로 상쇄하지 않는다. 열린 수행은 아래 네 축을 각각 `도움 필요 / 일부 수행 / 이 과제에서 독립 수행 / 미평가`로 남긴다. 말하기·쓰기 미평가는 0점도 합격도 아니다.

| 축 | 확인할 행동 | 실패·보충 예 |
|---|---|---|
| 정보 이해 | 실제 필요한 사람·물건·시간·조건을 정확히 찾음 | 날짜 오해면 숫자·시간 부분만 다시 지도 |
| 목적 달성 | 인사·요청·설명·합의 등 과제의 행동을 끝냄 | 문법은 맞아도 반환 대상이 다르면 확인 질문 연습 |
| 적절한 사용 | 관계·말투·출처·확신이 장면과 맞음 | 들은 말을 직접 봤다고 말하면 출처 전달 보충 |
| 확인·수리 | 이해 안 된 점을 묻고 오류·불확실성을 고침 | 모른다는 이유로 감점만 하지 않고 회복 행동 확인 |

객관 문항의 오답은 정답과 같은 배운 범위에서 만들고 문맥상 가능한 다른 답을 배제한다. 열린 과제는 의미·화행·관계가 같은 여러 답을 인정한다. 받아쓰기는 들은 어휘·순서를 보존하는 표면 변형만 인정한다. 새 형태를 먼저 가르치지 않은 조사 빈칸은 출제하지 않는다.

## 전이와 복습

각 단원의 `transfer`는 **새 활동을 제작할 명세**다. 실제 문항·음성이 없으면 설계 상태로 남긴다. `review_in`은 회수할 단원이고, 그곳에 `R-원단원ID` 활동을 제작해야 연결이 완성된다. 단순히 다음 단원 ID가 존재하는 것은 재사용 증거가 아니다.

문자 첫 두 음절은 가능한 새 조합이 없으므로 배열·음성 차례 변경을 재인으로 기록한다. F0.2부터는 시범에 없는 결합을 확인한다. 배운 단어의 의미 전이는 다른 실제 대상 그림과 음성을 써야 한다. F0 이후는 화자·상대·목표·자료 중 하나 이상이 달라져 답을 그대로 암기해 적용할 수 없는 과제를 만든다. 언어 목표와 무관한 전문 지식·새 게임 조작을 추가 난도로 넣지 않는다.

복습은 같은 활동 끝의 짧은 회상, 다른 날의 재확인, 이후 생활 맥락의 사용을 구분한다. 24시간·며칠·다음 주 같은 간격은 초기 운영 가설이며 학습자의 수행·부담 관찰로 조정한다. 정확한 간격이 효과를 보장한다고 말하지 않는다. `REVIEW-C2-CONTEXT`는 C2.2 이후 새 자료 묶음을 선택하는 후속 과제 슬롯이며 현재 제작 완료 콘텐츠가 아니다.

## 저장·복구와 완료 분모

기존 `CourseMastery` v5와 확장 기록의 소유권 계약을 유지한다. 교육 설계 데이터는 runtime으로 자동 연결하지 않는다. 실제 활동은 `operation_id, owner_id, content_revision, allowed_scope_at_start, raw_response, assistance, assessment_result, evidence_reference`를 저장하고 같은 작업 ID 재시도에 같은 결과를 반환해야 한다.

원 근거 없는 요약만으로 독립 확인을 복원하지 않는다. 이야기는 도움으로도 진행할 수 있고 반복 플레이·선택 에피소드는 진도 분모와 보상을 늘리지 않는다. 필수 단원이 미제작이면 구간 전체 완료가 아니다. 대체 활동은 같은 목표를 한 번만 센다. 개정된 과제는 과거 성취를 삭제하지 않고 현재 기준의 재확인을 별도 표시한다. 기능별 독립 확인과 단원 완료 수는 따로 표시한다.

계정 전환·오프라인·중단·원 근거 저장 후 후속 저장 실패·구버전 백업/복원·삭제는 구현 단계의 필수 검증이다. 현재 교육 설계 문서의 완성은 이 저장 구현 검증을 대신하지 않는다.
