# 구간별 학습 범위와 기대 결과

상태: 교육 설계 후보. 한국어 교원 감수·EN/DE 학습자 관찰 전이다. F0는 자체 입문 구간, A1~C2 및 `.1/.2`는 한글소리의 표시 구간이다. 한국어 표준 교육과정 급수나 TOPIK과 환산·인증하지 않는다. 아래 기대 결과는 **가르치고 확인할 목표**이며 등록·활동 완료만으로 획득했다고 표시하지 않는다.

## 단원을 읽는 법

`UNITS.psv`의 72개 단원과 `FOUNDATION.psv`의 28개 단원은 **100개 제작 묶음**이다. 한 행을 한 화면·한 문제·한 번의 학습으로 만들지 않는다. 한 묶음에 여러 문법이 배정되어 있으면 기능마다 `의미와 시범 → 도움 연습 → 다른 예`를 먼저 제작한다. 통합 과제는 그 뒤다. 특히 C1.2-02의 양보·첨가·대안·경고는 최소 네 하위 묶음이며, 배정된 표현을 한 번에 도입하지 않는다.

각 단원의 목표·어휘·예문·연습·전이 설계는 저작 자료다. 핵심 어휘는 제작 범위의 출발점이며 **폐쇄된 전체 어휘 목록이 아니다**. 실제 출제문·오답·음성 대본의 모든 요구 항목은 `ASSESSMENT_CONTRACT.md`의 문항 계약으로 확정한 뒤 공개한다. 기존 문법 링크는 사용할 후보의 위치이며 새 단원 콘텐츠 완성 증거가 아니다.

학습자가 상위 구간을 선택하면 그 구간의 목표를 유지한다. 아래 선행 조건은 준비·도움 추천용이다. 선택·이야기 접근을 잠그지 않으며 부족한 능력을 몰래 통과 처리하지 않는다. 잘 아는 사람은 새 문항으로 해당 능력을 확인하고 반복을 줄인다.

일두고택의 중심 사건은 사용자 [시즌 1 v3.0](../reference/SEASON1_V3_20261024.md)의 연이·도깨비 이야기이며, [전체 제작 계획](../../../superpowers/plans/2026-10-24-ildu-season1-v3-curriculum.md)과 [100단원 연결표](../season1-v3/UNIT_STORY_MAP.csv)를 따른다. 이전 H0~H6는 비교 이력이다. 아래 16구간은 사건의 잠금 단계가 아니다. 입문자도 번역·그림·도움으로 결말에 참여하며, 상급 첫 방문에는 같은 목표의 스포일러 없는 현대 활동을 제공한다. 역사 원본의 옛 입문 12묶음은 범위 참고로, 현재 문자 순서·구어 병행은 교육과정 원본과 FOUNDATION을 따른다.

## 분량·재미·중단 기준

첫 설계 가설은 새 자모 2~3개 또는 한 문장 틀과 핵심 단어 3~5개다. 과학적으로 검증된 한계나 모든 사람의 최적 분량으로 주장하지 않는다. 표의 어휘·문법은 한 번의 투입량이 아니라 제작 묶음 전체의 범위다.

멈출 수 있는 최소 단위는 “한 소리표를 돌려놓기 / 한 사람의 이름 확인 / 변경된 약속 한 가지 확인”이다. 그 행동의 결과를 보여 준 뒤 계속할지 선택한다. 시간 제한·연속 정답·일일 출석은 필수 학습 조건이 아니다. 틀려도 건물·돈·단서가 사라지지 않는다. 이야기 보상은 실제 행동 결과, 능력 확인은 별도 증거로 남긴다.

새 조작은 언어 과제 전에 뜻을 아는 예로 연습한다. 설명을 읽는 중 캐릭터 대사·음성이 끼어들지 않는다. 소리·글자·뜻·문법이 동시에 새로우면 먼저 의미를 그림·번역으로 제공하고 목표 하나씩 연습한다. 초보자도 추리의 내용은 성인 수준으로 즐길 수 있도록 사건 이해를 DE/EN으로 지원한다.

2026-10-23 확인: [국립국어원의 한국어 표준 교육과정 게시물](https://m.korean.go.kr/front/etcData/etcDataView.do?etc_seq=657&mn_id=46), [Council of Europe CEFR 기술자 안내](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors), [온라인 세종학당 입문 과정 안내](https://www.iksi.or.kr/lms/crse/crseApply.do?crseNo=121341). 공식 자료는 교육과정과 수행 중심 설계의 참고 근거다. 한글소리의 100개 제작 묶음·순서·사건·분량은 이 프로젝트의 설계 결정이며 공식 기관이 인증하거나 정한 단원 수가 아니다. 웹 페이지 열람은 첨부 교재 전체와 모든 문법의 급수 검수를 대신하지 않는다.
