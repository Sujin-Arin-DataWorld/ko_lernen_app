# 일두 시즌 1 · 챕터 진행과 목업·영상 제작 계획

도깨비가 중문 앞을 막는다. “오늘은 내가 문지기다.” 플레이어는 이름을 소개하고, 놓친 말은 다시 부탁한다. 도깨비가 같은 말을 다시 들려주고 몸을 비켜 준다. **배운 말이 동료의 행동과 다음 사건을 바꾸는 순간**을 챕터의 기본으로 제안한다.

2026-10-30 기획안. 사용자가 요청한 집필본 커밋과 후속 제작 기획의 범위다. 현재 앱에 이 흐름을 구현하거나 이미지·영상·새 캐릭터를 생성한 결과가 아니다.

## 한글소리에 맞는 RPG 진행

**NPC/사물 발견 → 짧은 부탁 → 필요한 말·소리 준비 → 도움 연습 → 상황에서 사용 → NPC의 구체적 반응 → 보고·장면 저장 → 다음 사건.**

테일즈위버의 공식 가이드는 NPC에게 임무를 수락하고 진행 상황을 확인한 뒤 다시 보고하는 흐름, 미니맵의 퀘스트 안내를 설명한다. 여기서는 그 구조를 학습 행동에 적용한다. 인물·그래픽·문양·대사를 옮겨 쓰는 방식으로 삼지 않는다. [Nexon 공식 퀘스트 가이드](https://static.tales.nexon.com/GameGuide/Guide3?tp=web)

| 층 | 플레이어가 이해할 것 | 저장·판정 원칙 |

| 본편10화 | 누구에게 돌아가며 어떤 사건을 알아가는가 | 공개된 사실과 보고 상태로 이어짐. 다음 반전은 정본 순서에서만 공개 |

| 11동128공정 | 집을 복원하는 개인 건축 과정 | 기존 공정·재화·소유 조건의 별도 영역. 챕터가 열렸다고 자동 지급하지 않음 |
| 다음 날 복습 | 다른 날에도 같은 기능을 써 볼 기회 | 새 챕터를 막는 의무 퀘스트가 아님. 누락해도 집·친구·기록 유지 |

초보자는 시범·번역·선택·지원 낭독으로 같은 이야기에 참여할 수 있다. 독립 수행은 실제 근거가 있을 때 별도로 남긴다. 도깨비의 기억100%는 서사의 결말 연출이며 한국어 숙달100%나 실제128공정 소유를 의미하지 않는다. v3.5 AP-1의 ‘완공률로 결말을 잠그지 않음’을 지킨다.

이야기의 첫 `집` 쪽지를 만났을 때도 학습 순서를 강제로 건너뛰지 않는다. 뜻·소리·자모/받침·입력 조작 준비를 확인하고, **먼저 배우고 돌아오기** 또는 **도움받아 쪽지 남기기**를 고른다. 미준비 상태에는 독립 회상 문항을 제안하지 않는다. 지원으로 본 정답은 이후 수업의 노출 이력에 남긴다. 같은 줄거리의 경험과 정상 입문1→2→3→4 학습 경로를 함께 보존한다.

## 첫 제작은 두 장면을 끝까지

**첫 번째: 사랑채의 첫 장.** 수진과 공부책을 만남 → ‘아’의 소리·모양·조립 → 말하거나 도움으로 참여 → 탈선비가 깨어남 → 동료가 다시 만났음을 보여 줌 → 다음 작은 부탁. 프롤로그와 본편에서 같은 각성 사건을 두 번 지급하지 않는다.

**두 번째: 중문간채 중간의 문지기.** 이미 아는 도깨비의 역할 놀이 → A1.1 소개·재요청 → 같은 내용의 실제 반복 → 도깨비가 비켜 섬 → 확인된 본편 사실 저장. 완공 E04의 폭풍·인영·30%는 이때 열지 않는다.

이 둘을 목업에서 끝까지 따라가 보면 ‘챕터 목록만 있는 앱’과 실제로 말이 사건을 바꾸는 흐름의 차이를 검토할 수 있다. 다음 단계의 Flutter 작업은 이 흐름의 학습 원본·상태·실패·복귀까지 확인하는 별도 범위로 둔다.

## 목업 이미지의 순서

처음부터128개의 화면을 새로 그릴 필요는 없다. **공통 학습 화면과 NPC 대화·결과의 틀을 먼저 정하고, 장면과 소품을 교체**한다. 화면 시안 수와 캐릭터 PNG·배경·소품·영상 키프레임 수는 각각 센다.

먼저 공부책 만남과 문지기 장면의 기본/도움 상태를 나란히 만든다. 이후 같은 질문을 유지한 오답 재시도, 저장 미확인, 중단 후 복귀, 다음 날 복습, 다시 보기까지 확장한다. 챕터 진입·결말·자료 비교는 해당 흐름이 검토된 뒤 추가한다. 정확한 프레임·상태 수는 [목업 표](MOCKUP_MATRIX.csv)를 기준으로 삼는다.

승인된 C안의 한지·목재·금색·입체적인 면과 눌림을 보존하되, 문장과 응답의 위치는 안정되게 둔다. 실제 한글·버튼·영어·독일어 안내는 합성 가능한 텍스트 층으로 둔다. 캐릭터나 한옥 구조를 다시 생성해서 기존 정본을 대체하지 않는다.

Android 공식 지침의 48dp 터치 영역, 제스처 외의 명시적 조작, 텍스트 대비와 확대를 검토 기준에 적용한다. 문서 확인일은 2026-10-30이며 해당 접근성 페이지의 표시된 갱신일은 2023-05-08이다. 실제 시안·작은 화면·기기 검증을 아직 수행하지 않았다. [Android 접근성 지침](https://developer.android.com/design/ui/mobile/guides/foundations/accessibility)

## 영상은 사건이 달라지는 곳에

상시 인사·문항·매번의 정답은 기존 PNG와 작은 반응으로 충분하다. 탈선비 각성, 첫 등불, 폭풍의 제한된 기억, 신수들의 구출, 마지막 편지의 여운, 빗장 수리·문 개방은 영상의 우선 후보이다. 같은 3초 리액션을 모든 답마다 강제 재생하지 않는다.

**배경과 기계적인 문 움직임은 승인된 R16 Blender 장면에서, 인물의 작은 반응은 정본 PNG 합성에서, 바람·안개 같은 보조 움직임은 참조 이미지 기반 영상 시험에서, 최종 길이·대사·자막은 편집 프로젝트에서** 만든다. 정확한 한옥 구조·빗장 위치·손의 접촉은 생성 모델의 일관성을 가정하지 않고 보존된 장면을 우선 사용한다. 이는 제작 판단이다.

[Google Flow](https://labs.google/fx/tools/flow)는 참조·첫/끝 프레임을 사용해 짧은 영상 시험을 하기 위한 후보, [Runway](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5)는 이미지 기반 움직임의 비교 후보로 둔다. [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve)에서 컷·합성·소리·자막을 결합한다. 모델·요금·계정별 접근은 실제 생성 직전에 확인하며 이번 작업에서는 가입·결제·업로드·유료 생성하지 않았다. 기능·대체 방식·공식 출처는 [영상 제작 계획](VIDEO_PRODUCTION_PLAN.md)에 정리했다.

두 에필로그의 **각10초는 편집 마스터 길이**다. 한 번의 생성으로 긴 대사·세 컷·정확한 글자·손동작을 모두 해결한다고 가정하지 않는다. KO 음성, 선택 언어 자막, 무음 대체 설명, 포스터 프레임을 함께 제작한다. 영상 스킵·재생 실패·중단·동작 줄이기에서도 같은 사건의 뜻과 다음 행동을 제공한다.

## 현재 앱과 연결할 때 남은 것

현재 조사한 기존 `/hanok/construction`은 협문·창고 공정 아트를 보여 주는 경로다. 이 문서의 R16 챕터·NPC 보고·기억 장면이 이미 그 화면에 구현됐다는 뜻은 아니다. 기존 Lernen·Hanok 진입점을 보존하면서 본편 안내를 어디에 붙일지는 목업 흐름에서 검토한다.

프롤로그/학습의 공유 이벤트, 선행 사실, 도움 상태, 저장 확정, 재시도·다시 보기, 계정·오프라인 복구, 재화 소유를 실제 소유자 서비스와 연결하는 작업이 남아 있다. 상세한 현재 경로·HEAD·에셋 해시와 제안의 차이는 각 제작 문서에 기록한다. 코드·에셋·예산·사용자 승인과 실제 검증을 마친 뒤에만 앱 완료로 판정한다.
