## 이번 검증과 남은 문턱

실제 픽셀을 연 것은 JSON `visual_review_this_task: true`에만 표시했다. 이 출처 조사 단계에서 생성·원본 수정은 0회다. 후속 [참조팩](ASSET_LOCK_LIST.md)에는 선택한 기존 파일의 바이트 동일 사본만 넣었다. JSON `current_task_generation_authorized: false`는 이번 목록 작업에서 생성을 실행하지 않았다는 범위 표시이며 파일의 영구 사용 적격성 판정이 아니다. 미확정 역할은 별도의 `source_status`와 `pending_roles`에 유지했다. Flutter·모션·실기기·CI·배포·전체 UI 승인을 뜻하지 않는다.

근거 파일의 현재 SHA는 JSON `evidence_sources`에 있다. 부모가 실행한 증분 변경 목록을 재사용했고 전체 이미지 재분류나 보관소 복원은 수행하지 않았다.
