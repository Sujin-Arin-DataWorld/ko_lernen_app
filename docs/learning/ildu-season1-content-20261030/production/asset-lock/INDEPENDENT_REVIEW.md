# 원본 고정 패키지 독립 검토

2026-10-30. 작성에 참여하지 않은 `/root/a11_content_review`가 파일을 읽고 검토했다. 초기 검토와 연이·수호기와 설정집 보충 검토 모두 모델 검토를 통과했다. P1/P2 수정 요청은 0건이다. 사람의 최종 미술 감수나 파생 에셋의 승인은 아니다.

검토한 범위는 캐릭터5명+현대11명에서 수진 중복을 제외한15정체성, R16 원본 보존, 솟을대문9/14 승인과 협문 구분, 새 동작/소품의 pending 상태, KO/EN 지시문의 의미 일치, 스포일러/학습 진도/보상 분리다. 참조팩에 들어간 파일과 ZIP의 원본 SHA, CSV/manifest 경로 수를 확인했다. 대형 native 전체 재해시는 이 검토자가 중복 실행하지 않았고 원본 조사 및 아래 별도 무결성 검사를 사용한다.

반영한 명료화는 `generation_input_allowed`를 `current_task_generation_authorized`로 바꾼 것이다. 이번 목록 작성에서 생성하지 않았다는 범위와 파일의 향후 사용 적격성을 구분했다. 실제로 미확정인 역할은 `source_status`/`pending_roles`에 남겼다.

보충 검토자는 `연이의 흔적과 도깨비 수호 문양 설정집.png`를 직접 열어 수호기와6종/시점, 묶인 편지·꽃무늬 씨앗주머니·손수 만든 물건이 설명과 일치함을 확인했다. 시트는 `REFERENCE_ONLY_ROLE_PENDING`이며 개별 정본·S1 역할·대문 부착을 확정하지 않는다. 최종 수량은378개 경로, 원본과 같은 바이트의 참조59개, 상징/소품/아이콘의 미확정 역할10개다. 캐릭터/동작의 미확정 항목은 별도로 관리한다.

기계 검사는 [VALIDATION.json](VALIDATION.json), 실제 출처와 상태는 [전체 목록](ASSET_LOCK_LIST.md) 및 각 JSON을 본다. 검토자는 원본·파일·Git·메모리를 수정하지 않았다. 앱 렌더·기기·Blender 동작·학습 효과·배포 검증은 포함하지 않는다.
