# 제작 AI 전달문 · 한국어

참조팩에서 **이번 작업에 필요한 파일만 실제 첨부**하고 아래 빈칸을 채워 전달한다. 로컬 경로·해시는 파일을 식별하는 목록이며 외부 AI에 이미지를 전달하는 수단은 아니다. 전체 팩이나 여러 인물의 얼굴을 한꺼번에 스타일 참조로 섞지 않는다.

## 작업 카드

```text
프로젝트: 한글소리 · 일두 시즌1
작업 ID / 장면 / 챕터:
제작물: [정지 합성 / 투명 소품 / 영상의 시작·끝 프레임 / 별도 동작 후보]
인물 ID + 실제 첨부 파일:
건물 키 + 공정 ID/번호 + 단독형/연결형 + 실제 첨부 파일:
장소/배치 참조(필요할 때만):
등장 소품 ID + 역할 상태 + 실제 첨부 파일:
고정할 원본 프레임:
이번에 바꿀 것(최소 범위):
출력 크기 / 화면비 / 길이 / 투명 여부:
텍스트·음성·자막 별도 납품 여부:
아직 원본이 없는 부분:
```

## 공통 지시문

```text
새로운 스타일을 발명하는 작업이 아니다. 첨부한 한글소리 원본의 인물 정체성, 건축 구조, 소품 정체성과 재료를 보존한 제작 작업이다. 작업 카드에 적힌 변경만 수행한다. 원본 파일을 덮어쓰지 않고 새 산출물은 파생 후보로 분리한다.

참조의 역할을 분리한다. 캐릭터 이미지는 그 인물의 얼굴/몸/의상/소품 기준, 건물 PNG와 native는 해당 건물/공정의 구조 기준, 고택 배치 이미지는 위치 관계 기준, C안 화면은 화면의 재료/층/위계 기준이다. 화면 목업의 임의 글자·표시 금액·진도를 사실로 베끼지 않는다. 다른 인물의 옷·얼굴이나 다른 건물의 창호·지붕을 섞지 않는다.

캐릭터의 얼굴 윤곽, 눈/코/입, 머리와 몸 비례, 헤어, 피부/털/깃, 의상 색과 재질, 매듭, 신발, 소품, 문양의 수·위치·방향을 첨부 원본 그대로 고정한다. 좌우 반전으로 비대칭 디테일을 바꾸지 않는다. 요청한 표정/포즈만 최소한으로 바꾸고 손·날개·뿔·소품의 수를 늘리지 않는다. 원본에 가려진 뒷면이나 새 접촉 동작은 상상으로 정본화하지 말고 원본 필요로 표시한다.

태고는 원본의 흰 털/줄무늬/푸른 눈/가슴 문양을 유지하며 차분하고 보호하는 백호다. 조이는 원본의 까치·갓·끈·가슴 문양을 유지하고 날개는 정확히 두 개다. 도깨비는 두 짧은 뿔·머리띠·복식·나무 방망이의 원형을 유지한다. 탈선비는 하회탈의 나무 조각 형태·갓·도포·부채를 유지한다. 수진과 현대 페르소나는 각자의 지정 원본을 유지한다. 플레이어를 특정 페르소나 얼굴로 대체하지 않는다.

건물의 평면, 전체 비례, 동별 위치, 기단, 기둥 수/간격, 보/서까래, 문/창호의 위치와 격자, 지붕 곡선/기와/처마/연결부, 현판의 모양과 위치를 원본 그대로 고정한다. 수치를 그림에서 추정해 재설계하지 않는다. Blender 작업은 기존 객체 이름/수/계층/원점/변환/UV/내장 텍스처를 유지한다. 요청되지 않은 기하 수정·재메시·텍스처 재생성은 하지 않는다. 정확한 새 시점이 필요하면 원본 native를 사용한다. 단일 PNG만 있을 때 보이지 않는 측면/뒷면을 만들어 구조 일치를 주장하지 않는다.

선택한 공정의 부재만 표시한다. 사랑채·중문간채의 단독 지붕과 연결형 지붕은 지정된 별도 파일을 사용한다. 협문·사당문·솟을대문은 서로 다른 에셋이다. 문 개방·빗장 수리는 실제 축/접촉 위치/시작·끝 동작 원본을 확인한 후 제작한다. 협문 native를 솟을대문으로 바꾸어 사용하지 않는다.

따뜻한 목재, 한지, 비단, 기와/돌/벽체, 황동/금색, 청록의 원본별 차이와 입체적인 층·조명·접지감을 유지한다. 모든 건물을 같은 단청이나 판타지 장식으로 칠하지 않는다. F-A 자유 배치 가구 컷아웃에는 바닥/방/접지 그림자를 굽지 않는다. 필요한 그림자는 합성 장면의 별도 층으로 만든다. 투명도와 기존 크롭은 파일별 계약을 따른다. 모든 원본이 투명 전신 컷아웃이라고 가정하지 않는다.

세 소용돌이 엠블럼과 approved_cloud_spiral UI 아이콘을 혼동하지 않는다. 파일 정체성 확인과 S1 배지 역할 지정은 별도다. 두 번 빛나는 연출 때문에 소용돌이를 두 개로 줄이지 않는다. 수호기와·구름 배지·보통 소품을 서로 바꾸지 않는다. 연이의 씨앗 주머니·심지·천 같은 사물에 배지 문양/관인/마법 장식을 임의로 넣지 않는다. 편지 보관 주머니를 씨앗 주머니로, 장수 문구 편지지를 첫 집 쪽지/마지막 편지로 대체하지 않는다.

첫 '집' 쪽지는 같은 한 장의 참조를 끝까지 유지한다. '이 집' 연습과 구별한다. 한글/독일어/영어 안내, 학습 문항, 버튼, 현판의 정확한 글자, 편지 본문은 제공된 원고를 사용하는 별도 텍스트/합성 층으로 납품한다. 기존 원본 글자를 지우거나 추정해서 다시 쓰지 않는다. UI 그림에 가짜 진도·보상·잔액을 굽지 않는다. Nevi_Bar5는 다섯 개 이미지 아이콘만 표시하며 보이는 텍스트 라벨을 새로 넣지 않는다.

장면은 작업 카드에 지정된 챕터/공정 시점만 사용한다. 초반에 완공 집·첫 등불·각성 이후 상태를 앞당기거나, 중문 문지기 놀이에 완공 폭풍·기억30%를 넣지 않는다. 단서/편지/마지막 인사는 해당 집필본의 공개 순서를 따른다. 새 학습 판정·진도·재화 지급은 그림/영상의 역할이 아니다.

영상은 잠긴 원본 시작/끝 프레임과 지정 동작만 사용한다. 인물/지붕/창살/배지가 프레임마다 변형되면 불합격이다. 읽는 동안 반복 운동을 넣지 않는다. 대사·음향·자막은 편집 층으로 분리하고 무음/정지 포스터 대체도 제공한다.

납품: 사용한 첨부 파일명과 SHA-256, 보존 항목, 실제 변경 항목, 미확정 항목, 원본과 같은 조건의 비교 이미지 또는 주요 프레임, 레이어/편집 프로젝트를 함께 제출한다. 원본 이름을 새 결과에 덮어씌우지 않는다. 참조가 부족한 항목은 SOURCE_PENDING으로 남기고 임의 대체하지 않는다. 새 산출물은 검토 전이며 승인 정본·앱 통합·기기·배포 완료로 표시하지 않는다.
```

프롬프트는 변경 범위를 전달한다. 동일 얼굴·정확한 건물 구조를 보증하지 않으므로, 구조 보존이 중요한 장면은 원본 PNG 합성/Blender 렌더를 기본으로 하고 결과를 비교 검수한다. 이번 문서는 생성·업로드·결제·앱 변경을 실행하지 않는다.
