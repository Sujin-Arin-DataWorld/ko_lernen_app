## 기존 포즈·영상 파일 사용 범위

JSON의 폴더별 인벤토리는 현재 파일을 찾기 위한 목록이다. 폴더에 존재한다고 특정 감정/행동/챕터에 확정된 것은 아니다. 탈선비 12개 PNG, 도깨비 직접 파일, 백호·까치의 다른 포즈와 기존 영상은 파일별로 고른 뒤 장면과 연결한다. 변신·불꽃·엽전 하위 폴더를 일반 대화 포즈로 혼용하지 않는다.

핵심 5개 지정 이미지는 실제로 열어 얼굴·복식·소품·표면을 확인했다. 현대11명 전체의 새로운 시각 재감수는 수행하지 않았고 기존 승인 출처와 현재 바이트 연결을 검증했다. 수진 원본에는 배경이 있으므로 전원을 투명 컷아웃이라고 가정하지 않는다.

## 확정 원본이 더 필요한 부분

- 플레이어를 크리스티안이나 새 고정 얼굴로 대체하지 않는다. 사용자 설정/현행 표현을 따른다. (`NO_FIXED_FACE_REQUIRED`)
- 연이의 확정 인물 원화/턴어라운드 미확인. 쪽지·편지·자취 중심의 기존 연출을 유지하고 새 얼굴을 고정하지 않는다. (`SOURCE_PENDING`)
- 정여창의 확정 캐릭터 원화 미확인. 사실적 초상이나 판타지 캐릭터를 임의로 추가하지 않는다. (`SOURCE_PENDING`)
- 장면의 노인 확정 원화 미확인. 탈선비/도깨비와 합치거나 새 외모를 정본으로 삼지 않는다. (`SOURCE_PENDING`)
- 확정 얼굴/의상과 별개로 양팔/비켜섬/빗장 수리의 정확한 손 접촉 및 시작·끝 프레임은 아직 선택·검수되지 않았다. (`ACTION_REFERENCE_PENDING`)
- 원본 폴더의 실제 전신 파일을 장면별로 검토·선택해야 하며 흉상만으로 숨은 디테일을 만들지 않는다. (`POSE_SELECTION_PENDING`)

## 제작 AI에 보낼 공통 규칙

- 이 파일의 SHA는 원본 선택/동일 바이트 확인용이다. 생성 결과의 동일 인물/구조 보증 수단이 아니다.
- 불투명 배경·투명도·손/발 크롭을 원본대로 보존한다. 모든 원본을 투명 전신 PNG라고 가정하지 않는다.
- 가로 반전으로 문양·손잡이·머리띠/부채 방향을 바꾸지 않는다. 필요한 반대 방향 포즈는 기존 검토 원본을 선택하거나 별도 후보로 검수한다.
- 고정한 원본은 덮어쓰지 않는다. 새 동작이 요청되면 별도 파생 후보로 기록하며 장면별 검수 전 정본이나 앱 통합으로 간주하지 않는다.
- S1 인간/신수/도깨비 역할과 현대 인물 역할을 섞지 않는다. 파일의 의상/소품을 다른 인물에게 옮기지 않는다.
