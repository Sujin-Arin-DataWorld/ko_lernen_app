## 3. 어디서 어떻게 만들 것인가

권장 조합은 **R16 Blender 정본 렌더 + 기존 정본 PNG의 2.5D 합성 + 필요한 분위기만 Flow/Veo + DaVinci Resolve 최종 편집**이다. 장면의 중요한 행동·정확한 형태는 통제 가능한 로컬 합성이 맡고, AI는 얇은 안개·비·작은 빛 변화처럼 교체 가능한 층에 한정한다.

| 도구·작업 장소 | 맡길 일 | 선택 기준·제약 |
|---|---|---|
| 로컬 Blender | 잠긴 R16 `.blend`의 카메라·빛·심도 렌더, 별도 승인 대문의 빗장·경첩·문짝 키프레임, PNG와 접촉 그림자 합성 | 건물의 배치·비례·기둥·벽·지붕·문 창호·UV·계층·이름을 고정. 빗장처럼 기계적으로 맞아야 하는 동작은 이 방식 우선. 신규 리깅·소품은 원본 건축과 분리한 제작 레이어로 관리 |
| 로컬 2.5D / Resolve Fusion | 원본 탈선비·도깨비의 등장·시선·몸 방향·그림자, 승인 소품 인서트, 배지의 세 소용돌이 빛 | 새 캐릭터를 그려 바꾸지 않음. 일반 수업의 반복 idle은 새 MP4보다 기존 짧은 영상과 정지 상태를 우선. 손·발이 필요한 새 동작은 원본을 왜곡하지 않는 리그로 검토 |

AI 프롬프트에 보존 조건을 넣어도 형태 보존이 보장되지는 않는다. 기둥 하나, 까치 날개 하나, 배지 소용돌이 하나라도 달라지면 해당 결과는 탈락시킨다. 건물·인물을 AI 결과 전체로 덮지 않고 원본 레이어를 다시 합성해야 한다.

## 6. 두 10초 마스터의 편집·언어·소리

A는 `3 + 4 + 3초`, B는 `4 + 3 + 3초`의 **각기 3컷 편집본**이다. 24fps 타임라인이면 각각 240프레임. Flow의 4·6·8초 소재, Blender 렌더, 고정 소품 PNG를 필요한 길이로 자르고 정본 시작·끝 프레임을 고정한다. 한 모델이 10초를 지원하더라도 한 번의 생성에 이 세 사건과 대사를 모두 맡길 이유는 없다.

B의 `0–4초`는 첫 `집` 쪽지·마지막 편지·빈 새 쪽, `4–7초`는 배지 두 펄스·이름 없는 먼 지붕, `7–10초`는 집 안 도깨비의 배웅과 〈한글소리 : 일두 — 지워진 목소리 (완)〉이다. 탈선비 “이 배움을 나누어 보겠나?”, 조이 “태고야, 배지가 또 불러!”, 도깨비 “다녀와라. 문은 열어 두마.”는 동봉 에필로그의 **요청 변주·압축 제안 대사**다. v3.5 원문 대사라고 표시하지 않는다. 빈 쪽을 쓰기 제출로 만들거나 다음 목적지·발신인을 확정하지 않는다.

v3.5 537행의 정본 현대 연락 한 컷은 B와 별도 보존한다. B에 네 번째 컷을 몰아넣거나, 정본 연락을 삭제된 설정처럼 취급하지 않는다. A 뒤의 쿠키는 편집안 선택에 따라 B 또는 정본 연락을 사용하되 서로 다른 원문 지위를 유지한다.

영상에는 실제 한글·UI·자막·완결 타이틀을 AI로 생성하지 않는다. 첫 쪽지의 `집`, 편지의 창작 원문 디자인과 현대어 풀이, 장부·역할 표시는 앱/후반 제작의 실제 텍스트 레이어로 분리한다. KO 대사 오디오와 KO·EN·de-DE 자막 파일을 별도 제작하며 **한 번에 선택한 자막 한 언어**만 표시한다. AI 영상이 내는 한국어 발화·입 모양을 발음 교육의 근거로 쓰지 않는다. 발음 시범은 승인된 녹음·TTS/음성 자료의 정확성 검수 경로를 따르고, 이야기 영상 입 모양에는 발음 채점을 연결하지 않는다.

긴 편지·태고 완문은 10초 바깥의 자율 읽기·낭독으로 보존한다. 사람의 KO 녹음과 EN/DE 읽기 검수가 끝나야 템포를 확정한다. B3 자막과 타이틀의 동시 가독성은 아직 검증하지 않았다. 작은 화면에서는 타이틀과 자막을 분리된 safe area에 놓고 마지막 프레임을 멈춰 읽는 지원을 검토한다. 효과음·음악은 대사를 가리지 않게 별도 stem으로 보관하고, 자동 재생 시 소리 경쟁을 만들지 않는다.

## 7. 재생과 대체 화면의 계약

1. **공개 자격 확인 → 포스터 → 사용자가 ‘장면 보기’ → 한 번 재생 → 정지 결과 → ‘계속’**의 구조다. 단서가 아직 공개되지 않았으면 갤러리·미리보기·poster에서도 노출하지 않는다. 아래 버튼 이름은 제작용 의미 명세이며 최종 현지화 UI는 구현 시 확정한다.
2. 영상 재생은 기존 TTS·캐릭터 영상 소유자와 조정한다. 문항 중 자동 끼어들기, 동시 TTS/영상 오디오, 화면 밖 반복 재생을 허용하지 않는다. route 이탈·백그라운드·가시성 상실·다른 미디어 소유권 전환에서는 재생과 소리를 멈추고 복귀 시 포스터/수동 재개로 돌아온다.
3. ‘건너뛰기’, 디코더/네트워크 실패, 다운로드 대기, 사용자 무영상 선택은 **같은 장면 설명·결과 poster와 같은 다음 위치**로 간다. essential story 사실은 대본·그림으로 모두 제공한다. 새 시청 보상, 정답, 건축 완료를 지급하지 않는다.
4. 무음은 화자·대사 자막과 “빗장이 맞물리고 문이 열린다” 같은 사건 설명으로 완결한다. 청각 단서만으로 문항을 풀게 하지 않는다. 시작·pause·replay·skip·continue는 터치 48dp와 접근 가능한 이름을 요구한다.
5. 동작 줄이기에서는 자동 동영상·parallax·확대·카메라 이동·배지 두 펄스를 끈다. end poster/자율 넘김 storyboard와 고정된 배지 밝음으로 동일 내용을 제공한다. 필요한 전환은 짧은 불투명도 변화만, 최대 0.2초를 계획 기준으로 둔다. 반복 점멸·진동·흔들림·학습 글자 움직임은 쓰지 않는다.
6. 처음 보기·재시청·도움 사용·무음·스킵은 각각 콘텐츠 이용 상태다. 한국어 독립 수행이나 언어 숙달 상태로 바꾸지 않는다. V10의 편지 낭독은 지원을 선택해도 같은 첫 대답을 들을 수 있게 설계하고 녹음을 끝내야 영상을 볼 수 있게 만들지 않는다.

## 8. 납품 형식과 검수

제작을 시작할 때 `Vxx_r01`별 폴더를 만들고 다음 묶음을 보존한다. 이번에는 이 계획 문서와 CSV만 만들었고 아래 납품물은 아직 없다.

- **clean master**: 1차 검토 기준 16:9·1920×1080·24fps SDR Rec.709. 텍스트·UI·자막·음성 없는 picture master와 무음 H.264 MP4 재생 파생본. 필요하면 원본 해상도 PNG sequence도 보존한다. AI 720p를 확대해도 원래 없던 디테일이 검증된 것은 아니다. 세로 앱에는 핵심 구도를 자르지 않는 contain 배치를 먼저 검토하며, 9:16 파생은 별도 구도로 검사한다.
- **정지 이미지**: `start.png`, `end.png`, spoiler 조건이 같은 `poster.png`, 무영상 `storyboard_01..n.png`. 생성 API에 제출한 프레임과 최종 마스터의 실제 첫/끝 프레임을 구분한다.
- **언어**: 원문 행과 화자가 있는 `dialogue_ko.txt`, 검수된 KO 녹음 `dialogue_ko.wav`, `subtitles_ko.srt`, `subtitles_en.srt`, `subtitles_de-DE.srt`, 장면 설명/접근 가능한 대본. 제목과 편지의 실제 텍스트 레이어 파일을 보존한다. 선택 자막이므로 master에 세 언어를 함께 굽지 않는다.
- **오디오**: 48kHz WAV의 dialogue·ambience·foley·music stem 및 mix, 권리·출처, 무음 대체 설명. 대사 피크·클리핑·불필요한 무음·루프 경계를 실제 파일로 듣고 확인한다.
- **재편집 원본**: Resolve `.drp`와 사용한 Fusion 설정, Blender `.blend`/링크된 정본·제작 레이어, EDL/타임라인, LUT·폰트·미디어 링크 목록, 재생성 지시. 네이티브 열기→저장→다시 열기→같은 export 검증을 수행한다.
- **출처 원장**: source별 실제 경로·기존 image ID·SHA-256·승인 범위·단서 공개 시점, 시작/끝 프레임 SHA, 모델명·활성 설정·프롬프트·seed(제공될 때)·생성 job ID·후보/탈락 이유·다운로드 SHA·편집 프로젝트 SHA·최종 출력 SHA. 없는 seed나 job을 발명하지 않는다.

100% 글자 크기·같은 언어·같은 viewport의 실제 Flutter 캡처에서 poster/영상 경계·재료감·캐릭터 신원·타이틀/자막/CTA 겹침과 crop을 검토한다. 큰 글자·작은 화면·무음·동작 줄이기는 별도 QA로 표시한다. 종이·목재·천·기와의 재료감과 접지 그림자·앞뒤 레이어가 유지되는지 확인한다. A의 손·빗장 접촉과 경첩축, 조이의 두 날개, 세 소용돌이는 프레임 단위로 검사한다. 재생 길이는 `ffprobe` 등으로 A/B 각각 10.00초·24fps·240프레임을 확인하고 소리를 직접 듣는다. 문서의 시간 합계만으로 검증 완료라 하지 않는다.

이 문서에는 `motion-foundations`의 ‘상태·주의·공간 이해에 기여하는 모션’, 동작 줄이기, 화면 밖 정지 원칙과 `video-editing`의 ‘원본→정확한 컷→합성→사람의 최종 검수’, 저장된 편집 프로젝트·렌더·창작 승인의 분리 원칙을 적용했다. React 전용 구현 예제나 특정 클라우드 음성·생성 공급자는 Flutter 구현 요구로 옮기지 않았다. 실제 변경은 반복 영상 대신 12개 접점으로 줄이기, 세 시제품 먼저 검토, AI 분위기 층만 분리, 스킵/무음/정지 대체를 매 행에 넣기다. 실제 렌더 검수는 후속 단계다.
