## 프롤로그 7장면과 1화의 겹침

1. **P01 산행:** 플레이어가 먼저 노인을 부축한다. 초보자는 수진의 통역을 받아도 같은 배지를 받는다.
2. **P02 숙소 밤:** 손길·수진의 이어 주는 목소리·두려움 없는 배움 약속으로 세 소용돌이가 공명한다. 한국어 발음 시험으로 배지를 깨우지 않는다.
3. **P03 구름길:** 태고·조이는 정여창을 수평적인 ‘그 친구’로 소개하고 도깨비에게 돌아가자고 초대한다.
4. **P04 솟을대문:** 고택 경계 안에서 도깨비와 재회한다. 도깨비 수호기와·구름 배지·어긋난 빗장은 서로 다른 기능이다.
5. **P05 고택 영공:** 모두의 비행은 결계 안에서만 이루어진다. 기억 고택의 폐허를 현존 문화재의 상태로 말하지 않는다.
6. **P06 사랑마당:** 공부와 복원의 약속. 새 가격이나 지급량 없이 기존 학습·경제 계약으로 안내한다.
7. **P07 사랑채 첫 장:** 첫 `아` 복원과 탈선비의 귀환. v3.5가 프롤로그 P7이자 1화/LQ01 착공 전 사건으로 쓴 **같은 한 번의 각성**이다.

`S1-P07` 하나를 프롤로그와 1화가 공유하고 `S1-LQ01-FIRST-A` 영수증도 하나만 둔다. 1화 탭을 연다고 다시 깨우거나 보상을 새로 만들지 않는다. P7 뒤부터 W02의 현대 일상 ↔ 사랑채 서안 안전 왕복이 열린다.

화 완료의 제안 조건은 **해당 화 마지막 사건의 행동·동료 반응·필수 공개 사실을 장면 또는 동등 요약으로 확인하고 저장 성공 영수증을 받음**이다. 초보 지원 경로도 이 조건을 충족한다. 다음 화 안내는 그 영수증을 사용하며, 화를 진행하려고 높은 단원 이수를 강제하지 않는다. 빠진 공개 사실이 있으면 앞 사건의 짧은 요약을 바로 이어서 볼 수 있다.

**본편 사건의 선형 공개 순서와 언어 교육과정의 교수 순서는 별개다.** 본편이 첫 쪽지에 도착했어도 정상 언어 학습은 F0.1→F0.2→F0.3→F0.4 순서를 유지한다. C01-02에서 수업으로 돌아갈 때 이야기 체크포인트를 보존하고, 1화 완료를 수업 진입 조건으로 요구하지 않는다. 초보자가 지금 이야기를 계속하고 싶으면 아래의 지원 쪽지 경로를 고를 수 있다.

사실 조건은 스포일러가 있는 장면 버전의 `all-of` 조건이다. 중립 연습·현재 선택 수준의 수업·현대 역할 카드는 계속 열어 둔다. 기존 계약의 `building_or_band_unlock=false`를 유지하고, 새로운 챕터 껍질과 완료 영수증은 이 문서의 제안임을 구분한다.

### 공개 순서에서 꼭 지킬 것

- **LQ05는 중문간채 중간이다.** 소개·되묻기 소동이 끝나도 E04·기억30%·중문간채 완공을 생성하지 않는다. E04는 별도 완공 사건에서 처음 보여 준다.
- **E05는 관찰, E06은 이름과 가족의 회복이다.** E05에서 소녀의 이름·절도·이름을 지운 보호 목적을 먼저 확정하지 않는다. 도깨비의 저점은 수업·이동·지급 불이익이 아니다.
- **E07은 익명 꽃씨, E08은 분산 보관과 닮은 전달 경로다.** E08의 세 atom은 장부·분산 보관·천의 사용이며, 발신인 확정이나 R2 이름 분리의 실제 목적이 아니다.
- **E09는 탈선비의 탄생과 기억의 한계다.** 안사랑채 중간①이 끝나도 E10을 보여 주지 않는다. **중간②에서 E10을 처음 공개**하고 완공에서 감사와 95%를 회수한다.
- **E11에서만** R2·R3-SEND·R3-COPY와 독립 경로 R3-HOUSE를 대조해 보호 목적과 평생 발신인을 확정한다.
- **E12는 첫 `집`의 같은 보관본 곁에서 읽는다.** 첫 대답은 사랑채의 “다 왔다, 연아. 내가 다 받았어.”, 두 번째는 솟을대문의 “연아. 이제 문은 고쳐 놨다.”다. 주인공의 “다녀왔습니다.”까지 보거나 동등 요약을 확인해야 END 영수증을 저장한다.
- LQ08의 `S1-E06.middle`, LQ10의 `S1-E08.started`는 기존 원고의 **장면 제시 체크포인트**다. 새 `fact:` atom이나 새 핵심 단서로 추가하지 않는다.

**C03-05의 학습 범위:** 현재 100단원에서 대응하는 것은 `A2.1-04 해도 되는 일과 해야 하는 일`의 허가·금지·의무 구분과 필요한 도움 요청이다. 사진 찍기 대신 도움을 전하면 도깨비가 쉴 자리를 고르는 구체적인 행동으로 연결한다. 예약·교환이 없는 이 사건에 A2.1-01/-02를 붙이지 않는다. 탈선비에게 공손히 전달하는 별도 행동이 없는 한 A2.1-06도 요구하지 않는다. 정본 LQ07의 따뜻한 물·차가운 것 피하기 같은 새 조언 덩어리는 그림·뜻·번역을 갖춘 이야기 지원이며 미학습 증상·조언의 독립 생성 평가로 확대하지 않는다.

**나머지 직접 연결도 실제 활동에 한정한다.** C03-01 시간표 합의는 A1.2-01/-06을 사용하고 현대 지도·교통 활동인 A1.2-02를 붙이지 않는다. C08-02의 두 기록과 지식 한계는 B2.1-06으로 연결한다. 통계 분모 비교인 B2.1-01과 강한 부정 표현의 발췌 해석인 B2.1-05는 여기서 가르치지 않으며 원래 100단원의 선택 학습 연결로 보존한다.

**C09-02의 핵심과 선택 귀환:** 안사랑채 본편은 도깨비가 E10의 희생을 이해하고 신수에게 감사하는 결과로 마친다. 그림·지원 감사 표현만으로 같은 완료 영수증을 받을 수 있다. B2.2-01/-06의 조건 협상·합의/보류는 이 안사랑채 장면의 필수 과제가 아니다. 본편 감사 영수증 뒤 원하면 **사랑채·4막 LQ12**로 돌아가 이미 공개한 E05/E08/E10의 범위에서 토론하고 현재 본편 지점으로 복귀한다. E11 전에는 이름 삭제의 실제 보호 이유를 확정하지 않는다. 이 선택 재방문은 새 필수 사건·fact·다음 화 완료 게이트를 만들지 않는다.

## 사건 생명주기·실패·재생

상태 이름과 저장 방식은 미래 구현을 위한 제안이다.

| 상태 | 의미 | 다음 상태 또는 복구 |
|---|---|---|
| `locked` | 다음 본편의 선행 장면 영수증 또는 스포일러 사실이 아직 준비되지 않음 | 선행 사건 완료 또는 접근 가능한 이전 사실 요약 확인 |
| `available` | 수락·이어하기 가능한 NPC/장소 사건 | 플레이어가 NPC/지도 안내에서 시작 |
| `in_progress` | 현재 필요·시범·참여 행동을 진행 | 도움 요청 시 supported; 행동/요약 제시 완료 시 ready |
| `supported` | 같은 사건에 번역·그림·시범·표현 선택·대리 소개·지원 낭독을 사용 | 도움으로 같은 서사 결과를 만들면 ready. 독립 수행으로 상태를 세탁하지 않음 |
| `ready` | 행동 결과와 해당 사실/장면이 제시되어 보고 확인을 누를 수 있음 | 확인/전하기를 누르면 save_pending. 여기서는 아직 completed 아님 |
| `save_pending` | 완료 영수증·사실 확인·참조 객체의 내구 저장이 진행/재시도 중 | 저장 성공만 completed; 실패/오프라인은 retry/안전 복귀. 다음 챕터 완료로 표시하지 않음 |
| `completed` | 이야기 행동 및 제시/확인 영수증의 저장 성공 | 원하면 replay. 학습·재화·실제 시공 권한은 변경하지 않음 |
| `replay` | 완료 사건의 선택 재생/복습 세션 | 기존 사실을 지우지 않고 현재 확인 상태를 설명. 중복 보상/새 독립 증거 없음 |

NPC에게 보고하는 행동은 도움받은 말·문장 선택·중개도 허용한다. 동료가 학습자의 의도를 듣고 실제로 물건을 바꾸거나 길을 내주거나 자료를 정리하는 결과를 보여 준다. 점수나 시간만 채운 채 자동으로 NPC가 감사하는 장면은 만들지 않는다.

영상/음성에는 다음을 분리한다.

- **`media_played`:** 재생 시작·구간·종료·기술 오류. 재생한 초나 끝까지 봤다는 값으로 fact를 부여하지 않는다.
- **`fact_presented`:** 해당 사실과 공개 한계를 담은 장면·자막·번역/그림 요약이 실제 제시된 이력.
- **`fact_acknowledged`:** 플레이어가 ‘확인·전하기·다음’으로 제시를 확인한 영수증. 이해도 점수는 아니다.
- **`story_fact_seen`:** 제시·확인 영수증의 저장 성공 상태. 선택 언어와 도움 경로를 함께 남긴다.
- **원 언어 수행:** 실제 원응답과 평가 조건. TTS를 눌렀거나 재생을 완료했다고 말하기/듣기 독립 수행으로 기록하지 않는다.

**스킵:** 즉시 같은 사건의 짧은 정지 그림·자막/번역 요약으로 전환한다. 예를 들어 E08은 ‘분산 보관·집에서 천을 사용·발신인과 보호 목적은 미확정’ 세 요점을 빠뜨리지 않는다. 요약 제시와 확인 뒤 저장하면 같은 이야기 진행이다. 전체 영상을 강제로 보게 하거나 스킵만으로 fact를 자동 부여하지 않는다.

**이어하기:** 마지막 합리적인 문장/행동 체크포인트와 먼저 쓴 도움을 보존한다. 영상을 그 지점에서 이어 보거나 같은 요약을 선택할 수 있다. 앱이 백그라운드로 가거나 떠날 때 재생/TTS 소유를 반납하고, 재생 오류는 학습 실패로 기록하지 않는다. 소리 없는 읽기·그림 경로로 같은 사건을 마칠 수 있다.

**저장:** 행동 확인 뒤 `save_pending`으로 이동하고 완료 영수증·fact 확인·첫 쪽지 참조를 같은 멱등성 키로 재시도한다. 실패·오프라인이면 ‘저장 다시 시도’와 안전 복귀를 제공한다. 저장 성공 전 다음 화 완료 표시·재화 지급·중복 장면 완료가 없다. 돌아오면 현재 미완료 입력/저장 대기에서 복구한다.

**재방문:** 이미 안 사실을 지우지 않는다. 같은 기록을 더 높은 언어로 다루더라도 새 발견으로 위장하지 않는다. LQ12는 E08 전후에 따라 추측/확인 범위를 바꾸고, E11 전에는 R2의 실제 이유를 확정하지 않는다. LQ15는 E06 재독해이며 LQ16은 END 이후 후일담이다.

## 나중 날 복습과 최소 새 제작물

각 사건을 마치면 이미 공개한 내용을 쓰는 선택 복습을 연다. 다음 날·몇 날 뒤의 새 맥락에서 다시 써 보도록 제안할 수 있지만, 복습 알림·오답·미접속이 다음 화를 막지 않는다. 같은 날 답을 본 뒤 재연, 도움받은 수행, 나중 날 힌트 없는 회상을 서로 다른 기록으로 둔다. 실제 간격·문항·판정은 기존 학습 명세와 학습자 검증을 따른다.

## 검토 통과 조건과 남은 위험

1. **내용:** 10화가 v3.5의 사건·공개 순서를 지키고, 정확히 fact15·단서12·기본훅33을 유지한다. P7/1화 각성, LQ05/E04, E08/E11, 중간①/②, 두 대답에 중복·선공개가 없다.
2. **입문자 수직 경로:** 같은 엔딩을 번역·그림·표현 선택·지원 낭독만으로 경험하는 흐름을 종이/수첩 단계에서 재연한다. 누구도 C2·128/128·마이크·개인정보·나중 날 복습에서 막히지 않는다.
3. **연결:** 각 사건에서 필요→시범→행동→동료 반응→보고→다음 위치가 명확하다. 첫 쪽지의 객체 참조가 끝까지 이어진다.
4. **복구:** 스킵은 같은 사실의 요약으로 이어지고, 저장 실패는 완료가 아니며, 재방문은 알려진 사실과 도움 이력을 유지한다.
5. **언어:** KO의 교수 범위와 EN/de-DE의 자연스러운 의미를 교사·원어민이 감수한다. UI의 du와 역할 대사의 정중한 호칭은 의도에 맞춰 검토한다.

가장 큰 미해결은 **이야기 준비 상태와 현행 시공/과정 게이트의 실제 바인딩**이다. 초보에게 첫 `집` 서사 작성을 지원하면서 정상 F0.4 교수 순서와 독립 I01의 답 노출을 보존하는 것도 콘텐츠/평가 검토가 필요하다. 첫 쪽지 참조·사실 제시·확인·내구 저장의 복구는 미래 구현 검증 항목이다. 이 세 문서는 편집 구조와 수량을 검토할 수 있는 제안이며 Flutter·기기·TTS·미디어·배포·사용자 승인 증거를 대신하지 않는다.
