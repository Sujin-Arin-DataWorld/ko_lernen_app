# 커리큘럼과 NPC 대화가 하나의 사건으로 이어지는 방식

[전체 색인](README.md) · [단원별 전문 목록](DETAIL_INDEX.md).

## 1. 집필 완료 범위와 확장 원고의 구분

**상세 학습 원고는 입문 1의 3단원, 입문 2의 7단원, 입문 3의 11단원, 입문 4의 7단원, A1.1의 6단원이다.** 실제 KO 대사와 EN/DE 안내, 문항, 도움, 오답 반응, 다음 날 회상을 포함한다. 나머지 A1.2~C2.2까지의 100단원 전체에는 서사·장소·핵심 대사·사실 공개 경계의 연결 원고가 있다. 이것을 모든 단원의 상세 문항까지 완성했다는 뜻으로 쓰지 않는다.

11동128공정 전문은 공정마다 생활 소동·인물 반응·다음 여운을 붙이는 집필안이다. 큰 컷신128편이나 앱 이미지128장 제작 완료를 의미하지 않는다.

## 2. 한 번의 학습이 사건이 되는 문법

**NPC/사물 발견 → 작은 부탁 → 필요한 말·소리 준비 → 시범 → 도움 연습 → 상황에서 사용 → 구체적 NPC 반응 → 사건 기록/보고 → 다음 부탁.**

문법 이름을 알려 주고 퀴즈를 푸는 것만으로 끝내지 않는다. 예를 들어 “제 모자가 아니에요.”라고 정정하면 도깨비가 소유자 표를 다시 살핀다. “다시 말해 주세요.”라고 하면 같은 정보를 실제로 다시 들려주고 길을 비킨다. 마지막에는 연이의 말을 전해 도깨비의 대답이 달라진다. 작은 정정과 마지막 낭독이 같은 ‘듣기·확인·전달’로 이어진다.

이 구조는 테일즈위버에서 사용자가 설명한 **인물 중심의 개별 퀘스트가 공통 본편으로 모이는 경험**을 한글소리 학습에 적용한 방향이다. 해당 게임의 아트·로고·고유 대사·전투 규칙을 옮기지 않는다.

## 3. 이름에서 첫 공부책·재회까지

### 이름

플레이어는 이야기에서 불릴 이름을 정한다. 목업의 Mira는 예시다. NPC와 플레이어 화자에 같은 이름이 이어져야 한다. 실명을 요구하거나 외형 생성기를 첫 필수 절차로 두지 않는다. 건너뛰기·기본 호칭·이름 수정은 제안 UX이며 실제 정책 확정/구현과 구분한다.

화면에 등장하는 역할 연습 카드의 가명은 이야기 이름과 별개다. 하린 카드로 자기소개를 연습했다고 플레이어의 저장 이름을 하린으로 바꾸지 않는다.

### 첫 공부책의 12개 핵심 상태

| 상태 | 플레이어 행동 | 이어질 인물·장면 |
|---|---|---|
| S01 이름 | 이야기 이름 정하기 | 같은 이름이 다음 화자/호칭으로 이어짐 |
| S02 마당 | 조이가 살피는 서안에 다가감 | 수진이 내 이름으로 동행하며 책에 주의를 이끎 |
| S03 첫 장 | 책을 함께 살펴보기 | 아직 탈선비 없이 수진의 안내 |
| S04 흐릿한 목소리 | 도깨비의 기억에 되묻기 | 책의 잔소리하던 목소리를 떠올리는 도깨비 |
| S05 시범 | 소리와 모형 보기 | 수진이 ㅇ 왼쪽·ㅏ 오른쪽의 아를 보여 줌 |
| S06 조립 | 같은 책 위에 두 조각 놓기 | 놓인 조각과 남은 자리가 명확한 도움 연습 |
| S07 복원 | 첫 아 완성 | 수진이 실제 조립 결과에 반응 |
| S08 낭독 선택 | 직접/함께/조용히 읽기 | 같은 이야기로 합류, 발화 채점 아님 |
| S09 내 대사 | 내 이름의 극중 화자가 아를 읽음 | 첫 소리의 의미와 인과가 드러남 |
| S10 각성 | 책의 짧은 반응 보기 | 복원·극중 낭독 뒤 탈선비 등장 |
| S11 재회 | 동료 대화 따라가기 | 놀람→익숙한 농담→외로움 인정→새 제자 부탁 |
| S12 다음 배움 | 탈선비와 다음 글자 준비 | 첫 음절부터 차근히, 단원 전체 숙달 선언 없음 |

S02~S12는 첫 공부책 구간의 발췌다. 그 앞의 정본 프롤로그 여섯 장면을 지운 것이 아니다. 첫 책 직후 A1.1로 점프하지 않고 입문1→2→3→4의 학습 경로를 유지한다.

첫 순간의 조립 재료는 **ㅇ+ㅏ**다. 아직 가르치지 않은 ㅓ·ㅗ를 최초 오답 보기로 쓰지 않는다. 첫 단원 전체에서는 뒤이어 어/ㅓ를 배우므로, 최초 각성 장면의 선택지 제한을 단원 전체 문자 범위로 오해하지 않는다.

### 재회에서 생략하면 안 되는 감정

아를 읽음 → 탈선비가 새 제자를 맞음 → 도깨비의 “…탈선비?” → 잠든 사이에도 공부하지 않았냐는 익숙한 농담 → 수백 년 만에 첫마디가 그거냐는 반응 → 홀로 남아 외로웠을 도깨비를 알아봄 → 도깨비가 투덜거리며 새 제자 교육을 부탁함 → 탈선비가 플레이어에게 다음 배움을 잇는다.

각성 이펙트 한 컷에서 곧바로 다음 퀴즈로 가면 이 귀환의 보상이 사라진다. 한 화면에는 한 화자의 한 차례를 두되, 대표 이미지에 없는 후속 대사도 [COPY-REVIEW 전문](sources/season1-rpg-image-production-20261031/COPY-REVIEW.md)과 첫 단원에 보존한다.

### 보조 상태 8개

A01 이름 입력 키보드 / A02 같은 조각의 위치 도움 / A03 조각을 유지한 오배치 재시도 / A04 음성 사용 불가와 자막 대안 / A05 현재 차례를 보존하는 잠시 나가기 / A06 부분 조립·이름·도움 상태로 복귀 / A07 이미 공개된 대화 기록 / A08 같은 각성을 정지 장면으로 전하는 동작 줄이기.

이 20상태×EN/DE=40장은 초기 첫 흐름의 이미지 계획 수량이다. 전체 범위의 제작 완료 수량이나 모든 대사 턴 수가 아니다.

## 4. 입문 네 구간과 A1.1의 연결

| 구간 | 단원 수 | 이야기 앵커 | 학습과 미술 경계 |

첫 집 쪽지는 사랑채/이야기 준비 조건이 확인된 뒤 정본 사건으로 보관한다. 그 전의 집 입력은 **지원 연습 초안**이다. 글자를 썼다는 이유로 사랑채를 완공 처리하거나 보관 이벤트를 지급하지 않는다. 보관된 첫 쪽지는 이후 이 집 연습·복습으로 덮어쓰지 않는다.

입문2의 마루 등은 별도 참고 사진으로 뜻을 준비할 수 있다. 그 그림을 미보유 완공 사랑채가 이미 생겼다는 장면으로 합성하지 않는다.

### A1.1 문지기의 실제 대화 인과

도깨비는 플레이어를 잊은 것이 아니라 **“오늘은 내가 문지기다”**라는 역할놀이를 한다. 연습 카드의 이름으로 인사/소개 → 한 대목을 놓침 → 다시 말해 달라고 요청 → 도깨비가 같은 전체 내용을 다시 전달 → 상황을 확인한 뒤 몸을 비켜 줌 → 다음 사건으로 간다.

되묻기를 선택했다고 다른 정보를 덧붙이거나 바로 정답 자막만 보여 주는 것으로 반복 듣기를 대신하지 않는다. 중문 완공 E04의 폭풍·인영·기억30%를 중간 문지기 학습 결과에 붙이지 않는다. 실제 이름 답안·마이크 점수·공정 완료·엽전을 한꺼번에 만들지 않는다.

## 6. 도움·오답·복습에서 지킬 것

- **의미와 새 소리 먼저:** 물건이나 조작을 몰라 틀린 것을 한국어 실패로 평가하지 않는다. 어려운 NPC 문장은 번역으로 이해할 수 있으며 모두 산출 목표가 아니다.
- **도움:** 시범·그림·선택·지원 낭독을 바로 제공한다. 도움 참여도 같은 본편으로 이어진다. 정답을 본 이력과 독립 수행은 분리한다.
- **오답:** 같은 질문·선택·이미 놓인 조각을 유지하고 무엇을 다시 볼지 짚는다. 흔들림·벌점·진도 박탈·친구가 다시 잠드는 연출은 하지 않는다.
- **음성 실패:** TTS/미디어 장애는 학습자 오답이 아니다. 비활성 이유와 읽기/자막 대안을 보여 주고 듣기 성공으로 기록하지 않는다.
- **다음 날 회상:** 다른 날에도 같은 기능을 쓸 기회를 제공한다. 복습 누락이나 실패로 집·친구·이야기를 회수하지 않는다.
- **저장 미확인:** 완료한 척하지 않고 입력과 현재 차례를 유지한다. 재시도·재생·재방문은 중복 완료/엽전을 만들지 않는다.
- **말하기:** 극중 대사를 선택하거나 함께 읽었다는 사실은 실제 녹음·발화 감지·발음 평가 증거가 아니다.

국 조립의 [ㄱ,ㅜ,ㄱ]처럼 같은 자모가 두 번 필요한 문항은 중복 제거하지 않는다. 모음 선택형은 정답 모양을 답안 자리에 먼저 노출하지 않는다. 이런 개별 제한은 [INTRO_UNITS](sources/season1-rpg-image-production-20261031/INTRO_UNITS.json)의 task/source binding과 단원 전문을 따른다.
