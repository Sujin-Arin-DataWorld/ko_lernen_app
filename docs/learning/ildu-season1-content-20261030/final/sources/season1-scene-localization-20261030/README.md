# 두 장면 · 영어/독일어 실제 서체 조판

한옥 에셋 최신 지정(2026-10-31): [Plan R16의 실제 투명 레이어·중문 원본 연결 기준](../season1-r16-source-update-20261031/README.md). 후속 한옥 장면에는 이 기준을 우선 적용한다. 기존 네 정지 비교판은 보존한다.

2026-10-30. 첫 공부책 만남과 중문 문지기를 각 EN/DE로 제작했다. UI·인물 대사는 해당 언어로 표시한다. 한국어 UI·한국어 검토판·새 학습 언어는 추가하지 않았다.

기준 조합은 Lora Medium500(이야기 제목) + Source Sans3 Regular400(본문) / SemiBold600(버튼·이름·단계)다. 기존 `ildu-type-review-20261030/fonts`의 실제 TTF를 사용했고 FONT_MANIFEST 해시와 OS/2 weight를 확인했다. 이미지 생성기가 그린 유사 글씨를 폰트 적용으로 판정하지 않았다. 글리프는 Pillow/FreeType으로 조판했다. 독일어 특수문자와 인용부호의 cmap도 검사했다.

- `book-en-lora.png`, `book-de-lora.png`: 첫 공부책 만남.
- `gate-en-lora.png`, `gate-de-lora.png`: 중문 문지기.
- `book-EN-DE.png`, `gate-EN-DE.png`: 왼쪽 영어·오른쪽 독일어 비교판.
- `COPY.json`: 실제 문구. `LAYOUT.json`: 줄별 서체·크기·위치. `VERIFICATION.json`: 폰트 해시·결과 해시·픽셀 검사.

목업 이미지의 글자 제거에는 내장 image_gen을 사용했다. 생성된 글자 없는 배경판 전체를 새 장면으로 사용하지 않고, 지정한 기존 글자 영역만 원래 목업에 옮겼다. 최종 언어별 TTF를 그 위에 조판했다. 첫 시도의 자동 인페인팅 잔흔은 최종 파일에서 교체했다. 앱 코드·HTML·Flutter·Figma·테마·원본 PNG는 변경하지 않았다.

원래 목업의 캐릭터·책·건물 주 이미지 사각 영역을 각 언어 결과와 픽셀 비교해 변경0을 확인했다. 그 밖에도 글자 제거/새 조판 허용 영역 밖의 변경0을 검사했다. 기존 글자 밑 배경은 복구된 영역이며 그 부분을 원본과 같은 바이트라고 주장하지 않는다. 보존 비교 기준은 이전 목업으로, 그 목업과 정본 캐릭터/건물 원본의 완전 동일성을 새로 입증한 것은 아니다.

이야기 제목24px/1.3, 본문17px/1.45, 버튼17px/600, 보조14~15px을 약2배 이미지 스케일로 적용했다. 본문은 왼쪽 정렬, 버튼만 가운데 정렬이다. 글자를 가로로 좁히지 않았고 긴 독일어는 줄바꿈했다. 모든 줄의 폭과 예약 높이를 검사했다. 실제390/320 기기·200% 글자 확대·상호작용·접근성 통과 검증은 이번 정지 파일 수정과 구분한다. 마루부리/Noto Sans KR 조합은 향후 한국어 학습 글자에 적용할 별도 역할이며 이 네 장에는 한국어 학습 글자가 등장하지 않는다.

최종 정지 이미지를 육안으로 확인했다. 이전 목업/폰트 비교판은 덮어쓰지 않았다. 새 폰트 조합을 앱 전역 최종 승인으로 취급하거나 커밋·푸시·배포하지 않았다.
