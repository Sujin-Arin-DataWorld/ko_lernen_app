## 대표 화면과 전체 목표의 구분

- 대표 과제는 해당 원고의 실제 P/I 문항 하나다. 한 장이 단원의 모든 글자·뜻·발화를 다 평가한다는 뜻은 아니다. unit_scope에 단원 전체 목표를 적었고 pattern_links.task_bindings에 원고의 P/I/R 문항별 실제 자료·보기·목표·지시·피드백 참조를 보존했다. source_row는 입문1의 비JSON 표 행을 그대로 보존한 제작자용 자료다.
- 대부분은 시범 모형이 있는 도움 연습이다. ㅐ/ㅔ·ㅙ/ㅞ·ㅒ/ㅖ·ㅢ의 대표는 원고의 형태 선택 I01로 골랐다. target은 매/괘/걔/희 같은 제시 글자이고 correct는 그 안의 모음이다. 여기서 청각 변별·발음·낱말 뜻을 평가하지 않는다. model_visible=false는 제시 글자를 숨긴다는 뜻이 아니라 정답 완성 모형을 덧붙이지 않는다는 뜻이다.
- 입문3 마지막 단원은 이미 익힌 아를 재조립하는 P01 대신 받침 ㅇ이 보이는 방의 P03을 대표로 선택했다. 원래 아/방 비교와 공/강 확인은 같은 원고의 연결 문항에 남아 있다.
- 입문4 D01-P01의 국은 ㄱ·ㅜ·ㄱ 세 조각이다. 두 ㄱ은 서로 다른 위치에 필요한 조각이므로 choices 배열을 집합으로 바꾸어 중복 제거하지 않는다. 배치 유형의 final은 받침을 뜻하며 ‘최종 완료’ 지표가 아니다.
- 입문4 입력 대표는 정답 모형이 공개된 D06-P01 도움 초안이다. 조각 ㅈ·ㅣ·ㅂ은 같은 원고 INPUT-집 대본에 명시된 모형이다. 초기 D06-I01의 모형 없는 첫 집 시도에는 이 정답·조각 묶음·키 순서·로마자를 먼저 보여 주지 않는다. I01은 나무·모자 등의 다른 낱말 입력보다 먼저라는 원고 순서를 보존한다.
- listen_choose의 audio_ref는 원고 읽기 대본 참조이며 제작/검수된 음성 파일이 있다는 뜻이 아니다. D05-P01은 원고의 지원 예시 문이와 실제 보기 무리/문이를 그대로 사용한다. 음성이 없으면 무음 상태·자막 도움으로 연습을 계속하며 듣기 정답으로 기록하지 않는다.
