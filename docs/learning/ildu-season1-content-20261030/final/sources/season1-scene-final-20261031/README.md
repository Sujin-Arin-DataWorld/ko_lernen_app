# 일두 시즌1 · 두 장면 목업 최종 검토본

2026-10-31. 현재 승인 범위인 **첫 공부책 만남 / 중문 문지기의 영어·독일어 4장**을 납품한다. 앱 코드·실행 화면·학습 진도·보상·배포 작업은 포함하지 않는다.

## 바로 볼 파일

| 장면 | English | Deutsch | 두 언어 비교 |
|---|---|---|---|
| 첫 공부책 만남 | book-en.png | book-de.png | book-EN-DE.png |

비교판의 왼쪽은 영어, 오른쪽은 독일어다. 개별 화면은887×1774 PNG이다. `DELIVERY.zip`에는 네 화면·비교판2장·실제 서체와 라이선스·텍스트/배치/QA 기록·직접 합성에 쓴 원본 사본이 있다. 이전 목업과 원본 파일은 덮어쓰지 않는다.

## 반영한 요청

- 앱 제목·설명·버튼·NPC 대사는 각 화면의 EN/DE로 표시한다. 한국어 UI는 넣지 않았다.
- 이야기 제목은 **실제 Lora Medium500**, 설명은 **실제 Source Sans3 Regular400**, 버튼/이름은 **실제 Source Sans3 SemiBold600**으로 FreeType 조판했다. 파일 SHA와 OS/2 weight를 검사했으며 이미지 생성기의 유사 글씨는 사용하지 않았다.
- 제목24px/1.3, 본문17px/1.45, 버튼17px/600, 보조14~15px의 기준을 약2배 이미지에 적용했다. 긴 독일어는 줄바꿈하고 가로로 압축하지 않았다. 설명은 왼쪽 정렬이다.
- C안의 청록·한지·목재·금색 버튼의 재료·두께·접촉 그림자를 유지했다. 첫 공부책 장면은 제공된 배경판의 기존 구도를 그대로 사용했다.
- 중문 장면은 새로 그린 한옥을 쓰지 않는다. 현행 R16 카탈로그의 `ildu.jungmunganchae-roof-bed` 원본 전체 캔버스를 직접 배치했다. 도깨비 역시 고정 PNG를 직접 합성해 원본 비례·복식·방망이·포즈를 유지했다. 두 파일 모두 자르기·가로변형·재색칠 없이 균일 축소만 했다. 주변 빈 패널의 색을 원본 렌더의 회색 배경과 맞췄으며 건물 픽셀에는 색조를 적용하지 않았다.
- 이전 생성 시안의 길게 변형된 도깨비/재해석 건물 대신 실제 원본을 사용하므로 중문 장면의 인물·건물 크기 관계는 이전 시안과 다르다. 주요 건축 부재와 지붕 윤곽이 보이도록 배치했다.

## 확인한 결과

`QA.json`은 실제 파일·폰트 해시, `LAYOUT.json`은 모든 줄의 실제 glyph 경계와 예약 영역, `COPY.json`은 문구를 담는다. 아래 항목을 검사했다.

1. 네 출력과 두 비교판이 열리며 PNG 크기가 정상이다.
2. 모든 문자열이 지정 TTF의 cmap에 있고, 독일어 ä/ö/ü/ß/ẞ/인용부호도 지원한다.
3. 모든 줄의 실제 glyph 경계가 예약 폭/높이에 들어간다. 제목 아래 목재 프레임, 듣기 버튼, CTA 화살표와 겹치지 않도록 배치했다.
4. 첫 공부책의 주 이미지 영역은 제공된 배경판과 동일하다. 중문·도깨비 합성 층은 원본 파일의 지정 균일 축소 결과와 일치한다. 글자 조판이 두 장면의 이미지 영역을 덮지 않는 것도 픽셀 비교했다.
5. 원본 입력·폰트·현재 R16 카탈로그는 변경하지 않았다. R16 원본 카탈로그 SHA가 앞서 고정한 출처와 일치한다.
6. 최종 네 장을 육안으로 확인했다. 한국어 잔여 글자, 문자 제거 흔적, 도깨비/대사 겹침, 긴 독일어의 잘림을 검토했다.

이는 정지 목업 검수다. 실제390/320 기기 재배치·200% 글자 확대·듣기/도움/저장 버튼 작동·접근성 통과를 검증한 것은 아니다. 실제 조작이 없으므로 마이크로인터랙션 점수는 N/A다. 이 검토본을 승인 정본이나 Flutter 통합 완료로 자동 승격하지 않는다.

## 장면과 상태 연결

첫 공부책의 Start/Starten은 첫 소리 시범·도움 연습으로 이어지고, 탈선비는 아직 나타나지 않는다. 중문은 A1.1에서 연습 카드로 소개·재요청을 준비하는 별도 시점이다. 두 장면이 바로 연속된 학습 단계라는 뜻은 아니다. 중문06 이미지는 제작용 시점 참고이며 실제 서사 중간 트리거를06으로 구현한 것이 아니다.

후속 사랑채 화면은 [최신 R16 투명 레이어 계약](../season1-r16-source-update-20261031/README.md)을 따른다. 현재 장면에 사랑채 완성본을 억지로 넣지 않으며 중문을 사랑채 투명본으로 대체하지 않는다. 보유 공정0·1은 건물/그림자 표시 없음, 기존 진도·잠금은 별도다. 목업은 새 공정·엽전·완료를 지급하지 않는다.

## 첨부 경로

사용자 첨부의 `/C:/...`를 Windows 절대 경로 `C:/...`로 정규화해 정상적으로 읽었다. 파일 누락이 아니었으며 원본을 이동/이름 변경하지 않았다. 올바른 경로는 `QA.json`의 inputs에 있다.

`render_final.py`는 이번 제작 컴퓨터의 경로를 쓰는 정지 이미지 조판 도구다. 앱 코드가 아니다. ZIP에는 별도 도구 설치나 원래 작업 공간 없이 열 수 있는 PNG·원본 사본·TTF·문서만 포함한다.
