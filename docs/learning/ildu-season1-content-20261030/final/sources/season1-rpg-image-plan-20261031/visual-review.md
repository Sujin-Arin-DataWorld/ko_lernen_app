# RPG 이미지 목업 시각 검토 — 제안, 2026-10-31

권장 방향은 **배경을 가진 2.5D 챕터 장면 + 고정 대화창**이다. C안의 한지·목재·의복 재질을 유지하면서, 플레이어가 세계 안에서 책을 복원하고 친구의 귀환을 목격하게 한다. 아래는 시각 디렉터의 제안이며 사용자 승인이 아니다. 이미지·HTML·앱·Figma는 생성하거나 변경하지 않았다.

## 실제 화면에서 확인한 차이

- `season1-scene-final-20261031/book-de.png`는 옷감·피부·머리카락·종이 두께·책상 목재·한지 대화창이 큰 화면에서도 읽힌다. 이 재질 밀도를 품질 기준으로 삼는다. 다만 완성된 실내와 서양식 책 더미를 현재 착공 전 스토리 공간의 정본으로 옮기지는 않는다.
- 거절된 `season1-rpg-prototype-20261031/captures/02-book-de.png`는 단색 배경과 바닥 경계, 큰 책, 작고 겹친 인물 때문에 같은 공간에 서 있다는 단서가 부족하다. 독립 자산의 해상도만 높여도 해결되지 않는다. 뒤쪽의 작은 갓 쓴 인물을 탈선비로 판독한 것은 조이 오인으로 정정한다. 실제 intro의 수진·조이 표시와 탈선비 숨김 검사 근거에 따라, 이 화면의 ‘복원 전 탈선비 등장’을 확정 오류로 보고하지 않는다.
- 참조팩의 `book_existing_tactile.png`는 실제로 현대식 양장 책 두 권이며 상태도 `REFERENCE_ONLY`다. 연이의 낡은 공부책 정본으로 확정된 자산이 아니다.

## A안의 연속 장면 설계

1. **이름을 받은 도착 장면:** 이름 입력 뒤 같은 사랑마당으로 연결한다. 수진의 대사에 입력한 이름이 들어가고, 화자가 플레이어인 차례에도 그 이름을 표시한다. 외형 선택이 없으면 새 아바타를 임의 생성하지 않고 플레이어 시점으로 구성한다.
2. **책 발견:** 공정 0·1 상태를 지킨다. 건물과 건물의 스튜디오 그림자는 없다. 넓고 빈 터 안의 주춧돌 자리와 낡은 서안, 상자에서 막 꺼낸 공부책 한 권으로 사건을 만든다. 경계 담장·솟을대문은 11동 건설과 별개지만 기존 기하와 배치를 재설계하지 않는다. 조이의 발견 행동이 읽히고 탈선비는 아직 없다.
3. **복원:** 같은 방향에서 서안 가까이로 시점을 이동한다. 책 페이지가 실제 조작면이며, 최신 `01_FIRST_SOUND.md`에 따라 첫 `아`는 `ㅇ`·`ㅏ`만으로 조립한다. 미학습 `ㅗ`·`ㅓ`를 오답 선택지로 사용하지 않는다. 수진은 한쪽에 남고 책과 경쟁하지 않는다. 큰 책 더미, 별도의 교재 소개 카드, 미리 채운 정답은 두지 않는다.
4. **각성·재회:** `아`가 되살아난 뒤에만 책의 금빛·청록빛과 탈선비가 나타난다. 이후 도깨비와 탈선비의 대화를 같은 마당에서 이어 간다. 폭발·레이저·완공 건물로 보상하지 않고, 친구가 돌아온 표정과 거리 변화로 장면을 만든다.

배경은 흐릿한 색판이 아니라 길·흙의 방향·서안 다리의 접촉·산 능선·하늘이 있는 장소여야 한다. 기존 인물의 광원을 먼저 읽고 배경 광원을 맞춘다. 새 그림자는 별도 레이어이며 발·서안 다리에 붙는다. R16 전경/그림자는 원래 같은 캔버스·동일 정렬로 사용하고 추가 색조 보정이나 AI 재생성을 하지 않는다.

화면 상단의 챕터 표시는 작게 두고, 이야기 장면이 화면의 약 2/3를 확보하는 구도로 시작한다. 하단 한지 대화창에 화자·한 차례 대사·다음 행동을 둔다. DE 문장이 길면 문장 호흡을 나누고 대화창 높이를 조절한다. 글자를 좁히거나 인물을 계속 축소하지 않는다. 제목은 실제 Lora 500, 본문·버튼은 실제 Source Sans 3이며 한국어는 학습 글자에만 사용한다. 48dp 터치와 safe area, 이름 입력 시 키보드가 뜬 화면을 별도로 계획한다.

## 즉시 실패로 판정할 조건

- 책·인물·서안의 소실점, 크기, 광원 방향 또는 발 접촉이 서로 맞지 않음.
- 원경이 없거나, 단색 바닥 위에 자산만 올린 상태.
- 공정 0·1에 건물/건물 그림자가 생기거나, 원본 R16·경계 구조가 바뀜.
- 후속 시안에서 첫 소리 복원 전에 탈선비가 출현하거나 마법이 이미 성공한 것으로 보임. 이는 향후 검수 조건이며 현재 `02-book-de.png`에 대한 확정 오류 판정이 아니다.
- 첫 `아` 조립에 미학습 `ㅗ`·`ㅓ`를 오답 선택지로 사용함.
- 연이의 공부책이 현대 양장 책 더미로 처리됨. 새 한지·실 제본 소품은 후보로 구분해야 함.
- 고정 캐릭터의 얼굴·의상·갓·탈·비율이 바뀌거나 캐릭터가 겹쳐 하나의 덩어리로 읽힘.
- 입력 이름이 이후 대화에 이어지지 않음, 또는 이름 입력이 별도 설정 페이지처럼 분리됨.
- 독일어 축소·가짜 폰트·잘린 학습 글자·대화창과 얼굴의 충돌.

## 보존과 검증의 경계

원본 파일을 그대로 합성하면 출처 파일의 바이트 보존은 검증할 수 있다. 화면상 확대·이동·알파 합성 이후 결과 픽셀은 원본과 달라진다. 캐릭터를 생성 모델에 다시 그리게 하면 정체성 참조는 가능하지만 얼굴·의상·자세의 픽셀 보존은 보장할 수 없다. 광원과 눈높이가 맞지 않는 원본 포즈를 억지로 배치하지 말고, 먼저 카메라를 원본에 맞추고 부족한 포즈는 별도 후보로 구분해야 한다. 고품질 시안과 원본 동일성, 정지 목업과 앱/실기기 검증은 각각 분리한다.

`ui-styling`은 구성 위계·재질 토큰·모바일 우선 조판에, `mobile-native`는 이름 입력/키보드·safe area·터치 영역과 실제 기기 검증 구분에 적용했다. 2026-10-31 확인한 Apple HIG의 [Designing for games](https://developer.apple.com/design/human-interface-guidelines/designing-for-games)는 세계 안에서 배우는 튜토리얼, 읽기 쉬운 게임 대사, 기기별 사용 가능한 화면과 조작 영역을 권한다. 이 원칙을 C안의 세계 장면과 학습 페이지에 적용하되 Apple의 외형을 복제하지 않는다.
