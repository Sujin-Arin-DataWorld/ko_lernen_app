# 첫 책과 첫 재회 — 주인공·초보자 경험 검토

2026-10-31. 계획 제안이며 새 이미지·HTML·앱 코드·Figma·커밋은 만들지 않았다.

**권고: 이름 입력부터 첫 공부책 복원·탈선비와 도깨비의 첫 재회까지, 핵심 12상태 + 보조 7상태를 EN/DE 각각 제작한다. 총 38장이다.** 모든 대사 턴을 별도 이미지로 만드는 수가 아니라 화면·조작·회복 상태를 검토하는 대표 이미지 수다. 글자만 다른 대사 턴은 대본에 연결한다. 산길·배지·비행(P-1~P-6)을 모두 새로 제작하는 것은 확장안으로 분리한다.

이름을 정한 플레이어의 시점으로 시작한다. 외형·성별·국적·장비·새 레벨 설정은 추가하지 않는다. 나의 말풍선에는 입력한 이름을 표시하고, 고정 주인공 얼굴을 새로 만들지 않는다. 수진은 동행자이며, 내가 먼저 돕고 글자를 맞춘 결과에 NPC가 반응한다.

| 번호 | 이미지가 보여 줄 순간 | 사용자 행동 → NPC 반응 → 다음 장면 |
|---|---|---|
| 01 | 이름 입력 | 이름 확인 → 수진이 동행을 제안 → 현재 장면 진입. 빈 이름에서는 시작 비활성화, 키보드에 CTA가 가려지지 않음 |
| 02 | 사랑마당·사랑채 주춧돌 연결 컷 | 원문 P-1~P-6의 짧은 연결 설명 읽고 계속 → 수진이 책 쪽을 봄 → 낡은 서안. 원문 사건의 상세 제작을 이번 범위에 넣지 않음 |
| 03 | 조이의 책 발견 | 조이가 찾은 책 보기 → 수진 U1-D01 → 책 펼치기 |
| 04 | 흩어진 첫 페이지 | 책 펼치기 → 도깨비 U1-D02의 툴툴거림과 흐릿한 기억 → 내 행동을 기다림 |
| 05 | 내 이름을 부르는 수진 | 대화 이어가기 → 수진 U1-D03의 구체적인 복원 제안 → 시범 |
| 06 | 소리·배치 시범 | 아 소리 듣기 또는 자막 보기 → 수진 U1-D04/T01, 완성 모형으로 왼쪽·오른쪽 설명 → 내가 해 보기 |
| 07 | 도움 모형이 있는 조립 시작 | ㅇ·ㅏ 조각 선택 → 수진이 기다림 → 조립. 드래그 외 탭으로 조각·자리를 선택하는 경로 제공 |
| 08 | 내가 한 조각을 놓은 중간 상태 | 나머지 조각 놓기 또는 수정 → 조각이 자리에 맞는 조용한 반응 → 한 글자로 합치기 |
| 09 | 아 복원 완료 | 완성 글자 확인 → U1-F06, 첫 페이지 먹빛 복원 → 낭독 선택. 독립 정답·단원 완료 표시 없음 |
| 10 | 첫 소리와 낭독 | 듣기/함께 읽기/자막으로 계속 → 극중 내 이름의 U1-D05 아 낭독 → 책의 각성. 실제 발화 감지·점수 없음 |
| 11 | 책에서 탈선비가 깨어남 | 짧은 장면 보기 또는 건너뛰기 → 탈선비의 첫 웃음과 도깨비의 놀람 → 이어지는 대화 |
| 12 | 첫 재회 채팅 | U1-D06~D12 대화를 내 속도로 잇기 → 농담에서 외로움을 알아보는 반응 → 탈선비와 다음 학습으로 이어짐 |

프롤로그 **일곱 사건을 지금 모두 새 목업으로 제작할 필요는 없다.** 이번 02는 폐허의 사랑마당·주춧돌·서안이라는 실제 공간을 먼저 보여 주는 한 장의 연결 컷이다. 연결 설명은 P-1~P-6의 사건을 겪고 이곳에 도착했다는 범위만 EN/DE로 전달한다. 산길의 도움→배지 공명→초대→대문 재회→결계 안 비행→복원 제안의 원문 인과는 보존한다. 이 여섯 사건의 상세 컷·모션은 **후속 제작 배치**로 분리하며, 책 사건 뒤로 서사 순서를 옮긴다는 뜻이 아니다. 완성 R16이나 새 단서로 빈 배경을 채우지 않는다. 이번 모션의 중심은 책 복원→탈선비 등장 한 사건이며, 시범·조각 눌림·채팅 반응으로 이어진다.

**보조 7상태는 다음으로 고정한다.** V01 이름 입력·키보드 열린 상태, V02 07 위치 도움, V03 08 오답 피드백, V04 10 음성 사용 불가, V05 중단 메뉴, V06 부분 조립 상태로 복귀, V07 대화 기록·장면 다시보기. V03은 모음 왼쪽 배치(U1-F02)를 대표로 그리며 위아래 배치·따로 나열(U1-F01/F05)은 같은 구조에서 문구·시범을 바꾼다. 후속 P-1 제작 시 입문/경험자 대사 분기를 원안대로 보존하되 이번 이미지 수에는 넣지 않는다.

- **도움·오답:** 원래 조각과 응답을 남기고 바로 같은 자리에서 재시도한다. 도움 노출 후 성공은 도움 연습이다. 책을 다시 흩뜨리거나 탈선비를 재우지 않는다. 흔들기·벌점·모욕 반응을 넣지 않는다.
- **무응답·무음:** 시간제한과 자동 실패가 없다. 현재 대화와 조립을 유지하고 도움·자막 경로가 계속 보인다. 듣기 실패는 발음 실패가 아니다. 직접 말하지 않아도 각성과 재회를 경험한다.
- **중단·복귀:** 도깨비의 “그냥은 못 나간다”는 농담이 앱 이탈 잠금이 되지 않는다. 현재 대사·조립·도움 상태를 저장하고 같은 지점으로 돌아온다. 실행 중이던 음성/영상은 정지하고 사용자가 재개한다.
- **다시보기:** 원래 대사와 내 이름을 유지한다. 공개된 사실만 기록에 보이며 복습은 첫 각성·보상을 재발행하지 않는다. 모션 감소에서는 같은 사건을 정지 전환·자막으로 전달한다. 별도 신규 서사 분기나 이미지 수를 추가하지 않는다.

**학습과 서사는 따로 기록한다.** 이번 조작은 U1-T01→U1-P01→U1-D05~D12의 도움받은 아 복원과 이야기 각성이다. 뒤의 어 학습·아/어 별도 확인·단원 마무리는 이 제작 범위 밖이다. 단원 완료, 독립 읽기 성공, 듣기 점수, 엽전을 이 장면에 붙이지 않는다. 원문 P-7의 조각 목록에는 ㅗ가 있으나 최신 첫 단원은 ㅇ·ㅏ·ㅓ/아·어로 한정한다. 첫 각성 조작에는 배운 ㅇ·ㅏ만 제공하고 ㅗ·ㅓ를 미학습 오답 조각으로 넣지 않는다.

세계 배경은 대화 중에도 이어져야 한다. 캐릭터가 배경 없는 스티커처럼 흩어지지 않게 같은 바닥·빛·시선을 공유한다. 한국어는 학습 대상, 조작·도움·선택 안내는 EN/DE다. Lora/Source Sans 3의 실제 조판, 독일어 줄바꿈, 48dp 터치, safe area를 화면 사양으로 남긴다. 앱 전체 탭·100단원·16구간 재설계와 새 인물·미공개 단서는 제외한다.

읽고 적용한 스킬은 `user-flows`의 행동·결정·오류·복귀 지도, `mobile-app-ui`의 모바일 터치·키보드·safe area, `brainstorming`의 범위·가정·제작 전 문서화다. 이미 확정된 사용자 의도를 재질문하지 않았다. 2026-10-31 확인한 [Apple Onboarding](https://developer.apple.com/design/human-interface-guidelines/onboarding)은 불필요한 초기 꾸미기를 미루고 현재 과제에서 직접 배우는 구조에, [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)은 짧고 취소 가능한 모션과 대체 전달에 반영했다.
