# 통합 계획 교차 검토

2026-10-31. 세 역할의 병렬 AI 검토와, 문서 작성 뒤의 독립 제작자 검토를 진행했다. 사용자 승인이나 실제 이미지 품질 검수를 대신하지 않는다.

- 미술: 배경과 접지·원근·광원을 먼저 해결하고, 원본 인물과 건물을 재생성하지 않는 방향을 채택했다.
- RPG/초보자 경험: 이름과 실제 행동의 회수, 첫 아의 도움 연습, 오답/중단/복귀를 분리했다. P1~P6 전체 제작은 이번 필수 범위에서 제외했다.
- 파이프라인: 생성 영역과 보호 레이어·실제 조판을 분리하고 Figma의 편집 구조 복원과 Flutter를 별도 단계로 정했다.
- 독립 제작자 확인 결과: **nothing important left**. 제작 결과를 크게 바꿀 필수 미답 질문과 통합 PLAN 내부의 수량 모순은 없다고 보고했다. 12핵심+8보조=40장, 연락판2개, QA8개의 수량을 확인했다. 세부 카메라·배치·대표 대사 턴은 명시된 제약 내의 제작 판단으로 남겼다.

검토 중 정정한 내용:

1. 미술 검토자가 거절 화면의 갓 쓴 조이를 탈선비로 오인한 주장을 소스 표시와 숨김 검사 근거에 따라 정정했다. ‘복원 전 탈선비 등장’은 현 거절 화면의 확정 오류가 아니며 향후 실패 조건이다.
2. 원안 P7의 ㅗ 소품 표기를 그대로 오답 조각으로 쓰려던 제안을 최신 첫 단원과 대조해 정정했다. 첫 아에는 ㅇ·ㅏ만 쓰고 미학습 ㅗ·ㅓ를 시험하지 않는다.
3. 파이프라인의 ‘뒤쪽 한지 벽·목재 프레임’ 표현을 착공 전 사랑마당의 지면·원경·출처 확인된 기존 경계로 정정했다. 미완공 사랑채의 실내나 새 건축 기하를 생성하지 않는다.
4. 경험 검토자의 38장 대안에 동작 줄이기 전용 시각 상태 2개 언어를 추가해 통합안은 40장으로 정했다. 독립 의견 수량을 사용자 승인으로 바꾸지 않았다.
5. UI/UX Pro Max 일반 검색의 Flat Design·어린이용 서체·홍보 페이지 구조는 프로젝트와 맞지 않아 버렸다. 명시적 style 검색의 skeuomorphism 결과에서 재질·깊이·몰입형 서사 지침만 참고했다.

이번 계획 단계에서 새 이미지·HTML·앱 코드·Figma 쓰기·커밋은 실행하지 않았다. 이전 거절 목업의 이미지와 코드는 보존돼 있지만 재사용 구현 기준이 아니다.
