## 0. 한 줄 결론

한글소리는 **입력(읽기·듣기 이해)** 콘텐츠는 듀오링고급으로 충실하나, 실생활 습득의 핵심인 **산출(말하기·쓰기) + 능동적 회상 + 오류 피드백**이 거의 비어 있다. → 이번 세션에 **"문장 짓기(산출 연습)"** 첫 엔진을 넣어 인식→인출 전환의 토대를 깔았다.

**강점:** 모든 콘텐츠가 예문/맥락 기반 + CEFR 레벨링 + 이중언어. 입력 자산은 상용 근접.

**핵심 갭(실생활 습득 관점):**
- **거의 모든 학습이 "4지선다/탭" 인식(recognition)** — 단어팩 Learn→Quiz→Boss, 시나리오 퀘스트 5종(hoerverstehen 33·uebersetzen 33·particlePop 27·luecken 6·batchimDrop 1) 전부 선택지. 능동 텍스트 입력은 워들·끝말잇기·받아쓰기뿐.
- **시나리오의 `speaker:"user"` 대사 101줄**(KO+DE+EN 원어민 완비)이 있는데 **현재는 자동 재생만** — 사용자가 만들어내지 않음.
- 오답 시 정답만 노출 — **"왜 틀렸는지" 피드백 0**.
- 듣기 화면 = TTS 수동 재생(받아쓰기 없음).

언어습득 이론(Swain output hypothesis / retrieval practice): **산출 압박 + 피드백 루프**가 없으면 인식만 늘고 실제 발화는 안 큰다. 이게 가장 큰 갭.

## 3. 이번 세션 구현 — Phase 1: "문장 짓기(Satz bauen)"

**1·3·4 레버를 한 기능으로:** 시나리오 사용자 대사를 **단어 타일로 직접 조립해 만들기**로 전환 = ①능동 산출(인식→인출) + ③역할극(읽기→대화 참여) + ④기존 원어민 콘텐츠 재사용(신규 번역 0). 오프라인·결정적·저위험(STT/LLM 채점 불필요).

구현:
- `lib/screens/quest_engines/satz_bauen_quest.dart` — `SatzBauenQuest`. 단어 은행 ↔ 답 영역 탭 이동, "확인" 채점, **오답 시 첫 불일치 위치 하이라이트**(최소 오류 피드백), 2회 후 정답 공개. TTS 듣기 버튼(선택). 라이트/다크.
- 채점은 **순수 함수**(`tokenize`/`isCorrectOrder`/`firstMismatch`) — 어절 분절 + 문장부호/공백 정규화.
- `QuestType.satzBauen` 추가 + 시나리오 플레이어 디스패치 + `targetVocabKeys()` 연동(실패 시 해당 문장 키가 오류-인지 SRS로 빨리 복습에 노출).
- 콘텐츠 시드 8개(A1×4·A2×4): cafe/airport/taxi/bunshik/subway/mart/ktx/cafe_study. targetKo·promptDe·promptEn = 기존 user 대사 그대로, distractors = 동일 레벨 실제 어절(가짜 0).
- l10n DE/EN +2키. 테스트 +12(채점 로직·시드 무결성).

검증: `flutter analyze` 0 · `flutter test` **412 통과** · ARB parity 924=924 · gen-l10n OK. ⚠️ 실기기 시각(타일 조립·오답 하이라이트·셀러브레이션·다크)은 Jin.

## 4. 단계 로드맵 (다음 결정용)

### Phase 2 — 산출·듣기 본격화 (다음 세션 후보)
- **인라인 사용자 턴 산출**: 시나리오 대화 흐름에서 `speaker:"user"` 줄 도달 시 자동 재생 대신 *그 줄을 문장 짓기로 만들게* → 진짜 역할극. (현재는 퀘스트 단계에만 삽입)
- **받아쓰기(Dictation)** 퀘스트: 듣고 타이핑. 기존 TTS·시나리오 재사용 → 가성비 높음.
- 문장 짓기 시드 8 → **user 대사 101줄 전체**로 확장(자동 생성 파이프라인).

### Phase 3 — 피드백·커버리지 심화
- **오류 피드백 강화**: "왜 틀림" — 조사/어순/철자 진단 메시지(현재는 위치 하이라이트만).
- **상황 커버리지 확충**: 전화·이메일·메신저(카톡)·직장 시나리오(현재 갭).
- **단어 산출 모드**: 뜻→한글 직접 입력을 단어팩에도(현재 타이핑 모드는 커스텀팩만).

### Phase 4 — 큰 베팅 (분기 단위, 사장님 결정)
- **말하기/발음평가(STT)** — on-device/클라우드. 정확도·비용·UX 리스크.
- **AI 회화 파트너**(Claude API) — 실생활 대화 + 무한 개인화 시나리오. 구독 정당화(커머셜 방향과 합치).
- **TOPIK 시험 모드**.
