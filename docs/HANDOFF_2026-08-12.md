## 4. 해결 못 한 기술적 한계 (다시 시도하지 않도록)

### 콤마 쉼 (B군 4의 후반부)
`안녕, 오랜만이야!` 가 콤마에서 안 쉬고 붙어 나온다.
**`ko-KR-Chirp3-HD-Zephyr` 는 SSML 을 지원하지 않는다** — `<break>` 로 쉼을
지시할 수단이 없다. 텍스트를 바꿔 우회(콤마→마침표)하면 억양이 달라져 더
어색해질 위험이 있어 손대지 않았다.

해결하려면 **음성 모델 교체**(SSML 지원 `ko-KR-Neural2-*`)를 검토해야 하고,
그건 전 음성 재합성 + 음색 변경이라 Jin 결정이 필요하다.

### `하` 한 글자
길이 게이트 6회 재시도 전부 미달(최장 0.22s, 하한 0.35s) → 최장본 채택.
`ㅎ+ㅏ` 는 유성 모음이라 `스`(0.14s 무성 마찰음)처럼 사라지진 않을 것으로 봤으나
**청취 확인 안 됨.**

### Chirp3-HD 는 비결정적이다
같은 텍스트·같은 파라미터로 요청해도 매번 다른 길이가 나온다
(`그` 가 0.20s ↔ 0.49s). 그래서 "한 번 합성해서 확인"이 성립하지 않는다.
`tool/generate_tts.py` 의 길이 게이트 + 재시도가 이 성질을 전제로 만들어졌다.

회귀테스트 `test/vocab_pack_typography_test.dart`.

**`TtsService.stop()` 이 정지를 안 했다.** 재생만 멈추고 `_speakToken` 은 그대로
둬서, 진행 중이던 `speak` 의 `whenComplete` 가 나중에 실행돼 주인 없는 200ms
타이머를 걸었다. 폐기된 화면이 앱 전역 타이머를 남기는 상태였다.
→ 토큰 증가 + `AudioPolicy.restoreDuckNow()`.

**Lückentext 보기 생성기 버그.** 각 레벨 최다 오답 3개가 전부 ㄱ 으로 시작했다
(가족·거기·계란 / 가구·가을·갈색). 정렬된 어휘 목록의 앞 3개를 집어 온 것.
A1 은 99문항 중 47문항이 같은 보기를 썼다.

**Blitz-Paare 옛 효과음.** `correct.wav`/`wrong.wav` 만 두 옥타브 내리고
`combo.wav` 를 C6-E6-G6(1046~1568Hz)에 남겨둬서, 콤보가 터질 때마다 폐기했어야
할 음색이 그대로 들렸다.

**`gen_sfx.py` 파괴적 버그.** `/tmp/chime_raw.wav` 가 없으면 사용자 chime 인
`complete.wav` 를 합성 폴백으로 조용히 덮어썼다. `/tmp` 는 재부팅·다른 OS 에서
반드시 사라지므로 스크립트를 한 번 더 돌리는 것만으로 사라졌다.

## 6. 도구·운영 메모

### TTS 캐시는 파일명이 내용을 반영하지 않는다
`tts/v3/{voice}/{sha1("voice|text")}.mp3` — **텍스트**의 해시다. 음성 내용을
바꿔도 파일명이 같아서 **기기 캐시가 저절로 무효화되지 않는다.**
업로드 후 반드시:
```bash
adb shell run-as com.sujinarin.ko_lernen_app rm -rf cache/tts_cache
```

### `tool/polish_tts.py` (신규)
앞뒤 묵음 제거. ffmpeg `-c copy` 로 **프레임 경계 무손실 절단**(재인코딩 0).
`--dry-run` 으로 측정만 가능. 멱등하다(`30bb60b` 에서 수정 — 그 전에는 돌릴
때마다 말끝이 조금씩 깎였다).

### `tool/regen_cloze_distractors.py` (신규)
cloze 오답 보기만 재생성. **`distractors` 외 필드는 절대 건드리지 않는다** —
예전에 cloze 를 통째로 재생성했다가 불변 source ID 계약이 깨져 테스트가
12→32 실패로 늘어난 적이 있다(`3dec039` 에서 되돌림).

### 골든 테스트는 Linux(CI) 정본
Windows 로컬에서는 skip 된다. 이번에 `home_layout`·`screen_layout` 에
`Platform.isLinux` 가드를 넣어 로컬 상시 빨간불 11건을 없앴다
(`design_components` 에는 원래 있었다).

### MIUI 설치
`flutter run` 의 설치가 `INSTALL_FAILED_USER_RESTRICTED` 로 거부될 수 있다.
직후 `adb install -r` 은 성공한다 — **폰 화면의 확인창**을 눌러야 한다.
설정 토글 문제가 아니다.

### 동시 작업 주의
여러 세션이 같은 저장소에서 `flutter` 명령을 돌리면 `.dart_tool` 삭제·APK 잠김
충돌이 난다. 빌드 전에 다른 세션 상태를 확인할 것.
