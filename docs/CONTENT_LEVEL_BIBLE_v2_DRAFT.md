## §0 조정 규칙 요약 (Jin 승인, Fable 설계)

1. **어휘 등급 권위 = NIKL 등급**(1급→A1 … 6급→C2). 세종 본편 유닛 어휘는
   **순서·주제 권위**이자 **승격 트리거**다 — NIKL 2급 이상 단어를 세종이 더
   낮은 레벨에서 생존/정형 표현으로 가르치면, 그 낮은 레벨에 **F9식 예외로만**
   등재한다(인용 필수). 예: 계시다/드리다/말씀(세종1 회화 익힘책 1-2, 9과
   어휘, p.99) → A1.
2. **문법 도입 레벨 = 세종 본편(OCR 원서, 있으면 우선)**. NIKL과 세종이 2등급
   이상 차이 나면 Jin 결정 목록에 올린다(Fable이 대신 정하지 않음). 세종이
   전혀 안 가르치는 NIKL 문법은 NIKL 등급 유지 + "세종 미도입" 표기.
   A1/A2는 세종 본편 문법이 OCR로 추출되지 않아(문법 연습 #N 형식, 인라인
   패턴 라벨 없음) **"세종 미검증(자료 없음)"**으로 별도 표기한다 — "세종
   미도입"(=확인 결과 안 가르침)과는 다른 상태다.
3. **주제/can-do/유닛 순서 = 세종 유닛**(인용). 레벨별 문장 규범은 세종 대화
   벤치마크(Q-S2, 글자수/어절/절수)로 측정한 범위로 설정.
4. **깊이 요구사항**(Q-C 기준): A1/A2 = 뜻 + 예문 1개; B1+ = 사용 노트(뉘앙스,
   전형 상황, 연어 2~3개, 대비 1~2개, 격식, 예문 2개) —
   `docs/CONTENT_USAGE_NOTES.md`(C9-T0, PR #356) 참고. **이 문서는 2026-09-16
   기준 main에 없다 — 아래 §depth는 목표를 서술한 것이고, PR #356 병합 전까지는
   시행 문서가 아니다.**
