## 1. 검수 루브릭 (통번역가 기준) — 모든 항목에 동일 적용

판정: `KEEP` / `FIX_KO` / `FIX_DE` / `FIX_EN` / `RELEVEL` / `REWRITE_TO_LEVEL` / `DROP`(대체 필요). 사유 코드를 붙인다.

**KO 자연성**
- N1 원어민이 그 상황에서 실제로 하는 말인가 (번역투·교재투, 불필요한 "저는/당신은" 반복 금지)
- N2 조사·어미 정합 (받침/조사, 과잉 조사, "에 대해" 남용)
- N3 레지스터 일관 (해요/합쇼/반말이 화자 관계와 일치. 장면 안에서 흔들림 금지)
- N4 연어: "결정을 내리다", "약속을 지키다" 등 자연 결합
- N5 맥락 완결: 예문 하나만 보고 이해되는가
- N6 표제어가 대표 의미·대표 용법으로 쓰였는가
- N7 문화·사실 정확성 (명절·제도·호칭)
- N8 TTS 위험 문자 없음 (ㅎㅎ·ㅋㅋ·~·… 남용, 숫자·로마자 읽기 모호)

**레벨 정합**
- L1 표제어·핵심 문법이 레벨 정본(NIKL 국제통용; `docs/data/level_bible/`)에 맞는가
- L2 예문의 **비표제 어휘**가 레벨+1등급 이하인가
- L3 길이 밴드(어절): A1 2–5 · A2 3–6 · B1 4–8 · B2 6–11 · C1 8–14 · C2 9–15 (시나리오 대사 ±2, 짧은 맞장구 예외)
- L4 상위 레벨에서 2등급 이상 쉬운 문장은 **표제어를 그 레벨의 용법(격식·추상·복문)으로 다시 쓴다**. 단순 길이 늘리기 금지

**DE (독일어권 학습자용)**
- T1 독일어 원어민이 그 상황에서 하는 말 (직역·과잉 설명 금지)
- T2 du/Sie가 KO 레지스터와 대응 (반말↔du, 낯선 사이 존댓말↔Sie, 친구 해요체↔du)
- T3 문화 등가 (말 놓다↔sich duzen, 수고하셨습니다↔장면별 등가어)
- T4 성별 중립은 **자연스러운 범위에서만**. "A oder B" 이중형·우회 표현 금지 (§5 D1)
- T5 독일식 따옴표 („…"), em/en dash 금지(`arb_l10n_guard`)
- T6 의미 누락·추가 없음

**EN**: T1·T4·T6 동일, 미국식 표준 일관.

**음성**: A1 KO 텍스트가 바뀐 항목은 전부 TTS 재합성 · A2 숫자·단위·영문 약어 읽기 확인 · A3 레벨별 표본 기기 청취

## 3. 실행 방식 (항목 단위)

1. **샤드**: 레벨별 약 120항목씩(예문은 표제어+예문+DE+EN을 한 행으로).
2. **1차 판정(검수 에이전트)**: §1 루브릭으로 전 항목 판정 → `docs/data/naturalness_v2/<wave>_<level>_<shard>.csv` (id, verdict, codes, ko_new, de_new, en_new, note). 검수자는 수정안만 내고, 데이터 파일은 직접 건드리지 않는다.
3. **2차 판정(Opus)**: 수정안은 **전수** 직독하고, KEEP 판정은 10% 표본으로 재확인한다 → 반려·재지시.
4. **적용**: `tool/apply_naturalness_patch.py`(id-키 패치, `--dry-run`) → 파생 재생성.
5. **게이트**: 결정적 감사 3종 재실행(마커 0·레벨 over2 0·밴드 이탈 0, 예외는 원장 등록) + 콘텐츠 후속 체크리스트 전 항목(TTS 매니페스트·can-do 지문·레벨 리포트·문맥 원장·샤드 sha·첫 대사 번들·dash 금지·gloss 시드·배분어 재사용 ≤4·게임 계약 cloze 정답 ≥2음절·satz ≥3어절) + 표준 대상 테스트.
6. **Jin 표본**: 레벨별 수정분의 10%를 `docs/data/review_packets/naturalness_v2_<level>_jin.md`로 묶어 승인받은 뒤 병합.

- **D1 독일어 성별 표기**: 현재는 "Partnerin oder Partner", "jemanden aus meinem Freundeskreis" 같은 이중형·우회 표현. → **권장: 문맥상 자연스러운 한 형태**(예: "mit meiner Freundin", "einen Freund"). 학습 예문에선 가독성이 우선이다.
