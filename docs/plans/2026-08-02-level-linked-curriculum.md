# 레벨 연동형 실전 한국어 커리큘럼 구현 계획

기준 브랜치: `codex/level-linked-curriculum-2026-08-02`
범위: 기존 콘텐츠를 보존하면서 코스 그래프, 개념 숙달, 레벨 상태 분리,
온보딩 진단, A1 16개 미션과 A2/B1/B2의 기존 활동을 실제 앱 흐름에 연결한다.

## Task 1: 콘텐츠 그래프와 데이터 계약

- `CourseUnit`, `Concept`, `FormFamily`, `ContentLink`, `SurfaceForm`,
  `MasteryEvidence`를 추가한다.
- 한글 표제어와 문법 표면형에서 안정 ID를 계산해 기존 CSV를 호환한다.
- 단일 `curriculum_manifest.json`에 코스 미션, 표현 가족, 시나리오 맥락,
  감사 기준을 기록한다.
- 모든 기존 어휘·문법·시나리오·스몰토크·cloze·문장조립 항목을 적어도 한
  코스 미션과 한 개념에 링크하고, 그래프 무결성을 테스트한다.

## Task 2: 숙달·오답 보정·해금

- `placementLevel`, `courseUnitId`, `browseLevel`을 별도 versioned 저장 키로
  둔다. 기존 `userLevelCode`는 호환용으로 유지한다.
- 개념 증거는 활동 ID, 정오답, 오답 원인, 시각을 남긴다.
- 필수 개념과 시나리오 체크포인트의 정확도가 70% 이상일 때 다음 미션을
  해금한다. 오답은 같은 개념의 보정 연습을 추천한다.
- 기존 단어 SRS는 그대로 유지하고, 코스 개념 복습 큐를 별도로 둔다.

## Task 3: 앱 흐름과 진단

- 홈의 다음 행동과 학습 경로는 현재 코스 미션을 열고, 단어·문법·게임·
  시나리오는 미션 안의 연습실 링크로 제공한다.
- 레벨을 아는 사용자는 기존 직접 선택으로 시작한다.
- 추천이 필요한 사용자는 녹음 없는 8문항 진단을 완료하거나 건너뛰고,
  추천 시작 미션을 확인한다.

## Task 4: A1 파일럿과 기존 활동 연결

- 네 미션: 인사·한글 병행, 자기소개와 `입니다`, 주제·주어 조사,
  주문·요청과 `을/를`.
- `입니다 / 이에요·예요 / 이야·야`, `합니다 / 해요 / 해`,
  `할까요? / 할래요? / 하자 / 할래?`, 조사 가족을 현실 카드로 제공한다.
- 기존 자기소개·공항·카페/분식 시나리오, 어휘 팩, cloze, 문장 조립 결과가
  개념 증거와 보정 추천을 남기게 한다.

## Task 5: A1 한국 생활 첫 90일 확장

- A1 16개 미션에 13개 시나리오 체크포인트를 배치한다.
- 수업 첫 만남, 전화·메신저, 배달 주소 확인, 되묻기, 호칭·거리 조절,
  병원·안전의 6개 현실 시나리오를 추가한다.
- 모든 A1 시나리오에 조사/활용 보정 활동과 직접 산출 활동을 연결한다.

## Task 6: A2 말투 전환과 스몰토크 관계 맥락

- 145개 스몰토크 노드에 상대·관계, 안전한 대안 질문, 다음 대화 턴을
  기록한다.
- `할까요? / 할래요? / 하자 / 할래?`를 A2 약속·제안 미션에서 관계별로
  보여 주고, 화면에서 그 관계와 안전한 대안을 학습자가 확인할 수 있게 한다.

## Task 7: B1/B2 재연결

- B1 6개와 B2 6개 미션 각각에 명시적 시나리오 평가 링크를 둔다.
- 상위 레벨의 기존 단어·문법·시나리오를 이유·간접화법·완곡함·공식 말투
  선택으로 다시 배치한다.

## Task 8: 검증 및 운영 기록

- 단위 테스트로 ID·링크·순환 선수 조건·해금 경계·오답 보정·진단을 검증한다.
- `flutter analyze`와 직렬 전체 테스트를 실행한다.
- 변경 사항 및 검증 결과를 `AGENTS.md`와 Codex 메모리에 기록한다.

## 완료 경계

이번 변경은 구조·트리거·온보딩·A1 생활 시나리오·A2 관계형 스몰토크·B1/B2
재연결을 완성한다. 이후 새로운 원문을 대량으로 추가하기 전에는 자동 검수와
별도로 한국어 화자가 자연스러움, 관계 적절성, 문화 맥락, 받침/활용 정확성을
최종 검수한다.
