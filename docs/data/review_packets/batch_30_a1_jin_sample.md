## POS별 배분어(Distractor) 규칙 요약

1. **접속부사 8개**(그래서/그러니까/그러면/그럼/그런데/그렇지만/그리고/하지만) — **Tier B**(R8): 정답 = 접속사 그대로, 배분어 = 사전형 동사 또는 조사(2+1 또는 3+0 구성, `open connective frame` 태그) — 접속사 자리에 사전형/조사를 넣으면 두 번째 문장을 열 수 없어 항상 비문. 그러면·그럼은 질문–응답 프레임("민호 씨, 배가 고파요? 그러면…" / "레나 씨, 오늘 바빠요? 그럼…")으로 재구성.
2. **1음절 부사 2개**(못/잘) — 정답 = "부사+서술어" 묶음, 배분어 = 같은 부사 + 이미 나온 목적어와 충돌하는 서술어.
3. **개방형 부사 9개**(가장/보통/아주/아직/안녕히/얼마나/열심히/왜/참) — 정답 = 부사(또는 서술어 접합), 배분어 = 문맥과 부류가 다른 부사.
4. **대명사류 13개**(그/그것/그쪽/이것/이쪽/저것/저쪽/무엇/뭐/어디/언제 + 결속형 내/제) — 정답 = 대명사+조사(또는 내/제+명사), 배분어 = 다른 부류의 대명사 + 같은 조사 → 격조사 오류/범주 불일치.
5. **의존명사·단위명사 12개 + 수사·관형사 8개(억 포함) + 순수 수사 3개(구십/팔십/천)** — 정답 = 숫자(혹은 이름)+올바른 단위명사(계사 접합 포함), 배분어 = **같은 숫자/이름 + 틀린 단위명사**.
6. **순수 관형사 3개**(무슨/어떤/여러) — Tier B: 배분어 = 사전형 동사 + 같은 명사.
7. **수사 1개(스물)** — 열린 계사 자리; 배분어 = 범주가 다른 명사+이에요.
8. **감탄사 2개**(그래/아) — 질문/사과 뒤 응답 프레임; 배분어 = 사전형 동사로 감탄사만 대체.
