## POS별 배분어(Distractor) 규칙 요약

Fable 브리프의 품사별 지침을 아래처럼 기계 검증 가능한 형태로 구현했다(전체 근거는 매니페스트 `posRules` 참고, 공유 모듈 `a1_draft_rules.py`/`distractor_rules.py`에 있는 헬퍼로 `test_batch_30_draft.py`가 자동 검증):

1. **접속부사 8개**(그래서/그러니까/그러면/그럼/그런데/그렇지만/그리고/하지만) — 결과(그래서·그러니까)/조건(그러면·그럼)/대조(그런데·그렇지만·하지만)/첨가(그리고) 4클러스터로 나누고, 배분어는 항상 **다른 클러스터**의 접속사만 쓴다(같은 클러스터끼리는 바꿔도 여전히 유효한 문장이 되어 금지). 예문은 강한 인과/조건/대조/첨가 관계라 다른 클러스터로 바꾸면 논리가 어긋난다.
2. **1음절 부사 2개**(못/잘) — 정답 = "부사+서술어" 묶음(예: `못 먹어요`), 배분어 = 같은 부사 + 이미 나온 목적어와 충돌하는 서술어(`못 자요`/`못 입어요`/`못 타요`).
3. **개방형 부사 9개**(가장/보통/아주/아직/안녕히/얼마나/열심히/왜/참) — 정답 = 부사(또는 2음절 게임 규칙을 맞추기 위해 참처럼 서술어를 접합), 배분어 = 문맥과 부류가 다른 부사(정도부사 자리에 시제/양태 부사 등)라 넣으면 의미가 성립하지 않는다.
4. **대명사류 13개**(그/그것/그쪽/이것/이쪽/저것/저쪽/무엇/뭐/어디/언제 + 결속형 내/제) — 정답 = 대명사+조사(또는 내/제+명사, 조사를 가질 수 없는 결속형이므로), 배분어 = 다른 부류(사물/방향/사람/시간)의 대명사 + 같은 조사 → 격조사 오류 또는 범주 불일치로 비문/의미 불성립.
5. **의존명사·단위명사 12개 + 수사·관형사 8개(억 포함) + 순수 수사 2개**(가지/권/년/때/마리/명/번/살/쪽/호/중/씨, 마흔/백만/서른/십만/아흔/여든/일흔/억, 구십/팔십) — 정답 = 숫자(혹은 이름)+올바른 단위명사(필요하면 서술어 이에요/예요까지 접합해 조사가 blank 밖에서 홀로 남지 않게 함), 배분어 = **같은 숫자/이름 + 틀린 단위명사**(범주 불일치로 결정적 의미 불성립). 것(문법적 의존명사)은 "N은 제 것이에요" + 범주 불일치 명사(친구/나라/이름)로, 때는 2급 "-(으)ㄹ 때" 대신 1급-안전한 "N + 때"(시험 때)로 처리했다.
6. **순수 관형사 3개**(무슨/어떤/여러) — 서로 근의어라 Tier A(다른 관형사로 교체)가 오히려 유효한 문장을 만들 위험이 있어 브리프의 예외 조항대로 Tier B: 배분어 = 사전형 동사 + 같은 명사(`가다 음식`/`먹다 음식`/`오다 음식`) — 활용되지 않은 사전형은 명사를 직접 수식할 수 없어 항상 비문.
7. **수사 1개(스물)** — "스물이에요"처럼 통째로 열린 서술어 자리(계사)라 Batch 25의 PREDICATE_SLOT_WAIVER와 같은 부류; 배분어 = 범주가 다른 명사+이에요(가방이에요/이름이에요/우산이에요).
8. **감탄사 2개**(그래/아) — 질문/사과 뒤에 오는 응답 프레임에 앵커링하고, 배분어는 감탄사 자리에 사전형 동사를 넣어(가다/먹다/오다) 응답을 완성하지 못하게 한다(라이브 네/아니요/와 선례와 동일 기법).
