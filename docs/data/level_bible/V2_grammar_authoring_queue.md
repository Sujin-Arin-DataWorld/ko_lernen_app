## 우선순위 1 — 간접화법 어미족 (B1, 세종 3B 직접 근거)

**항목**: `-는다고2/-냐고/-으라고/-자고` (평서/의문/명령/청유 간접화법
어미, NIKL 3(B1) 표현 `-는다고3` 및 이형태
`-ㄴ다고3/-다고3/-라고5/-느냐고2/-냐고2/-으냐고2/-자고3/-으라고3/-라고8`).

- **레벨**: B1.
- **세종 인용**: 세종학당 한국어 3B(영어), p.231, "세종 3A/3B 실물".
- **왜 최우선인가**: v1 §B.3①은 이미 "간접화법 도입"을 B1 can-do로
  서술하고 있고, 세종3 11과 "배우들이 연기를 정말 잘한다고 해요"가 바로
  이 어미족의 실제 용례다(§B.3① 인용 신설, 2026-09-16) — **원칙은 이미
  바이블에 있는데 콘텐츠(grammar.csv 행)만 없다.**
- **행에 필요한 것**: 평서(`-는다고 하다`)·의문(`-냐고 하다`)·명령
  (`-으라고 하다`)·청유(`-자고 하다`) 4갈래를 한 행에 담을지 분리할지
  결정(권장: 평서형 1행 + 나머지 3개는 note/이형태 칸에서 다루거나 각각
  별도 id) → 설명 DE/EN(간접화법 개념: 직접인용 "" → 간접 서술), 예문
  2개(격식/비격식 각 1, 세종 3B p.231 예문 참고해 페르소나 교체), 퀴즈
  디스트랙터는 같은 B1 인용어미(`-다면서`·`-는지` 등)와 구분되게.
- **연관**: `-는지`(grammar_b1_whether)가 이번 PR에서 B1→B2로 이동했으므로
  같은 유닛(b2_02_professional_opinion)에 있던 디스트랙터 세트가 바뀌었다
  — 새 간접화법 행을 만들 때 quiz_distractor_ids를 그 변경 이후 기준으로
  잡을 것.

## 우선순위 2 — `-거든1` (연결어미, B1, 세종 3A 직접 근거)

**항목**: `-거든1`(이형태 `거들랑`) — 연결어미, "이유 설명"(예: "오늘 좀
바빠요. 시험이 있거든요" 류의 연결형; **종결어미 `-거든2`와 다른 형태**,
`-거든2`는 이미 `grammar_b1_explanatory_reason`으로 match되어 있어
저작 불필요).

- **레벨**: B1.
- **세종 인용**: 세종학당 한국어 3A(영어), p.237, "세종 3A/3B 실물".
- **행에 필요한 것**: 설명 DE/EN(연결어미 "-거든"이 이유를 먼저 깔고
  뒤에 본론을 잇는 용법임을 `-어서`/`-으니까`와 대비), 예문 2개, 퀴즈
  디스트랙터는 `grammar_b1_explanatory_reason`(종결어미 -거든2)과 확실히
  구분되는 문맥으로(연결 vs 종결).

## 우선순위 3 — A2 결손 6건 (세종 미검증, NIKL 근거만)

세종 A1/A2 본편은 OCR로 문법 라벨이 추출되지 않아(§0.2, 익힘책 "문법
연습 #N" 형식) 아래 6건은 세종 근거 없이 NIKL 등급만으로 저작해야 한다
— "세종 미도입"(확인 결과 안 가르침)이 아니라 **"세종 미검증(자료
없음)"**임을 행 note에 남길 것.

| 항목(NIKL 2급) | 이형태 | 레벨 | 비고 |
|---|---|---|---|
| `-다가1(1)` | -다5, 다가도 | A2 | §B.3에도 `-다가1(2)` 동형이 3급 중복 라벨로 있음 — 두 항목이 서로 다른 세종/NIKL 분류인지 저작 시 재확인 |
| `에게로` | | A2 | 조사, 저빈도 — 예문 2개 확보가 어려우면 저빈도 사유로 저작 순연 검토 |
| `에다가` | 에다 | A2 | 조사 |
| `에서부터(서부터)` | | A2 | 조사 |
| `-지` | -지요(-죠) | A2 | 반말체 부가의문 — A2 담화 규칙(반말 인지, §B.2⑥)과 연결해서 저작 |
| `-을 것1` | -ㄹ 것1 | A2 | 명사형 — 이미 있는 `-는 것`(A2 표현)과 최소대립쌍 예문으로 구분 필요 |

## 우선순위 4 — `-는 만큼` (B1로 확정, 세종은 C2에서만 확인)

**항목**: `-는 만큼`(이형태 `-ㄴ 만큼/-은 만큼/-ㄹ 만큼/-을 만큼`).

- **레벨**: **B1**(Jin 결정 1, `docs/CONTENT_LEVEL_BIBLE.md` §0 참고 —
  NIKL 3급 권위를 세종 6급 근거보다 우선).
- **세종 인용(참고, B1 저작에는 직접 쓰지 않음)**: 세종학당 한국어 6,
  unit4 "시장과 정부" p.19(C2, 문어체 근거제시 용법) — B1 저작은 이
  문어체 인용을 그대로 따르지 말고 §B.3① 조사 "만큼"(B1, missing_in_app,
  세종 3B p.229) 쪽 구어 비교 용법을 기준으로 삼을 것.
- **행에 필요한 것**: 설명 DE/EN(구어 비교 "-는 만큼" = "~하는 정도로"),
  예문 2개(비교 용법 중심, 문어체 근거제시 뉘앙스는 넣지 않음 — 그건
  C1/C2 확장 후보로 별도 검토), 퀴즈 디스트랙터는 조사 "만큼"과 표현
  "-는 만큼"을 헷갈리지 않게. **저작 시 반드시 확인**: 세종6 p.19 원문
  예문을 다시 읽고 "두 레벨에 다른 용법으로 나눠 넣을지"(Fable 원 추천
  (C))를 재검토 — 이번 세션은 "B1 유지"까지만 확정했고 분리 여부는 열어
  뒀다.
