# B1 문법 대응: 동형어와 문법 기능 구분

## 범위와 판정 한계

국제통용 3급 문법 67항목의 대응 후보를 집계할 때, 같은 글자라는 이유로
서로 다른 문법 기능을 포함하지 않는다. 기준은 저장소의
`tools/content_factory/lexicon/nikl_kiiq_2017_grammar.csv` 원형·동형어 번호·품사·의미와
`assets/data/grammar.csv`의 현재 패턴·설명·예문이다.

아래는 자동 집계에서 제외할 **정확한 원형/앱 항목 쌍**이다. 사람 검수 승인이나
새 콘텐츠의 승격이 아니다. 기존 대응표 스키마의 `observed_syntactic_candidate`는
표면형 겹침만 관측했다는 뜻으로 사용하며 의미상 대응을 인정하지 않는다.
`reviewState`도 `observed_syntactic_candidate`로 두어 `reviewed_source` 승인을 만들지 않는다.
`reviewedSource` 필드는 기존 스키마가 요구하는 근거 문서 위치이며 사람 승인 기록이 아니다.

## 제외할 대응

| 정확한 sourceKey | 제외할 appGrammarId | 원자료와 앱 예문의 차이 |
|---|---|---|
| `G3:-으나` | `grammar_a1_or_particle` | 원자료는 연결어미 `-으나`, 변이형 `-나4`, 의미 `대립`이다. 앱의 `N(이)나`와 “커피나 차를 드세요.”는 명사 사이의 선택을 나타내는 조사로, 대립 연결어미의 근거가 아니다. |
| `G3:이고` | `grammar_a1_sequence_connector` | 원자료는 조사 `이고`, 변이형 `고1`, 의미 `모두 포함`이다. 앱의 `V-고`와 “밥을 먹고 공부해요.”는 동작을 연결하며, 명사에 붙는 포함 조사의 근거가 아니다. |
| `G3:-거든2` | `grammar_b1_conditional_geodeun` | 원자료는 종결어미 `-거든2`, 변이형 `거든요`, 의미 `이유`이다. 앱의 “서류가 준비되거든 연락해 주십시오. / 집에 도착하거든 전화해 줘.”는 뒤의 요청에 조건을 붙이는 연결어미이며 이유를 제시하는 종결어미가 아니다. |

## 보존할 대응과 집계 해석

- `G2:이나` → `grammar_a1_or_particle`: 선택 조사 대응은 계속 후보에 포함한다.
- `G1:-고3` → `grammar_a1_sequence_connector`: 동작 연결 대응은 계속 후보에 포함한다.
- `G3:-거든1` → `grammar_b1_conditional_geodeun`: 조건 연결어미 대응은 유지한다.
- `G3:-거든2` → `grammar_b1_explanatory_reason`: 이유 종결어미 대응은 유지한다.
- `G3:-는다고3`의 기존 간접 인용 네 항목 대응 및 기존 검토 근거는 변경하지 않는다.

집계의 `missing_in_app`은 이 매핑에서 확인된 대응이 없다는 뜻이다. 앱 전체에
그 문법이 전혀 없다는 확정이나 사람 검수 결과로 확대하지 않는다. 나머지 표면형
매치도 의미·학습·과제·평가 완료를 보장하지 않는다. 학습 CSV, 원자료 CSV,
기존 검토 원본, 번역, TTS, 진행도 저장 형식은 이 감사 수정의 변경 대상이 아니다.
