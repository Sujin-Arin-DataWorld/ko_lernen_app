# B1 문법 카드와 Phase 과제의 감사 범위

F1 문법 대응표의 비교 대상은 `assets/data/grammar.csv`다. 기존 상태 이름
`missing_in_app`은 이 문법 카드 목록에서 대응을 찾지 못했다는 뜻이며,
앱의 모든 학습 경로에 설명이나 연습이 없다는 뜻으로 확대하지 않는다.
반대로 `match`도 용법·학습 수준·평가 타당성이나 사람 검수를 보증하지 않는다.

## 2026-09-24 소스 확인

main `768337a0237347d505665fc50314a0d6cc43f463`의 아래 자료를 대조했다.

- 기준 목록: `tools/content_factory/lexicon/nikl_kiiq_2017_grammar.csv`의 3급 67항목.
- 과제와 목표: `assets/data/phase_tasks.json`의 B1 목표 중
  `sourceRequirementKey`가 `grammar/G3:`로 시작하는 항목.
- 연결: `assets/data/learning_phases.json`의 KP09–KP13 `taskIds`와
  각 목표의 `bindings` 및 실제 과제 ID·레벨·모드.

67개 기준 요구 모두에 읽기 R과 표현 P 목표가 각각 하나씩 있다.
목표 134개는 서로 다른 과제 134개에 연결돼 있다. 공개 상태는 `partial`,
목표의 `mastery`는 모두 `unverified`다. 이는 과제 연결의 재고 확인이며,
67항목의 교육 품질이나 B1 전체 완료를 판정한 것이 아니다.

소스 경로는 학습 경로의 `/course/phases` → Phase 상세의
`PhaseTaskPanel` → `/learning-phase/task`다. `PhaseTaskCatalog`는
게시 해시와 과제·목표 연결을 검증한다. 이 연결의 존재와 실제 휴대전화에서
모든 과제를 사용할 수 있다는 증거는 구분한다.

## 후속 작업

1. 카드 감사표의 누락만 보고 같은 문법 과제를 중복 작성하지 않는다.
2. 기존 과제의 한국어 뜻·말투, DE/EN 설명·선택지, 선행 학습과 수준을 검수한다.
3. 과제 진입·큰 글자·오류 복구·답변 제출과 필요한 음성을 실제 화면과 기기에서 확인한다.
4. 표현 과제의 제한된 허용 답변 목록을 모든 유효한 표현의 완전한 채점기로 취급하지 않는다.
5. 별도 문법 카드가 필요하면 발견하기 쉬운 진입점이나 설명 보완으로 기록한다.
   같은 학습 요구를 두 번 집계하거나 기존 진행도·보상을 다시 지급하지 않는다.

`-고 싶어 하다`, `-(으)려면`, `-아/어 두다` 보완 초안도 기존 Phase 요구와
겹친다. 원본과 검토 이력은 보존하고 기존 과제와 비교한 뒤 필요한 개선만
채택한다. 새 초안이나 자동 검사 성공을 사람 승인으로 올리지 않는다.

현재 남은 완료 증거는 사람 검수, 평가의 타당성, 실제 기기 접근·학습,
필수 음성 및 전체 학습 기능과 수준의 품질이다. 단순한 ID 대응 수로 대체하지 않는다.
