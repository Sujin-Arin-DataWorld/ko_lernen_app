- **topic_progression** [implemented] 개인·주변·서비스에서 사회·자료·제도·추상·전문·문학으로 넓힌다. 상위 레벨에도 가족·동료의 일상 관계를 남기고 요구하는 추론·관점 조절을 높였다.
