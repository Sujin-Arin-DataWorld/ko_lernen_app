## 권장 콘텐츠 생산 방식

스캔 자료에서 복원한 것은 복사할 문장이 아니라 주제, 문법 기능, 활동 흐름이다. 실제 생산은 다음 순서로 한다.

1. 주제와 담화 기능만 적은 씨앗 명세를 만든다.
2. 교재 문장을 보지 않은 상태에서 상황, 대화, 선택지와 번역을 독립 창작한다.
3. 같은 씨앗에서 시나리오, 듣기, 문장 만들기, 발음, 빈칸, 스몰토크를 파생한다.
4. 각 항목을 정확한 레벨, 코스 단원, 개념 ID에 연결한다.
5. PDF 추출 텍스트와 exact 및 near-match 검사를 수행한다.
6. 독일어와 영어 번역, 발음 표기, 정답, 난이도를 별도로 검수한다.
