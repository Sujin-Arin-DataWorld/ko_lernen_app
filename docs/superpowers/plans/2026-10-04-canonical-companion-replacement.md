## 교체 순서

1. **정본 등록:** PNG의 투명도·여백·해시, 영상의 전체 프레임·소리·처음과 끝 자세를 확인한다. 원본 보존 경로와 실제 사용 파일을 연결하는 manifest를 만든다. 밝은 앱 배경에서 42/54/144dp 비교로 시선과 얼굴 가독성을 검수한다.
2. **공통 캐릭터 경로 교체:** `Mascot`, 오류·빈 상태, 프로필·선택, 홈·학습 카드, 끝말잇기·듣기·게임 결과를 동일한 캐릭터 카탈로그로 연결한다. 직접 적힌 옛 PNG 경로도 교체한다. 저장된 `tiger`/`magpie` 선택값과 음성 resolver는 보존한다.
3. **옛 영상 혼용 제거:** `HomeHeroClips`, `CharacterClips`, `TigerStageVideo`의 기본·폴백·호출부를 함께 점검한다. 새 영상이 없는 슬롯은 새 PNG와 짧은 UI 반응으로 표현한다. 새 까치 폴더에는 MP4가 없다. `backho.mp4`는 10.04초/1920×1080/24fps이며 반복 대기로 바로 적용하지 않는다. 유료 영상 제작은 계획하지 않는다.
4. **수명주기·실패 복구:** 숨김·백그라운드·동작 줄이기와 원샷 완료의 한 번 실행을 유지한다. 위젯 교체·dispose 뒤 이전 재생 Future가 실패해도 새 상태에 영향을 주지 않는다. 이미지 실패는 같은 정본 가족의 폴백을 한 번만 시도한다. 이전 영상용 확대·크롭을 새 PNG에 적용하지 않고 비정방형 스티커의 원본 비율을 보존한다.
5. **전체 검증:** 정지·영상·실패 fallback에서 옛 캐릭터가 다시 나오지 않는지 검사한다. 새 원본 해시, 에셋 잠금 테스트, 선택값·보상 회귀, 320/390dp·태블릿·DE/EN·큰 글자·모션 감소를 확인한다. 상태는 대기 → 진행 → 검증 → 완료로 갱신하며 구현·검증 근거를 남긴다.
