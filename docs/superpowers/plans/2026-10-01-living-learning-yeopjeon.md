# Hangul Sori를 ‘살아 있는 학습 앱’으로 개선하는 계획

> 실행: superpowers 실행·검증 절차를 사용한다. 사용자 요청으로 엽전 경제와 건축을 기존 계획에 추가하고 지금 구현한다. 커밋·푸시·배포는 별도 요청 전 수행하지 않는다.

**Goal:** 기존 한지·단청·호랑이·까치·일두고택 정체성을 유지하면서 학습의 선택·정답·오답·완료·보상·건축을 반응하는 하나의 흐름으로 연결한다.

**Architecture:** 검증된 학습 완료는 건축 자격의 정본이다. 별도 원장에 엽전과 실제 공사 소유 상태를 함께 저장한다. 연출은 결과를 보여주고 저장 권한을 갖지 않는다. 기존 학습 진도, 건물, 장식은 보존한다.

**Tech:** Flutter, 기존 Sori 컴포넌트, SharedPreferences 확인 쓰기, AppL10n DE/EN, 기존 승인된 한옥 단계와 캐릭터 클립.

## 공통 요구사항

- 사용자는 설명을 확인하고 직접 다음 문제로 넘어간다. 시간제 게임의 규칙은 바꾸지 않는다.
- 버튼 눌림·선택·정답·오답·완료에 목적이 있는 짧은 모션과 햅틱. 하나의 사건에서 중복 진동 방지. 사운드·진동·동작 줄이기 설정 독립.
- 색만으로 결과 전달 금지. reduced motion, 키보드, Semantics, 화면 이탈 수명주기, 작은 화면/큰 글자 지원.
- XP·숙련도·엽전은 분리. 오답 벌금, 현금 판매, 가챠, 공사 대기 타이머, 엽전으로 다음 학습 잠금 없음.
- 매일 최초 완료 20개, 그날 추가 완료의 학습 목표 10개, 확인된 추천 복습 10개를 지급하는 최소 경제. 지급 출처별 재시도/재실행 중복 방지. 마일스톤 지원금은 기본 공사비 40개/단계를 충당한다. 실제 복습 출처를 확인할 수 없으면 복습 보상을 지급하지 않는다.
- 사랑채 16단계와 B2 34단계의 학습 자격은 유지. 기존 사용자는 첫 경제 초기화 시 이미 획득한 건축을 무상 인정. 이후 학습 자격과 지불된 건축 단계 분리. 승인된 고택 배치와 작품을 유지.
- 완료 영수증은 엽전 증가·잔액·다음 공사 목표를 합쳐 보여줌. Today와 Hanok에서 잔액 및 공사 진입 가능. 구체적인 결과를 저장한 뒤 표시.
- 단일 원장 문서에 잔액·거래 출처·건축 소유권을 원자적으로 기록. 저장 거부·불명 응답·연타·앱 재시작·계정 전환·복원·초기화 검증.

매일 첫 확인 완료 20개, 두 번째 10개, 건축 자격 단계당 지원금 40개와 공사비 40개를 연결했다. 추천 복습 10개는 실제 복습 완료 출처를 검증하는 정본이 연결될 때까지 지급·홍보하지 않는다. 과거 건물과 학습 완료는 최초 이관에서 보존하고 소급 일일 보상은 지급하지 않는다. 복원은 충돌하는 두 지갑 이력을 합치거나 최대 잔액을 택하지 않고 정합성 오류로 반환한다.
