# 일두고택 V3 도면 기반 누적 8단계 에셋 설계

- 날짜: 2026-08-28
- 상태: 사용자 승인 반영 — 최소 일치도 95%, 기존 V3 정본과 동일한 완성본
- 대상 월드: 2412×2622, 1206×2622 뷰포트, 가로 팬 1회
- 원칙: 다른 세션 결과는 카메라·광원 참고만 허용하고 건축 형상 정본으로 사용하지 않는다.

## 1. 목표

현재 `personal_hanok_v3`의 지정 건물·문 에셋을 정체성 정본으로 유지하면서, 각 구조물이 실제로 지어지는 과정을 8개의 누적 PNG 단계로 만든다. 단계별 이미지를 각각 재해석하지 않고, 한 건물에 하나의 공통 좌표계와 구성요소 레이어를 만든 뒤 순차 합성한다.

완성 단계는 새 그림이 아니다. 지정 V3 원본을 바이트 보존 복사하여 픽셀·SHA-256 100% 동일하게 사용한다. 1~7단계는 해당 완성 원본의 기단·기둥·칸·처마·지붕·창호 앵커와 `ildu_Blueprint`의 평면·입면·단면·상세도를 결합해 역구성한다.

## 2. 증거 우선순위

1. 사용자가 지정한 현재 V3 원본: 재질, 색, 마감, 최종 실루엣, 건물 정체성
2. `ildu_Blueprint` 107파일: 칸수, 평면, 기둥열, 가구, 지붕 형식, 기단·계단, 창호 위치
3. 저장소 실측 스프라이트 사양: 도면의 수치와 시기별 충돌 해소
4. 최종 일두고택 배치도와 월드 매니페스트: 배치 각도, 크기, 바닥 접점
5. 다른 세션의 8방향 시트: 카메라 높이, 방향 전환, 광원 연속성만 참고

하위 출처가 상위 출처와 충돌하면 하위 출처를 버린다. 일반 한옥 관습이나 생성 모델의 재해석으로 빈 부분을 임의 보충하지 않는다.

## 5. 누적 8단계

모든 단계는 해당 건물 정본과 같은 픽셀 캔버스, 알파 여백, 바닥 기준점, 배치 각도를 사용한다.

1. **자리 잡기·규준** — 정본 바닥 외곽과 기둥 중심에 대응하는 지반 정리, 규준선, 초석 위치. 완성 부재 없음.
2. **초석·기단** — 실제 돌블록, 자연석/장대석 구분, 도면에 있는 계단만 설치.
3. **기둥·바닥틀** — 앞·뒤·가려지는 기둥열, 장귀틀·동귀틀·마루틀. 기둥은 최종 굵기 100%와 입체 재질을 즉시 사용.
4. **보·도리·대공** — 모든 기둥 머리에 보를 연결하고 종보·대량·도리·대공을 같은 앵커에 설치.
5. **서까래·추녀·산자** — 용마루에서 처마까지 닿는 둥근 서까래, 팔작 귀의 부채꼴 서까래, 맞배 박공 구조, 산자 설치.
6. **적심·볏짚·보토·기와 시공 중** — 볏짚을 초가 지붕처럼 노출하지 않고 전통 기와지붕의 하부 보토층으로 표현. 일부 면에 기와가 올라가는 누적 공정.
7. **기와·용마루·벽체·창호** — 지붕 완성 후 회벽·판벽·문선·살문·널문을 건물별 도면대로 설치. 마감 전 상태.
8. **완성 V3** — 지정 원본 파일을 변형 없이 그대로 사용. 재생성·리터칭·색보정 금지.

## 6. 얇은 기둥 금지 규칙

- 선·스트로크·1차원 벡터로 기둥을 표현하지 않는다.
- 정본에서 보이는 기둥 외곽을 마스크로 추출하고 단계 3부터 동일 폭을 유지한다.
- 원주는 원통 명암·배흘림·목재 결을, 각주는 면별 명암·모서리 마모를 가진 래스터 부재로 제작한다.
- 사랑채는 장주·단주·누마루 고주를 구분한다.
- 안채는 각기둥, 사당은 주칠 원주처럼 건물별 부재 형식을 공유하지 않는다.
- 뒤 기둥은 가려지기 전 단계에서 존재해야 하며 다음 단계에서 임의로 사라지거나 이동하지 않는다.

## 7. 제작 방법

1. 정본을 편집 대상 이미지로 불러온다.
2. 정본의 바닥선·기단·기둥 중심·처마·용마루·칸 경계를 좌표 앵커로 기록한다.
3. 정본에서 돌·목재·기와·회벽·창호 재질 팔레트와 구성요소 마스크를 추출한다.
4. 완성본에 가려진 보·도리·서까래는 도면 수치와 앵커 사이에서만 복원한다.
5. 독립 단계 이미지를 생성하지 않고 `stone`, `floor_posts`, `beams`, `rafters`, `roof_bed`, `tiles`, `walls_changho`, `finish` 레이어를 한 번씩 만든다.
6. 단계 이미지는 앞 단계 레이어를 그대로 유지한 누적 합성으로 출력한다.
7. 생성형 편집 결과가 앵커를 벗어나면 부분 수정을 반복하지 않고 해당 레이어를 폐기 후 재제작한다.

## 8. 95% 일치도 계약

### 완성 단계

- V3 원본과 출력 8단계 파일의 SHA-256 동일: 필수
- 원본 크기·알파 채널·RGB 픽셀 동일: 필수
- 따라서 8단계 정체성 일치도는 100%

### 1~7단계 점수

| 항목 | 비중 | 합격 기준 |
|---|---:|---|
| 도면 구조 | 30 | 평면·칸수·기둥열·지붕 형식·계단 조건 일치 |
| V3 앵커 | 30 | 존재하는 구성요소의 마스크/중심선 등록 일치 95% 이상 |
| 누적 연속성 | 20 | 이전 단계 픽셀 이동·소실 없음 |
| 재질·색·명암 | 10 | 정본에서 추출한 팔레트와 재질군 사용 |
| 카메라·바닥 접점 | 10 | 같은 캔버스·투영·기준점 유지 |

총점 95점 이상이어야 통과한다. 다음 하드 게이트는 총점과 무관하게 즉시 실패다.

- 기둥 중심 또는 바닥 접점이 마스터 캔버스에서 1px 초과 이동
- 칸수, 맞배/팔작/우진각/겹처마 형식 오류
- 기둥 머리가 보에 닿지 않음
- 서까래가 용마루 또는 처마선에 닿지 않음
- 창고에 계단 생성
- 아래채에 널문 생성
- 안곳간채의 전면 문 수 오류
- 중문간채 개방 마루칸 폐쇄
- 사당 단청·겹처마 누락
- 독립 중문 또는 일반 한옥 대체물이 혼입

## 9. 사랑채 시범 승인 게이트

전체 확대 전에 사랑채 한 채만 다음 순서로 검증한다.

1. 최종 정본을 배치 각도·캔버스에 등록
2. 단계 2~5로 기단·전후 기둥·보·도리·서까래 결구를 우선 확인
3. 단계 6에서 볏짚·보토가 초가처럼 보이지 않는지 확인
4. 단계 7의 지붕·창호가 단계 8 정본으로 자연스럽게 이어지는지 확인
5. 8단계 전체 시트와 개별 투명 PNG, 자동 검사 보고서를 사용자에게 제시
6. 사용자 승인 후에만 다른 건물·문으로 확대

기존 `sarangchae_construction_pilot_v1`의 얇은 선 기반 단계는 이 설계의 입력이나 승인 근거로 사용하지 않는다.
