## 1. 확정된 사용자 요구

> 4개 건물 모두 사람이 살았고 사용했던 건물이라는 점을 잊지말고 평면 구현이 아닌 입체면으로 건물을 지어져나가는 방향을 설계해야돼. 기둥과 처마, 지붕이 만들어져가면서 어긋나지않아야하고, 의미있는 공정단계로 유저들이 한옥을 만든 선조들의 지혜를 배우길 바래.

네 건물을 생활공간의 일부로 다룬다. 곳간은 물건을 보관하고 사람이 드나들어 사용하는 공간이며, 이를 주거용 방으로 바꾸지는 않는다. 실내 체적, 출입구, 바닥 높이, 문 열림, 앞뒤 동선, 지붕 아래 깊이가 구조에 포함되어야 한다.

학습자가 기억할 것은 부재명만이 아니다. 비·추위·더위·짐의 무게·생활 동선이라는 문제를 재료와 구조로 어떻게 해결했는지, 그 선택을 한국어로 설명하고 요청할 수 있게 한다.

## 3. 제작의 중심: 완성된 하나의 입체 구조

먼저 완성 건물의 공간과 구조를 정하고, 공정은 그 구조의 부재가 설치되는 순서로 만든다.

1. 동일 시기의 평면·입면·단면을 묶는다. 1990년대 보수도면과 2007 현황의 치수를 평균내거나 섞지 않는다.
2. 도면으로 실내 깊이, 주칸, 기둥열, 바닥 높이, 벽 두께, 출입구를 정의한다. 승인 V3 이미지로 외관·재질·창호 리듬을 맞춘다.
3. 각 기둥과 보·도리·서까래에 고유 ID와 접합 위치를 준다. 초석 상면, 기둥 머리, 처마 끝, 용마루, 문 회전축, 마루 귀틀의 좌표를 고정한다.
4. 모든 단계와 방향은 이 구조를 공유한다. 기둥이나 보가 설치된 이후에는 그 부재의 위치·폭·색이 다음 단계에서 바뀌지 않는다. 공사용 임시 지지는 별도 부재로 설치·제거한다.
5. 건물별 완성 형상이 통과한 뒤 재질을 정돈한다. 새 공정 이미지를 만들 때마다 건물 전체를 다시 그려 부재 위치를 맞추는 방식을 사용하지 않는다.

**권장 제작 방식:** 부재를 분리한 3D 제작 원본으로 깊이·접합·가림 관계를 확보하고, V3 외관에 맞춘 2.5D 공정 프레임을 같은 장면에서 출력한다. 사용자에게 보이는 시공 화면도 앞·옆·실내 깊이와 겹침을 드러낸다. 기존 8방향 표시 체계를 재사용할 수 있으나, 연속 회전·자유로운 내부 이동이 필요하면 실시간 3D 표시를 별도 구현해야 한다.

현재 이미지 패키지의 카메라 표기는 동일하지 않다. 아래채는 23도, 안채와 곳간은 28도이며 중문채 문서는 수직축 기준 28도라고 기록한다. 따라서 `28deg`라는 이름만으로 같은 카메라라고 간주하지 않는다. 제작 시 실제 기준 프레임의 투영을 대조하고, 모델과 정본이 충돌하면 그 차이를 먼저 해결한다. 이번 설계에서 카메라나 지도 배치를 임의로 바꾸지 않는다.

마지막 장면은 승인 정본과 연속되어야 한다. 마지막 순간에 다른 건물 이미지로 교체해 지붕이나 기둥이 튀는 방식은 통과하지 않는다. 원본에서 보이지 않는 내부는 도면 확인 부분과 설명용 재구성 부분을 구분한다.

## 4. 공통 공정과 배울 이유

국가한옥센터의 시공 설명을 기본 순서 근거로 삼되, 실제 부재와 상세는 해당 건물 도면을 우선한다. 시공 화면의 묶음은 아래와 같고 건물에 따라 분리하거나 합친다.

| 공정 | 화면에서 보이는 입체 변화 | 생활과 연결하는 질문 | 한국어 행동 예시 |
|---|---|---|---|
| 터와 높이 | 건물 자리·통로·지면 높이를 보여준다 | 사람이 어디로 들어가고 물은 어디로 흐를까? | “물이 이쪽으로 흐르게 해요.” |
| 기단·초석 | 돌의 앞·옆면과 상면, 서로 다른 초석 높이가 생긴다 | 나무 기둥을 왜 이 돌 위에 세울까? | “기둥을 돌 위에 세워요.” |
| 치목·기둥 | 밑면을 맞춘 기둥이 앞뒤 열에 선다 | 울퉁불퉁한 돌 위에 기둥을 어떻게 맞출까? | “바닥에 맞게 깎아 주세요.” |
| 보·도리·상량 | 앞뒤 기둥을 보로, 옆 방향을 도리로 연결한다 | 무거운 지붕을 여러 부재가 어떻게 받칠까? | “보를 기둥 위에 올려요.” |
| 서까래·처마 | 지붕 골격이 벽선 밖으로 뻗고 처마 아래 공간이 생긴다 | 비가 올 때 처마 아래와 밖은 어떻게 다를까? | “처마 아래에서 기다려요.” |
| 지붕 바탕 | 도면에 해당하는 개판/산자·적심·보토의 층을 단면으로 본다 | 기와 밑에는 무엇이 있을까? | “기와를 얹기 전에 바탕을 만들어요.” |
| 기와 | 암키와·수키와·마루기와가 지붕면을 채운다 | 기와를 겹쳐 놓으면 빗물이 어떻게 흐를까? | “빗물이 아래로 흘러요.” |
| 벽과 개구부 | 실내와 외부의 경계가 생기고 문 자리와 방 깊이가 드러난다 | 어느 곳을 닫고 어느 곳을 열어 두었을까? | “이쪽은 방이고 저쪽은 마루예요.” |
| 바닥과 생활 구조 | 온돌·마루·보관 바닥 등 건물에 맞는 구조를 만든다 | 이 공간에서 어떻게 따뜻하게 지내거나 물건을 둘까? | “방은 따뜻하고 마루는 시원해요.” |
| 창호·출입 | 문짝이 실제 회전축으로 움직이고 실내가 열리고 닫힌다 | 빛과 바람, 출입을 어떻게 조절할까? | “문을 조금 열어 주세요.” |
| 완성·사용 | 동일한 건물에서 통행·휴식·집안일·물건 보관을 체험한다 | 어떤 생활을 가능하게 만든 집일까? | “여기에서 쉬어도 돼요?” |

기둥 밑면을 돌에 맞추는 그랭이질, 장귀틀·동귀틀·청판을 조립하는 마루, 구들장의 열과 연기의 이동은 국가한옥센터 자료를 참고한다. 특정 건물의 아궁이·고래·굴뚝 위치는 도면을 확인한 뒤 표현한다. 바람·열·물 화살표는 이해를 돕는 설명 레이어이며 성능 계산 결과로 표시하지 않는다.

학습용 단면을 켜는 행동은 시공을 되돌리는 행동이 아니다. 지붕이 설치된 후 온돌을 볼 때는 지붕·앞벽을 보기 모드에서만 가리고, 완료한 건축 상태는 유지한다.

## 5. 건물별 공간과 공정

아래 도면 특성은 현재 `_sprite_spec_2026-08-24.md`와 승인 패키지에 정리된 기준이다. 치수 확정과 구조 모델 제작 전에는 원도면 시트와 다시 맞춘다. 공정 수는 구조 검토 후 정하며 모든 건물을 같은 수로 맞추지 않는다.

### 5.1 중문채: 사람을 맞이하고 안팎을 연결하는 건물

식별 조건: 5칸 맞배 홑처마. 중문 1칸, 방 2칸, 열린 마루 2칸. 높은 석축과 앞뒤 지면차, 통행문, 마루 아래 깊이를 보존한다. 4·5칸의 X 표기는 가새 부재를 추가하는 근거가 아니다. 열린 마루 전면을 벽으로 막지 않는다.

**공정 흐름:** 통행·높이 잡기 → 석축·초석·도면의 계단 → 기둥열 → 보·도리와 상량 → 맞배 서까래 → 지붕 바탕 → 기와 → 방 벽체와 배면 → 두 방의 온돌·방바닥 → 열린 마루의 귀틀·청판 → 중문·방 창호 → 출입과 마루 사용.

- 석축 단계: 정면만 쌓지 않고 앞뒤 높이와 문을 통과하는 길을 함께 만든다.
- 골조 단계: 문 칸·방 칸·마루 칸이 같은 기둥열 안에서 어떻게 달라지는지 보여준다.
- 생활 구조 단계: 2007 중문채 횡단면도의 두 방 아래에 `한식 온돌`이 표기되어 있다. 이 방들을 빈 상자로 끝내지 않고 온돌과 방바닥 공정을 포함한다. 상세 고래·아궁이 위치는 이 표기만으로 만들어 넣지 않는다.
- 마루 단계: 청판 아래 지지 구조와 뒤쪽 벽까지 보여준다. 정본에 있는 마루 아래 기와 적치는 구조재와 분리한다.
- 완료 장면: 문을 열고 안쪽 공간으로 들어가는 동선, 마루에 잠시 머무는 장면.
- 한국어: 안/밖, 들어가다/나오다, 건너가다, “안으로 들어가도 될까요?”, “이쪽으로 오세요.”
- 생활 지혜의 초점: 출입·머무름·경계를 한 건물 안에서 구분한 공간 구성.

### 5.2 아래채: 온돌방과 마루가 함께 있는 생활 공간

식별 조건: 3칸 맞배 홑처마, 몸체 약 7,500×4,000mm, 전면 툇마루 깊이 1,180mm. 왼쪽 마루방 1칸과 오른쪽 온돌방 2칸, 서로 다른 살문과 앞뒤 창호 배열을 보존한다.

**공정 흐름:** 방·마루 자리 잡기 → 자연석·초석 → 기둥과 마루 지지 → 보·도리 → 맞배 서까래·지붕 바탕 → 기와 → 방의 벽과 개구부 → 온돌 구조와 바닥 마감 → 마루방·툇마루 귀틀과 청판 → 살문·한지 창호 → 계절에 따른 사용.

- 온돌 단계: 마감 직전 단면에서 구들장을 지지하는 구조와 연기 흐름을 보여준다. 현 승인 세트는 오른쪽 낮은 아궁이 2개를 명시한다. 상세 경로는 단면 도면 확정 후 제작한다.
- 마루 단계: 툇마루가 벽면에 붙인 얇은 띠가 되지 않도록 실제 깊이·하부 공간·끝단을 드러낸다.
- 완료 장면: 신발을 벗고 오르기, 온돌방에서 쉬기, 마루에서 바람 느끼기.
- 한국어: 방/마루, 따뜻하다/시원하다, 열다/닫다, “추우니까 문을 닫아 주세요.”
- 생활 지혜의 초점: 계절과 활동에 따라 바닥과 공간을 다르게 사용하는 방식.

### 5.3 안채: 부엌·방·대청이 연결되는 살림의 중심

식별 조건: 길게 이어진 일자 8칸, 낮은 자연석 기단, 팔작 홑처마, 비균등 주칸과 서로 다른 창호. 중앙 대청, 방 깊이, 부엌·부속 부분, 뒤쪽 마루 관계를 보존한다. 사랑채의 높은 누마루·난간을 이식하지 않는다.

**공정 흐름:** 부엌·방·대청의 자리와 동선 → 기단·초석 → 앞뒤 기둥열 → 보·도리·상량 → 추녀와 합각 골격 → 팔작 서까래 → 지붕 바탕 → 기와·지붕 마루 → 방·부엌의 벽체 → 부엌 위 다락 → 아궁이·온돌과 방바닥 → 대청·앞뒤 마루 → 공간별 창호 → 밥짓기·휴식·가족의 이동.

- 골조 단계: 긴 정면 뒤에 방이 들어갈 깊이와 앞뒤 기둥열이 먼저 보여야 한다.
- 처마 단계: 추녀의 위치가 양 지붕면과 처마 끝을 결정하고, 이후 기와가 올라가도 그 선은 바뀌지 않는다. 홑처마에 임의로 부연을 추가하지 않는다.
- 생활 구조 단계: 부엌에서 방으로 이어지는 난방은 도면이 확인하는 연결을 사용한다. 다른 건물의 온돌 단면을 복제하지 않는다.
- 수직 공간 단계: 2007 `안채 종단면도-3`의 `부엌` 위에 `다락`과 청판 THK45가 직접 표기되어 있다. 다락을 지붕의 검은 음영으로 지우지 않고 별도 바닥과 아래 공간으로 만든다. 이 단면의 시멘트 바닥 표기는 기록 당시 상태이며, 이를 조선시대 원래 공법으로 설명하지 않는다.
- 창호 단계: 대청·방·부엌에 같은 창문을 일괄 설치하지 않고 용도별 차이를 드러낸다.
- 완료 장면: 부엌에서 준비한 음식을 옮기고, 대청을 지나 방으로 들어가는 짧은 생활 동선.
- 한국어: 먼저/다음에, 부엌/방/대청, 데우다/차리다/옮기다, “상을 어디에 놓을까요?”
- 생활 지혜의 초점: 취사·난방·통풍·이동을 하나의 생활 공간에 엮은 구성.

### 5.4 안채곳간채: 물건을 지키고 꺼내 쓰는 생활 공간

식별 조건: 4칸 맞배 홑처마, 몸체 약 9,360×2,700mm, 1·3·4칸의 전면 널문 3곳, 2칸의 이어진 판벽. 하부 세로 판벽·상부 회벽·측면과 배면 환기구, 경사면에서 달라지는 초석 노출을 보존한다.

**공정 흐름:** 반입 동선과 지면 높이 → 기단·초석 → 기둥 → 보·도리 → 맞배 서까래 → 지붕 바탕 → 기와 → 다진 바닥 → 판벽·회벽과 두 저장 구역 → 널문·철물·환기구 → 보관·꺼내기.

- 골조 단계: 사람이 짐을 들고 들어갈 문 너비·실내 깊이를 보여준다.
- 벽체 단계: 판벽이 실내 체적을 둘러싸는 과정을 전면·측면·배면에서 읽을 수 있어야 한다.
- 사용 단계: 문을 열고 물건을 안쪽에 둔 뒤 닫는다. 학습 소품은 가역적인 생활 연출 레이어로 둔다.
- 한국어: 넣다/꺼내다/보관하다, 개/자루 등 실제 소품의 단위, “쌀 두 자루를 안에 넣어 주세요.”
- 생활 지혜의 초점: 물건을 보호하면서 드나들고 관리할 수 있도록 개구부와 공간을 구성한 방식.
- 직접 확인: 2007 `안곳간채 평면도`에는 `광` 두 구역과 그 사이 벽, 바닥의 `삼화토다짐` 표기가 있다. 바닥은 이 기록에 따라 다진 바닥으로 설계한다. 목재 마루나 온돌로 바꾸지 않는다.
- 확인 필요: 구체적 보관 품목, 내부 선반, 다짐 재료의 배합, 환기구의 당시 사용 설명은 추가 자료가 필요하다. 학습용 짐 소품을 실제 소장품처럼 소개하지 않는다.

## 6. 한국어와 건축이 만나는 한 단계

**생활 문제 관찰 → 구조 살펴보기 → 한국어 듣고 행동하기 → 부재 설치 → 결과 확인**을 한 묶음으로 한다.

예: 아래채 마루 만들기.

1. 지금은 바닥틀만 있어서 사람이 올라설 수 없다. 뒤쪽 방과 앞쪽 마루의 깊이를 보여준다.
2. 장귀틀·동귀틀·청판을 부재 강조로 구분한다. 쉬운 설명을 먼저 듣고 전문 용어는 눌러 더 본다.
3. “긴 나무 사이에 짧은 나무를 끼워 주세요.”를 듣고 해당 위치를 고른다.
4. 귀틀과 청판이 실제 홈에 맞춰 들어간다. 이미 설치된 기둥은 움직이지 않는다.
5. 마루가 완성되고 사람이 올라가 쉬는 모습을 본다. “마루에서 쉬어요.”를 말하거나 문장으로 구성한다.

초급은 위치·동작을 이해하는 과제, 중급은 이유·순서를 설명하는 과제, 고급은 자료를 비교하고 생활 관습을 해석하는 과제로 확장한다. 같은 구조를 학습 수준에 맞춰 다르게 설명하며, 이 문서에서 CEFR과 건물 해금을 새로 고정하지 않는다.

역사적 사회 질서를 현재의 올바른 행동으로 강요하지 않는다. 실제 사용자의 성별·신분·관행은 해당 시대와 자료를 붙여 설명한다. 정답은 의사소통 과제와 구조 이해를 평가한다.

KO를 의미 원문으로 두고 DE/EN에는 짧은 설명과 선택형 용어 풀이를 제공한다. 명칭은 UI의 `아랫채`, 자료의 `아래채`, `안채곳간채/안곳간채`를 용어 검토 후 일관되게 연결한다. 기존 ID는 그대로 유지한다.

## 7. 앱 표시와 상태

- 시공 보기: 한 건물에 집중한 입체 사선 시점. 앞뒤 기둥열과 바닥 깊이가 읽히는 크기를 확보한다.
- 내부 보기: 같은 구조의 지붕·앞벽을 가리는 단면 또는 절개. 건축 상태와 학습 상태를 바꾸지 않는다.
- 부재 보기: 접합부 확대와 짧은 설명. 이미 설치된 부재 전체에 ID를 유지한다.
- 사용 보기: 완성 뒤 통행·휴식·집안일·보관의 생활 장면. 재생해도 보상이나 공정 완료가 중복되지 않는다.
- 도움 기능: 드래그와 탭 선택을 함께 제공하고, 자막·음성 반복·동작 줄이기를 지원한다.

기존 `IlDuBuildingConstructionPlan`의 `buildingId`, `planVersion`, `canonicalSha256`, 가변 `stages`, 안정적인 `stageId`는 재사용 후보이다. 추가로 부재 목록, 설치 전제, 구조 원본 버전, 카메라 ID, 내부 보기, 출처를 표현할 데이터 설계가 필요하다. 아직 코드에 있다고 주장하지 않는다.

공정의 순차 진행과 부재의 물리적 설치 전제는 구별한다. 지붕은 지지 구조 이전에 설치될 수 없고, 단면 보기나 복습은 완료 상태를 바꾸지 않는다. 온보딩 체험으로 실제 건설 진행·XP·아이템·다음 건물 승인 상태를 올리지 않는 기존 경계를 유지한다.

## 8. 제작·검수 순서

1. 네 건물 각각의 승인 원본, 원도면 시트, 구조 특징, 미확인 내부를 잠근다.
2. 중문채 한 건물에서 실내·통행·기둥열·지붕이 있는 입체 구조 원본을 만든다. 개방 마루와 문이 있어 깊이·가림·동선 검증이 가능하다.
3. **기단 → 골조 → 서까래 → 지붕 완성 → 전체 완성**의 주요 상태를 같은 카메라에서 먼저 검수한다. 이것은 검수용 상태 묶음이며 최종 학습 단계를 5개로 제한하지 않는다.
4. 골조 검수 후 치목, 지붕 바탕, 마루, 창호 등 의미 있는 공정을 나누고 한국어 과제를 붙인다.
5. 중문채 검수가 끝나면 아래채의 온돌·마루, 안채의 팔작·살림 동선, 곳간의 판벽·보관 동선으로 확장한다. 건물 구조는 각각 도면에 따라 만든다.
6. 최종 정본과 연결되는지 확인한 뒤 앱에 공정 계획·표시·진행 저장을 연결하고 실제 기기에서 검수한다.

통과 조건:

- 영구 부재는 설치 후 다음 단계에서 좌표·크기·방향이 변하지 않는다.
- 초석 상면과 기둥 밑면, 보·도리·서까래의 접합점이 모델 좌표에서 일치한다. 의도한 맞춤 외에 빈틈·관통·뜬 부재가 없다.
- 처마 끝선과 용마루의 기준점이 같은 카메라의 단계별 투영에서 이동하지 않는다. 가림·그림자 변화는 구조 이동과 구분한다.
- 비교용 출력에서는 외곽과 주요 접합점을 겹쳐 검사한다. 허용 픽셀 오차는 출력 크기와 래스터화 방식을 정한 뒤 설정한다. 지금 임의의 95%나 100% 점수로 보증하지 않는다.
- 문짝의 움직임이 기둥·문틀·바닥을 관통하지 않는다. 도면에 맞는 문 열림과 통행 여유가 있다.
- 방과 벽에는 두께가 있고, 마루 아래·처마 아래·열린 문 뒤에는 실제 깊이와 가림 관계가 있다.
- 마지막 단계에서 승인 정본의 칸 수·창호·기둥·지붕·접지 위치가 튀지 않는다.
- 학습자는 공정 후 “무엇을 만들었는가, 왜 필요한가, 어떻게 사용하는가”를 자기 수준의 한국어로 수행할 수 있다.
- 작은 화면에서 방·마루·문·지붕의 차이가 읽히고 확대·내부 보기·자막·음성 조작이 가능하다.

| N-section | 2007 안채 종단면도-3의 부엌과 그 위 다락, 앞뒤 처마 차이, 다락 청판 | 부엌·다락의 수직 관계를 포함하고 같은 단면의 모든 바닥 높이를 동일 기준점에 연결한다. |
| S-plan | 2007 안곳간채 평면의 4칸, 두 광과 중앙 벽, 삼화토다짐 바닥, 앞뒤 기둥열 | 두 개의 보관 체적과 바닥 다짐을 독립 공정으로 구현하도록 설계한다. |
| S-section | 판벽 THK30·회벽 THK90, 지면 높이 차이, 기둥·도리·지붕의 관계 | 경사지와 바닥, 벽 재료별 두께를 가진 구조로 만든다. |

**치수 문제를 처리하는 규칙:** 이번 설계는 아래 불일치를 임의 보정하지 않는다. `observedDimension`과 `resolvedModelDimension`을 분리하고, 후자가 정해지지 않은 축은 제작 단계에서 잠금 검사를 통과할 수 없다.

- 아래채 총폭 7,500과 주칸 합 7,470의 30mm 차이: 마지막 칸에 30mm를 더하거나 전체를 늘이는 자동 보정 금지. 2007 다른 시트와 기준선을 비교한다.
- 중문채 평면의 10,240과 횡단면의 12,470 계열: 각각의 범위와 연결부를 식별하고 동일 건물 좌표에 등록한 뒤 사용한다. 단면 자체가 평면과 일치한다고 선언하지 않는다.
- 안채 1995·2007 외곽과 면적: 시기별로 보존한다. 승인 V03의 공간 배치와 선택한 시기 도면 사이 차이는 모델 제작 전 검수 항목이다.
- 아래채의 지붕평면만으로 현재 3칸 실내의 상세 온돌 경로를 확정할 수 없다. 원본에 없는 굴뚝·선반·동선을 생성하는 대신 해당 항목은 상세 제작의 출처 확인 대상으로 둔다.

위 항목은 공정·학습 방향 설계의 누락이 아니라, 구조 제작자가 반드시 해결할 구체적인 입력 조건이다. 이 문서가 치수 확정 모델이나 문화유산 복원 시방서를 대체하지 않는다.

## 11. 어긋남을 막는 입체 제작 계약

### 11.1 좌표와 설치 상태

- 건물 로컬 좌표: 정면에서 오른쪽 `+X`, 건물 안쪽 `+Y`, 위쪽 `+Z`. 원점은 선택한 평면의 기준 기둥축과 기준 높이의 교점으로 한 번 정한다.
- 모든 부재는 `partId`, `sourceRef`, `localTransform`, `geometryHash`, `materialId`, `installedAtStageId`, `jointIds`를 가진다.
- 설치가 끝난 영구 부재의 최종 좌표는 이후 모든 단계에서 같다. 설치 애니메이션만 시작 위치에서 최종 위치로 이동한다.
- 설치 완료 후 `M_world(part) = M_world(building) × M_local(part)`를 유지한다. 단계마다 다른 부모 변환, 비균등 확대, 캔버스 맞춤 이동을 주지 않는다.
- 카메라, 광원, 건물 스케일, 바닥 기준선, 출력 캔버스와 공통 crop을 버전으로 잠근다. 단계마다 알파 bbox를 꽉 차게 확대하는 처리를 금지한다.
- 내부 보기는 같은 장면에서 앞벽·지붕의 표시만 바꾼다. 별도로 다시 그린 내부 그림으로 교체하지 않는다.

### 11.2 부재 접합과 설치 전제

| 연결 | 반드시 공유할 기준 | 설치 전제·확인 |
|---|---|---|
| 초석 ↔ 기둥 | 초석 접촉면과 그랭이질한 기둥 밑면 | 초석이 먼저 설치됨. 의도한 접촉면에 공중 틈이 없어야 함 |
| 기둥 ↔ 보·창방 | 기둥머리의 접합점과 해당 부재의 맞춤 위치 | 지지 기둥 전체와 공사용 임시 지지가 준비됨 |
| 보·대공 ↔ 도리 | 보 상면·대공 상하 접점·도리 중심선 | 부재가 없는 빈 공간에 도리를 띄우지 않음 |
| 도리 ↔ 서까래 | 도리 받침면·서까래 지점·처마 끝 제어선 | 필요한 도리가 모두 설치됨. 지붕 바탕을 올려도 서까래 방향이 바뀌지 않음 |
| 추녀 ↔ 팔작지붕 | 안채의 모서리, 추녀 끝, 합각과 연결되는 지붕면 | 맞배 세 건물에는 팔작용 추녀 구성을 복제하지 않음 |
| 서까래 ↔ 바탕 ↔ 기와 | 같은 지붕 기준 곡면과 층별 두께 | 지붕을 판 한 장으로 두껍게 만드는 대신 각 층이 앞 층 위에 놓임 |
| 기둥·지지 ↔ 귀틀 ↔ 청판 | 받침 위치, 홈, 최종 마루 상면 | 귀틀 지지 없이 청판을 떠 있게 놓지 않음 |
| 부엌 ↔ 다락 | 동일 단면의 바닥·천장 높이와 다락 바닥 지지 | 다락을 받는 구조재는 골조 공정에서 확보하고, 후속 공정은 청판·마감 설치로 구분 |
| 문틀 ↔ 문짝 | 문축·문짝 치수·열림 방향·바닥 높이 | 닫힘/중간/열림 상태에서 기둥·벽·바닥과 간섭하지 않음 |

벽은 외부면·내부면·두께를 갖고 문과 창은 실제 개구부를 가진다. 마루 하부, 문 뒤, 처마 아래, 다락 아래에는 관찰 가능한 공간이 남는다. 구조에 존재해야 하지만 카메라에서 가려지는 부재도 모델에서 삭제하지 않는다.

### 11.3 공정당 확인할 네 상태

1. **설치 전:** 지지 부재와 아직 비어 있는 설치 자리가 보인다.
2. **설치 중:** 부재가 가림 관계를 유지하며 이동하고 접합부에 맞춰진다.
3. **설치 후:** 영구 부재를 잠그고, 앞 단계와 동일한 기둥·처마 기준점이 유지된다.
4. **쓰임 확인:** 지금 만든 부분의 역할을 사람이 이용하거나 단면 설명으로 확인한다. 아직 바닥이 없으면 사람이 그 위에 서는 연출을 하지 않는다.

검수 장면은 같은 카메라에서 겹쳐 본 비교, 반대쪽 사선 시점, 내부 절개를 포함한다. 첫 두 장면은 위치·외관, 내부 절개는 숨은 깊이와 지지 관계를 확인한다. 설치 전에 지붕 완성 실루엣을 가는 안내선으로 잠시 보여주는 것은 허용하되 완성 부재처럼 보이지 않게 한다.

| N13 `changho` | 공간별 다른 문과 창 | “이 문을 열면 어디로 갈까요?”를 확인한다. 앞면 창호를 배면에 그대로 복제하지 않는다. |

## 13. 대표 학습 장면 네 개

모드: AUTHOR+AUDIT. 모두 이번에 만든 **설계용 예시**이며 실제 역사 인물의 대화나 현장 사용 허가가 아니다. 앱 안내자와 성인 학습자의 시뮬레이션, 역할 설명과 해요체를 기본으로 한다. DE는 앱 안내의 `du`, EN은 국제 영어다. 관계·성별·신분을 역사 사실로 추가하지 않는다. 말하기는 같은 의미를 허용하는 `semantic`, 행동 과제는 부재·위치·수량 ID로 판정한다.

### 중문채 J11 — 통행문 사용

- 장면: 문짝 설치 후 작동 확인. 안내자가 “문을 달았어요. 이제 열어 볼까요?”라고 제안한다.
- 학습자 KO: **“제가 문을 열게요.”**
- 추가 허용형: “제가 열게요.” — 문이 유일하게 강조된 상황에서 허용.
- EN: “I'll open the gate.” / DE: “Ich mache das Tor auf.”
- 행동: 문짝 손잡이를 선택해 연다. 문은 고정된 회전축으로 움직이고 안쪽 통로가 드러난다.
- 평가: 자신이 하겠다는 의사와 문 열기 행동. 허가 요청인 “문을 열어도 돼요?”는 이 과제의 동일 변형이 아니다.
- 문화 연결: 출입문과 방·머무는 마루가 구분되어 있다는 점을 관찰한다.

### 아래채 A10 — 마루 귀틀 맞추기

- 장면: 긴 귀틀 사이에 짧은 귀틀을 설치한다. 안내자가 “긴 나무 사이에 짧은 나무를 끼워 주세요.”라고 요청한다. 선택한 홈 한 곳이 강조되어 있다.
- 학습자 KO: **“여기에 끼우면 돼요?”**
- 추가 허용형: “이 홈에 끼우면 돼요?”
- EN: “Does it go here?” / DE: “Kommt es hier hinein?”
- 후속: “네. 그다음에 마루판을 끼워요.”
- 행동: 강조된 홈에 귀틀을 맞춘 후 청판을 설치한다. 같은 부재가 설치 전후 동일 ID를 가진다.
- 평가: 맞는 위치 확인과 실제 설치. `여기`의 대상은 강조된 홈 ID로 잠그고, 자유 회전 후에도 같은 홈을 가리킨다.
- 문화 연결: 판재를 받는 귀틀과 홈의 역할을 보고, 바닥 아래 구조가 남는 것을 확인한다.

### 안채 N10 — 부엌 위 다락

- 장면: 같은 단면에서 부엌과 다락을 함께 본다. 안내자가 “다락은 어디에 있어요?”라고 묻는다.
- 학습자 KO: **“부엌 위에 있어요.”**
- 추가 허용형: “다락은 부엌 위에 있어요.”
- EN: “It's above the kitchen.” / DE: “Es ist über der Küche.”
- 행동: 다락 바닥을 선택하면 지지 구조와 아래 부엌이 함께 강조된다.
- 평가: 위/아래의 수직 관계와 대상 공간. 다른 건물의 다락 위치를 이 답으로 일반화하지 않는다.
- 문화 연결: 도면에 실제로 있는 수직 공간 구성을 읽는다. 다락의 구체적 수납물이나 이용자를 추정하지 않는다.

### 안채곳간채 S08 — 다진 바닥

- 장면: 마루가 있는 아래채를 본 뒤 곳간 바닥 공정을 시작한다. 안내자가 도면의 바닥 표시를 확대하고 “여기도 마루판을 깔까요?”라고 묻는다.
- 학습자 KO: **“여기는 흙을 다져서 바닥을 만들어요.”**
- 추가 허용형: “여기는 흙을 다져 바닥을 만들어요.”
- EN: “Here, the earth is compacted to make the floor.” / DE: “Hier wird die Erde für den Boden festgestampft.”
- 행동: 바닥 다짐 공정을 실행한다. 내부 바닥 높이와 중앙 칸막이 자리는 유지된다.
- 평가: 이 건물의 바닥 유형 구별. “모든 곳간은 흙바닥이에요.”는 근거 범위를 넘어서는 답이다.
- 문화 연결: 건물마다 생활 목적과 기록된 바닥 구성이 다름을 관찰한다. `삼화토`의 정확한 재료 배합은 이 문항에서 묻지 않는다.

예시 감사: KO↔EN, KO↔DE, EN↔DE에서 화행·지시대상·수량·공간 관계를 자체 대조했다. J11은 의사 표명, A10은 위치 확인 질문, N10은 위치 설명, S08은 바닥 선택 설명으로 유지된다. 독립 원어민·교육자 검수나 실제 학습 효과 검증은 수행하지 않았으며 출시 콘텐츠 승인으로 표시하지 않는다.
