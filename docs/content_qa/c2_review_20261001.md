# C2 삼언어 콘텐츠 검수 · 2026-10-01

## 범위와 판정

C2 단어 예문과 연결된 Satz·Cloze 문항 8묶음, 런타임 시나리오 30개와 연결 듣기 120문항을 KO·EN·DE로 직접 대조했다. 이번 변경은 모델의 언어 검수와 구조 검증을 거친 교정안이다. 원어민·한국어 교육자·법률/의료 전문가의 독립 승인을 뜻하지 않는다.

## 반영

- 단어 `0093`, `0095`, `0100`, `0115`, `0141`, `0149`, `0159`, `0187`: 표제어·정의·예문의 의미, 격식, 법적 함의를 조정하고 연결된 Satz·Cloze를 맞췄다. 원본 팩/생성 스크립트와 후속 카피 지문도 함께 갱신했다.
- 후속 단어 `0052`, `0060`, `0117`, `0120`, `0166`, `0174`: `체면 경제`·`자리를 문서화하다`·`결정 불가역`·`발화의 자리`·`집단 소송점`처럼 실제 발화에 어색한 조어를 장면에 맞는 표현으로 바꿨다. `3영업일`이라는 근거 없는 결과 통보 기한은 통보 시점과 방법을 확인하는 문장으로 바꿨다. 연결 게임 12문항과 후속 카피 지문, 생성 원본을 함께 수정했다.
- 시나리오에서 `준희` 표기, 폭우와 침수, 주택 미소유와 주거 상실, 집회 지연 시간의 범위, 자동 거절 뒤의 오류 시정, 로봇 배치 담당자, 재현 실패의 가능한 조건, 복지 신청자의 규정 위반 가능성을 삼언어에서 맞췄다.
- `c2_w10_friends`는 떠나는 동료에게 다음 작품 크레딧을 약속하던 문장을 이미 함께 만든 작품의 기여 표기를 바로잡겠다는 말로 바꿨다. 지분 정리와 우정의 대화는 그대로 유지했다.
- `c2_w10_record`는 소유권 판정·입증 책임을 기록관 직원이 확정하지 않도록 남은 자료 탐색으로 좁혔다. `c2_w10_mandate`는 후견 절차와 위임장 즉시 발급 약속 대신 어머니의 의사 및 은행 확인 절차를 묻는다.
- `c2_w10_impact`는 셔틀이 밤에 운행하지 않는다는 정책 조건을 밝히고 야간 근무자가 혜택을 받지 못한다는 결론으로 맞췄다. `c2_w10_limitation`은 사고일만으로 소멸시효를 단정하거나 진단서 한 장으로 청구 가능성을 보증하지 않는다. `c2_w10_fandom`은 해당 커뮤니티 규정의 범위를 명시하고 의견 차이와 위반 신고를 구분한다.
- 듣기 대사·뜻·어순 과제, 시나리오 작성 정본(비 W10), TTS·첫 줄 manifest, 장면 자산 인벤토리를 다시 생성했다. 변경된 한국어에 필요한 TTS를 각 교정 묶음마다 합성·Storage에 업로드했고, 첫 대사 번들 178개를 맞췄다. W10 승인 초안은 보존하고 런타임 샤드만 후속 교정했다.

## 추가 확인이 필요한 장면

위 5개 W10 장면의 내부 모순과 단정은 모델 검수로 교정했지만, 실제 한국 법률·은행 절차 및 커뮤니티 운영 규칙의 정확성은 별도 전문가 검수가 필요하다. [민법 제766조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=900157593)는 불법행위 손해배상 청구의 인지 시점을 명시하며, 장면의 사고 날짜만으로 시효 완성을 단정할 근거가 없었다. 후속 단어 6개도 모델 교정안이며 원어민·교육자 승인 상태가 아니다.

TTS Storage의 키 완전성은 실제 발음·억양 청취 평가와 별개다. 승인 초안은 보존했고 런타임 사본과 후속 카피 리비전을 수정했다.
