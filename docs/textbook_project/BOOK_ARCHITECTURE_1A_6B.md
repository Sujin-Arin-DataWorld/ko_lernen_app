# 1A–6B Book Architecture

The first publishing spine preserves the **48 canonical macro-units** and splits them across 12 books.
Micro-units are added only after allocation reveals a real density or pedagogy problem.

| Book | Level lens | Macro units | Theme |
|---|---|---:|---|
| 1A | A1 | 8 | 첫 만남과 생존 한국어 |
| 1B | A1 | 8 | 일상과 관계의 시작 |
| 2A | A2 | 4 | 계획·메시지·감정 |
| 2B | A2 | 4 | 서비스·일·이동·집 |
| 3A | B1 | 3 | 경험·정보·직장 |
| 3B | B1 | 3 | 관계·문제 해결·공동체 |
| 4A | B2 | 3 | 공식 대화와 협의 |
| 4B | B2 | 3 | 책임·면접·공동체 판단 |
| 5A | C1 | 3 | 근거·포용·미디어 |
| 5B | C1 | 3 | 정책·문화노동·관계 경계 |
| 6A | C2 | 3 | 제도·기술윤리·이의제기 |
| 6B | C2 | 3 | 책임·기억·담론 권력 |

## Units

### 1A — 첫 만남과 생존 한국어

- **a1_01_greetings_hangul** — 첫 인사와 다시 묻기
- **a1_02_self_intro_identity** — 이름과 출신 말하기
- **a1_03_topic_subject_particles** — 가게에서 물건 찾기
- **a1_04_order_request_object** — 음식과 수량 주문하기
- **a1_05_numbers_time** — 시간 확인하기
- **a1_06_transport_directions** — 교통에서 내릴 곳 말하기
- **a1_07_contact_address** — 자연스럽게 연락 방법 정하기
- **a1_08_clarify_repair** — 못 들었을 때 다시 묻기

### 1B — 일상과 관계의 시작

- **a1_09_home_daily_life** — 집에서 물건 찾기
- **a1_10_health_safety** — 작은 실수에 사과하기
- **a1_11_titles_relationships** — 새 친구와 취향 말하기
- **a1_12_daily_negation** — 메뉴가 있는지 묻기
- **a1_13_register_switching** — 친한 말과 공손한 말 알아듣기
- **a1_14_payment_delivery** — 가게에서 필요한 것 말하기
- **a1_15_first_class_work** — 첫 수업에서 옆 사람 만나기
- **a1_16_survival_capstone** — 첫 주말 계획 세우기

### 2A — 계획·메시지·감정

- **a2_02_plans_proposals** — 약속을 제안하고 바꾸기
- **a2_03_chat_relationships** — 메신저로 상황 알리기
- **a2_04_feelings_health** — 증상과 느낌 설명하기

### 2B — 서비스·일·이동·집

- **a2_05_delivery_services** — 교환·택배 문제 해결하기
- **a2_06_study_work** — 공부·일에서 실수 바로잡기
- **a2_07_travel_repair** — 이동 중 불편을 요청으로 바꾸기

### 3B — 관계·문제 해결·공동체

### 4A — 공식 대화와 협의

### 4B — 책임·면접·공동체 판단

- **b2_06_advanced_capstone** — 공동체 갈등에서 조건부 절충 만들기

### 5A — 근거·포용·미디어

- **c2_03_automation_redress** — 자동 판단의 이의 제기와 재심 설계하기

- **c2_06_fandom_discourse_power** — 미디어 프레이밍과 지역 영향 논증하기
