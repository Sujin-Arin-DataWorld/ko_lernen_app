# Textbook Quality Gates

A unit cannot become publication-ready unless all required gates pass.

1. **Rights gate** — provenance/license/clean-room status valid.
2. **Level gate** — grammar, vocabulary, sentence and discourse load match the canonical level bible.
3. **Natural Korean gate** — native-quality Korean, not grammar-target prose.
4. **Relationship/register gate** — speech level matches exact relationship, chronology and setting.
5. **Corpus gate** — native-usage profile exists for the topic/subtopic or an explicit exception is documented.
6. **Pragmatics gate** — requests/refusals/agreement/disagreement/repair teach social effect, not only semantics.
7. **EN localization gate** — authored independently from KO + EN native evidence; no DE->EN chain.
8. **DE localization gate** — authored independently from KO + DE native evidence; no EN->DE chain.
9. **Spoken-surface gate** — display-only markers are separated from spoken/audio script.
10. **Assessment gate** — learner must retrieve/produce/mediate, not only recognize.
11. **Recycling gate** — target vocabulary/grammar reappears across delayed contexts and modes.
12. **Trend freshness gate** — slang/current language has date, audience, status and recheck policy.
13. **Safety/factual gate** — medical/legal/safety claims use authoritative terminology/sources.
14. **Human pilot gate** — real learners reveal confusion, transfer errors and unnatural explanations before final publication.

## Anti-pattern failures
Reject or rewrite if:
- dialogue exists only to explain a fact;
- character voice collapses into generic textbook language;
- low-level dialogue becomes childish;
- a desired grammar form forces an unnatural sentence;
- modern topic causes hidden C1 vocabulary in an A1 unit;
- EN/DE are literal translations rather than native pedagogical explanations;
- typed chat markers are read literally by audio;
- research coverage is mistaken for content approval.
