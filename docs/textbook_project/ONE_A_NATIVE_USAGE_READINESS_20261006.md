## Evidence rule

READY_FOR_UNIT_CONTRACT means:
- the relevant domain has independent KO/EN/DE native-usage evidence;
- common translationese risks are documented;
- register and spoken/display differences are represented.

It does **not** mean:
- all dialogue is publishable;
- every vocabulary item is final;
- learner-error explanations are complete;
- audio has been generated.
