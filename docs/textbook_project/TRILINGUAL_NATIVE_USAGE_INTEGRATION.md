# Trilingual Native-Usage Integration

Canonical source: `tools/content_factory/canonical_scenarios/trilingual_native_usage_registry_20261006.json`

## Purpose
The textbook must not teach a translation table. It must teach how KO, EN and DE native speakers actually frame the same communicative domain.

The registry's 32 topics become the publishing project's reusable native-usage layer.

## Per topic / per language minimum
Broad pass:
- 3 independent source contexts
- 8 normalized usage patterns
- 2 register lanes
- 1 translationese warning

Deep pass:
- 4+ independent contexts
- 15–25 normalized patterns
- 3+ register lanes where meaningful
- freshness and confidence metadata
- spoken/display note where chat forms differ from speech

## Register lanes
- everyday / casual
- relationship / service
- work / professional
- academic / institutional
- online / chat

Do not force lanes that do not naturally exist.

## Textbook consumption rule
A unit may pull:
1. durable core expressions for required learning;
2. contextual alternatives for recognition;
3. translationese warnings for EN/DE learners;
4. spoken-vs-written notes;
5. trend/slang only as dated optional capsules.

Research coverage never equals content approval.

## Relationship-first dialogue rule
Before mining grammar or vocabulary:
1. lock relationship + chronology + register;
2. define a real-life friction/task;
3. include a character-specific human beat when safe;
4. write natural Korean;
5. mine language only from the accepted Korean copy;
6. re-run level audit;
7. if human review changes the dialogue, discard stale mining and re-mine.

## Cross-language risks to preserve
- Korean honorifics do not map mechanically to German Sie/du.
- Korean omitted subjects must not be mechanically restored as English pronouns.
- German modal particles may carry pragmatic work without a direct Korean source token.
- Domain labels may shift across languages: a culturally valid Korean label can sound unnatural as an everyday EN/DE label.
- Humor and teasing must preserve function and relationship, not literal wording.

## Publishing output
Each unit should eventually expose:
- Korean core dialogue
- EN learner notes authored from KO + native EN profile
- DE learner notes authored from KO + native DE profile
- optional "How people actually say it" panel
- optional "Don't translate this literally" panel
- corpus provenance and review date in teacher/editor metadata
