# Unit 04 Model Editorial Audit — 2026-10-06

Scope: structure/pedagogy/localization consistency check. This is **not** a human native-speaker approval.

## Findings

### Resolved — learner-facing explanation language
The original STUDENT_MASTER is pedagogical master copy but is Korean-heavy for a true beginner.

Resolution:
- added STUDENT_EN.md
- added STUDENT_DE.md
- both are independently localized rather than chained translations.

### Resolved — productive vs recognition-only
Staff language remains authentic but is not automatically assigned as learner production grammar.

Examples kept recognition-first:
- 주문하시겠어요?
- 뭐 드릴까요?
- 포장이세요?
- 안 매운 걸로 드릴게요.

### Resolved — counter overload
Only 하나 / 한 잔 are core production.
A full counter table is deferred.

### Resolved — particle overgeneralization
The unit explicitly contrasts:
- 고기를 먹어요.
- 떡볶이 하나 주세요.

This prevents both:
- "particles are optional";
- "every noun always needs a particle."

### Resolved — localization literalism
EN:
- 주세요 is not fixed to "Give me".

DE:
- 주세요 is not fixed to "ich bekomme/ich kriege".

### Still open before publication
- human Korean educator review;
- native EN pedagogy review;
- native DE pedagogy review;
- adult learner pilot;
- page layout and typography;
- final audio/TTS review by Jin.

## Decision

Unit 04 remains the **reference vertical slice** for 1A package structure.

The other seven 1A units may now be materialized from their locked contracts using the same package standard, but remain DRAFT_MATERIALIZED until unit-specific editorial review.
