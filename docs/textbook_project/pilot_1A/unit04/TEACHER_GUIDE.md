# Teacher Guide — Korean 1A Unit 04
# 음식과 수량 주문하기

## Unit purpose

This pilot tests whether the publishing system can combine:

- authentic Korean service language;
- A1 production limits;
- native-use evidence;
- explicit pragmatics;
- English/German transfer-aware explanation;
- listening + reading + speaking + writing;
- delayed recycling;
- app source reuse without dumping the app bank into print.

## Core can-do

By the end of the unit, learners can:

1. order one food/drink item;
2. add a basic quantity;
3. ask one condition question;
4. modify one condition;
5. respond to short staff-side service language.

## Do not overteach

This unit is **not** the place to teach:

- every Korean counter;
- the full object-particle theory;
- all honorific service morphology;
- `-(으)시겠어요?` production;
- `-ㄹ게요` as a full grammar lesson;
- full price-number system;
- restaurant etiquette as universal rules.

## Authority hierarchy

1. Canonical dialogue:
   `bunshik_tteokbokki`

2. Supplementary service variation:
   `a1_w10_eat`

3. Native-use evidence:
   `food_drink` profile from Tier 1 Batch 01

4. Practice bank:
   selected cloze/sentence items only

Do not treat every app exercise mapped to this unit as printable core material.

## Suggested 80-minute lesson

### 0–8 min — Scene first

Play/read the core dialogue without grammar explanation.

Question:
- What is ordered?
- Is it spicy?
- What does the learner finally choose?

### 8–18 min — Notice the useful chunks

Board:

- 떡볶이 하나 주세요.
- 많이 매워요?
- 안 매운 걸로 주세요.

Ask learners what each utterance **does**.

Do not start from “today's grammar is 을/를.”

### 18–30 min — Description vs service order

Contrast:

- 고기를 먹어요.
- 떡볶이 하나 주세요.

Teaching point:
Korean particles are important, but natural service orders can be compact.

This prevents an English/German learner from concluding either:
- “particles are optional everywhere,” or
- “every noun must always have a particle.”

### 30–40 min — Quantity as chunks

Teach only:
- 하나
- 한 잔

Optional:
- 두 잔 if class is ready.

Do not open a complete classifier table.

### 40–50 min — Native service variation

Use:
- 이거 하나 주세요.
- 아메리카노 한 잔 주세요.
- 포장해 주세요.

Staff recognition:
- 뭐 드릴까요?
- 포장이세요?

### 50–60 min — EN/DE transfer mini-lane

#### English-L1

Ask:
What is wrong with memorizing `주세요 = Give me`?

Elicit:
politeness/formula mismatch.

Offer:
- Can I get...?
- Can I have...?
- I'll have... please.

#### German-L1

Avoid:
`주세요 = ich bekomme`

Offer:
- Ich hätte gern...
- Einmal ..., bitte.
- Ich nehme...

Explain that all are contextual equivalents, not morpheme translations.

### 60–72 min — Role-play

Learner must:
- choose item
- choose quantity
- ask/modify one condition
- respond to staff

Change roles.

### 72–80 min — Retrieval exit task

Remove the book.

Show a menu card only.

Learner orders one item and condition.

## Expected errors

### EN-L1

1. bare numeral / missing counter
2. “Give me...” carried into English explanation
3. SVO-style Korean assembly
4. particle overuse after memorizing 을/를

Feedback:
do not say “wrong Korean order” only.
Rebuild as chunks:
`떡볶이 | 하나 | 주세요`

### DE-L1

1. one-to-one mapping of `주세요` to one German formula
2. numeral+noun expectation without classifier
3. German clause analogy overextended
4. over-formal service German carried into Korean assumptions

## Pronunciation feedback

Priority:
1. intelligibility
2. phrase grouping
3. question intonation

Do not interrupt every phonetic deviation during the role-play.

Correct after the turn unless misunderstanding occurs.

## Pragmatics

`주세요` is learner-safe and productive.

Staff-side honorific/service questions are mostly comprehension input at this point.

Learners should not feel they must reproduce the employee's morphology to be polite.

## Culture caution

Do not claim:
- “Koreans always say X in restaurants.”
- “You must call staff this way.”
- “아아 is how young Koreans always order.”

Present:
- stable service Korean
- common variants
- clearly marked contemporary/optional shorthand.

## Evidence use

The native-usage corpus is used to identify recurring wording and register.

Community/blog sources do not become factual authorities.

No third-party textbook sentence sequence is used.

## Assessment rubric — 10 points

| Criterion | Points |
|---|---:|
| correct item communicated | 2 |
| quantity chunk | 2 |
| polite request | 2 |
| one condition/question | 2 |
| continues interaction after staff response | 2 |

Passing suggestion:
7/10 plus no complete interaction breakdown.
