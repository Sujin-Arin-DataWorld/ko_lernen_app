## A. Meaning first

Read the core chunks and match each one to its communicative job.

- 카톡 하세요?
- 카카오톡으로 연락할까요?
- 제가 카톡 보낼게요
- 도착하면 연락할게요
- 10분 정도 늦을 것 같아요

Functions:
- suggest_contact_channel
- offer_contact
- confirm_contact
- delay_notice
