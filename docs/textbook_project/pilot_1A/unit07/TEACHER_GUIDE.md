# Teacher Guide — Korean 1A Unit 07
# 자연스럽게 연락 방법 정하기

Status: DRAFT_MATERIALIZED

## Can-do

- 상대에게 부담을 덜 주는 방식으로 연락 방법을 제안하고 연락처·채널을 확인할 수 있다.
- 늦거나 일정이 바뀔 때 짧은 메시지를 보낼 수 있다.

## Communicative problem

연락처 교환을 필수 절차로 가정하지 않고, 채널을 제안하거나 자신의 연락처를 먼저 제공하는 선택지를 배운다.

## Relationship / register

- Primary relationship: new classmates / new friends
- Korean register: polite-friendly
- EN default: friendly
- DE default: contextual du/Sie

## Productive language

- **(으)로** — A particle with official senses including direction, route, means/tool and method. The lesson selects only the relevant sense.
  *Official sources: KRDIC_EURO: 한국어기초사전: 으로 (국립국어원)*
- **있어요** — For this unit, 있다 is used in its official dictionary location/existence sense, with the pattern 1이 2에 있다.
  *Official sources: KRDIC_ITDA: 한국어기초사전: 있다 (국립국어원)*

## Formulaic production

- **카톡 하세요?** — 카톡 하세요?  
  Fixed learner-use chunk in this unit; no generalized grammar rule is introduced here.
- **-(으)ㄹ까요?** — 카카오톡으로 연락할까요?
  Officially sourced function: It has an official use for asking the listener's opinion or making a proposal; it also has a separate conjectural-question use.
  *Official sources: KRDIC_LKKAYO: 한국어기초사전: -ㄹ까요/-을까요 (국립국어원)*
- **-ㄹ게요** — 제가 카톡 보낼게요 / 도착하면 연락할게요
  Officially sourced function: An expression, mainly spoken, in which the speaker promises or signals an intention to do an action to the listener.
  *Official sources: KRDIC_LGEYO: 한국어기초사전: -ㄹ게요 (국립국어원)*
- **-(으)ㄹ 것 같아요** — 10분 정도 늦을 것 같아요
  Officially sourced function: An official NIKL teacher guide presents 것 같다 as expressing the speaker's conjecture and also as a way to state an opinion or feeling less categorically.
  *Official sources: NIKL_INTERMEDIATE_GEOT_GATDA: 중급 한국어 1 교원용 지침서: 것 같다 (국립국어원)*

These are learner-usable chunks whose full grammar analysis is intentionally deferred.

## Recognition/context only

- **-(으)실래요?** — Recognize this in context; this unit does not teach a generalized production rule for it.

## Teaching order

1. play/read the scene;
2. establish meaning;
3. notice core chunks;
4. explain only necessary form;
5. contrast native-use variation;
6. address EN/DE transfer risk;
7. run interaction task;
8. delayed retrieval.

## EN-L1 risk

- **EN-A1-SUBJECT-OMISSION**: Repeating 저는/제가 or explicit pronouns because English clauses normally require overt subjects.
- **EN-A1-SPEECHLEVEL**: Expecting politeness to be optional lexical courtesy rather than sentence-final grammar.

## DE-L1 risk

- **DE-A1-SUBJECT-OMISSION**: Restoring ich/du mechanically in Korean because German finite clauses usually express a subject.
- **DE-A1-DU-SIE**: Assuming 존댓말=Sie and 반말=du.

## Pragmatics

- contact exchange is a boundary act
- offer-your-own-contact can be lower-pressure than demanding theirs
- late message includes apology + approximate delay + next step

## Culture caution

- KakaoTalk is culturally salient but should not become the only model of Korean digital communication.

Do not convert contextual patterns into universal rules.
