# Teacher Guide — Korean 1A Unit 07
# 자연스럽게 연락 방법 정하기

Status: DRAFT_MATERIALIZED

## Can-do

- 상대에게 부담을 덜 주는 방식으로 연락 방법을 제안하고 연락처·채널을 확인할 수 있다.
- 늦거나 일정이 바뀔 때 짧은 메시지를 보낼 수 있다.

## Communicative problem

연락처 교환을 필수 절차로 가정하지 않고, 채널을 제안하거나 자신의 연락처를 먼저 제공하는 선택지를 배운다.

## Relationship / register

- Primary relationship: new classmates / new friends
- Korean register: polite-friendly
- EN default: friendly
- DE default: contextual du/Sie

## Productive language

- (으)로: channel/means, e.g. 카카오톡으로
- 있어요: presence/contact resource
- -아/어 주세요: simple instruction/request

## Recognition/context only

- -(으)ㄹ까요?: high-value proposal chunk; production can begin as formula but full grammar analysis belongs later
- -ㄹ게요: promise/intent chunk in messaging; recognition/formula only in early A1

## Teaching order

1. play/read the scene;
2. establish meaning;
3. notice core chunks;
4. explain only necessary form;
5. contrast native-use variation;
6. address EN/DE transfer risk;
7. run interaction task;
8. delayed retrieval.

## EN-L1 risk

- **EN-A1-SUBJECT-OMISSION**: Repeating 저는/제가 or explicit pronouns because English clauses normally require overt subjects.
- **EN-A1-SPEECHLEVEL**: Expecting politeness to be optional lexical courtesy rather than sentence-final grammar.

## DE-L1 risk

- **DE-A1-SUBJECT-OMISSION**: Restoring ich/du mechanically in Korean because German finite clauses usually express a subject.
- **DE-A1-DU-SIE**: Assuming 존댓말=Sie and 반말=du.

## Pragmatics

- contact exchange is a boundary act
- offer-your-own-contact can be lower-pressure than demanding theirs
- late message includes apology + approximate delay + next step

## Culture caution

- KakaoTalk is culturally salient but should not become the only model of Korean digital communication.

Do not convert contextual patterns into universal rules.

## Pronunciation

- 카카오톡 contraction/rhythm
- QR code mixed-script handling
- 연락할게요 linking

## Assessment

Must produce:
- 카카오톡으로 연락할까요?
- 도착하면 연락할게요

Must recognize:
- 카톡 하세요?
- 연락처 알려 주실래요?

Success:
arranges contact without assuming consent

## Production ceiling

short chat messages; no complex explanation of why plans changed
