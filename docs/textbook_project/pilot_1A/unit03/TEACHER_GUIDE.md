# Teacher Guide — Korean 1A Unit 03
# 가게에서 물건 찾기

Status: DRAFT_MATERIALIZED

## Can-do

- 가게에서 원하는 물건이 어디 있는지 묻고 위치를 이해할 수 있다.
- 은/는과 이/가를 짧은 실제 문맥 안에서 구별해 사용할 수 있다.

## Communicative problem

마트에서 물건을 찾으며 topic/focus를 실제 질문-답 구조로 경험한다.

## Relationship / register

- Primary relationship: customer ↔ store staff
- Korean register: polite
- EN default: neutral service
- DE default: Sie

## Productive language

- 은/는: established topic / contrast
- 이/가: subject/focus in identification/existence
- 에 있다: location/existence

## Formulaic production

- none

These are learner-usable chunks whose full grammar analysis is intentionally deferred.

## Recognition/context only

- none

## Teaching order

1. play/read the scene;
2. establish meaning;
3. notice core chunks;
4. explain only necessary form;
5. contrast native-use variation;
6. address EN/DE transfer risk;
7. run interaction task;
8. delayed retrieval.

## EN-L1 risk

- **EN-A1-PARTICLES-OMIT-REPLACE**: Particle omission or replacement remains a major error class for English-speaking Korean learners.
- **EN-A1-TOPIC-SUBJECT**: Treating both as a single English-style subject marker or swapping them without discourse motivation.
- **EN-A1-E-ESEO**: Using one generic location marker because English 'at/in' does not align with Korean predicate-conditioned location marking.

## DE-L1 risk

- **DE-A1-PARTICLE-CASE**: Treating 은/는, 이/가, 을/를 as equivalents of German Nominativ/Akkusativ or articles.
- **DE-A1-TOPIC-FOCUS**: Searching for a German case-form equivalent instead of learning Korean information structure.
- **DE-A1-E-ESEO-EURO**: Mapping Korean location/direction particles directly onto German prepositions/cases.

## Pragmatics

- 저기요 as attention-getter in service context
- repairing wrong identification without over-apology

## Culture caution

- store-staff attention strategies vary; 저기요 is useful but tone matters.

Do not convert contextual patterns into universal rules.

## Pronunciation

- 은/는 and 이/가 attachment
- 있어요 linking
- 이거/그거 deictic rhythm

## Assessment

- ___는 어디에 있어요?
- ___에 있어요
- ___가 여기 있어요

Must recognize:
- 은/는
- 이/가

Success:
uses particles in context, not through isolated translation

avoid abstract topic-vs-subject theory; context first
