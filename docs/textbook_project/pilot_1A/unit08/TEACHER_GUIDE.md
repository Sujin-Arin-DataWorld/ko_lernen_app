# Teacher Guide — Korean 1A Unit 08
# 못 들었을 때 다시 묻기

Status: DRAFT_MATERIALIZED

## Can-do

- 못 들었는지, 뜻을 모르는지, 이해를 확인하려는지 구분해 적절한 repair를 사용할 수 있다.
- 숫자·이름·출구 같은 중요한 정보를 되묻고 확인할 수 있다.

## Communicative problem

모르는 척 넘어가지 않고 짧은 repair 전략으로 실제 대화를 유지한다.

## Relationship / register

- Primary relationship: learner/traveler ↔ staff/teacher/new acquaintance
- Korean register: polite productive default; casual recognition
- EN default: neutral polite
- DE default: Sie to staff, du among peers

## Productive language

- -아/어 주세요: repeat/slow request
- 무슨 N: meaning question, chunk-first
- 아니에요: correct information

## Recognition/context only

- -는데요: natural interpersonal softening but above productive target for this unit
- 계신지: honorific embedded form; recognition/context only
- 몰랐어요: past explanation; not target grammar here
- -ㄹ게요: promise/next action; recognition only
- 뭐라고요?: intonation-sensitive and can sound surprised/challenging; recognition first

## Teaching order

1. play/read the scene;
2. establish meaning;
3. notice core chunks;
4. explain only necessary form;
5. contrast native-use variation;
6. address EN/DE transfer risk;
7. run interaction task;
8. delayed retrieval.

## EN-L1 risk

- **EN-A1-SPEECHLEVEL**: Expecting politeness to be optional lexical courtesy rather than sentence-final grammar.

## DE-L1 risk

- **DE-A1-DU-SIE**: Assuming 존댓말=Sie and 반말=du.

## Pragmatics

- hearing problem ≠ meaning problem ≠ confirmation
- short repair forms are intonation-sensitive
- repair is a learner autonomy strategy

## Culture caution

- politeness in repair depends on relationship and tone; no single direct translation is safe in every setting.

Do not convert contextual patterns into universal rules.

## Pronunciation

- 3 vs 13
- question echo intonation
- 말씀해 주세요 / 천천히 phrase rhythm

## Assessment

Must produce:
- 다시 말씀해 주세요
- 무슨 뜻이에요?
- 13번이요?

Must recognize:
- 뭐라고요?
- 뭐라고 했어?

Success:
uses correct repair type without switching language
