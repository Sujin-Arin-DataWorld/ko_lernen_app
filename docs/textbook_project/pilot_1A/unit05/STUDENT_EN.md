# Korean 1A · Unit 05
# Checking time and plans

## By the end of this unit, you can:

- Ask for a meeting time and confirm or correct the time.
- Use basic native-Korean hour numbers in a real scheduling task.

## Why this unit exists

Use numbers to confirm real information instead of memorizing a number list in isolation.

## 1. Core scene

**Learner**
오늘 몇 시에 만나요?
*What time are we meeting today?*

**Sujin**
일곱 시에 만나요.
*At seven.*

**Learner**
여섯 시 아니에요?
*Isn't it at six?*

**Sujin**
아니요, 일곱 시예요.
*No, at seven.*

**Learner**
아, 일곱 시요.
*Oh, seven.*

**Sujin**
네. 카페 앞에서 봐요.
*Right. See you in front of the café.*

### First task

Do not translate every word. Identify:
- who is speaking;
- what the immediate goal is;
- which line solves the problem.

## 2. What you should be able to say

- **몇 시에 만나요?**
- **일곱 시에 만나요**
- **여섯 시 아니에요?**
- **아니요, 일곱 시예요**
- **몇 번이에요?**

These are the productive chunks for this unit.

### Productive grammar

- **N시에** — time point
- **아니에요** — correction/negation

The goal is not to memorize labels. Use the forms to solve the scene.

## 3. Understand first — do not overlearn yet

- No extra recognition-only form in this unit.

Authentic input can contain grammar above your current production target. Understanding it does not mean you must produce it now.

## 4. Living Korean

### Pragmatics

- Repeating a number back is normal when accuracy matters.
- Short echo questions are useful for confirmation.

### Culture/context

- Korean uses more than one number system; learn each system with the task that needs it.

Avoid the rule “Koreans always say X.” Learn who says what, to whom, and why.

## 5. English-speaker transfer notes

### EN-A1-COUNTERS

**Risk:** Using bare numerals because English normally does not require classifier-like counters.

**Teaching response:** Teach high-frequency lexical chunks (한 명, 한 잔, 한 개, 두 시) by task, not an exhaustive classifier table.

## 6. Sound focus

- native Korean hour numbers
- Sino-Korean phone/price digit awareness
- 십삼 vs 삼 discrimination

## 7. Input mission

- Distinguish 6 vs 7 and 3 vs 13.
- Listen for a time/place pair.

## 8. Output mission

- Set a meeting time.
- Correct one intentionally wrong time.

## 9. Reading

- Read a simple appointment card, price, or phone digits.

## 10. Writing

- Write a time/number from audio.

## 11. Interaction mission

Complete a schedule-grid information-gap task.

## 12. Exit task

You must be able to produce:

- 몇 시에 ___?
- N시에 ___

You must be able to recognize:

- 여섯 시 아니에요?
- 아니요, 일곱 시예요.

**Success:** Confirm a time accurately after one misunderstanding.

## Production ceiling

Time plus one location; no complex scheduling clauses.

This unit is part of a spaced-recycling curriculum. The target language returns in later contexts.
