## Communicative problem

숫자를 외우는 대신 약속 시간·가격·전화번호처럼 실제 정보 확인에 쓴다.

## Relationship / register

- Primary relationship: new friends / service situations
- Korean register: polite
- EN default: neutral
- DE default: contextual

## Productive language

- N시에: time point
- 아니에요: correction/negation

## Recognition/context only

- none

## Teaching order

1. play/read the scene;
2. establish meaning;
3. notice core chunks;
4. explain only necessary form;
5. contrast native-use variation;
6. address EN/DE transfer risk;
7. run interaction task;
8. delayed retrieval.

## EN-L1 risk

- **EN-A1-COUNTERS**: Using bare numerals because English normally does not require classifier-like counters.

## DE-L1 risk

- **DE-A1-COUNTERS**: Expecting German numeral+noun structure to transfer directly.

## Pragmatics

- repeat-back is normal when numbers matter
- number confirmation uses intonation and short echo forms

## Culture caution

- Korean uses multiple numeral systems by task; teach the needed system with the task rather than a giant chart first.

Do not convert contextual patterns into universal rules.

## Pronunciation

- native Korean hour numbers
- Sino-Korean phone/price digit awareness
- 십삼 vs 삼 discrimination

## Assessment

Must produce:
- 몇 시에 ___?
- N시에 ___

Must recognize:
- 여섯 시 아니에요?
- 아니요, 일곱 시예요.

Success:
confirms a time accurately after one misunderstanding
