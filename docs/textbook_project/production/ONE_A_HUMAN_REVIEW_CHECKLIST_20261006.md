# Korean 1A Human Review Checklist — 2026-10-06

This checklist is for **human approval after model editorial pass**.

A checked model-validation box is never treated as human approval.

---

# A. Korean educator review

For every unit:

- [ ] Can-do is realistic for A1 adults.
- [ ] The core scene solves a real communicative problem.
- [ ] Korean dialogue sounds natural for the exact relationship and setting.
- [ ] Speech level matches chronology and relationship.
- [ ] Productive grammar is genuinely appropriate for A1.
- [ ] Formulaic production is useful enough to justify learning before full analysis.
- [ ] Recognition-only language is not accidentally tested as production.
- [ ] Vocabulary load fits the level.
- [ ] Sentence length and clause density fit the Level Bible.
- [ ] Pragmatics are taught as choices/effects, not national stereotypes.
- [ ] Culture notes are accurate and proportionate.
- [ ] Pronunciation focus matches what learners actually need to understand/say.
- [ ] No app-specific shortcut has leaked into print as if it were canonical Korean.
- [ ] Assessment actually measures the unit Can-do.

# D. Audio / spoken-surface review

- [ ] Every spoken line has a reviewed spokenSurfaceKo.
- [ ] display-only markers are not read literally.
- [ ] ㅋㅋ/ㅎㅎ are not converted mechanically.
- [ ] English chat markers such as lol/lmao are not automatically spoken.
- [ ] German chat spellings/emoji are not automatically spoken.
- [ ] Intonation carries the intended speech act.
- [ ] Number contrasts are intelligible.
- [ ] Proper names are pronounced consistently.
- [ ] Recognition-only forms sound natural, not artificially slowed beyond usefulness.
- [ ] Audio supports the printed task and does not introduce untracked target language.

# E. Visual / print review

- [ ] Unit fits the 14-page student-book budget.
- [ ] Workbook fits the 10-page unit budget.
- [ ] Korean text is visually dominant over translation/support text.
- [ ] Hangul size remains comfortable for beginner decoding.
- [ ] No page is overloaded because app items were dumped into print.
- [ ] A spread has one obvious pedagogical purpose.
- [ ] Living Korean panels are visually distinct from required production.
- [ ] Formulaic production is visually distinct from recognition-only language.
- [ ] EN/DE learner notes do not interrupt the main Korean flow.
- [ ] QR/app links are optional enhancements, never required for the core task.
- [ ] Print remains usable offline.

---

# F. Assessment review

- [ ] Correct answers are defined where an exact answer exists.
- [ ] Legitimate variants are listed.
- [ ] Open production uses a rubric rather than one fake “correct” sentence.
- [ ] Partial credit is defined where appropriate.
- [ ] A learner can pass by accomplishing the communicative goal, not by copying wording.
- [ ] Transfer diagnostics do not punish natural EN/DE variants.
- [ ] Recognition-only grammar is not required in productive assessment.
- [ ] Delayed retrieval is included.
- [ ] At least one interaction/repair task exists.
- [ ] Answer key feedback explains the reason, not just the answer.

---

# G. Rights / provenance review

- [ ] All printed Korean dialogue is project-owned or clean-room authored.
- [ ] Web/news/blog/review/community sources are used as evidence, not copied as lesson text.
- [ ] Third-party textbook sequences are not reproduced.
- [ ] Quotes, if any, remain within permitted limits and have source metadata.
- [ ] Trend/current-language claims include date and context.
- [ ] Health/legal/safety terminology uses authoritative sources where needed.

---

# H. Pilot-readiness gate

Before a unit enters learner pilot:

- [ ] Korean educator decision is not HOLD.
- [ ] EN or DE edition has native pedagogy review for the pilot cohort.
- [ ] Audio script has spoken-surface review.
- [ ] Answer key exists for closed tasks.
- [ ] Rubric exists for open tasks.
- [ ] Pilot task IDs are stable.
- [ ] No participant name/email is required in the learning-event log.
- [ ] Recording, if used, has a separate consent/retention process.
- [ ] Baseline and delayed-retrieval tasks are defined.

Only after these checks can the unit move from:
`MODEL_EDITORIAL_PASS_COMPLETE_HUMAN_REVIEW_OPEN`

to:
`HUMAN_REVIEWED_READY_FOR_PILOT`
