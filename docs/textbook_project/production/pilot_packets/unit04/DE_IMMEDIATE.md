## Aufgabe

Du bist in einem Bunsik-Lokal.

Bestelle **ein Tteokbokki**.
Frage, ob es sehr scharf ist.
Wenn ja, bestelle die milde Variante.

Setze das Gespräch fort, wenn das Personal eine kurze Frage stellt.

## Erfolg ist kein einziger Musterdialog

Kommuniziert werden sollen:
- Produkt
- Menge
- höfliche Bitte
- Bedingung/Frage
- Reaktion auf die andere Person
