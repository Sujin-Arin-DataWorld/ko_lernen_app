# Unit 04 Pilot — EN Baseline

Participant code:

Do this **before** teaching Unit 04.

## Task

You are at a café in Korea.

Menu:
- 아메리카노
- 주스
- 샌드위치

Try to order **one Americano** in Korean using anything you already know.

Then, if you can, ask whether 떡볶이 is very spicy.

Do not look up a model sentence.
