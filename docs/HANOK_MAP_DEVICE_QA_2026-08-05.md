# 개인 한옥 지도 실기기 QA

**상태:** 자동 회귀 통과 후 실기기 확인 대기. 이 문서는 실기기 성공을
주장하지 않는다.

## 대상 기기와 상태

각 기기에서 아래 네 조합을 모두 확인한다.

| 기기 | 방향 | 시스템 글자 |
|---|---|---|
| Galaxy Tab | 세로 · 가로 | 1.0 · 1.3 |
| Xiaomi Pad | 세로 · 가로 | 1.0 · 1.3 |

확인용 진도 상태는 다음 세 가지다.

| 상태 | 최소 진도 | 기대 결과 |
|---|---|---|
| 초반 | A1/A2 완료, B1 25% | 솟을대문과 빈 대지 |
| 중간 | B1 100%, B2 50% | 문·행랑·사랑·안채·대청 |
| 완성 | B2 100% | 사당과 연못 위를 가로지르는 다리를 포함한 후원 |

## 확인 항목

1. `/hanok`에서 세로·가로 회전 뒤 지도가 4:3 비율을 유지하고, 건물·후원이
   찌그러지거나 흰/검은 폴백으로 바뀌지 않는다.
2. 사랑채·대청·행랑·안채 양쪽 날개·후원 두 지점·사당을 각각 눌러 다른
   장소가 열리지 않는지 확인한다. 특히 대청과 후원, 사랑채와 행랑채 경계가
   중요하다.
3. 1.3배 글자에서 지도 아래의 선택 카드와 접근성 장소 목록의 버튼이 잘리지
   않고 최소 44dp로 눌린다.
4. 안채·대청·행랑·사당·후원을 열었을 때 새 학습 데이터를 만들지 않고,
   기존 안방/대청·연습·도장첩/통계·오늘의 글자/퀘스트로만 이어지는지
   확인한다. 사랑방은 기존 추천 엔진이 고른 다음 학습을 연다.
5. 새 milestone을 해금한 뒤 지도에 다시 들어가면 한 번만 목재 조립·먼지·
   단청 glint 연출이 나오고, 재진입에는 반복되지 않는지 확인한다. reduce
   motion에서는 정적 확인과 명시적 계속 버튼만 보이는지 확인한다.
6. 완성 상태에서 연못과 다리가 하나의 후원 레이어로 유지되어, 다리가 물과
   관계없이 떠 있거나 방향이 틀어지지 않는지 확인한다.

## 기록 형식

각 결과에 기기 모델·OS·앱 버전·방향·글자 배율·진도 상태·통과/실패·스크린샷을
남긴다. 실패는 눌렀던 장소와 실제 열린 장소, 재현 순서, 화면 녹화 또는
스크린샷을 함께 기록한다.
