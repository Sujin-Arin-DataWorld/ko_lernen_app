# 한글소리 홈 개편 — 필요한 에셋 목록

개편안을 완성하는 데 실제로 필요한 것만 적었습니다. 프롬프트는 그대로 복사해서 쓰시면 됩니다.

**스타일 기준선(style anchor)**: 지금 앱에 들어있는 **로우폴리 호랑이**입니다. 모든 캐릭터·일러스트는 여기에 맞춰야 합니다 — 삼각 면 분할, 면 안은 단색(그라데이션 없음), 따뜻한 자연광, 외곽선 없음. 프롬프트마다 이 조건을 넣어뒀습니다.

> 팁 — ChatGPT에서 만드실 때 **기존 호랑이 PNG를 먼저 업로드**하고 "match this exact illustration style" 한 줄을 덧붙이면 스타일 일치율이 크게 올라갑니다.

## 1·2. 캐릭터 정지 이미지 — 영상에서 추출 ★최우선

**결론: 생성하지 마세요.** 보유하신 영상에서 프레임을 뽑는 게 더 좋습니다.
캐릭터가 이미 완성된 모습 그대로 나오고, 영상과 정지 이미지의 인상이 100% 일치합니다 — AI로 다시 만들면 미묘하게 다른 얼굴이 나와서 오히려 어색해집니다.

**목표 파일**
```
assets/images/character/tiger_sitting.png    512×512 · 투명 PNG
assets/images/character/magpie_sitting.png   512×512 · 투명 PNG
```

### 1단계 — 알파 채널이 있는지 먼저 확인

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=pix_fmt -of csv=p=0 \
  assets/video/character/magpie_sitting.mp4
```

- `yuva420p` / `rgba` 처럼 **`a`가 붙어 있으면** → 이미 투명 배경. 3단계 건너뛰세요
- `yuv420p` 처럼 `a`가 없으면 → 배경 제거 필요 (3단계)

### 2단계 — 가장 좋은 프레임 고르기

먼저 컨택트 시트를 뽑아 눈으로 고릅니다. 고개 들고, 눈 뜨고, 정면 가까운 컷이 좋습니다.

```bash
ffmpeg -i assets/video/character/magpie_sitting.mp4 \
  -vf "fps=2,scale=220:-1,tile=5x4" contact_magpie.png
```

마음에 드는 시점(예: 3.5초)을 정했으면 그 한 장만 뽑습니다.

```bash
ffmpeg -ss 00:00:03.5 -i assets/video/character/magpie_sitting.mp4 \
  -frames:v 1 -q:v 1 magpie_frame.png
```

호랑이도 동일하게. **두 캐릭터의 카메라 각도·크기가 비슷한 프레임을 고르세요** — 나란히 놓이진 않지만 사용자가 캐릭터를 바꿔보면 위화감이 느껴집니다.

### 3단계 — 배경 제거 (알파가 없을 때만)

```bash
pip install rembg
rembg i magpie_frame.png magpie_cut.png
```

`rembg`가 깃털 가장자리를 잘 못 따면 remove.bg 또는 Photoshop **개체 선택 → 가장자리 다듬기**를 쓰세요. 까치는 검은 몸이라 어두운 배경에서 뭉칠 수 있습니다.

### 4단계 — 정사각 캔버스에 여백 8%로 배치

```bash
ffmpeg -i magpie_cut.png -vf \
  "scale=471:471:force_original_aspect_ratio=decrease,pad=512:512:(ow-iw)/2:(oh-ih)/2:color=#00000000" \
  -y assets/images/character/magpie_sitting.png
```

### 체크리스트

- [ ] 배경이 **완전 투명**인가 (흰색 아님) — 새 카드색 `#FFFDF8` 위에 올려서 확인
- [ ] 두 캐릭터의 화면 내 크기가 비슷한가
- [ ] 가장자리에 원본 배경색 테두리(fringe)가 남지 않았는가
- [ ] 512px에서 얼굴 표정이 읽히는가

> **표정 변형(`_cheer`, `_think`)** 이 필요하면 — 영상에 해당 동작이 이미 들어 있는지 먼저 확인하세요. 있으면 그 구간에서 프레임을 뽑으면 됩니다. 없을 때만 생성하시고, 그때는 **추출한 정지 이미지를 레퍼런스로 업로드**하고 아래를 쓰세요.

```
Same character as the reference image — identical style, identical palette,
identical proportions and face design. Change only the pose: [POSE].

Flat geometric facets, solid color per facet, no gradients, no outlines.
Transparent background, full body, centered, no shadow, no text.
```

| 변형 | `[POSE]` | 쓰이는 곳 |
|---|---|---|
| `tiger_cheer.png` | `sitting upright, one front paw raised in a cheering gesture, mouth open in an encouraging roar` | 레슨 완료 |
| `tiger_think.png` | `lying down, head resting on one paw, eyes half-closed, pondering` | 오답 / 힌트 |
| `magpie_cheer.png` | `wings half-open and lifted, head up, joyful energetic posture` | 레슨 완료 |
| `magpie_think.png` | `head tilted, one wing raised toward the beak, thoughtful puzzled expression` | 오답 / 힌트 |

## 3. 앱 마크

**파일** `assets/brand/app_mark.svg`
**규격** 벡터 정사각 · 헤더 34dp / 런처 아이콘 512px 겸용

핵심 개념: **창호(한옥 문살) + 소리**. 문살 격자의 한 칸이 음파로 열리는 형태.

```
Minimal flat vector app icon, square with rounded corners.

Concept: a traditional Korean hanok window lattice (changho) — a simple
2x2 grid of thin straight bars forming a cross — where the lower-right pane
opens outward into three concentric sound-wave arcs radiating to the right.

Style: geometric, precise, two colors only. Deep dancheong teal-green
background (#10564C) with the lattice and sound waves in warm paper white
(#FFFDF8). Bar weight even and confident, roughly 1/12 of the icon width.
Generous margin — the lattice occupies about 62% of the canvas.

Flat design, no gradients, no shadows, no 3D, no text, no characters.
Must stay legible at 24px.
```

**체크리스트**
- [ ] 24px로 줄여도 격자와 음파가 구분되는가
- [ ] 캐릭터가 안 들어갔는가 (마크는 캐릭터와 분리 — 지금 겹침 문제의 원인)

## 4. 마당 아이콘 6종

**파일** `assets/icons/madang_*.svg`
**규격** 24×24 그리드 · 선 굵기 2dp · 라운드 캡 · `currentColor` 단색

한 번에 6개를 같은 세트로 만들어야 통일됩니다.

```
A set of 6 minimal line icons in one consistent style, drawn on a 24x24 grid
with 2px uniform stroke weight, round caps and round joins, no fill, single
color, generous 2px padding inside the grid.

Subtle Korean traditional influence: gently curved eaves-like arcs where a
curve is needed, otherwise clean geometric lines. Not decorative, not
illustrative — UI icons.

The 6 icons:
1. HANGEUL — a stylized Korean consonant block inside a light square frame
2. PRONUNCIATION — a microphone: rounded capsule with a curved stand base
3. VOCABULARY — two overlapping rounded rectangles like stacked flashcards
4. REVIEW — a circular arrow loop, open at the top right, with an arrowhead
5. LISTENING — five vertical bars of varying heights, like an equalizer
6. CULTURE — a hanok roof: a wide curved eave line over two simple pillars

Present them evenly spaced on a plain white background, all the same size
and optical weight. No labels, no color, no shadows.
```

> 참고: 목업에는 제가 임시 아이콘을 넣어뒀습니다. 급하면 그대로 출시해도 되고, 나중에 교체해도 레이아웃은 안 흔들립니다.

## 6. 웰컴 영상 — 보유, 확인만 필요

```
assets/video/character/tiger_sitting2.*     ← 실제 파일명·확장자 확인 필요
assets/video/character/magpie_sitting.mp4   ← 확인됨
```

**둘 다 있으므로 새로 만들 필요 없습니다.** 온보딩 완료 직후 **1회만** 재생하고, 이후 홈에서는 위에서 뽑은 정지 이미지를 씁니다.

### 확인할 것

```bash
ffprobe -v error -show_entries stream=width,height,pix_fmt,duration,codec_name \
  -of default=noprint_wrappers=1 assets/video/character/magpie_sitting.mp4
ls -lh assets/video/character/
```

- [ ] **화면비** — 목업은 4:5(1080×1350) 기준. 16:9면 웰컴 화면 프레임을 조정하거나 영상을 리프레임해야 합니다
- [ ] **길이** 5~7초 — 10초 넘으면 건너뛰기를 누릅니다
- [ ] **용량** 2MB 이하 — 첫 실행 체감 속도에 직결
- [ ] **독일어 자막** — 소리 끄고 보는 사용자가 다수입니다. 없으면 영상 위 텍스트 오버레이로 대체 가능
- [ ] **파일명 통일** — `tiger_sitting2` → `tiger_sitting.mp4`로 맞추면 코드가 한 줄로 정리됩니다

### 이름을 통일하면 생기는 것

```dart
// 영상
String video(String state) =>
    'assets/video/character/${profile.character}_$state.mp4';
// 정지 이미지
String art(String state) =>
    'assets/images/character/${profile.character}_$state.png';

// profile.character 는 'tiger' 또는 'magpie'
```

캐릭터 선택이 화면에 반영되는지 확신이 안 서던 문제가 여기서 **구조적으로** 해결됩니다 — 분기문이 없으니 빠뜨릴 곳도 없습니다.

### 재생 정책

- [ ] `prefers-reduced-motion` / Android 애니메이션 배율 0 → 정지 이미지 + 텍스트로 대체
- [ ] 1회 재생 여부는 **서버가 아닌 로컬 플래그**로 (재설치 시 다시 보여도 무방)
- [ ] 건너뛰기 버튼은 처음부터 노출 (숨겼다 나오면 짜증)

Palette: warm hanji paper background (#F4EEE0), dancheong temple colors on
the woodwork — deep teal-green (#10564C), earth red (#9B2F26), gold ochre

## 파일 정리 제안

```
assets/
├─ brand/        app_mark.svg, wordmark.svg
├─ icons/        madang_*.svg (6)
├─ images/
│  └─ character/ tiger_sitting.png, tiger_cheer.png, tiger_think.png
│                magpie_sitting.png, magpie_cheer.png, magpie_think.png
├─ textures/     hanji_tile.png
└─ video/
   └─ character/ tiger_sitting.mp4, magpie_sitting.mp4      ← 보유
```

`{character}_{state}` 규칙으로 통일하면 캐릭터 분기가 코드에서 아예 사라집니다 (6번 참고).
호랑이 영상만 `tiger_sitting2` → `tiger_sitting.mp4`로 맞추면 끝입니다.

캐릭터 선택이 화면에 반영되는지 확신이 안 서던 문제도, 이 규칙 하나로 구조적으로 해결됩니다.
