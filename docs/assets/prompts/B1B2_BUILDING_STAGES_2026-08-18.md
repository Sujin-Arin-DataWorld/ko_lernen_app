hanok 원장(provenance) 관할. 참조 6종(솟을대문·행랑채·안채·대청마루·사당·후원)은 PR5a′로

## 0. 기하 조사 (0cr)

배경 워크플로 3개 에이전트(`wf_d4912fe4-ad0`)가 `derive_hanok_a1_kit.classify()`를 그대로 이식해
6개 대상의 행/열 실루엣을 실측했다. 핵심 발견:

- **classify()의 TILE/WOOD 휴리스틱은 estate 건물에 잘 안 옮는다** — 그림자 진 벽·따뜻한 톤 석재가
  타일/나무로 오분류된다. 모든 경계값은 classify() 출력이 아니라 **실루엣 폭 변화율**(측정)로 잡았다.
- **안채는 3개 구역**(왼쪽 채·뒤로 물러난 대청·오른쪽 채)이 서로 다른 ridgeRow/eaveRow/wallBaseRow를
  가진다 — 단일 행 표로는 표현이 안 된다.
- **사당은 문+담장이 아니라 단일 지붕 실루엣**이었다 — 원안의 "대문+담장+사당" 가정이 틀렸다. 작은
  담장 기둥 조각 2개만 양끝에 붙어 있다.
- **대청마루는 생성이 전혀 필요 없다** — 기둥이 이미 완전히 노출돼 있어 3단계 전부 크롭만으로 된다.
- **후원은 행 기반이 아니다** — 연결요소 2개(정자·연못 군집 vs 장독대·바위 군집)에 classify()가 66%를
  나무/기와로 오분류한다(단풍 색). 수작업으로 확인한 사각 영역만 신뢰했다.

전체 보고서: `derive_estate_building_stages.py` 상단 docstring과 각 `*_stages.json`의 `note` 필드.

## 1. 단계 사양(override JSON, 사람이 실측해 고정)

`docs/assets/hanok_estate_kit/{building}_stages.json` — a1_kit_overrides.json과 같은 정신으로,
classify()를 신뢰하지 않고 연구에서 실측한 rowMin/window/region 값을 그대로 고정 기록했다.

| 건물 | 단계 수 | 생성 필요 | 근거 |
|---|---:|---|---|
| 솟을대문 | 3 | O(골조 1회) | 계단식 지붕, 단일 window로 충분(finished_alpha가 나머지 처리) |
| 행랑채 | 4 | O(골조 1회) | 뚜렷한 석축 없음, 문지방 국소 돌출은 finished_alpha가 자동 처리 |
| 안채 | 4 | O(골조 1회, 3구역 동시) | 3구역 서로 다른 rowMin, 굴뚝 돌출은 finished_alpha가 자동 처리 |
| 사당 | 3 | O(골조 1회) | 담장 기둥 조각은 크롭 전용(생성 대상 아님) |
| 대청마루 | 3 | X | 완전 개방형, classify()의 wood 오판(채도 기반 override로 대체) |
| 후원 | 3 | X | 연결요소+수작업 사각 영역, 장독대는 항아리 포함 하나로 취급 |

## 3. 정렬(0cr, 결정론) — `tool/derive_estate_building_stages.py --align --target-bbox`

1. 원본 청록 배경을 chroma-key 디코드(`cut_prop_sheet.chroma_to_alpha` 재사용).
2. 출력 자체의 알파 바운딩박스를 측정해 그 영역만 크롭.
3. 완성 건물의 실측 alpha bbox 크기로 LANCZOS 리스케일 후 같은 좌표에 붙임.
4. **재디스필 필요**: LANCZOS 보간이 저알파(<24/255) 가장자리 픽셀에 청록 기미를 되살렸다(28→17px,
   전부 alpha<24 림 노이즈로 확인) — 리스케일 후 despill 재적용 + 저알파 림 alpha=0 클램프로 해결.
5. 완성 건물 alpha와 교집합(포함 게이트, dilate 0).

## 4. 조립(0cr, 결정론) — `--build`

`{building}_stages.json`의 `reveal`/`regionUnion`/`final` 규칙대로 각 단계 RGBA를 합성하고
게이트 4종을 통과해야 저장된다: 포함(완성 알파 밖 0px) · 구조 연속성(recall 1.0, 이전 단계 픽셀
전량 다음 단계에 생존) · 생성 레이어 chroma 잔여 0(finished PNG 자체의 그림자/이끼 녹색조는 검사
대상에서 제외 — 실제 청록 잔여가 아니므로) · 바이트 예산(건물 350KB, 후원 1.3MB). **마지막 단계는
