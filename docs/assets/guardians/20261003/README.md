## 제작 기준

새 파생 에셋은 이 세 원화를 직접 참조한다. 형태를 둘러싼 검은 선 대신 곡면의 빛·색·겹침과 부드러운 그림자로 입체감을 만든다. 세밀한 무광 붓결은 유지하고 매끈한 플라스틱이나 평면 벡터로 바꾸지 않는다. 호랑이의 해부 구조, 까치의 깃털 구조, 해치의 민화 신수 구조는 각자 유지한다.

해치는 길고 날렵한 몸, 짧은 주홍 코와 압축된 민화 얼굴, 정면을 보는 또렷한 호박색 눈, 눈과 떨어진 얇은 구름눈썹을 유지한다. 에메랄드·따뜻한 주황빛 머리 장식과 잎 모양 꼬리, 붉은 화염 장식, 큰 짙은 반점, 금색 방울과 붉은 잎 목걸이, 네 발의 짧은 발톱을 유지한다. 작은 점은 추가하지 않는다. 개·늑대·호랑이 얼굴이나 비대한 근육형 몸으로 바꾸지 않는다.

최종 해치의 생성 명세는 [haechi-generation-spec.json](haechi-generation-spec.json)에 보관한다. 이전 단계의 로컬 참조 경로는 생성 이력이며 승인된 정본의 대체 경로가 아니다. 제삼자 참고 이미지 자체는 이 디렉터리에 포함하지 않는다.

## 앱 에셋 제작과 연결

이 디렉터리는 제작용 원본을 보관한다. 현재 앱의 `tiger`는 Taego, `magpie`는 Joy를 가리킨다. 네 이름을 네 캐릭터로 나누지 않는다. 해치의 역할·출연 위치·선택 방식은 다음 설계에서 실제 소비 코드와 대조해 정한다.

현재 정적 포즈 PNG, 온보딩 애니메이션 WebP, 캐릭터 영상, 포스터와 폴백, 듀오 장면은 기존 경로로 동작한다. 새 정본을 모든 슬롯에 단순 복사하지 않는다. 각 소비 화면에서 필요한 포즈·표정·시선·비율·프레이밍·애니메이션·폴백을 먼저 설계하고 별도 파생 파일로 만든다. 원본 디렉터리를 `pubspec.yaml`에 등록하지 않는다.
