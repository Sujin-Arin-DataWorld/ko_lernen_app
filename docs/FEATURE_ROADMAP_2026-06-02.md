## Tier A — 빠른 고효율 (출시 직후 1~2주, 저위험·고가치)

### A1. 나만의/사진 단어를 "오늘의 복습"(메인 SRS)에 편입 ⭐최우선
- **문제**: 현재 커스텀/사진 단어는 플립카드에서 "Gewusst"만 기록(`addVokSeen`)되고, 메인 SRS 스케줄(오늘의 복습)에는 안 들어가는 것으로 보임(확인 필요). → 사장님이 직접 모은 "안 외워지는 단어"가 정작 반복 노출이 안 됨.
- **할 일**: 커스텀/책 단어를 메인 SRS 큐에 등록 → 매일 "오늘의 복습"에 섞여 나옴. 정답/오답이 간격을 조절.
- **가치**: 사장님 핵심 페인("계속 안 외워짐")을 **정면으로** 해결. 책 한 컷·나만의 단어장의 가치를 몇 배로.
- **효): 중 / 위험: 낮음 (기존 SRS 서비스 재사용).

### A2. "어려운 단어 모음"(Leech) 자동 화면 ⭐
- 일정 횟수 이상 틀린 단어를 자동 수집 → "이 단어들만 집중" 화면. (Anki의 leech 개념)
- **가치**: "안 외워지는 단어"를 앱이 **알아서** 골라줌 → 학습 효율 직접 상승.
- 효: 중 / 위험: 낮음.

### A3. 단어장 학습 모드 확장 (Quizlet/클래스카드식)
현재 = 플립카드 + 4지선다. 추가:
- **짝 맞추기(Matching)**: 한국어↔뜻 카드 짝짓기 (제한시간) — 가볍고 중독성.
- **받아쓰기/스펠링(Tippen)**: 뜻을 보고 한국어를 **직접 타이핑** → 인출(production) 학습. 인식보다 기억에 강함.
- **사진 퀴즈**: 첨부 사진을 보고 단어 맞히기 (사진 첨부 기능 활용).
- 효: 중(각 모드 ~화면 1개) / 위험: 낮음.

### A4. 퀴즈 화면에 사진 노출 (③ 질문 답변)
- **무슨 기능?**: 지금 4지선다 퀴즈는 한국어 글자만 보여줌. 단어에 사진이 있으면 **질문 카드에 그 사진도 함께** 띄우는 것. 시각 단서가 기억을 강화(그림-단어 연합). A3의 "사진 퀴즈"와 연결.
- 효: 소 / 위험: 낮음. (A3에 포함 가능)

### A5. 단어장 정리 — 검색·정렬·폴더(태그)
- 단어 많아지면 필수: 검색, 가나다/최근/난이도 정렬, 단어장 묶음(폴더).
- 효: 중 / 위험: 낮음.

## Tier B — 중간 투자 (출시 후 1~2개월)

### B1. 듣기 받아쓰기(Dictation) 퀘스트
- 시나리오 문장을 듣고 **빈칸/전체를 타이핑**. 듣기 화면 + TTS 재사용.
- 가치: 듣기+철자 동시 훈련. 기존 자산 재활용이라 가성비 높음.

### B2. 한글 생산 모드 (타이핑/쓰기)
- 한글 화면이 지금은 획순 따라쓰기(인식). 뜻·소리를 주고 **직접 입력**하는 인출 모드 추가.
- (출시 전 deferred됐던 Hangul IoU 정확도 측정도 여기서.)

### B3. 단어장 내보내기 (CSV / Anki)
- 가져오기(CSV)는 됨 → 내보내기로 양방향. 파워유저·이탈 방지.

### B4. 책 한 컷 고도화
- 여러 장 연속 촬영(배치), OCR 결과 인라인 편집 개선, 잘못 추출된 단어 빠른 삭제.

### B5. 게이미피케이션 폴리시
- 일일 목표(개수) 설정 + 달성 링/연속, 업적 배지 확장, 주간 요약.

## Tier C — 큰 베팅 (분기 단위, 차별화)

### C1. 말하기·발음 평가 (STT) 🎤
- 사용자가 단어/문장을 **말하면** 음성인식으로 정확도 피드백. 언어앱의 핵심 차별화.
- 효: 큼 / 위험: 중(STT 정확도·비용·UX). 온디바이스 STT 또는 클라우드.

### C2. TOPIK 시험 모드
- TOPIK I/II 유형 문제(어휘·문법·읽기·듣기) + 모의고사. 한국어 학습자 강력 니즈 + 프리미엄 가치.

### C3. 계(契) 커뮤니티 (이미 v3.0 계획)
- 친구 단어장 공유는 됨 → 모임방·공동 한옥·주간 목표·스티커. (plan: stately-rising-jongga Phase 6~8)

### C4. 원어민 음성(녹음) + 홈 위젯
- TTS → 핵심 단어/시나리오 원어민 녹음으로 품질 업. 홈스크린 위젯(오늘의 단어/스트릭).

## 추천 실행 순서 (사장님 목표 정렬)

1. **A1**(커스텀/사진 단어 → 메인 SRS) — 페인 정면 해결, 기존 기능 가치 극대화
2. **A2**(어려운 단어 모음) + **A3**(짝맞추기·타이핑·사진퀴즈, A4 포함)
3. **A5**(단어장 정리) → 여기까지가 "나만의 단어장 완성형"
4. 출시·피드백 → **B1/B2**(받아쓰기·한글 타이핑) + **B5**(게이미피케이션)
5. 차별화 베팅: **C1 말하기** 또는 **C2 TOPIK** 중 택1 → **C3 커뮤니티**

> 한 줄: **A1 → A2 → A3** 만 해도 "안 외워지는 단어" 문제가 앱의 강점으로 바뀜. 사진·CSV·자동채우기로 모은 단어가 매일 복습 루프에 흐르고, 못 외운 건 앱이 골라주고, 다양한 모드로 굳히는 흐름.
