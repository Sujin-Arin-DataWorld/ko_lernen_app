1. 현재 화면 진단 측정 기반

스크린샷에서 실제 픽셀 색을 추출해 WCAG 2.1 명도대비를 계산했습니다. 체감하신 문제가 수치로 그대로 나옵니다.

현재
개편안
1
CTA가 배경에 묻힌다 치명
주 버튼 #FF9154와 페이지 배경 #F8F0E3의 대비가 1.97:1입니다. 비텍스트 UI 최소 기준 3:1에 못 미쳐, 버튼 경계가 배경에 녹아버립니다. 버튼 위 흰 글씨는 2.23:1 — 큰 글씨 기준 3:1조차 미달입니다.
해결 — 단청 적색 #9B2F26으로 교체. 배경 대비 6.42:1, 흰 글씨 7.42:1. 주황을 버리지 않고 호랑이 액센트로 옮겨 캐릭터 정체성에 씁니다.
2
카드가 배경과 같은 색이다 치명
스탯 카드·학습경로 카드·하단 내비 배경이 모두 #F2ECDC, 페이지 배경은 #F8F0E3 — 대비 1.04:1. 사실상 같은 색이라 카드라는 인지가 생기지 않고, 화면 전체가 뿌옇게 한 덩어리로 읽힙니다. "답답하다"의 실제 원인입니다.
해결 — 카드는 #FFFDF8(한지 흰색) + #8A6E45 창호 목재 테두리 1.5px. 테두리 대비 4.70:1로 경계가 분명해지고, 한옥 문살 모티프가 그대로 정체성이 됩니다.
3
같은 링크가 세 번 반복된다 치명
"Neues Pack · Begrüßung & Höflichkeit (1)" (상단) → "Jetzt lernen" (주 버튼) → "Begrüßung & Höflichkeit (1) · Jetzt" (학습경로) — 전부 같은 곳으로 갑니다. 선택지가 셋인 줄 알고 사용자가 멈칫하는데, 실은 하나입니다.
해결 — 하나의 「이어서 배우기」 카드로 통합. 레슨명 + 진행 점 + 버튼이 한 카드 안에 들어가고, 상단 중복 라인은 삭제합니다.
4
첫 사용자에게 빈 게이지 두 개를 보여준다 중간
Lv 1 · 0 XP, 일일목표 0/45 XP — 0%짜리 진행바가 나란히 둘. 게다가 트랙 #E4DDC3과 카드 대비가 1.15:1이라 보이지도 않습니다. 첫 화면이 "너는 아무것도 안 했다"로 시작합니다.
해결 — 1일차에는 게이지 대신 디딤돌 7칸(이번 주)을 놓고 오늘 칸만 밝힙니다. 데이터가 쌓인 뒤(12일차) 스트릭·레벨·목표를 한 카드로 승격시킵니다.
5
로고와 앱 이름이 겹쳐 있다 중간
까치 이미지가 "Hangeul Sori" 워드마크 위로 올라와 글자를 가립니다. 브랜드가 처음 등장하는 자리에서 이름을 읽을 수 없습니다.
해결 — 마크(창호 문양 34dp) + 워드마크를 가로로 분리. 캐릭터는 헤더에서 빼고 히어로 카드로 내려 제 역할을 하게 합니다.
6
"Willkommen zurück!" — 처음 온 사용자에게 중간
스트릭 1일, 0 XP인 신규 사용자에게 "다시 오신 걸 환영합니다"라고 인사합니다. 방금 온보딩을 마친 사람에게는 틀린 문장입니다.
해결 — 1일차 전용 인사와 캐릭터별 첫 대사를 분리. 웰컴 영상은 온보딩 직후 1회만 재생하고 그 다음부터 홈으로 직행합니다.
7
본문·라벨 글씨가 작다 경미
"Tage", "0 XP", "Lernpfad" 같은 라벨이 11~12dp로 보이고, 색 #8A7F70 기준 대비는 3.47:1로 본문 기준 4.5:1 미달입니다. 외국어 학습 앱은 읽기 부담이 곧 이탈입니다.
해결 — 캡션 하한 13dp, 본문 16dp, CTA 19dp. 보조 텍스트 색은 #6B5F51(5.37:1)로 낮춥니다.
8
내비게이션이 두 군데로 갈린다 경미
헤더의 아이콘 4개(학습그룹·프로필·통계·설정)와 하단 탭이 겹칩니다. 학습그룹·프로필은 양쪽 모두에 있습니다. 게다가 헤더 아이콘은 약 40dp로 최소 터치 타깃 48dp 미만입니다.
해결 — 헤더에는 스트릭 + 설정만. 학습그룹·프로필은 하단 탭에만 두고, 통계는 프로필 안으로 넣습니다.

왜 까치호랑이인가

까치와 호랑이는 조선 민화 까치호랑이(鵲虎圖)의 한 쌍입니다. 새해에 걸어 액운을 막고 좋은 소식을 부르던 그림이죠. 두 캐릭터가 이미 한 쌍이라는 사실이 앱 전체에 공짜로 이야기를 만들어 줍니다 — 호랑이는 밀어주고, 까치는 소식을 물어옵니다. 한옥·단청·창호와도 같은 세계관 안에 있어서 듀오링고식 무국적 초록색과 정면으로 갈라지는 지점이 여기입니다.

  • 색에만 의존하지 않기 — 마당 타일 상태는 색 + 텍스트("12 Karten fällig")를 함께 씁니다. 색약 사용자도 읽힙니다.

  • 동적 글자 크기 — 시스템 글꼴 확대 200%까지 레이아웃이 깨지지 않는지 확인. 마당 타일은 고정 높이 대신 min-height로.

  • 영상 자막 — 웰컴 영상에 독일어 자막 필수. 소리 없이 보는 사용자가 다수입니다.
