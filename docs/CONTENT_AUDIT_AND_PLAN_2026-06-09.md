## 2. 벤치마크 — 상용 기준 대비

CEFR 레벨별 **누적 어휘** 기준(유럽어 일반): A1 ≈ 500 · A2 ≈ 1,000 · B1 ≈ 2,000 · B2 ≈ 4,000개.
상용 앱(예: LingoDeer)은 A1–B1을 문법 골격 + 토픽별 어휘 + 스토리로 촘촘히 커버.

| 레벨 | 우리 어휘 | CEFR 누적 기준 | 충족률(개략) |
|---|---|---|---|
| A1 | 211 | ~500 | ~42% |
| A2 | +140 (누적 351) | ~1,000 | ~35% |
| B1 | +103 (누적 454) | ~2,000 | ~23% |
| B2 | +72 (누적 526) | ~4,000 | ~13% |

→ 어휘는 **레벨이 올라갈수록 상용 기준과의 격차가 커짐**. 문법(88)은 골격은 갖췄으나 상용 앱의 세분화된 패턴 수에는 미달.

## 3. 갭 분석 (4대 약점)

1. **어휘 영어 미지원 (🔴 최우선 차단)** — 526단어·88문법이 독일어 전용. 영어권 사용자에게 학습 콘텐츠가 사실상 비어 있음. 시나리오·스몰토크·한글만 영어 있음 → **반쪽짜리 영어 앱**.
2. **어휘 절대량 부족 (🔴)** — 특히 A2~B2. 상위 레벨 학습자는 금방 콘텐츠 고갈.
3. **콘텐츠 타입 단조 (🟡)** — 단어카드·퀴즈·시나리오·게임은 있으나 **읽기 지문, 듣기 받아쓰기, 문화 노트(독립), 발음 미니레슨** 등 "다양성"을 만드는 모드가 약함.
4. **품질·검수 체계 부재 (🟡)** — 콘텐츠 추가 시 원어민 검수·음성(TTS) 커버리지·예문 자연스러움을 보장하는 절차/스키마가 없음. (실측상 현재 데이터 품질 자체는 양호하나, "대량 확장" 시 품질 관리가 핵심 리스크)

## 4. 개선 로드맵 (우선순위별)

### P0 — 상용화 차단 해소 (이번 세션 착수)
- **P0-A. 기존 526어휘 + 88문법 영어 이중언어화.** 독일어(검수본)를 앵커로 영어 열 추가. → 전 카탈로그 즉시 영어 대응.
  - vocab CSV에 `english, pos_en, example_english` **맨 뒤 3열 추가** (인덱스 0–10 불변 → 빌드 안전).
  - grammar CSV에 `type_en, explanation_en, example_en, note_en` 추가.
- **P0-B. 코드 배선(후속).** `Vocab`/`Grammar` 모델에 영어 필드 + `locale_service` 연동으로 EN UI에서 영어 표시. (콘텐츠 준비 후 별도 코드 작업)

### P1 — 어휘·문법 양 확충 (CEFR 채우기)
- 어휘 526 → **2,000+** 단계적: A2 +400, B1 +500, B2 +600 (토픽팩 단위, 처음부터 DE+EN).
- 문법 88 → **150+**: 레벨별 누락 패턴 보강(A2/B1 연결어미·시제·인용·피동/사동 등).
- 신규 단어는 빈도순(우선 고빈도) + 토픽 균형. 처음부터 3필드(ko/de/en) 완비로 생성.

### P2 — 새 콘텐츠 타입 (다양성)
- **읽기 지문**: 레벨별 60–150자 단문 + 어휘/문법 태깅 + 이해 문제 (graded reading).
- **듣기/받아쓰기**: 기존 TTS 파이프라인 재사용, 시나리오·문장 받아쓰기 모드.
- **문화 노트(독립 카드)**: 시나리오 내장 culturalNote를 독립 학습 카드로.
- **발음 미니레슨**: 받침·연음·경음화 등 규칙별 짧은 레슨(한글 화면 확장).

### P3 — 회화·스몰토크 확장 + 품질 체계
- 시나리오 33 → **100+**, 스몰토크 145 → **400+** (토픽·레벨 균형).
- **콘텐츠 품질 게이트**: 스키마 검증 스크립트(필드 완전성·레벨 일관성·중복) + 원어민 검수 체크리스트 + TTS 사전생성 커버리지 확인.

## 6. 생성 파이프라인 (반복 가능)
1. 번역/생성은 한국어 + 검수된 독일어를 앵커로 영어 작성 (원어민 표현).
2. Python 스크립트로 **맨 뒤 열만 추가** → 기존 인덱스 불변.
3. 검증: 재파싱 후 cols 0–10 원본과 바이트 동일 + 행수·팩 분포 불변 + 영어 필드 공란 0.
4. `\n` 라인터미네이터·필요한 경우만 따옴표(쉼표 포함 예문) — Dart `csv` 패키지 호환.
