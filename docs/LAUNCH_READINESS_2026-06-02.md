## 3. 사장님이 가장 원하는 기능 "사진→단어장→저장→공유"의 진실

| 단계 | 상태 |
|---|---|
| 사진 촬영/갤러리 선택 + 자르기 | ✅ 됨 |
| OCR (기기 내, 한국어, 무료) | ✅ 됨 (ML Kit, 사진은 기기 밖으로 안 나감) |
| 단어/문법/예문 추출 + 번역(DE/EN) | ⚠️ **Cloud Function 배포 필요**. 미배포 시 "오프라인=문법 패턴 31개만" 표시, 단어 추출·번역 안 됨 |
| 단어장(내 책장) 저장 | ✅ 됨 (로컬 + Firestore 베스트에포트) |
| 나만의 연습 팩 생성·학습 | ✅ 됨 |
| **친구에게 공유** | ❌ **미구현** (v3.0 커뮤니티 기능) |

**요점**: "저장해서 내 단어장·연습문장 만들기"는 완성. 하지만 **"친구한테 공유"는 아직 존재하지 않음.** 그리고 번역·단어추출이 제대로 되려면 **Cloud Function을 반드시 배포**해야 함 (코드는 준비됨, 미배포 상태).

Cloud Function 코드: `functions/analyze_korean_text/main.py` (Python, OKT 형태소분석 + DeepL 번역 + 문법 검출). 배포 명령·DeepL 키 설정은 `docs/store/closed-testing-checklist-v2.md` §1.2 참조.

## 9. 솔직한 리스크 Top 3
1. **실기기 검증 0회** — 코드/테스트는 통과해도 실제 화면 깨짐·권한 흐름·다크모드 문제는 디바이스에서만 드러남. 내부 테스트의 첫 목적이 바로 이것.
2. **Cloud Function 미배포** — 플래그십 "사진→단어"가 반쪽 동작. 테스터가 가장 기대할 기능이라 첫인상 좌우.
3. **에셋 누락(특히 다크 한옥·책 한 컷 일러스트)** — 빌드는 되지만 "듀오링고급 생동감" 목표 대비 비주얼 완성도 갭. 출시는 가능, 폴리시는 후속.

## 10. 추천 순서 (현실적)
