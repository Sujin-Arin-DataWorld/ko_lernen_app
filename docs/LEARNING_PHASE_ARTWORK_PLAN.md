# 30 Phase 이미지 제작 주제와 공용 이미지 교체 순서

Phase 전용 30장은 현재 모두 **이미지 준비 중**이다. 앱은 DE `Bild in Vorbereitung`, EN `Image in preparation`으로 표시한다. 기존 팩 224개 중 전용 162개와 공용 62개는 정상 파일을 그대로 사용한다.

## 제작 기준

- `docs/LISTENING_CARD_RECIPE.md`의 고정 프롬프트에서 SUBJECT만 교체한다.
- 800×600 WebP, 4:3 원본 → 16:10 카드 크롭. 제목을 가린 100px 검사를 거친다.
- 주제가 드러나는 물건 2–3개를 중심으로, 크림색 여백·면 분할 민화 스타일을 유지한다. 사람·손·동물·글자·숫자·로고·방 전체 장면을 넣지 않는다.
- 문학·아이러니·대우법 등 추상 목표는 정물만으로 완전히 구분하기 어렵다. 서로 다른 핵심 물건을 사용하고 카드 제목으로 뜻을 보완한다. 제작 후 혼동되는 후보는 재작업한다.
- 우선 Phase 01–08과 교체 P1 12개(20장), 이후 Phase 09–30과 교체 P2 10개(32장)를 제작한다. 총 제안 52장. 나머지 공용 40개는 유지 후 재평가한다.

## 라이브 연결 범위

앱 진입은 `Lernpfad / Learning path → 30 Lernphasen / 30 learning phases → Phase → 관련 대화 자유 연습`이다. 현재 미션 순서와 관계없이 기존 48개 미션의 실제 시나리오를 바로 열 수 있다. A1/A2/B1/B2/C1/C2의 Phase 수는 4/4/5/5/6/6이다. 기존 미션은 원래 ID와 평가·진도 규칙을 유지한다. 현재 활성 체크포인트의 실제 수행만 기존 숙달 서비스가 판정하며, 다른 Phase를 보거나 미래 시나리오를 연습했다고 코스 순서가 바뀌지 않는다.

Phase 목표는 정본의 KO/EN/DE 문구를 그대로 투영했다. 연결된 시나리오는 관련 주제의 자유 연습이다. Phase 고유 과제는 준비 중이라고 모든 상세 화면에 명시한다. Phase 전체 목표·336개 문법·모든 읽기/쓰기 장르의 구현을 뜻하지 않는다. 특히 KP26–30의 문학·아이러니·하게체/하오체 과제를 기존 관계·미디어 시나리오와 동등하다고 표시하지 않는다. 독립 Phase 숙달 판정이나 새 자동 잠금 해제는 없다.

예전 86 Can-do 생산형 평가 게이트는 이 연결에서 사용하지 않는다. 누락된 과제를 승인된 것으로 바꾸거나 현재 시나리오를 임의로 다시 쓰지 않는다.

## 재생성·검증

`python tool/build_learning_phase_catalog.py`와 `--check`를 사용한다. Python 테스트는 정본 신선도, 실제 미션 ID·레벨, 준비 중 상태를 검증한다. Flutter 테스트는 30개 로딩, 레벨 선택, 관련 미션 이동, 잘못된 입력, 좁은 화면·큰 글씨와 그림 폴백을 검증한다.
