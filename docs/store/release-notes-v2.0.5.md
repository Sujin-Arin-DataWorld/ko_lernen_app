# Hangul Sori 2.0.5 release notes

## Deutsch

Neu in Version 2.0.5:

- Die Lernkarten wurden überarbeitet. Gesten, Kartenwechsel und das Wiederholen
  schwieriger Wörter funktionieren jetzt zuverlässiger.
- Start, Heute und Entdecken zeigen den Lernfortschritt genauer an.
- Die Darstellung auf Smartphones und Tablets wurde verbessert. Dazu kommen
  Korrekturen bei Texten, Bedienungshilfen und Stabilität.

## English

New in version 2.0.5:

- Learning cards have been reworked. Gestures, card transitions, and
  difficult-word review are now more reliable.
- Home, Today, and Discover now show learning progress more accurately.
- Layouts work better across phones and tablets, with additional fixes for
  text, accessibility, and stability.
