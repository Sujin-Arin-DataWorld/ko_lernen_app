# 구독 운영 중단 기록

Hangul Sori의 Premium 구독 판매와 앱 내 결제는 2026-09-05에 제거되었다.

- 모든 CEFR 학습 콘텐츠와 시나리오는 결제 없이 열린다.
- 책 분석은 하루 20회, 발음 평가는 하루 50회의 기존 최고 서비스 한도를 모든
  로그인 사용자에게 동일하게 적용한다.
- Android와 iOS 빌드에는 RevenueCat 공개 키를 넣지 않는다.
- `FREE_LAUNCH`, `BETA_UNLOCK_ALL`, `RC_ANDROID_KEY`, `RC_IOS_KEY` 빌드 플래그는
  접근권한이나 결제 기능을 바꾸지 않는다.
- Google Play 또는 App Store에 구독 상품을 새로 만들거나 연결하지 않는다.

서버의 과거 entitlement 문서 처리 코드는 기존 데이터 삭제와 마이그레이션 안전성을
위해 남아 있지만, 앱에는 구매·복원·paywall 진입점이 없다. 구독을 다시 도입하려면
새 제품 결정과 개인정보·스토어 정책 검토를 거쳐 별도 기능으로 설계해야 한다.
